# AWS DataSync Cheat Sheet

**AWS DataSync** เป็นบริการถ่ายโอนข้อมูลออนไลน์ที่ช่วยลดความยุ่งยาก ปรับการทำงานให้เป็นอัตโนมัติ และเร่งการคัดลอกข้อมูลจำนวนมหาศาลไปและกลับจาก **บริการจัดเก็บข้อมูลของ AWS** ผ่านอินเทอร์เน็ตหรือ **AWS Direct Connect**

**DataSync สามารถคัดลอกข้อมูลระหว่าง:**
* Network File System (NFS), Server Message Block (SMB), และ Hadoop Distributed File Systems (HDFS)
* Object storage (แบบติดตั้งในศูนย์ข้อมูล หรือทั่วไป)
* Amazon S3 buckets
* Amazon Elastic File System (Amazon EFS)
* Amazon FSx สำหรับ Windows File Server
* Microsoft Azure (Blob Storage และ Files) และ Google Cloud Storage

---

## รูปแบบการทำงาน (How It Works)
1. **ติดตั้ง Agent:** ติดตั้ง DataSync Agent ในสภาพแวดล้อมของคุณและเชื่อมโยงกับบัญชี AWS เพื่อเข้าถึงเซิร์ฟเวอร์ไฟล์ (NFS/SMB)
2. **สร้าง Task:** กำหนดต้นทาง (Source), ปลายทาง (Destination) และตั้งค่าการโอนย้าย เช่น ตารางเวลา (Schedule)
3. **เริ่มการถ่ายโอน:** เริ่มงานและตรวจสอบความเคลื่อนไหวผ่านคอนโซลหรือ Amazon CloudWatch

---

## แนวคิดหลัก (Concepts)
* **Agent:** Virtual Machine ที่ใช้สำหรับอ่านหรือเขียนข้อมูลในพื้นที่ On-premises
* **Location:** จุดต้นทางหรือปลายทางที่ใช้ในการถ่ายโอนข้อมูล
* **Task:** ชุดคำสั่งที่ประกอบด้วย 2 Location (ต้นทาง-ปลายทาง) และการตั้งค่าวิธีการโอนย้าย
* **Task execution:** การรันงานในแต่ละครั้ง ซึ่งจะมีสถานะต่างๆ เช่น `TRANSFERRING` (กำลังถ่ายโอน) และ `VERIFYING` (กำลังตรวจสอบ)

---

## คุณสมบัติเด่น (Features)
* **โปรโตคอลความเร็วสูง:** ใช้โปรโตคอลที่ AWS ออกแบบมาเฉพาะเพื่อเร่งความเร็วในการเคลื่อนย้ายข้อมูล
* **ประสิทธิภาพ:** Agent ตัวเดียวสามารถใช้งานแบนด์วิดท์เครือข่ายได้เต็มที่ถึง 10 Gbps
* **ความปลอดภัย:** ข้อมูลถูกเข้ารหัสระหว่างรับ-ส่งด้วย TLS และรองรับการเข้ารหัสข้อมูลที่จัดเก็บ (At rest) ของ S3 และ EFS
* **ความถูกต้องของข้อมูล:** ทำการตรวจสอบความครบถ้วน (Integrity checks) ทั้งระหว่างทางและเมื่อถึงปลายทาง
* **โหมดการโอนย้าย:**
    * **Basic Mode:** โหมดมาตรฐาน (จำกัดที่ 50 ล้านไฟล์)
    * **Enhanced Mode:** ออกแบบมาเพื่อ S3 ไป S3 โดยเฉพาะ ให้ประสิทธิภาพสูงกว่าและไม่จำกัดจำนวนไฟล์
* **VPC Endpoints:** รองรับ AWS PrivateLink เพื่อรับส่งไฟล์ผ่านเครือข่ายส่วนตัว (VPC)
* **IPv6 Support:** รองรับการเชื่อมต่อ Agent และการโอนข้อมูลผ่าน IPv6

---

## กรณีการใช้งาน (Use Cases)
* **การย้ายข้อมูล:** ย้ายไฟล์ไปยัง S3, EFS หรือ FSx
* **ประมวลผลข้อมูลแบบ Hybrid:** รับส่งข้อมูลเข้า-ออก AWS เพื่อนำไปประมวลผลต่อตามตารางเวลาที่กำหนด
* **การเก็บข้อมูลถาวร (Archiving):** ย้าย "Cold data" จากระบบจัดเก็บราคาแพงในเครื่องไปยัง S3 Glacier หรือ Deep Archive
* **การป้องกันข้อมูล:** สำรองข้อมูลจากระบบ NAS ไปยัง S3

---

## การเปรียบเทียบกับบริการอื่น
* **vs AWS CLI:** DataSync เร็วกว่าเครื่องมือ Command line ถึง 10 เท่า และมีการจัดการอัตโนมัติ เช่น การรันซ้ำเมื่อพลาด (Retry) และการตั้งตารางเวลา
* **vs Snowball:** DataSync เหมาะสำหรับการโอนย้ายออนไลน์ (มีอินเทอร์เน็ต) ส่วน Snowball เหมาะสำหรับการโอนย้ายออฟไลน์ในที่ที่แบนด์วิดท์จำกัด
* **vs File Gateway:** ใช้ DataSync เพื่อย้ายข้อมูลก้อนใหญ่มายัง S3 ก่อน แล้วจึงใช้ File Gateway เพื่อให้แอปพลิเคชันในเครื่องเข้าถึงไฟล์เหล่านั้นได้ต่อเนื่อง

---

## ค่าบริการ (Pricing)
* **คิดตามปริมาณข้อมูล:** จ่ายตามจำนวน Gigabyte ที่คัดลอกจริง (Flat fee)
* **ค่าบริการอื่นๆ:** จะมีค่าบริการมาตรฐานของบริการที่เกี่ยวข้อง เช่น ค่า Request/Storage ของ S3, ค่า Data Transfer Out (ถ้าโอนออกจาก AWS), และค่าบริการ CloudWatch Logs/Metrics
* **VPC Endpoints:** หากใช้ PrivateLink จะมีการคิดค่าบริการ Interface VPC endpoint ตามปกติ

---

## ข้อจำกัด (Limits)
* **จำนวน Task:** สูงสุด 100 tasks ต่อหนึ่งภูมิภาค (ต่อบัญชี)
* **จำนวนไฟล์ต่อ Task:** 50 ล้านไฟล์สำหรับโหมด Basic (โหมด Enhanced ไม่จำกัด)
* **ทรูพุตสูงสุด:** 10 Gbps ต่อหนึ่ง Task
