# AWS Transfer Family Cheat Sheet

**AWS Transfer Family** เป็นบริการรับส่งไฟล์ที่ปลอดภัยเพื่อย้ายไฟล์เข้าและออกจากบริการจัดเก็บข้อมูลของ AWS เช่น **Amazon S3** และ **Amazon EFS**
* คุณไม่จำเป็นต้องรันหรือดูแลโครงสร้างพื้นฐานเซิร์ฟเวอร์ด้วยตนเอง
* สามารถจัดสรรเซิร์ฟเวอร์ Transfer Family ที่รองรับได้หลายโปรโตคอล (SFTP, FTPS, FTP) พร้อมกัน

---

## ประโยชน์ (Benefits)
* เป็นบริการแบบ Managed เต็มรูปแบบและปรับขนาด (Scale) ได้แบบเรียลไทม์
* ไม่ต้องแก้ไขแอปพลิเคชันหรือดูแลโครงสร้างพื้นฐานของโปรโตคอลรับส่งไฟล์เอง
* รองรับสูงสุด 3 Availability Zones พร้อมระบบ Auto Scaling และการทำงานแบบ Redundant
* เชื่อมต่อกับ S3 และ EFS เพื่อใช้ประโยชน์จากฟีเจอร์ต่างๆ ของบริการเหล่านั้นได้โดยตรง

---

## คุณสมบัติพิเศษ
* **Managed File Transfer Workflows (MFTW):** บริการจัดการเวิร์กโฟลว์ไฟล์แบบ Serverless เพื่อประมวลผลไฟล์ที่อัปโหลดโดยอัตโนมัติ
* **Web Apps:** อินเทอร์เฟซบนเบราว์เซอร์ที่ใช้งานง่ายสำหรับผู้ใช้ทั่วไปเพื่ออัปโหลดและดาวน์โหลดไฟล์
* **SFTP Connectors:** ช่วยให้โอนย้ายไฟล์ระหว่าง Amazon S3 และเซิร์ฟเวอร์ SFTP ภายนอกได้อย่างปลอดภัย (รองรับการ Upload, Download, List, Delete, Rename, และ Move)

---

## ประเภทของ Server Endpoint
1.  **Publicly accessible:** เข้าถึงได้ผ่านอินเทอร์เน็ตสาธารณะ (รองรับ IPv6 สำหรับ SFTP)
2.  **VPC hosted:** เข้าถึงได้เฉพาะภายใน VPC (หรือผ่าน VPN/Direct Connect)
    * สามารถตั้งค่าให้เป็นแบบ **Internet Facing** ได้ (รองรับเฉพาะ SFTP และ FTPS)
    * **Web Apps** รองรับ VPC hosted สำหรับการเข้าถึงแบบส่วนตัว

---

## การจัดการผู้ใช้และการเข้าถึง
* **Hostname:** สามารถใช้ Custom Domain และจัดการผ่าน **Amazon Route 53** หรือ DNS อื่นๆ ได้
* **แหล่งเก็บข้อมูลผู้ใช้ (Identity Providers):**
    * **Service managed:** ใช้ SSH keys (ผู้ใช้ต้องมีชื่อไม่ซ้ำกันในเซิร์ฟเวอร์)
    * **AWS Managed Microsoft AD:** (ไม่รองรับ Simple AD)
    * **Custom Identity Provider:** ใช้ **API Gateway** หรือ **AWS Lambda** เพื่อเชื่อมต่อกับระบบเก็บรายชื่อผู้ใช้ภายนอก
* **Home Directory:** คือจุดลงจอดใน S3 bucket หรือ EFS filesystem สามารถใช้ **Logical directories** เพื่อสร้างโครงสร้างโฟลเดอร์เสมือน (Virtual) เพื่อซ่อนชื่อ Bucket หรือพาธจริงจากผู้ใช้ได้

## การเปรียบเทียบการจัดการ Access
| ฟีเจอร์ | Amazon S3 | Amazon EFS |
| :--- | :---: | :---: |
| รองรับ Session Policies | ใช่ | ไม่ใช่ |
| รองรับ POSIX (User/Group ID) | ไม่ใช่ | ใช่ |
| รองรับ Logical directories | ใช่ | ใช่ |

## โปรโตคอลที่รองรับ
* **SFTP (Secure Shell File Transfer Protocol):** รับส่งไฟล์ผ่าน SSH (พอร์ต 22) เป็นโปรโตคอลสมัยใหม่ที่ใช้ช่องทางเดียวสำหรับทั้งคำสั่งและข้อมูล
* **FTPS (File Transfer Protocol Secure):** รับส่งไฟล์พร้อมการเข้ารหัส TLS (พอร์ต 21 สำหรับเชื่อมต่อ, 8192–8200 สำหรับข้อมูล) ต้องใช้ใบรับรองจาก **AWS Certificate Manager (ACM)**
* **FTP (File Transfer Protocol):** การรับส่งไฟล์แบบไม่เข้ารหัส **รองรับเฉพาะภายใน VPC เท่านั้น** (ห้ามเปิดสู่สาธารณะ)
* **AS2 (Applicability Statement 2):** มาตรฐานสำหรับการแลกเปลี่ยนข้อมูล B2B ที่ปลอดภัย (EDI) มักใช้ในงานโลจิสติกส์และสาธารณสุข

---

## ค่าบริการ (Pricing)
* **ค่าบริการรายชั่วโมง:** คิดตามโปรโตคอลที่เปิดใช้งาน (SFTP, FTPS, FTP, AS2) และค่า Web app endpoint
* **ค่าปริมาณข้อมูล:** คิดตามปริมาณข้อมูลที่อัปโหลดและดาวน์โหลด
* **Managed Workflows:** ไม่มีค่าใช้จ่ายเพิ่มเติมในการใช้งาน
