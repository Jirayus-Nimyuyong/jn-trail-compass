# Migration Evaluator Cheat Sheet

**Migration Evaluator** เป็นบริการที่ช่วยให้องค์กรประเมินโครงสร้างพื้นฐาน On-premises และวางแผนการย้ายระบบไปยัง AWS โดยจะให้ข้อมูลเชิงลึกเกี่ยวกับต้นทุนในการรันเวิร์กโหลดบน AWS และแนะนำทรัพยากรที่เหมาะสมที่สุดตามรูปแบบการใช้งานจริง

---

## กรณีการใช้งาน (Use Cases)
* **การสำรวจข้อมูล (Discovery):** ใช้ Agentless Collector เพื่อสำรวจโครงสร้างพื้นฐานในวงกว้าง หรืออัปโหลดข้อมูลที่มีอยู่เดิมอย่างปลอดภัยเพื่อนำมาวิเคราะห์
* **การปรับแต่งให้เหมาะสม (Optimization):** บันทึกภาพรวมของสภาพแวดล้อม On-premises ปัจจุบัน เพื่อปรับปรุงการใช้ไลเซนส์ซอฟต์แวร์, ทำแผนผังความสัมพันธ์ของเซิร์ฟเวอร์ (Dependency Mapping) และสำรวจกลยุทธ์การย้ายระบบต่างๆ
* **การวางแผน (Planning):** ประเมินสถานะปัจจุบัน กำหนดเป้าหมายบน AWS และสร้างแผนความพร้อมในการย้ายระบบพร้อมการคาดการณ์ต้นทุนคลาวด์ที่แม่นยำ

---

## คุณสมบัติเด่น (Features)

### 1. การสำรวจทรัพยากร (Inventory Discovery)
* รวบรวมข้อมูลทรัพยากร On-premises อัตโนมัติ เช่น เซิร์ฟเวอร์, VM, ฐานข้อมูล ฯลฯ
* ใช้เครื่องมือรวบรวมข้อมูลแบบ **Agentless** (ไม่ติดตั้งเอเย่นต์) ซึ่งเป็นการเข้าถึงแบบอ่านอย่างเดียว (Read-only) จึงไม่ขัดจังหวะการทำงานของระบบเดิม
* รองรับสภาพแวดล้อมทั้ง **VMware, Hyper-V และ Bare Metal** รวมถึงระบบปฏิบัติการ Windows, Linux, Active Directory และ SQL Server

### 2. ข้อมูลเชิงลึกฉบับย่อ (Quick Insights)
* **สรุปหน้าเดียว:** สำหรับผู้บริหาร เพื่อแสดงการประหยัดต้นทุนที่คาดการณ์ไว้
* **แยกรายละเอียดต้นทุน:** แบ่งตามโครงสร้างพื้นฐานและไลเซนส์ซอฟต์แวร์
* **คำแนะนำทางเทคนิค:** แนะนำการย้ายแบบ Re-host ไปยัง **Amazon EC2** และ **Amazon EBS** โดยอ้างอิงจากข้อมูลการใช้งานจริงในปัจจุบัน

### 3. การประเมินพื้นที่จัดเก็บข้อมูล (Storage Assessment)
* **Storage Insights:** ระบุเวิร์กโหลดที่ใช้พื้นที่เก็บข้อมูลสูง (เช่น File server หรือ Backup server) และเสนอโอกาสในการลดต้นทุน
* **คำแนะนำเฉพาะทาง:** แนะนำบริการจัดเก็บข้อมูลที่ตรงจุด เช่น **Amazon FSx** หรือ **Amazon S3** แทนที่จะใช้แค่ EC2/EBS เพียงอย่างเดียว

### 4. การทำแผนผังความสัมพันธ์ (Server Dependency Mapping)
ทำงานร่วมกับ **AWS Migration Hub** เพื่อรวบรวมการเชื่อมต่อ TCP ทำให้สามารถ:
* มองเห็นภาพความเชื่อมโยงระหว่างเซิร์ฟเวอร์ (Server-to-server dependencies)
* จัดกลุ่มเซิร์ฟเวอร์ตามแอปพลิเคชันเชิงตรรกะ
* ระบุกลุ่มเซิร์ฟเวอร์ที่เหมาะสมที่สุดสำหรับการย้ายในระลอกแรก (First wave)

## กรณีทางธุรกิจ (Migration Evaluator Business Case)
หลังจากได้รับ Quick Insights แล้ว องค์กรสามารถขอรับ **Business Case** แบบเต็มรูปแบบ ซึ่งจะมีทีมสถาปนิกโซลูชัน (Solution Architects) ของ AWS มาช่วยวิเคราะห์ข้อมูลเชิงลึก 6 ส่วนดังนี้:

1.  **Analysis and Insights:** ภาพรวมของกลยุทธ์การเก็บข้อมูล สมมติฐาน ขอบเขต และกรอบเวลาการประเมิน
2.  **Financial Summary:** สถานการณ์จำลองแบบ ‘what-if’ เพื่อเปรียบเทียบทางเลือกในการซื้อทรัพยากร
3.  **Business Value:** ไฮไลต์คุณค่าด้านผลิตภาพพนักงาน ความทนทานในการดำเนินงาน และการประเมินด้านความยั่งยืน (การลดการปล่อยคาร์บอน)
4.  **Deployment Summary & Licensing:** ข้อมูลเชิงลึกเกี่ยวกับไลเซนส์ SQL Server และ Windows Server เปรียบเทียบรุ่น BYOL (นำไลเซนส์มาเอง) และแบบรวมไลเซนส์ (LI)
5.  **Storage Assessment:** แผนผังการจับคู่ข้อมูลกับบริการพื้นที่จัดเก็บของ AWS พร้อมการคาดการณ์ต้นทุน
6.  **Next Steps:** คำแนะนำขั้นตอนต่อไปเพื่อให้การย้ายระบบประสบความสำเร็จ

---

## ค่าบริการ (Pricing)
**Migration Evaluator เป็นบริการฟรีของ AWS** ไม่มีค่าใช้จ่ายในการใช้เครื่องมือ การสร้างรายงาน หรือการปรึกษากับสถาปนิกโซลูชันของ AWS คุณจะเสียค่าใช้จ่ายก็ต่อเมื่อมีการเริ่มใช้งานทรัพยากรบน AWS จริงในระหว่างหรือหลังการย้ายระบบเท่านั้น
