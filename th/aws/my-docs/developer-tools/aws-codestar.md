# AWS CodeStar Cheat Sheet

**AWS CodeStar** เป็นบริการพัฒนาซอฟต์แวร์บนคลาวด์ที่รวบรวมเครื่องมือที่จำเป็นสำหรับการพัฒนา, สร้าง (Build) และติดตั้ง (Deploy) แอปพลิเคชันบน AWS ได้อย่างรวดเร็ว
* มักใช้ร่วมกับ CodeCommit, CodeBuild, CodeDeploy และ CodePipeline เพื่อสร้าง CI/CD Toolchain ที่สมบูรณ์

### คุณสมบัติเด่น (Features)
* **Project Management Dashboard:** มีแดชบอร์ดจัดการโปรเจกต์ รวมถึงความสามารถในการติดตามปัญหา (Issue Tracking) โดยใช้ซอฟต์แวร์ Atlassian JIRA
* **Unified Interface:** หน้าจอเดียวที่ใช้ติดตามกิจกรรมของแอปพลิเคชันและความคืบหน้าในทุกขั้นตอน ตั้งแต่การ Commit โค้ด, การ Build, การทดสอบ ไปจนถึงการ Deploy
* **Project Templates:** มีเทมเพลตหลากหลายสำหรับรันบนแพลตฟอร์มที่ต่างกัน (EC2, Lambda, Elastic Beanstalk) เช่น:
    * **Web service:** สำหรับงานเบื้องหลังหรือการเรียก API
    * **Web application:** สำหรับงานที่มีหน้าจอผู้ใช้ (UI)
    * **Static web page:** สำหรับเว็บไซต์ HTML
    * **Alexa skill:** สำหรับโปรเจกต์ Alexa ที่รันบน Lambda
    * **Config rule:** สำหรับจัดการกฎอัตโนมัติของ AWS Config
* **ภาษาที่รองรับ:** Java, JavaScript, PHP, Ruby, Python และ ASP.NET
* **ประกาศสำคัญ:**
    * บริการเดิมที่ชื่อ CodeStar Connections เปลี่ยนชื่อเป็น **AWS CodeConnections** (มีผลตั้งแต่วันที่ 29 มีนาคม 2024)
    * หลังจากวันที่ **31 กรกฎาคม 2024** จะไม่รองรับการสร้างโปรเจกต์ใหม่ผ่านกระบวนการเดิมของ CodeStar อีกต่อไป แนะนำให้เปลี่ยนไปใช้เครื่องมือเวอร์ชันใหม่แทน

### ความปลอดภัย (Security)
* ใช้ **AWS IAM** ในการจัดการตัวตนของนักพัฒนา และมีนโยบายความปลอดภัยตามบทบาท (Role-based) ในตัว
* **การเข้ารหัส:** ข้อมูลที่จัดเก็บ (At rest) จะถูกเข้ารหัสโดยอัตโนมัติ (ยกเว้น Project ID)
* **บทบาทใน CodeStar (Roles):**
    * **Owner (เจ้าของ):** เพิ่ม/ลบสมาชิก, แก้ไขแดชบอร์ด และลบโปรเจกต์ได้
    * **Contributor (ผู้ร่วมงาน):** แก้ไขแดชบอร์ดและส่งโค้ดได้ (ถ้าเก็บใน CodeCommit) แต่เพิ่ม/ลบสมาชิกหรือลบโปรเจกต์ไม่ได้
    * **Viewer (ผู้เข้าชม):** ดูแดชบอร์ดและโค้ดได้ แต่ไม่สามารถแก้ไขหรือเคลื่อนย้ายส่วนประกอบใดๆ บนแดชบอร์ดได้

---

### การทำงานกับโปรเจกต์ (Working With Projects)
* สามารถสร้างโปรเจกต์ผ่านคอนโซลโดยใช้เทมเพลต หรือใช้ AWS CLI พร้อมเทมเพลต Toolchain ของคุณเอง
* **IDEs ที่รองรับ:** AWS Cloud9, Eclipse และ Visual Studio

---

### ค่าบริการ (Pricing)
* **ไม่มีค่าธรรมเนียมเพิ่มเติม** สำหรับการใช้ AWS CodeStar คุณจ่ายเพียงแค่ค่าทรัพยากร AWS อื่นๆ (เช่น EC2, S3) ที่ถูกสร้างขึ้นภายใต้โปรเจกต์ CodeStar ของคุณเท่านั้น
