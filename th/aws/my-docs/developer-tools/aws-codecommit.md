# AWS CodeCommit Cheat Sheet

**AWS CodeCommit** เป็นบริการควบคุมเวอร์ชันซอร์สโค้ด (Source Control) แบบ Managed เต็มรูปแบบที่ให้บริการพื้นที่เก็บข้อมูล (Repository) บนพื้นฐานของ Git ที่มีความปลอดภัยสูง คล้ายกับ GitHub

* **สถานะปัจจุบัน:** บริการนี้ **ไม่เปิดให้บริการสำหรับลูกค้าใหม่แล้ว** ลูกค้าเดิมยังคงสามารถใช้งานต่อไปได้
* **คำแนะนำ:** มีคำแนะนำให้ **ประเมินการพึ่งพา CodeCommit** และพิจารณาย้ายไปยังแพลตฟอร์ม Git อื่นๆ หากต้องการชุดฟีเจอร์ที่รองรับอนาคต
* ใช้สำหรับจัดเก็บและจัดการเวอร์ชันของไฟล์ทุกประเภท รวมถึง Assets ของแอปพลิเคชัน เช่น รูปภาพและไลบรารี

### แนวคิดหลัก (Concepts)
* **Active User (ผู้ใช้ที่มีการเคลื่อนไหว):** ตัวตน AWS (User/Role/Root) ที่เข้าถึง Repository ในเดือนนั้นๆ (รวมถึงการเข้าถึงผ่าน CodeBuild/CodePipeline หรือ Server ด้วย)
* **Repository:** วัตถุพื้นฐานในการควบคุมเวอร์ชัน เป็นที่เก็บโค้ดและประวัติโครงการทั้งหมดอย่างปลอดภัย
* **Pull Request:** กลไกที่ช่วยให้ผู้ใช้ตรวจสอบ แสดงความคิดเห็น และรวมโค้ด (Merge) จากกิ่ง (Branch) หนึ่งไปยังอีกกิ่งหนึ่ง
* **Approval Rule:** กฎที่กำหนดจำนวนผู้ใช้ที่ต้องอนุมัติ Pull Request ก่อนที่จะทำการ Merge ได้
* **Commit:** ภาพถ่าย (Snapshot) ของเนื้อหาและการเปลี่ยนแปลงใน Repository ณ ช่วงเวลาหนึ่ง
* **Branch:** ตัวชี้ไปยัง Commit ช่วยให้แยกการทำงานในฟีเจอร์ใหม่ๆ ได้โดยไม่กระทบต่อสายหลัก

---

### คุณสมบัติของ Repository และไฟล์
* **การเชื่อมต่อ:** ใช้คำสั่ง `git clone` เพื่อคัดลอก Repo ลงเครื่อง, `git push` เพื่อส่งข้อมูลขึ้น และ `git pull` เพื่อดึงข้อมูลลงมา
* **Triggers:** สร้างได้สูงสุด 10 รายการต่อ Repository เพื่อส่งการแจ้งเตือนไปยัง **Amazon SNS** หรือเรียกใช้งาน **AWS Lambda** เมื่อมีการ Push โค้ดหรือเกิดเหตุการณ์อื่นๆ
* **การจัดการไฟล์:** สามารถจัดโครงสร้างไฟล์เป็นไดเรกทอรี และระบบจะติดตามทุกการเปลี่ยนแปลงโดยอัตโนมัติ

### Pull Requests (การขอรวมโค้ด)
* ต้องมี 2 Branch: **Source branch** (โค้ดที่ต้องการให้ตรวจ) และ **Destination branch** (ที่ที่ต้องการนำโค้ดไปรวม)
* ช่วยรักษาคุณภาพโค้ดผ่านการรีวิวและกฎการอนุมัติ (Approval rules)
* สามารถแก้ไขความขัดแย้งของโค้ด (Merge conflicts) ผ่าน Console หรือเครื่องมือ Diff ก่อนทำการ Merge

### ความพร้อมใช้งานสูงและความปลอดภัย (HA & Security)
* **ความทนทาน:** CodeCommit เก็บข้อมูล Repository ไว้ใน **Amazon S3** และ **Amazon DynamoDB**
* **การส่งผ่านข้อมูล:** รองรับการรับส่งผ่าน **HTTPS** (ใช้ User/Pass แบบ Static) และ **SSH** (ใช้ Public/Private Keys)
* **การเข้ารหัส:** ข้อมูลที่จัดเก็บ (At rest) จะถูกเข้ารหัสอัตโนมัติผ่าน **AWS KMS** โดยใช้คีย์เฉพาะของลูกค้า
* **การเข้าถึงชั่วคราว:** รองรับการให้สิทธิ์ชั่วคราวผ่าน SAML, Federation, Cross-Account หรือ Amazon Cognito

### การตรวจสอบและการแจ้งเตือน (Monitoring)
* ใช้ **AWS IAM** เพื่อควบคุมว่าใคร เข้าถึงอะไร เมื่อไหร่ และอย่างไร
* บันทึกประวัติการใช้งานผ่าน **AWS CloudTrail** และดูสถานะผ่าน **AWS CloudWatch**
* รับการแจ้งเตือนเหตุการณ์สำคัญผ่าน **Amazon SNS**

---

### ค่าบริการ (Pricing)
* **ฟรีสำหรับ 5 Active Users แรกต่อเดือน:** ได้ Repository ไม่จำกัด, พื้นที่เก็บข้อมูล 50 GB/เดือน และ 10,000 Git requests/เดือน
* **ส่วนที่เกิน:** คิดค่าบริการต่อ Active User ที่เกินมา โดยจะได้รับพื้นที่เพิ่ม 10 GB และ 2,000 Git requests ต่อคน
* *Git request* รวมทุกการ Push/Pull หรือการแก้ไขผ่าน Console/API

### ขีดจำกัด (Limits)
* ค่าเริ่มต้นที่ 1,000 Repositories (ขอเพิ่มได้)
* ไฟล์เดียว (Single blob) ขนาดไม่เกิน **2 GB**
* ขนาดไฟล์รวมในหนึ่ง Commit ไม่เกิน **20 MB**
* ขนาดไฟล์แต่ละไฟล์ไม่ควรเกิน **6 MB**
