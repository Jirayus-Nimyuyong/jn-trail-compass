# AWS Fargate Cheat Sheet

**AWS Fargate** เป็นเอนจินการประมวลผลแบบ Serverless สำหรับคอนเทนเนอร์ ที่ทำงานร่วมกับทั้ง **Amazon Elastic Container Service (ECS)** และ **Amazon Elastic Kubernetes Service (EKS)**
* ช่วยขจัดความจำเป็นในการจัดเตรียม (Provision), กำหนดค่า (Configure) และการสเกลคลัสเตอร์ของ Virtual Machines เพื่อรันคอนเทนเนอร์ คุณเพียงแค่กำหนดความต้องการของแอปพลิเคชัน (CPU, หน่วยความจำ) และ Fargate จะทำหน้าที่จัดการโครงสร้างพื้นฐานเบื้องหลังให้ทั้งหมด

---

## รูปแบบการทำงาน (How It Works)
* **กรณีการใช้งาน (Use Case):** การเปิดใช้งานคอนเทนเนอร์โดยไม่ต้องจัดเตรียมหรือจัดการอินสแตนซ์ EC2
* **การจัดการ:** เหมาะสำหรับผู้ที่ต้องการบริการ Managed Service ในการจัดการคอนเทนเนอร์คลัสเตอร์

---

## การตั้งค่า (Configurations)
* **ทรัพยากร:** สำหรับ ECS Task Definitions ที่ใช้ Fargate คุณต้องระบุจำนวน CPU และหน่วยความจำในระดับ Task
* **ระบบปฏิบัติการและสถาปัตยกรรม:** รองรับ Linux (X86_64 และ ARM64/Graviton2) และ Windows Server (X86_64)
* **การจำกัดทรัพยากร:** รองรับพารามิเตอร์ `ulimits` เพื่อกำหนดขีดจำกัดทรัพยากรสำหรับคอนเทนเนอร์
* **การบันทึกข้อมูล (Logging):** รองรับ Log Drivers ได้แก่ `awslogs`, `splunk`, `firelens` และ `fluentd`

### พื้นที่เก็บข้อมูล (Storage)
* **พื้นที่เก็บข้อมูลชั่วคราวเริ่มต้น (Default Ephemeral Storage):** แต่ละ Fargate Task จะได้รับพื้นที่เก็บข้อมูลชั่วคราวฟรี **20 GiB** (ใช้รวมกันสำหรับอิมเมจ, ล็อก และพื้นที่ทำงานชั่วคราว)
* **พื้นที่เก็บข้อมูลที่กำหนดเองได้ (Configurable Storage):** คุณสามารถเพิ่มพื้นที่เก็บข้อมูลชั่วคราวได้สูงสุดถึง **200 GiB** สำหรับงานที่ต้องประมวลผลข้อมูลจำนวนมาก
* **พื้นที่เก็บข้อมูลแบบถาวร (Persistent Storage):** Fargate Task สามารถเมานต์ (Mount) ระบบไฟล์ **Amazon EFS** เพื่อใช้พื้นที่เก็บข้อมูลร่วมกันแบบถาวรได้

---

## การอัปเดตและการทำงานร่วมกัน (Updates & Execution)
* **การอัปเดต:** หากคุณต้องการอัปเดต Platform Version ของบริการที่กำลังรันอยู่ คุณสามารถอัปเดตบริการ ระบุเวอร์ชันใหม่ และเลือก "Force new deployment" เพื่อให้ Task ถูกสร้างใหม่ด้วยเวอร์ชันล่าสุด
* **Amazon ECS Exec:** เป็นวิธีที่ช่วยให้ลูกค้าสามารถรันคำสั่งภายในคอนเทนเนอร์ที่รันบน EC2 หรือ Fargate ได้ โดยให้การเข้าถึงแบบ Interactive Shell หรือรันคำสั่งเดียวไปยังคอนเทนเนอร์ที่กำลังทำงานอยู่

---

## เครือข่าย AWS Fargate (AWS Fargate Network)
* การกำหนดค่าเครือข่ายสำหรับ Fargate **ต้องตั้งค่า Network Mode เป็น `awsvpc` เท่านั้น**
* โหมด `awsvpc` จะมอบ Elastic Network Interface (ENI) และ Private IP Address ของตัวเองให้กับแต่ละ Task

---

## การปฏิบัติตามข้อกำหนด (AWS Fargate Compliance)
* รองรับมาตรฐานระดับสากล เช่น PCI DSS Level 1, ISO 9001, ISO 27001, ISO 27017, ISO 27018, SOC 1, SOC 2, SOC 3 และ HIPAA

---

## ค่าบริการ (AWS Fargate Pricing)
คุณจ่ายตามจำนวนทรัพยากร vCPU และหน่วยความจำที่แอปพลิเคชันของคุณเรียกใช้
* **ความละเอียดในการเรียกเก็บเงิน:** คำนวณเป็นรายวินาที (ขั้นต่ำ 1 นาที) เริ่มตั้งแต่การดึง Container Image จนถึง Task สิ้นสุดการทำงาน
* **ปัจจัยด้านราคา:** อัตราค่าบริการจะแตกต่างกันไปตามระบบปฏิบัติการ (Linux vs. Windows) และสถาปัตยกรรม CPU (x86 vs. ARM/Graviton)
* **ค่าพื้นที่เก็บข้อมูล:** ฟรี 20 GiB แรก และจะจ่ายเพิ่มเฉพาะส่วนที่กำหนดค่าเกินกว่าจำนวนเริ่มต้นนี้เท่านั้น
* **วิธีประหยัดค่าใช้จ่าย:**
    * **Fargate Spot:** ให้ส่วนลดสูงมากสำหรับงานที่ทนทานต่อความผิดพลาด (Fault-tolerant) โดยใช้ทรัพยากรส่วนเกินของ AWS
    * **Compute Savings Plans:** ให้ราคาที่ถูกลงแลกกับการทำข้อตกลงใช้งานในปริมาณที่คงที่ (เช่น ระยะเวลา 1 หรือ 3 ปี)
