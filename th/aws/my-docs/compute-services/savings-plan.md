# AWS Savings Plan Cheat Sheet

**Savings Plan** เป็นรูปแบบการคิดราคาที่มีความยืดหยุ่น ซึ่งช่วยให้คุณประหยัดค่าใช้จ่ายในการใช้งาน Amazon EC2, AWS Fargate และ AWS Lambda
* คุณสามารถซื้อ Savings Plans ได้จากบัญชีใดก็ได้ ไม่ว่าจะเป็นบัญชีหลัก (Payer) หรือบัญชีที่เชื่อมโยง (Linked account)
* โดยค่าเริ่มต้น สิทธิประโยชน์จาก Savings Plans จะมีผลกับการใช้งานในทุกบัญชีภายใต้ AWS Organization หรือครอบครัวการเรียกเก็บเงินรวม (Consolidated billing) นอกจากนี้คุณยังสามารถเลือกจำกัดสิทธิประโยชน์ให้ใช้ได้เฉพาะบัญชีที่ซื้อแผนนั้นๆ เท่านั้นก็ได้
* เช่นเดียวกับ Reserved Instances (RI) คุณมีตัวเลือกการชำระเงินแบบ จ่ายล่วงหน้าทั้งหมด (All Upfront), จ่ายล่วงหน้าบางส่วน (Partial upfront) หรือ ไม่ต้องจ่ายล่วงหน้า (No upfront)

## ประเภทของแผน (Plan Types)

**1. Compute Savings Plans**
* ให้ความยืดหยุ่นสูงสุดและมอบส่วนลดสูงสุดถึง 66% จากราคาแบบ On-Demand
* แผนนี้จะใช้กับปริมาณการใช้งาน EC2 โดยอัตโนมัติ โดย**ไม่เกรงกลัวต่อตระกูลอินสแตนซ์** (เช่น M5, C5), **ขนาดอินสแตนซ์** (เช่น c5.large, c5.xlarge), **ภูมิภาค** (เช่น us-east-1, us-east-2), **ระบบปฏิบัติการ** (เช่น Windows, Linux) หรือ **Tenancy** (Shared, Dedicated, Dedicated Host)
* แผนนี้ยังมีผลครอบคลุมไปถึงการใช้งาน **Fargate** และ **Lambda** ด้วย
* คุณสามารถย้าย Workload ระหว่างตระกูลอินสแตนซ์ที่ต่างกัน, เปลี่ยนการใช้งานระหว่างภูมิภาค หรือย้ายแอปพลิเคชันจาก Amazon EC2 ไปยัง Amazon ECS โดยใช้ Fargate ได้ตลอดเวลาและยังคงได้รับส่วนลดจาก Savings Plan

**2. EC2 Instance Savings Plans**
* มอบส่วนลดสูงสุดถึง 72% จากราคา On-Demand เพื่อแลกกับการทำข้อตกลงใช้งานใน**ตระกูลอินสแตนซ์ที่เจาะจง** ภายใน**ภูมิภาค AWS ที่เลือก** (เช่น ตระกูล M5 ใน N. Virginia US-East-1)
* แผนนี้จะมีผลครอบคลุมการใช้งานโดยไม่เกี่ยงขนาดอินสแตนซ์, OS และ Tenancy ภายในตระกูลที่ระบุในภูมิภาคนั้นๆ
* คุณสามารถเปลี่ยนขนาดอินสแตนซ์ภายในตระกูลเดิม (เช่น จาก c5.xlarge เป็น c5.2xlarge) หรือเปลี่ยนระบบปฏิบัติการ (เช่น จาก Windows เป็น Linux) หรือย้ายจาก Dedicated tenancy มาเป็น Default และยังคงได้รับส่วนลดตามแผนเดิม

## ตารางเปรียบเทียบ Savings Plan vs RIs

| คุณสมบัติ | Compute Savings Plans | EC2 Instance Savings Plans | Convertible RIs | Standard RIs |
| :--- | :---: | :---: | :---: | :---: |
| ส่วนลดเมื่อเทียบกับ On-Demand | สูงสุด 66% | สูงสุด 72% | สูงสุด 66% | สูงสุด 72% |
| ปรับใช้ราคาอัตโนมัติกับทุกตระกูลอินสแตนซ์ | ✓ | — | — | — |
| ปรับใช้ราคาอัตโนมัติกับทุกขนาดอินสแตนซ์ | ✓ | ✓ | เฉพาะ Regional | เฉพาะ Regional |
| ปรับใช้ราคาอัตโนมัติกับทุก Tenancy หรือ OS | ✓ | ✓ | — | — |
| ปรับใช้กับ Fargate และ Lambda โดยอัตโนมัติ | ✓ | — | — | — |
| ปรับใช้ราคาอัตโนมัติข้ามภูมิภาค (Regions) | ✓ | — | — | — |
| ตัวเลือกระยะเวลา 1 ปี หรือ 3 ปี | ✓ | ✓ | ✓ | ✓ |

## การตรวจสอบ (Monitoring)

* หน้า **Savings Plans Inventory** จะแสดงภาพรวมโดยละเอียดของแผน Savings Plans ที่คุณครอบครองอยู่
* หากคุณเป็นผู้ใช้ในบัญชีที่เชื่อมโยง (Linked account) ของ AWS Organizations คุณสามารถดูแผนที่บัญชีของคุณเป็นเจ้าของได้
* หากคุณเป็นผู้ใช้ในบัญชีหลัก (Payer account) คุณสามารถเลือกดูได้ทั้งแผนที่บัญชีหลักครอบครองอยู่ หรือดูแผนของทุกบัญชีใน AWS Organizations ทั้งหมด
* คุณสามารถใช้ **AWS Budgets** เพื่อตั้งงบประมาณสำหรับการใช้งาน (Utilization), ความครอบคลุม (Coverage) และต้นทุนของ Savings Plan ได้
