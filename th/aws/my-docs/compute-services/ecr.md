# Amazon Elastic Container Registry (ECR) Cheat Sheet

**Amazon ECR** เป็นบริการ Docker Registry ของ AWS ที่มีการจัดการเต็มรูปแบบ (Managed Service) ซึ่งทำงานในระดับ **ภูมิภาค (Regional)** การออกแบบนี้ช่วยให้การติดตั้งใช้งาน Image มีความยืดหยุ่น คุณสามารถ Push และ Pull อิมเมจจากภูมิภาคเดียวกับที่ Docker Cluster ของคุณรันอยู่ เพื่อประสิทธิภาพสูงสุดในการทำงาน

**Amazon Elastic Container Registry (Amazon ECR)** เป็นที่เก็บ Container แบบ Managed ที่ให้ประสิทธิภาพสูง ช่วยให้คุณสามารถติดตั้งใช้งานอิมเมจของแอปพลิเคชันและ Artifact ต่างๆ ได้ทุกที่อย่างมั่นใจ
* ช่วยขจัดความจำเป็นในการรัน Repository ของตัวเอง หรือความกังวลเรื่องการสเกลโครงสร้างพื้นฐานที่อยู่เบื้องหลัง

---

## คุณสมบัติ (Features)
* ECR รองรับ **Docker Registry HTTP API V2** ทำให้คุณสามารถใช้คำสั่ง Docker CLI หรือเครื่องมือ Docker ที่คุณคุ้นเคยในการทำงานได้ตามปกติ
* ECR จัดเก็บทั้ง Container ที่คุณสร้างเอง และซอฟต์แวร์ Container ที่คุณซื้อผ่าน AWS Marketplace
* ECR จัดเก็บ Container Image ของคุณไว้ใน **Amazon S3**
* ECR รองรับการกำหนดและจัดระเบียบ Repository ใน Registry ของคุณโดยใช้ **Namespaces**
* คุณสามารถรับ-ส่ง Container Image ผ่านทาง **HTTPS**

---

## ส่วนประกอบ (Components)

### Registry (เรจิสทรี)
* แต่ละบัญชี AWS จะได้รับหนึ่ง Registry โดยจะมีทั้ง **Private Registry** (ค่าเริ่มต้น) สำหรับอิมเมจภายใน และ **Public Registry** สำหรับการแบ่งปันอิมเมจทั่วโลก
* URL พื้นฐานสำหรับ Registry คือ `https://aws_account_id.dkr.ecr.region.amazonaws.com`
* คุณต้องยืนยันตัวตนผ่าน AWS CLI (`aws ecr get-login-password`) ก่อนที่จะ Push หรือ Pull อิมเมจ

### Authorization Token (โทเค็นการอนุญาต)
* Docker Client ของคุณต้องยืนยันตัวตนกับ ECR ในฐานะผู้ใช้ AWS ก่อน โดยคำสั่ง `get-login` ใน AWS CLI จะให้ข้อมูลประจำตัวเพื่อนำไปใช้กับ Docker

### Repository (รีโพซิตอรี)
* เป็นอ็อบเจกต์ที่เก็บ Docker Images, Open Container Initiative (OCI) images และ Artifact ที่รองรับ OCI
* ECR ใช้การกำหนดสิทธิ์แบบ **Resource-based** เพื่อระบุว่าใครสามารถเข้าถึง Repository ได้และทำอะไรได้บ้าง
* คุณสามารถตั้งค่า Repository ให้เป็น **"Immutable" (ไม่สามารถเปลี่ยนแปลงได้)** เพื่อป้องกันการเขียนทับ Image Tag ช่วยให้มั่นใจว่า Tag เฉพาะ (เช่น v1.0) จะชี้ไปยังอิมเมจตัวเดิมเสมอ
* **ECR Lifecycle Policies:** ช่วยจัดการวงจรชีวิตของอิมเมจใน Repository โดยอัตโนมัติ

## ความปลอดภัย (Security)
* โดยค่าเริ่มต้น IAM User จะไม่มีสิทธิ์ในการสร้างหรือแก้ไขทรัพยากร ECR คุณต้องใช้ **IAM Policies** ในการกำหนดสิทธิ์
* รองรับการใช้ **Customer Master Keys (CMK)** ที่จัดการโดย **AWS KMS** เพื่อเข้ารหัสอิมเมจ
* **VPC Endpoints (PrivateLink):** ช่วยให้อินสแตนซ์ EC2 หรือ Pods ใน EKS สามารถ Pull อิมเมจได้โดยไม่ต้องผ่านอินเทอร์เน็ตสาธารณะ ช่วยให้ทราฟฟิกอยู่ภายในเครือข่ายของ AWS เท่านั้น

### การสแกนอิมเมจ (Image Scanning)
* **Basic Scanning:** ใช้ฐานข้อมูล CVE จากโปรเจกต์โอเพนซอร์ส Clair (ฟรี)
* **Enhanced Scanning:** ทำงานร่วมกับ **Amazon Inspector** เพื่อสแกนช่องโหว่ของ OS และ Programming Language Package แบบอัตโนมัติและต่อเนื่อง (มีค่าใช้จ่าย)

### การลงนามอิมเมจ (Image Signing)
* ทำงานร่วมกับ **AWS Signer** เพื่อลงนามอิมเมจทางคริปโตกราฟี ช่วยให้ Orchestrator (เช่น EKS) ตรวจสอบความถูกต้องของอิมเมจก่อนติดตั้งใช้งานได้

## ค่าบริการ (Pricing)
คุณจ่ายเฉพาะจำนวนข้อมูลที่จัดเก็บและข้อมูลที่โอนย้ายออกไปยังอินเทอร์เน็ต

### ค่าจัดเก็บข้อมูล (Storage Costs)
* **Standard Storage:** จ่ายตามข้อมูลที่เก็บ (ประมาณ $0.10/GB/เดือน)
* **Archive Storage:** ระดับการจัดเก็บที่ราคาถูกลง สำหรับอิมเมจที่เข้าถึงไม่บ่อย (เหมาะสำหรับการเก็บเพื่อ Compliance หรือตรวจสอบ)
    * **การดึงข้อมูล (Retrieval):** อิมเมจในชั้น Archive ไม่สามารถ Pull ได้ทันที ต้องทำการ "Restore" ก่อน (ใช้เวลาไม่กี่นาทีถึงหลายชั่วโมง) และมีค่าธรรมเนียมการดึงข้อมูลต่อ GB
* **Public Repositories:** ฟรีค่าจัดเก็บ 50 GB ต่อเดือน

### ค่าโอนย้ายข้อมูล (Data Transfer Costs)
* **Data Transfer IN:** การโอนข้อมูลเข้า ECR **ฟรี**
* **Data Transfer OUT:**
    * **ในภูมิภาคเดียวกัน:** โอนไปยังบริการคำนวณของ AWS ใน Region เดียวกัน **ฟรี**
    * **ต่างภูมิภาค:** คิดค่าบริการตามอัตราการโอนข้อมูลข้าม Region มาตรฐาน
    * **ไปยังอินเทอร์เน็ต:** คิดค่าบริการต่อ GB ตามระดับการใช้งาน
* **สิทธิ์สำหรับ Public Repository:** ฟรี 500 GB/เดือน (แบบไม่ระบุตัวตน) หรือ 5 TB/เดือน (หากยืนยันตัวตนด้วยบัญชี AWS)

### ค่าสแกนอิมเมจ (Image Scanning Costs)
* **Basic Scanning:** ฟรี
* **Enhanced Scanning:** คิดค่าบริการต่ออิมเมจ (สแกนครั้งแรกเมื่อ Push ประมาณ $0.09 และการสแกนซ้ำต่อเนื่องเมื่อมีช่องโหว่ใหม่ประมาณ $0.01)

### ค่าใช้จ่ายอื่นๆ
* **Pull Through Cache:** ตัวฟีเจอร์ไม่มีค่าธรรมเนียมเพิ่มเติม แต่คุณต้องจ่ายค่าจัดเก็บอิมเมจที่ถูกแคชไว้และค่าโอนข้อมูลข้ามภูมิภาค (ถ้ามี)
* **Lifecycle Policies:** ตัวจัดการนโยบาย **ฟรี** และช่วยลดค่าใช้จ่ายโดยการลบหรือย้ายอิมเมจเก่าออกโดยอัตโนมัติ
