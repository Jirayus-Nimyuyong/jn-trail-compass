# AWS Snowball Edge Cheat Sheet

**AWS Snowball Edge** เป็นอุปกรณ์ตระกูล Snowball ประเภทหนึ่งที่มีพื้นที่จัดเก็บข้อมูลและกำลังการประมวลผลในตัวสำหรับฟีเจอร์บางอย่างของ AWS โดยสามารถรองรับการประมวลผลในท้องถิ่น (Local processing) และภาระงานแบบ Edge-computing นอกเหนือไปจากการโอนย้ายข้อมูลระหว่างสภาพแวดล้อมท้องถิ่นของคุณกับ AWS Cloud
* มีพื้นที่จัดเก็บข้อมูลที่รองรับ S3 และการประมวลผลในตัว เพื่อสนับสนุนการรัน Lambda functions และ EC2 instances
* **ตัวเลือกการกำหนดค่าอุปกรณ์:**
    * **Storage optimized (เน้นพื้นที่จัดเก็บ):** มีความจุสูงสุด โดยมีพื้นที่ใช้งานได้ 80 TB, 24 vCPUs และหน่วยความจำ 32 GiB สามารถโอนย้ายข้อมูลได้สูงสุด 100 TB ต่อหนึ่งเครื่อง
    * **Compute optimized (เน้นการประมวลผล):** มีประสิทธิภาพการประมวลผลสูงสุดด้วย 52 vCPUs, หน่วยความจำ 208 GiB และพื้นที่จัดเก็บ NVMe SSD แยกเฉพาะ 7.68 TB สำหรับ Instances นอกจากนี้ยังมีพื้นที่จัดเก็บเพิ่มเติมอีก 42 TB
    * **Compute Optimized with GPU:** เหมือนกับรุ่น Compute optimized แต่มีการติดตั้ง GPU เพิ่มเติม (เทียบเท่ากับที่มีในอินสแตนซ์ P3 ของ Amazon EC2)

> **การแจ้งเตือนการบริการ:** ตั้งแต่วันที่ **7 พฤศจิกายน 2025** เป็นต้นไป AWS Snowball Edge จะไม่เปิดรับลูกค้าใหม่ บริการนี้จะยังคงใช้งานได้เฉพาะลูกค้าเดิมที่ลงทะเบียนก่อนวันที่ระบุดังกล่าวเท่านั้น

## คุณสมบัติ (Features)
* อะแดปเตอร์เครือข่ายรองรับความเร็วในการโอนย้ายข้อมูลสูงสุด 100 GB ต่อวินาที
* บังคับใช้การเข้ารหัสข้อมูล (Encryption) ทั้งในขณะที่ข้อมูลถูกจัดเก็บ (At rest) และระหว่างการขนส่งทางกายภาพ
* สามารถนำเข้า (Import) หรือส่งออก (Export) ข้อมูลระหว่างสภาพแวดล้อมท้องถิ่นของคุณกับ S3 ได้
* มีหน้าจอ LCD บนตัวเครื่องเพื่อจัดการการเชื่อมต่อเครือข่ายและดูข้อมูลสถานะการบริการ
* สามารถทำ **Cluster** อุปกรณ์ Snowball Edge เพื่อใช้งานพื้นที่จัดเก็บและประมวลผลในท้องถิ่น เพื่อให้ได้ความทนทานของข้อมูลระดับ 99.999% (ใช้เครื่อง 5–10 เครื่อง)
* สามารถเขียน **Python-language Lambda functions** เพื่อเชื่อมโยงกับ S3 buckets เมื่อสร้างงานอุปกรณ์ โดยฟังก์ชันจะทำงานเมื่อมีการรันคำสั่ง S3 `PUT` object ในเครื่อง
* มี Endpoints ที่รองรับ S3 และ EC2 ช่วยให้ใช้งานผ่านการเขียนโปรแกรม (Programmatic) ได้
* สามารถเชื่อมต่อ Volume สำหรับเก็บข้อมูลแบบบล็อกถาวร (Persistent block storage) หลายตัวเข้ากับอินสแตนซ์ EC2 บนอุปกรณ์ได้
* รองรับ Volume แบบ SSD ที่ปรับแต่งประสิทธิภาพ (**sbp1**) สำหรับงานที่ไวต่อความหน่วง เช่น Machine Learning หรือใช้ HDD แบบเน้นความจุ (**sbg1**)

## ประเภทของงาน (Job Types)
* **Import To S3:** โอนย้ายข้อมูลท้องถิ่นขนาด 80 TB หรือน้อยกว่าไปยังอุปกรณ์เครื่องเดียวเพื่อย้ายเข้า S3 (หากข้อมูลมากกว่านี้ต้องสร้างงานใหม่หรือ Clone งานเดิม)
* **Export From S3:** โอนย้ายข้อมูลจำนวนเท่าใดก็ได้จาก S3 ไปยังอุปกรณ์ Snowball Edge หลายเครื่อง แล้วขนส่งกลับมายังศูนย์ข้อมูลของคุณทีละเครื่อง
* **Local Compute and Storage Only:** งานที่ใช้อุปกรณ์เครื่องเดียวหรือหลายเครื่องในรูปแบบ Cluster เพื่อใช้งานเฉพาะในท้องถิ่นเท่านั้น
    * **Cluster job:** สำหรับงานที่ต้องการความทนทานของข้อมูลและความจุพื้นที่จัดเก็บเพิ่มขึ้น (ใช้ 5 ถึง 10 เครื่อง เรียกว่า Nodes)

## คำแนะนำ (Recommendations)
* สถานะ **Job created** เป็นสถานะเดียวที่สามารถยกเลิกงานได้ หากสถานะเปลี่ยนไปแล้วจะไม่สามารถยกเลิกได้
* ไฟล์ทั้งหมดที่โอนไปยัง Snowball ควรมีขนาดไม่ต่ำกว่า 1 MB
* เพิ่มความเร็วด้วยการรันคำสั่งเขียนข้อมูลหลายรายการพร้อมกัน (Multiple write operations) จากหลายหน้าต่าง Terminal
* แนะนำให้โอนไฟล์ขนาดเล็กแบบเป็นชุด (Batch)

---

## ความปลอดภัย (AWS Snowball Edge Security)
* ข้อมูลทั้งหมดที่โอนไปยังอุปกรณ์จะได้รับการปกป้องด้วยการเข้ารหัส SSL ผ่านเครือข่าย
* ใช้การเข้ารหัสฝั่งเซิร์ฟเวอร์ (Server-side encryption) เพื่อปกป้องข้อมูลที่จัดเก็บอยู่บนเครื่อง
* การเข้าถึงต้องใช้ Credentials ที่ AWS สามารถตรวจสอบสิทธิ์ได้และต้องมีสิทธิ์ในการเข้าถึงทรัพยากร AWS ที่เกี่ยวข้อง

---

## ค่าบริการ (Pricing)
* คิดค่าบริการตามประเภทเครื่อง (Storage optimized หรือ Compute optimized)
* คิดค่าบริการตามระยะเวลาการทำข้อตกลงใช้งาน: On-demand (ตามการใช้งาน), ข้อตกลง 1 ปี หรือ 3 ปี
* สำหรับแบบ On-demand จะเสียค่าธรรมเนียมบริการต่องานโอนข้อมูล ซึ่งรวมระยะเวลาการใช้อุปกรณ์ที่หน้างาน 10 วัน (ไม่นับวันขนส่ง) หากเกิน 10 วันจะเสียค่าบริการเพิ่มเติมเป็นรายวัน
* มีค่าธรรมเนียมการตั้งค่า (One-time setup fee) ครั้งเดียวต่องานที่สั่งผ่านคอนโซล

---

## ข้อจำกัด (Limits)
* ข้อมูลที่โอนย้ายแต่ละชิ้นต้องมีขนาดสูงสุดไม่เกิน **5 Terabytes**
* งานต้องเสร็จสิ้นภายใน 120 วันนับจากวันที่เตรียมอุปกรณ์ Snowball Edge
* ขีดจำกัดเริ่มต้นของจำนวนอุปกรณ์ Snowball Edge ที่สามารถครอบครองได้พร้อมกันคือ 1 เครื่อง
* หากจัดสรรหน่วยความจำขั้นต่ำ 128 MB ต่อฟังก์ชัน จะสามารถมี Lambda functions ได้สูงสุด 7 ฟังก์ชันในหนึ่งงาน (เนื่องจากขีดจำกัดทางกายภาพ)
