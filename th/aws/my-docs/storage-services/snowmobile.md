# AWS Snowmobile Cheat Sheet

**การยกเลิกการให้บริการ (Service Retirement):** ตั้งแต่ **เมษายน 2024** เป็นต้นไป AWS ได้ยกเลิกบริการ Snowmobile แล้ว และไม่มีให้สั่งจองอีกต่อไป สำหรับลูกค้าที่ต้องการย้ายชุดข้อมูลขนาดใหญ่ ควรพิจารณาใช้ **AWS Snowball Edge** สำหรับการถ่ายโอนแบบออฟไลน์ หรือ **AWS DataSync** สำหรับการถ่ายโอนแบบออนไลน์แทน

* **AWS Snowmobile** เคยเป็นบริการถ่ายโอนข้อมูลในระดับ **Exabyte-scale** ที่ใช้สำหรับย้ายชุดข้อมูลขนาดใหญ่มากไปยัง AWS
* รูปแบบบริการประกอบด้วยตู้คอนเทนเนอร์ขนส่งสินค้าขนาด 45 ฟุตที่มีความทนทานสูง ขนส่งโดยรถกึ่งพ่วง (Semi-trailer truck) สามารถบรรจุข้อมูลได้สูงสุดถึง **100 PB**
* Snowmobile ถูกออกแบบมาเพื่อการย้ายข้อมูลมหาศาล เช่น การย้ายศูนย์ข้อมูลทั้งแห่ง ซึ่งการถ่ายโอนผ่านเครือข่ายแบบดั้งเดิมนั้นไม่สามารถทำได้จริง
* เมื่อบันทึกข้อมูลเสร็จ Snowmobile จะถูกส่งกลับไปยังภูมิภาค (Region) ของ AWS ที่กำหนดไว้ เพื่อทำการอัปโหลดข้อมูลเข้าสู่บริการจัดเก็บข้อมูลของ AWS เช่น **S3** หรือ **Glacier**
* Snowmobile ใช้ระบบความปลอดภัยหลายชั้นเพื่อปกป้องข้อมูลของคุณ รวมถึงมีการใช้บุคลากรฝ่ายรักษาความปลอดภัยเฉพาะทาง:
    * การติดตามด้วย GPS, การตรวจสอบระบบเตือนภัย
    * การเฝ้าระวังด้วยวิดีโอตลอด 24 ชั่วโมงทุกวัน (24/7 Video surveillance)
    * มีตัวเลือกเสริมเป็นรถรักษาความปลอดภัยขับร่วมขบวนในระหว่างการเดินทาง
* ข้อมูลทั้งหมดถูกเข้ารหัสด้วยกุญแจเข้ารหัส 256 บิตที่คุณจัดการผ่าน **AWS Key Management Service (KMS)** และถูกออกแบบมาเพื่อความปลอดภัยและการตรวจสอบลำดับการครอบครองข้อมูล (Chain-of-custody) อย่างสมบูรณ์

**ค่าบริการ (Pricing):** ราคาของ Snowmobile คิดตามปริมาณข้อมูลที่จัดเก็บไว้บนรถบรรทุกต่อเดือน
