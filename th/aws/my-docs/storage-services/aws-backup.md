# AWS Backup Cheat Sheet

**AWS Backup** เป็นบริการที่ช่วยให้คุณสามารถรวบรวมและจัดการการปกป้องข้อมูล (Data Protection) ให้เป็นศูนย์กลางและเป็นไปอย่างอัตโนมัติ ทั้งในบริการต่างๆ ของ AWS และ Hybrid Workloads

---

## แนวคิดหลัก (Concepts)

### แผนการสำรองข้อมูล (Backup Plan)
* คือการกำหนดนโยบายที่ระบุว่า **เมื่อใด** และ **อย่างไร** ที่คุณต้องการสำรองข้อมูลทรัพยากร AWS
* จัดเก็บข้อมูลการสำรองตามรอบเวลาแบบ **Incremental** (เก็บเฉพาะส่วนที่เปลี่ยนแปลง)
* สามารถสร้างได้ผ่าน AWS Console, API, CLI, SDK หรือ CloudFormation
* สามารถกำหนดเป้าหมายการสำรองข้อมูลได้ดังนี้:
    * **Resource type:** สำรองทุกอินสแตนซ์หรือทรัพยากรในประเภทนั้นๆ
    * **Resource:** สำรองทรัพยากรตัวใดตัวหนึ่งโดยเฉพาะ
* รองรับแผนการสำรองข้อมูลหลายแผนสำหรับ Workload ที่มีความต้องการต่างกัน
* การจะลบแผนการสำรองข้อมูล คุณต้องลบทรัพยากรทั้งหมดที่เชื่อมโยงกับแผนนั้นออกก่อน
* เมื่อมีการเปลี่ยนระยะเวลาการเก็บรักษา (Retention Period) ในกฎการสำรองข้อมูล ข้อมูลสำรองที่ถูกสร้างขึ้น **ก่อนหน้า** การอัปเดตจะยังคงมีระยะเวลาการเก็บรักษาเท่าเดิมไม่เปลี่ยนแปลง

### ห้องเก็บข้อมูลสำรอง (Backup Vault)
* เป็นคอนเทนเนอร์สำหรับจัดเก็บและจัดระเบียบข้อมูลสำรองของคุณ
* สามารถสร้างได้หลาย Vault หากต้องการใช้กุญแจเข้ารหัส (Encryption Keys) หรือนโยบายการเข้าถึง (Access Policies) ที่ต่างกันในแต่ละกลุ่มข้อมูล
* ต้องใช้ **AWS KMS** ในการเข้ารหัสข้อมูลสำรองที่เก็บไว้ใน Vault
* **AWS Backup Vault Lock:** ช่วยบังคับใช้ระยะเวลาการเก็บรักษาและป้องกันการลบข้อมูลก่อนกำหนด
* **คุณไม่สามารถลบ Vault ต่อไปนี้ได้:**
    * Default Backup Vault ของ AWS Backup
    * Automatic Backup Vault ของ Amazon EFS

### ข้อมูลสำรอง (Backup)
* หรือเรียกว่า **Recovery Point** คือเนื้อหาของทรัพยากร ณ เวลาใดเวลาหนึ่ง
* Recovery points จะถูกจัดเก็บไว้ใน Backup Vaults
* สามารถกู้คืน (Restore) ได้ผ่าน AWS Console หรือ API
* ข้อมูลสำรองสร้างขึ้นได้จาก:
    * สร้างอัตโนมัติผ่านแผนการสำรองข้อมูล (Backup Plans)
    * สร้างด้วยตัวเองผ่านการสั่งสำรองข้อมูลตามความต้องการ (On-demand Backup)
* สามารถคัดลอกข้อมูลสำรอง (Backup Copies) ข้ามพื้นที่ได้ดังนี้:
    * ข้ามภูมิภาค (**AWS Regions**)
    * ข้ามบัญชี (**AWS Accounts**)
* สามารถกำหนดนโยบายวงจรชีวิต (Lifecycle Policies) และเพิ่ม Tag ให้กับข้อมูลสำรองได้

## AWS Backup Audit Manager

### กรอบการตรวจสอบ (Audit Frameworks)
* คือชุดการควบคุมที่ช่วยให้คุณประเมินแนวทางปฏิบัติในการสำรองข้อมูลของคุณ
* ช่วยค้นหากิจกรรมการสำรองข้อมูลและทรัพยากรที่ยังไม่ปฏิบัติตามมาตรฐาน (Non-compliance) ที่คุณตั้งไว้
* หนึ่ง Framework จะใช้ได้กับหนึ่งบัญชี และจำกัดสูงสุด 10 Framework ต่อภูมิภาค (Region)
* แบ่งออกเป็น 2 ประเภท:
    * AWS Backup Framework
    * Custom Framework

### รายงานการตรวจสอบ (Audit Reports)
* สร้างหลักฐานการตรวจสอบ (Audit Trail) ในรูปแบบรายงานประจำวันหรือตามคำขอโดยอัตโนมัติ
* ต้องสร้าง "Report Plan" จากเทมเพลตรายงานก่อนจึงจะสร้างรายงานได้
    * เทมเพลตรายงานการสำรองข้อมูล (Backup report templates)
    * เทมเพลตรายงานการปฏิบัติตามข้อกำหนด (Compliance report templates)
* รายงานต้องอยู่ในภูมิภาคและบัญชีเดียวกับ S3 Bucket ที่ใช้เก็บรายงานเท่านั้น
* แต่ละบัญชี AWS สามารถมี Report Plans ได้สูงสุด 20 แผน

## การตรวจสอบและติดตาม (AWS Backup Monitoring)
* **AWS Organizations:** จัดการและตรวจสอบงานสำรองข้อมูล, กู้คืน และคัดลอก ข้ามหลายบัญชี AWS
* **Amazon EventBridge:** ใช้ดูและตรวจสอบเหตุการณ์ต่างๆ ของ AWS Backup
* **AWS CloudWatch:** ติดตามมาตรวัด (Metrics), สร้างการแจ้งเตือน (Alarms) และดู Dashboard
* **AWS CloudTrail:** ตรวจสอบการเรียกใช้งาน API ของ AWS Backup
* **Amazon SNS:** สมัครรับข้อมูลเพื่อแจ้งเตือนเหตุการณ์ของ AWS Backup

## ค่าบริการ (AWS Backup Pricing)
คุณจะถูกเรียกเก็บเงินตามรายการต่อไปนี้:
* ปริมาณพื้นที่จัดเก็บข้อมูลสำรองที่ใช้งาน
* ปริมาณข้อมูลสำรองที่มีการถ่ายโอนข้ามภูมิภาค (Cross-Region)
* ปริมาณข้อมูลสำรองที่คุณทำการกู้คืน (Restore)
* จำนวนครั้งที่มีการประเมินการสำรองข้อมูล (Backup Evaluations)
