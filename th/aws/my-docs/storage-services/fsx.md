# Amazon FSx Cheat Sheet

**Amazon FSx** เป็นโซลูชันระบบไฟล์ (File System) ของผู้ให้บริการภายนอกแบบ Managed เต็มรูปแบบ โดยใช้การจัดเก็บข้อมูลแบบ SSD และ HDD เพื่อให้ประสิทธิภาพที่รวดเร็วและความหน่วง (Latency) ต่ำ มี 4 โซลูชันหลักใน AWS ดังนี้:

---

## 1. Amazon FSx for Windows File Server
ระบบไฟล์ Microsoft Windows แท้แบบ Managed เต็มรูปแบบ รองรับโปรโตคอล SMB, Windows NTFS และการทำงานร่วมกับ Microsoft Active Directory (AD)

### กรณีการใช้งานที่พบบ่อย (Common Use Cases)
* **โฮมไดเรกทอรี:** ระบบไฟล์ที่ผู้ใช้หลายคนเข้าถึงได้ และกำหนดสิทธิ์ในระดับไฟล์หรือโฟลเดอร์ได้
* **ส่วนแบ่งไฟล์ทางธุรกิจ:** งานที่ต้องการพื้นที่เก็บข้อมูลร่วมกันผ่าน NTFS และโปรโตคอล SMB
* **งานด้านสื่อ:** การแปลงรหัส (Transcoding), การประมวลผล และการสตรีมสื่อ
* **แอปพลิเคชันเว็บ:** เช่น Content Management และ IIS
* **SQL Server:** สำหรับการติดตั้งแบบ High Availability (FCI)

### คุณสมบัติและการทำงาน
* **การเชื่อมต่อ:** รองรับ EC2, Workspaces, AppStream 2.0 และ VMware Cloud on AWS
* **On-premises:** เข้าถึงได้ผ่าน Direct Connect หรือ VPN และใช้ **Amazon FSx File Gateway** เพื่อทำ Cache ข้อมูลในเครื่องให้เข้าถึงได้เร็วขึ้น
* **Windows File Share:** เข้าถึงผ่านฟังก์ชัน Map Network Drive ของ Windows โดยมีโฟลเดอร์เริ่มต้นชื่อ `share`
* **Storage:** รองรับการจำกัดโควตาผู้ใช้ (User storage quotas) และใช้ **DFS Namespaces** เพื่อรวมหลายระบบไฟล์เข้าด้วยกัน
* **Data Deduplication:** ลดค่าใช้จ่ายโดยการลบข้อมูลที่ซ้ำซ้อน
* **ประสิทธิภาพ:** SSD สูงสุด 64 TB ต่อระบบไฟล์ และทรูพุตสูงสุด 2GB/s (หากใช้ DFS จะขยายได้ถึงระดับ Petabytes และความเร็วหลายสิบ GB/s)

## 2. Amazon FSx for Lustre
ระบบไฟล์ประสิทธิภาพสูงที่ปรับแต่งมาเพื่อการประมวลผลงานที่รวดเร็ว (Lustre เป็นระบบไฟล์คู่ขนานแบบ Open-source ที่ยอดนิยม)

* **ประเภทพื้นที่เก็บข้อมูล:** เลือกได้ทั้ง SSD (ความหน่วงต่ำกว่ามิลลิวินาที) หรือ HDD (ประหยัดค่าใช้จ่ายได้สูงสุด 80% สำหรับงานเน้นทรูพุต)
* **การทำงานร่วมกับ S3:** สามารถใช้ FSx เป็น "Hot storage" (ข้อมูลที่เข้าถึงบ่อย) และใช้ S3 เป็น "Cold storage" (ข้อมูลที่เข้าถึงน้อย) โดยเชื่อมโยงผ่าน **Data Repository Associations (DRA)**
* **การติดตั้ง (Deployment):** มีแบบ **Scratch** (ชั่วคราว ไม่มีการทำสำเนา) และ **Persistent** (ระยะยาว มีการทำสำเนาข้อมูล)
* **ประสิทธิภาพ:** ความหน่วงต่ำกว่ามิลลิวินาที ทรูพุตหลายร้อย GB/s และ IOPS หลายล้านครั้ง รองรับการเข้าถึงพร้อมกันจากอินสแตนซ์นับพันตัว

---

## 3. Amazon FSx for NetApp ONTAP
โซลูชันพื้นที่เก็บข้อมูลร่วมกันที่ให้ประสิทธิภาพสูง เข้าถึงได้จาก Linux, Windows และ macOS ทั้งบน AWS และ On-premises

* **องค์ประกอบ:** ประกอบด้วย Storage Virtual Machines (SVMs) และ Volumes
* **โปรโตคอล:** รองรับ NFS, SMB และ iSCSI
* **การจัดการระดับชั้นข้อมูล (Storage Tiering):** ย้ายข้อมูลที่เข้าถึงไม่บ่อยไปยัง **Capacity pool tier** โดยอัตโนมัติ (เลือกโหมดได้ทั้ง Auto, Snapshot-only, All หรือ None)
* **ฟีเจอร์ขั้นสูง:** รองรับ **SnapLock** (สำหรับการปฏิบัติตามกฎระเบียบแบบ WORM - เขียนครั้งเดียวอ่านหลายครั้ง) และการบีบอัดข้อมูล (Data Compression)

---

## 4. Amazon FSx for OpenZFS
บริการจัดเก็บไฟล์ที่ให้ IOPS สูงถึง 1 ล้านครั้ง ด้วยความหน่วงระดับไมโครวินาที

* **จุดเด่น:** ช่วยให้ย้ายข้อมูลจาก On-premises ZFS มายัง AWS ได้โดยไม่ต้องแก้ไขโค้ดแอปพลิเคชัน
* **เทคโนโลยี:** ขับเคลื่อนด้วยโปรเซสเซอร์ตระกูล **AWS Graviton**
* **ความสามารถด้านข้อมูล:** รองรับการบีบอัด Z-Standard, การทำ Snapshot ในพริบตา และการทำ Data Cloning
* **ความพร้อมใช้งาน:** รองรับการติดตั้งแบบ **Multi-AZ** เพื่อความพร้อมใช้งานสูง

---

## ความพร้อมใช้งานและความทนทาน (HA and Durability)
* **การทำสำเนา:** จำลองข้อมูลอัตโนมัติภายใน AZ ที่อาศัยอยู่
* **การติดตั้ง:** มีทั้งแบบ Single AZ และ Multi-AZ (Multi-AZ รองรับใน Windows, OpenZFS และ NetApp ONTAP)
* **Backup:** ใช้ Volume Shadow Copy Service (VSS) เพื่อสำรองข้อมูลที่สอดคล้องกันรายวันไปยัง S3 โดยอัตโนมัติ (เก็บรักษาไว้ 7 วันเป็นค่าเริ่มต้น)

---

## ความปลอดภัย (Security)
* **การยืนยันตัวตน:** รองรับ Microsoft Active Directory ผ่านโปรโตคอล SMB
* **การเข้ารหัส:** เข้ารหัสข้อมูลขณะจัดเก็บ (At-rest) ด้วย AWS KMS และขณะรับ-ส่ง (In-transit) ด้วย SMB Kerberos session keys
* **มาตรฐาน:** รองรับ ISO, PCI-DSS, SOC และ HIPAA eligible
* **การตรวจสอบ:** รวมเข้ากับ AWS CloudTrail เพื่อบันทึกการเรียกใช้งาน API

---

## ค่าบริการ (Pricing)
* **การเรียกเก็บเงิน:** คิดค่าบริการรายชั่วโมงตามความจุของพื้นที่จัดเก็บ (ต่อ GB-เดือน) และทรูพุต (ต่อ MBps-เดือน)
* **สำรองข้อมูล:** คิดค่าบริการรายชั่วโมงตามปริมาณข้อมูลสำรอง (ต่อ GB-เดือน)
* **การประหยัด:** สามารถเปิดใช้ Data Deduplication เพื่อลดพื้นที่จัดเก็บที่ซ้ำซ้อนและลดต้นทุนได้
