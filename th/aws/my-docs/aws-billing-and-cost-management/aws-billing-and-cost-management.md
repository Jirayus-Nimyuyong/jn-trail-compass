# AWS Billing and Cost Management Cheat Sheet

* **Cost Explorer:** ใช้ติดตามและวิเคราะห์การใช้งาน AWS เปิดให้ใช้ฟรีสำหรับทุกบัญชี
* **Budgets:** ใช้สำหรับจัดการงบประมาณในบัญชีของคุณ
* **Bills:** ดูรายละเอียดค่าใช้จ่ายปัจจุบัน
* **Payment History:** ดูประวัติการชำระเงินย้อนหลัง
* **รอบบิล:** ระบบจะปิดรอบบิลตอนเที่ยงคืนของวันสุดท้ายในแต่ละเดือนเพื่อคำนวณค่าใช้จ่าย
* **การชำระเงิน:** AWS จะเรียกเก็บเงินผ่านบัตรเครดิตที่ลงทะเบียนไว้เมื่อสิ้นสุดรอบบิล หรือเมื่อมีค่าธรรมเนียมแบบจ่ายครั้งเดียว และจะออกใบแจ้งหนี้เป็นไฟล์ PDF
* **CloudWatch:** สามารถสร้าง **Billing Alerts** เพื่อแจ้งเตือนเมื่อค่าบริการเกินเกณฑ์ที่กำหนด
* **Cost Allocation Tags:** ใช้แท็กเพื่อติดตามต้นทุนในระดับละเอียด มี 2 แบบคือ แบบที่ AWS สร้างให้ (AWS generated) และแบบที่ผู้ใช้กำหนดเอง (User-defined)
* **Dashboards:** สร้างแดชบอร์ดที่ปรับแต่งได้เพื่อรวมภาพข้อมูลต้นทุนและการใช้งาน และแชร์ข้ามบัญชีได้

### คุณสมบัติเด่น (Features)
* **Cost Anomaly Detection:** ใช้ Machine Learning ตรวจสอบรูปแบบการจ่ายเงินที่ผิดปกติ
* **Pricing Calculator:** ประมาณการค่าใช้จ่ายคลาวด์ทั้งแบบทั่วไปและแบบในคอนโซล (In-console)
* **Cost Optimization Hub:** แหล่งรวมคำแนะนำในการประหยัดเงินสำหรับ EC2, Aurora, DynamoDB และ Savings Plans
* **Amazon Q Integration:** ใช้ Generative AI ช่วยวิเคราะห์ต้นทุนและหาโอกาสในการประหยัดค่าใช้จ่าย
* **User Attribute Cost Allocation:** จัดสรรต้นทุนตามแอตทริบิวต์ของผู้ใช้ใน IAM Identity Center

---

### AWS Cost Anomaly Detection
* ใช้ ML ในการตรวจจับและแจ้งเตือนการจ่ายเงินที่ผิดปกติในเวิร์กโหลดของคุณ
* รับการแจ้งเตือนได้ทั้งแบบรายบุคคลหรือรายงานสรุปผ่านอีเมล และสามารถเชื่อมต่อกับ **Amazon SNS** เพื่อส่งการแจ้งเตือนไปยัง **Slack** ได้
* ทีมงานสามารถประเมินรูปแบบการใช้จ่ายเพื่อลดการแจ้งเตือนที่ผิดพลาด (False Positive)

### AWS Billing Conductor
* ช่วยให้กระบวนการออกรายงานและเรียกเก็บเงินง่ายขึ้นสำหรับกลุ่มบัญชีที่มีลูกค้าปลายทางคนเดียวกัน
* **Billing Group:** ชุดของบัญชีภายใน Consolidated Billing ที่แชร์ลูกค้าคนเดียวกัน โดย "บัญชีหลัก" (Primary Account) จะสามารถมองเห็นต้นทุนรวมของทั้งกลุ่มได้

---

### AWS Free Tier (สิทธิ์ใช้งานฟรี)
* เมื่อสมัครบัญชีใหม่ คุณจะได้รับสิทธิ์ Free Tier นาน **12 เดือน** โดยอัตโนมัติ
* ใช้บริการได้ฟรีภายใต้ขีดจำกัดที่กำหนด
* สามารถติดตามการใช้งาน Free Tier และตั้งการแจ้งเตือนผ่าน **AWS Budgets** เพื่อป้องกันค่าใช้จ่ายส่วนเกิน

### AWS Cost and Usage Reports (CUR)
* ให้ข้อมูลรายละเอียดการใช้ทรัพยากรและต้นทุนโดยประมาณในรูปแบบไฟล์ **.csv** เก็บไว้ใน **S3 Bucket**
* สามารถเลือกความละเอียดของข้อมูลได้แบบ รายชั่วโมง (Hourly), รายวัน (Daily) หรือรายเดือน (Monthly)
* สามารถอัปโหลดเข้า **AWS Redshift** หรือ **QuickSight** เพื่อวิเคราะห์ข้อมูลเชิงลึกได้โดยอัตโนมัติ

### AWS Cost Explorer
* ช่วยแสดงภาพข้อมูลต้นทุนของบริการ 5 อันดับแรกที่มียอดสูงสุด และแจกแจงรายละเอียดของทุกบริการในรูปแบบตาราง
* **Billing Views:** แชร์มุมมองข้อมูลต้นทุนที่คัดกรองแล้วให้ทีมงานเข้าถึงเฉพาะข้อมูลที่เกี่ยวข้องกับพวกเขาได้
* ดูข้อมูลย้อนหลังได้สูงสุด **12 เดือน** และพยากรณ์ค่าใช้จ่ายล่วงหน้าได้ **3 เดือน**
* **การเปิดใช้งาน:** ต้องใช้บัญชี Root ในการเปิดใช้งานครั้งแรก หากเป็นบัญชีหลัก (Management Account) ขององค์กร การเปิดใช้งานจะมีผลกับทุกบัญชีในองค์กร

### AWS Budgets (การจัดการงบประมาณ)
* ตั้งงบประมาณเพื่อรับการแจ้งเตือนเมื่อค่าใช้จ่ายจริงหรือ **ค่าใช้จ่ายพยากรณ์ (Forecasted)** เกินจำนวนที่ตั้งไว้
* ข้อมูลจะถูกอัปเดตสูงสุด 3 ครั้งต่อวัน
* **ประเภทของงบประมาณ:**
    * **Cost budgets:** วางแผนงบประมาณเป็นตัวเงิน
    * **Usage budgets:** วางแผนตามปริมาณการใช้งานบริการ
    * **RI utilization budgets:** แจ้งเตือนเมื่อการใช้งาน Reserved Instance ต่ำกว่าเกณฑ์ที่กำหนด
    * **RI coverage budgets:** แจ้งเตือนเมื่อสัดส่วนอินสแตนซ์ที่ครอบคลุมด้วย RI ต่ำกว่าเกณฑ์
* การแจ้งเตือนส่งผ่านอีเมล หรือ Amazon SNS
* **งบประมาณ 2 รายการแรกที่สร้างจะไม่มีค่าใช้จ่าย (ฟรี)**
