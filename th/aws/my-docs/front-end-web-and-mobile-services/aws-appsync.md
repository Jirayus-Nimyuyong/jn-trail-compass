# AWS AppSync Cheat Sheet

**AWS AppSync** เป็นบริการ GraphQL และ Pub/Sub API แบบ Serverless ที่ช่วยเพิ่มความคล่องตัวในการพัฒนาเว็บแอปพลิเคชันและโมบายแอปพลิเคชันสมัยใหม่
* **AppSync GraphQL APIs:** ให้จุดเชื่อมต่อ (Endpoint) เดียวในการคิวรีและอัปเดตข้อมูลจากฐานข้อมูล, Microservices และ API หลายแห่งได้อย่างปลอดภัย
* **AppSync Pub/Sub APIs:** อัปเดตข้อมูลและเผยแพร่ไปยังไคลเอนต์ที่สมัครสมาชิก (Subscribed) โดยอัตโนมัติผ่านการเชื่อมต่อ WebSockets แบบ Serverless

---

### แนวคิดหลัก (Concepts)

#### 1. GraphQL
* ช่วยให้แอปพลิเคชันดึงข้อมูลจากเซิร์ฟเวอร์ได้
* **GraphQL Proxy:** ส่วนประกอบที่รันเอนจิน GraphQL เพื่อประมวลผลคำขอและแมปไปยังฟังก์ชันการทำงานของข้อมูล
* **การดำเนินการ 3 ระดับ:**
    * **Query:** ดึงข้อมูล (อ่านอย่างเดียว)
    * **Mutation:** เขียนข้อมูลตามด้วยการดึงข้อมูล
    * **Subscription:** การเชื่อมต่อระยะยาวเพื่อรับข้อมูลแบบเรียลไทม์
* **Schema:** ตัวกำหนดความสามารถของ API ประกอบด้วยประเภทข้อมูล (Types) ทั้งแบบ Root และแบบที่ผู้ใช้กำหนดเอง



#### 2. ส่วนประกอบในการสร้าง GraphQL API
* **GraphQL Schema:** นิยามของ API ทั้งหมด
* **Data Source:** ทรัพยากร AWS ที่ API เข้าไปโต้ตอบด้วย (เช่น DynamoDB, Lambda, ElasticSearch)
* **Resolvers (ตัวประมวลผล):** ใช้ Mapping Templates เพื่อแปลงนิพจน์ GraphQL ให้อยู่ในรูปแบบที่แหล่งข้อมูลใช้งานได้
    * **Unit resolver:** ดำเนินการคำสั่งเดียวกับแหล่งข้อมูลเดียว
    * **Pipeline resolver:** ดำเนินการหลายคำสั่งกับหลายแหล่งข้อมูลต่อเนื่องกัน
* **JavaScript Resolvers:** ปัจจุบันรองรับการเขียนด้วย JavaScript (เพิ่มเติมจาก VTL) ทำให้เขียนตรรกะได้ยืดหยุ่นและ Debug ได้ง่ายขึ้น

### คุณสมบัติเด่น (Features)
* **Real-time Data:** สามารถทำให้แหล่งข้อมูลใดๆ ใน AWS เป็นแบบเรียลไทม์ได้โดยใช้ Directive ใน Schema
* **Data Filtering:**
    * **Basic:** กรองตามอาร์กิวเมนต์ที่ไคลเอนต์กำหนด
    * **Enhanced:** กรองตามตรรกะที่กำหนดไว้ที่ส่วนหลัง (Backend) ของ AppSync
* **Caching:** สามารถแคชข้อมูลที่ถูกเรียกใช้บ่อยเพื่อลดภาระของ Resolver โดยเลือกแคชเฉพาะบางฟิลด์ (Per-field) ได้
* **Compression:** บีบอัดการตอบสนองของ API เพื่อให้ดาวน์โหลดได้เร็วขึ้นและประหยัดค่าถ่ายโอนข้อมูล
* **Custom Domain Names:** รองรับการใช้ชื่อโดเมนของคุณเองสำหรับ API

---

### ความปลอดภัยและการตรวจสอบ (Security & Monitoring)
* **การอนุญาตสิทธิ์ (Authorization):** สามารถระบุประเภทการอนุญาตได้หลายแบบ:
    * API_KEY, AWS_LAMBDA, AWS_IAM, OPENID_CONNECT, AMAZON_COGNITO_USER_POOLS
    * สามารถใช้งานหลายโหมดพร้อมกันได้ (เช่น IAM + Cognito) ในระดับ Resolver หรือ Operation
* **การป้องกัน:** ใช้ **AWS WAF** เพื่อป้องกันการโจมตีทางเว็บและ API
* **Monitoring:** * **CloudWatch Logs:** สำหรับตรวจสอบและ Debug คำขอ
    * **AWS X-Ray:** สำหรับติดตามเส้นทาง (Tracing) ของคำขอ GraphQL
    * **CloudTrail:** สำหรับบันทึกประวัติการเรียกใช้ API

---

### ค่าบริการ (Pricing)
คุณจะถูกเรียกเก็บเงินตามรายการดังนี้:
* การดำเนินการคิวรี (Query) และการแก้ไขข้อมูล (Data modification)
* การอัปเดตข้อมูลแบบเรียลไทม์ (Real-time updates)
* จำนวนนาทีที่เชื่อมต่อกับ AppSync (Connection minutes)
* อินสแตนซ์สำหรับแคช (Dedicated cache instance - ถ้ามีการใช้งาน)
