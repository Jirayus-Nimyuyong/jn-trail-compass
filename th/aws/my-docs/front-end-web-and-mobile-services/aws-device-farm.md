# AWS Device Farm Cheat Sheet

**AWS Device Farm** ช่วยให้คุณสามารถตรวจสอบและโต้ตอบกับแอปพลิเคชัน Android, iOS และเว็บแอปบน **อุปกรณ์จริง (Physical devices)** ที่ดูแลโดย Amazon Web Services (AWS)

### คุณสมบัติหลัก (Key Features)
* **การทดสอบแอปแบบอัตโนมัติ (Automated App Testing):** คุณสามารถอัปโหลดชุดทดสอบที่เขียนเอง หรือใช้การทดสอบความเข้ากันได้แบบสำเร็จรูป (Script-free) โดยระบบจะรันการทดสอบพร้อมกันหลายอุปกรณ์เพื่อให้ทราบผลในไม่กี่นาที พร้อมรายงานสรุป Log, รูปภาพ Screenshot แบบพิกเซลต่อพิกเซล และตัวชี้วัดประสิทธิภาพ
* **การโต้ตอบผ่านการเข้าถึงระยะไกล (Remote Access Interaction):** ช่วยให้คุณโต้ตอบกับอุปกรณ์จริงได้แบบเรียลไทม์ผ่านเว็บเบราว์เซอร์ มีประโยชน์มากในการทดสอบการใช้งานจริงหรือช่วยลูกค้าตั้งค่าอุปกรณ์
* **สภาพแวดล้อมในโลกจริง (Real-World Environments):** ปรับแต่งสภาพแวดล้อมการทดสอบได้ เช่น ตำแหน่งที่ตั้ง (Location), ภาษา, การเชื่อมต่อเครือข่าย และการติดตั้งแอปที่จำเป็นอื่นๆ เพื่อจำลองสถานการณ์จริงของผู้ใช้
* **การเชื่อมต่อกับเวิร์กโฟลว์การพัฒนา:** รองรับการใช้งานร่วมกับ IDE และระบบ CI (Continuous Integration) ผ่าน Plugin และ API เพื่อเริ่มการทดสอบและรับผลลัพธ์โดยอัตโนมัติ
* **สภาพแวดล้อมที่กำหนดเองสำหรับเว็บ:** รองรับการทดสอบเว็บแอปบนเบราว์เซอร์เดสก์ท็อป (Chrome, Firefox, Edge) พร้อมระบุเวอร์ชันได้
* **การบันทึกวิดีโอ:** บันทึกวิดีโอความละเอียดสูงในทุกเซสชันการทดสอบ ทั้งแบบอัตโนมัติและแบบแมนนวล (Manual)

---

### คำศัพท์ที่สำคัญ (Terminology)
* **Device Pool:** กลุ่มของอุปกรณ์ที่มีคุณสมบัติร่วมกัน เช่น แพลตฟอร์มเดียวกัน หรือรุ่นเดียวกัน
* **Job:** คำขอให้ Device Farm ทดสอบแอป 1 แอป บนอุปกรณ์ 1 เครื่อง
* **Project:** พื้นที่ทำงานหลักที่รวบรวมการรัน (Runs) ต่างๆ เอาไว้
* **Run:** คำขอทดสอบแอป 1 แอป บนอุปกรณ์หลายเครื่อง (ประกอบด้วยหลาย Job)
* **Metering:** การเรียกเก็บเงินตามการใช้งานอุปกรณ์

---

### การเลือกอุปกรณ์ (Device Selection)
* **ตัวเลือกที่หลากหลาย:** มีทั้งเบราว์เซอร์เดสก์ท็อป และอุปกรณ์มือถือ iOS, Android และ Fire OS
* **อุปกรณ์จริง:** ใช้ทรัพยากรอุปกรณ์จริงใน AWS Cloud ที่มีการอัปเดตอยู่เสมอ
* **Private Devices:** สามารถจองอุปกรณ์เฉพาะสำหรับทีมของคุณเท่านั้น เพื่อผลลัพธ์ที่แม่นยำและความพร้อมใช้งานที่สูงกว่า

---

### ประเภทการทดสอบ (Test Types)
* **Framework ที่รองรับ:** Appium (Java, Python), Calabash, Espresso, XCTest และอื่นๆ
* **Fuzz Testing:** จำลองเหตุการณ์สุ่มจากผู้ใช้ (แตะ, ปัด, หมุนเครื่อง) เพื่อหาจุดที่แอปค้าง (Crash)
* **Built-in Explorer:** บอทอัตโนมัติที่จะสำรวจหน้าจอต่างๆ ของแอปและบันทึกจุดที่ผิดพลาดโดยที่คุณไม่ต้องเขียนสคริปต์เอง
* **Selenium:** รองรับสคริปต์ Selenium WebDriver สำหรับการทำ Automation บนเว็บเบราว์เซอร์เดสก์ท็อป

---

### รายงานการทดสอบ (Test Reports)
ให้รายงานโดยละเอียดซึ่งรวมถึง:
* **ตัวชี้วัดประสิทธิภาพ:** การใช้ CPU, ปริมาณการใช้หน่วยความจำ (Memory), การสิ้นเปลืองแบตเตอรี่ และความเร็วในการเรนเดอร์เฟรมภาพ
* **Timeline View:** ลำดับเหตุการณ์ตามเวลาเพื่อให้ง่ายต่อการ Debug
* **Raw Logs:** สามารถดาวน์โหลด Log ของอุปกรณ์และเครือข่ายออกมาวิเคราะห์เองได้

---

### ค่าบริการ (Pricing)
* คิดค่าบริการตาม **เวลาทั้งหมด (นาที)** ที่ใช้ในการรันการทดสอบอุปกรณ์
* จ่ายตามจริงเมื่อสิ้นเดือน ไม่ต้องมีข้อผูกมัดหรือสัญญาโครงการระยะยาว

---

### ความปลอดภัย (Security)
* **การล้างข้อมูล (Sanitization):** หลังจากทดสอบเสร็จ AWS จะทำการล้างข้อมูลในอุปกรณ์ (Wipe data) และรีเซ็ตการตั้งค่าใหม่ เพื่อให้อุปกรณ์พร้อมสำหรับการใช้งานถัดไปในสถานะที่สะอาด
* **VPC Endpoints:** ควบคุมทราฟฟิกของอุปกรณ์ผ่าน AWS PrivateLink เพื่อความปลอดภัยระดับเครือข่าย
* **การแยกส่วน (Isolation):** แยกการทำงานของแต่ละแอปในระหว่างการทดสอบ เพื่อป้องกันการแทรกแซงข้อมูลระหว่างกัน
