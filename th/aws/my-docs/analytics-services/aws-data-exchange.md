# AWS Data Exchange Cheat Sheet

**AWS Data Exchange** เป็นบริการที่ช่วยให้ผู้ใช้สามารถค้นหา สมัครใช้งาน (Subscribe) และใช้งานข้อมูลจากบุคคลที่สาม (Third-party data) บนคลาวด์ได้
* มีแคตตาล็อกส่วนกลางที่ **ผู้ให้บริการข้อมูล (Data Providers)** สามารถเผยแพร่ผลิตภัณฑ์ข้อมูล และ **ผู้สมัครใช้งานข้อมูล (Data Subscribers)** สามารถค้นหาและสมัครสมาชิกได้
* คุณสามารถค้นหาและใช้ชุดข้อมูลสาธารณะที่เป็นส่วนหนึ่งของโปรแกรม **Open Data on AWS** ได้ทั้งแบบมีหรือไม่มีบัญชี AWS

---

### แนวคิดหลัก (Concepts)

#### 1. ข้อมูล (Data)
AWS Data Exchange จัดระเบียบข้อมูลโดยใช้ 3 ส่วนประกอบหลัก:
* **Assets (สินทรัพย์):** ชิ้นส่วนของข้อมูล
* **Revisions (ฉบับปรับปรุง):** ตัวบรรจุสินทรัพย์อย่างน้อยหนึ่งรายการขึ้นไป
* **Data sets (ชุดข้อมูล):** ชุดของฉบับปรับปรุงอย่างน้อยหนึ่งรายการขึ้นไป
* *ประเภทของสินทรัพย์จะเป็นตัวกำหนดวิธีการส่งมอบข้อมูลไปยังผู้สมัครใช้งาน*

#### 2. ผลิตภัณฑ์ (Product)
* คือหน่วยในการแลกเปลี่ยนบน AWS Data Exchange ซึ่งเผยแพร่โดยผู้ให้บริการและเปิดให้ผู้สมัครใช้งานเข้าถึง
* ผลิตภัณฑ์ที่เผยแพร่จะถูกแสดงรายการใน **AWS Marketplace** ด้วย
* **องค์ประกอบของผลิตภัณฑ์:** รายละเอียดผลิตภัณฑ์, ข้อเสนอ (Offers) และชุดข้อมูล

#### 3. ผู้สมัครใช้งาน (Subscriber)
* ผลิตภัณฑ์ข้อมูลทั้งหมดอยู่บนระบบ **การสมัครสมาชิก (Subscription)**
* หากผู้ให้บริการยกเลิกการเผยแพร่ผลิตภัณฑ์ คุณจะยังคงเข้าถึงชุดข้อมูลได้ตราบเท่าที่การสมัครสมาชิกของคุณยังไม่หมดอายุ
* **Bring Your Own Subscription (BYOS):** สามารถย้ายและจัดการการสมัครสมาชิกที่มีอยู่เดิมกับผู้ให้บริการที่เข้าร่วมได้โดยไม่มีค่าธรรมเนียมเพิ่มเติม
* สามารถแชร์สิทธิ์การใช้งาน (Licenses) ผลิตภัณฑ์ข้อมูลให้กับบัญชีอื่นภายใน **AWS Organization** เดียวกันได้

#### 4. ผู้ให้บริการ (Provider)
* ผู้ให้บริการสามารถให้สิทธิ์เข้าถึงผลิตภัณฑ์ที่ยังไม่ได้เปิดเผยต่อสาธารณะได้
* **Extended Provider Program (EPP):** โปรแกรมสำหรับผู้ให้บริการที่ต้องการเผยแพร่ข้อมูลที่มีข้อมูลส่วนบุคคลที่ละเอียดอ่อนภายใต้ข้อกำหนดที่เข้มงวด
* **Offers (ข้อเสนอ):** กำหนดเงื่อนไขที่ผู้สมัครใช้งานต้องยอมรับเมื่อสมัครสมาชิก รวมถึงข้อเสนอแบบส่วนตัว (Private offers) และข้อเสนอแบบ BYOS

#### 5. งาน (Jobs)
* คือการดำเนินการนำเข้า (Import) หรือส่งออก (Export) ข้อมูลแบบอซิงโครนัส (Asynchronous)
* รายการงานจะถูกลบหลังจากสร้างครบ 90 วัน
* ทั้งผู้ให้บริการและผู้สมัครใช้งานสามารถส่งออกฉบับปรับปรุงของชุดข้อมูลไปยัง **Amazon S3** bucket ที่มีสิทธิ์เข้าถึงได้

---

### ความปลอดภัย (Security)
* AWS Data Exchange จะสแกนไฟล์ออบเจ็กต์ใน Amazon S3 ที่ผู้ให้บริการเผยแพร่ก่อนจะเปิดให้ผู้สมัครใช้งานเข้าถึง (สำหรับวิธีการส่งมอบแบบไฟล์)
* บริการไม่ได้รับประกันว่าข้อมูลจะปราศจากมัลแวร์ 100% แต่ผู้ใช้สามารถหาผลิตภัณฑ์ด้านความปลอดภัยเพิ่มเติมได้ใน AWS Marketplace

---

### ค่าบริการ (Pricing)
* **ผู้สมัครใช้งาน (Data Subscribers):** จ่ายค่าผลิตภัณฑ์ข้อมูลที่สมัครสมาชิก แบ่งเป็นแบบรายครั้ง/รายเดือน (Subscription-based) และแบบจ่ายตามการใช้งานจริง (Pay-as-you-go) *นอกจากนี้ยังต้องจ่ายค่าบริการ AWS อื่นๆ ที่ใช้ในการจัดเก็บหรือประมวลผลข้อมูลด้วย*
* **ผู้ให้บริการ (Data Providers):** จ่ายค่าจัดเก็บข้อมูล (Storage) ของผลิตภัณฑ์ และมีค่าธรรมเนียมการดำเนินการ (Fulfillment fee) สำหรับการสมัครสมาชิกใหม่แต่ละรายการ
* **ค่าถ่ายโอนข้อมูล (Data Transfer):** หากมีการนำเข้าหรือส่งออกข้อมูลข้าม Region หรือส่งออกผ่าน Signed URL ไปยังอินเทอร์เน็ต จะมีค่าใช้จ่ายในการถ่ายโอนข้อมูลตามปกติของ Amazon S3
