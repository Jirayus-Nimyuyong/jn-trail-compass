# Amazon QuickSight Cheat Sheet

**Amazon AppFlow** เป็นบริการรวมข้อมูล (Integration Service) ที่ช่วยให้กระบวนการรับส่งข้อมูลระหว่างแอปพลิเคชันภายนอก (SaaS) และบริการต่างๆ ของ AWS เป็นไปอย่างอัตโนมัติและปลอดภัย โดยไม่ต้องเขียนโค้ด

### คุณสมบัติเด่น (Features)
* **การซิงค์ข้อมูล:** รัน Flow ตามความต้องการ (On-demand) หรือตามตารางเวลาเพื่อให้ข้อมูลระหว่าง SaaS และ AWS ตรงกันเสมอ
* **การรวมข้อมูล:** รวบรวมข้อมูลจากหลายแหล่งเพื่อนำไปเทรนเครื่องมือวิเคราะห์ (Analytics) ได้อย่างมีประสิทธิภาพและประหยัดค่าใช้จ่าย
* **เครื่องมือจัดการ Flow:** ติดตามได้ว่าข้อมูลถูกย้ายไปที่ไหนและเมื่อไหร่
* **ความปลอดภัย:** ข้อมูลถูกเข้ารหัสทั้งขณะจัดเก็บ (At rest) และระหว่างรับส่ง (In transit)
* **AWS PrivateLink:** รองรับการโอนถ่ายข้อมูลผ่านเครือข่ายส่วนตัวของ AWS แทนการส่งผ่านอินเทอร์เน็ตสาธารณะ
* **Custom Connectors:** ใช้ SDK (Java/Python) เพื่อสร้างตัวเชื่อมต่อสำหรับ API ส่วนตัว หรือระบบ On-premise
* **การเชื่อมต่อกับบริการอื่น:** * ทำงานร่วมกับ **Glue Data Catalog** เพื่อใช้ในการวิเคราะห์ข้อมูล
    * รองรับการทำ **S3 Partitioning** เพื่อให้คิวรีข้อมูลได้เร็วขึ้น
    * ส่งเหตุการณ์สถานะของ Flow ไปยัง **Amazon EventBridge**
* **ประสิทธิภาพ:** รองรับข้อมูลสูงสุด **100 GB ต่อการรันหนึ่งครั้ง**
* **ตัวเชื่อมต่อ SaaS:** รองรับมากกว่า 50 รายการ (เช่น Facebook Ads, Zendesk, Stripe, Salesforce)

### แนวคิดหลัก (Concepts)

#### 1. การเชื่อมต่อ (Connections)
* ให้สิทธิ์การเข้าถึงต้นทางและปลายทางเพื่อเปิดให้ข้อมูลไหลผ่าน
* เก็บรายละเอียดการตั้งค่าและข้อมูลประจำตัว (Credentials) เช่น Username, Password, API Tokens
* ใน AWS CLI และ API จะเรียกการเชื่อมต่อนี้ว่า **Connector Profiles**
* สามารถใช้ **KMS Keys** ที่ลูกค้าจัดการเองเพื่อเข้ารหัส Access Tokens ได้

#### 2. การจัดการข้อมูล (Data Mapping & Tasks)
* **Data Mapping:** กำหนดว่าฟิลด์จากต้นทางจะถูกย้ายไปลงฟิลด์ไหนในปลายทาง
* **Concatenation:** รวมหลายฟิลด์จากต้นทางเป็นฟิลด์เดียวในปลายทาง
* **Masking:** ปิดบังข้อมูลที่ละเอียดอ่อน (เช่น แสดงเป็นเครื่องหมายดอกจัน `*`)
* **Truncation:** ตัดความยาวของฟิลด์ให้เหลือตามที่กำหนด
* **Filtering:** ใช้ตัวกรองเพื่อควบคุมว่าระเบียน (Records) ใดบ้างที่จะถูกส่งไปยังปลายทาง

#### 3. ตัวจุดชนวน (Triggers)
กำหนดว่า Flow จะเริ่มรันเมื่อไหร่:
* **Run on-demand:** สั่งรันด้วยตัวเองทุกครั้งที่ต้องการย้ายข้อมูล
* **Run on event:** รันเมื่อเกิดการเปลี่ยนแปลงในแอป SaaS (รองรับ Change Data Capture - CDC)
* **Run on schedule:** รันตามตารางเวลาที่กำหนดซ้ำๆ
    * **Full transfer:** ส่งข้อมูลทั้งหมด ณ เวลานั้น (Snapshot)
    * **Incremental transfer:** ส่งเฉพาะข้อมูลที่เพิ่มหรืออัปเดตใหม่นับจากการรันครั้งล่าสุดที่สำเร็จ

### ค่าบริการ (Pricing)
* คิดค่าบริการตาม **จำนวนครั้งที่มีการรัน Flow** (Flow runs)
* คิดค่าบริการ **การประมวลผลข้อมูล** (Data processing) สำหรับ Flow ที่มีปลายทางอยู่บน AWS หรือใช้ PrivateLink
* มีค่าบริการมาตรฐานในการขอใช้ (Requests) และการจัดเก็บข้อมูล (Storage) เมื่ออ่าน/เขียนจากบริการของ AWS
* มีค่าใช้จ่ายเพิ่มเติมหากมีการใช้งาน **AWS KMS** เพื่อเข้ารหัสข้อมูล
