# AWS Glue Data Quality Cheat Sheet

**AWS Glue Data Quality** เป็นบริการสำหรับตรวจสอบและวัดคุณภาพของข้อมูล โดยเป็นส่วนหนึ่งของบริการ AWS Glue และถูกสร้างขึ้นบนเฟรมเวิร์กโอเพนซอร์สที่ชื่อว่า **DeeQu**

* รองรับการตรวจสอบคุณภาพข้อมูลบนตารางประเภท Iceberg, Delta Lake และ Hudi ที่จัดการโดย **AWS Lake Formation**
* เชื่อมต่อกับตารางใน **Amazon SageMaker AI Lakehouse** เพื่อการวิเคราะห์และกำกับดูแลที่รวมเป็นหนึ่งเดียว
* สามารถใช้งานร่วมกับ **Zero-ETL Integrations** เพื่อตรวจสอบความถูกต้องของข้อมูลที่นำเข้าจากบริการอื่นๆ ของ AWS ที่รองรับ

### กรณีการใช้งาน (Use Cases)
* วิเคราะห์ชุดข้อมูลที่ถูกจัดทำดัชนีไว้ใน **AWS Glue Data Catalog**
* เฝ้าติดตามคุณภาพของข้อมูลใน **Data Lake** อย่างต่อเนื่อง
* เพิ่มขั้นตอนการตรวจสอบคุณภาพข้อมูลเข้าไปในงาน **AWS Glue ETL** แบบดั้งเดิม
* ใช้ภาษาเฉพาะทางที่เรียกว่า **Data Quality Definition Language (DQDL)** เพื่อกำหนดกฎเกณฑ์คุณภาพข้อมูล
* จัดระเบียบและรายงานผลลัพธ์คุณภาพข้อมูลข้ามทีมหรือข้ามโดเมนโดยใช้การติดป้ายกำกับกฎ (**Labeled rules**)
* ตรวจสอบข้อมูลที่นำเข้าผ่าน **Zero-ETL Pipelines** โดยไม่ต้องสร้างระบบตรวจสอบเอง

### คุณสมบัติเด่น (Features)
* **Serverless:** ไม่ต้องจัดการเซิร์ฟเวอร์ AWS จะดูแลส่วนนี้ให้ทั้งหมด
* **Quick Start:** วิเคราะห์ข้อมูลและสร้างกฎคุณภาพข้อมูลให้คุณอย่างรวดเร็ว
* **Data Quality Issues Detection:** ใช้ Machine Learning เพื่อระบุปัญหาคุณภาพข้อมูลที่อาจเกิดขึ้น
* **Rule Customization:** มีกฎสำเร็จรูปให้เลือกใช้กว่า 25 แบบ และอนุญาตให้คุณสร้างกฎของตัวเองได้
* **Data Quality Score:** ให้คะแนนสรุปภาพรวมคุณภาพข้อมูลทั้งหมดของคุณ
* **Bad Data Identification:** ระบุระเบียน (Records) ที่เป็นต้นเหตุทำให้คะแนนคุณภาพข้อมูลลดลงได้อย่างแม่นยำ
* **Pay as you go:** จ่ายตามการใช้งานจริง ไม่มีค่าใช้จ่ายล่วงหน้าหรือข้อผูกมัดระยะยาว
* **No lock-in:** สร้างขึ้นบน DeeQu ซึ่งเป็นโอเพนซอร์ส ทำให้มีความยืดหยุ่นสูง
* **Rule Labeling:** รองรับการติดป้ายกำกับกฎ เพื่อจัดกลุ่ม กรอง และรายงานผลตามหมวดหมู่ ทีม หรือโดเมน
* **Constants in DQDL:** รองรับการใช้ค่าคงที่ (Constants) ในสคริปต์ DQDL ช่วยลดขนาดคิวรีและทำให้ชุดกฎขนาดใหญ่บำรุงรักษาได้ง่ายขึ้น
* **Pre-processing Queries:** อนุญาตให้ใช้ SQL Query เพื่อเตรียมหรือกรองข้อมูลก่อนที่กฎคุณภาพข้อมูลจะถูกประเมินผล
* **Automatic Column Statistics:** สร้างสถิติระดับคอลัมน์โดยอัตโนมัติ เพื่อเพิ่มความแม่นยำในการทำ Profile และประเมินผลกฎ

### ค่าบริการ (Pricing)
* ค่าบริการคิดตามทรัพยากรที่ใช้และระยะเวลาที่รันระบบ
* การเพิ่มการตรวจสอบคุณภาพข้อมูลในงาน ETL อาจทำให้ระยะเวลารันงานนานขึ้นหรือใช้ DPU มากขึ้น
* ค่าบริการมาตรฐานอยู่ที่ **$0.44 ต่อ DPU-hour**
* อาจมีค่าใช้จ่ายเพิ่มเติมเมื่อประเมินกฎกับชุดข้อมูลขนาดใหญ่ หรือเมื่อใช้งานร่วมกับงาน AWS Glue ETL ที่มีการบริโภค DPU เพิ่มขึ้น
