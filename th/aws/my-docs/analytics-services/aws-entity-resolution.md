# AWS Entity Resolution Cheat Sheet

**AWS Entity Resolution** เป็นบริการแบบ Managed เต็มรูปแบบที่ช่วยให้องค์กรสามารถจับคู่ เชื่อมโยง และยกระดับข้อมูลจากแหล่งข้อมูลลูกค้า ผลิตภัณฑ์ ธุรกิจ หรือสุขภาพที่หลากหลาย โดยจะช่วยจัดการกระบวนการรวมข้อมูลโดยการระบุข้อมูลที่ซ้ำกันและรวมบันทึกข้อมูลที่กระจัดกระจายเข้าด้วยกัน

* บริการนี้มีเทคนิคการจับคู่ทั้งแบบ **ใช้กฎ (Rule-based)**, **ใช้ Machine Learning** และ **ใช้ข้อมูลจากผู้ให้บริการภายนอก (Third-party)** เพื่อให้ได้ชุดข้อมูลที่เป็นหนึ่งเดียวและมีคุณภาพสูง
* รองรับการเข้ารหัสข้อมูลเพื่อความปลอดภัยและการปฏิบัติตามข้อกำหนด (Compliance)
* การปรับปรุงคุณภาพข้อมูลช่วยให้ตัดสินใจได้ดีขึ้น สร้างโปรไฟล์ลูกค้าที่สมบูรณ์ขึ้น และทำให้การดำเนินงานคล่องตัวขึ้น

---

### คุณสมบัติเด่น (Features)

* **ลดการเคลื่อนย้ายข้อมูล:** อ่านข้อมูลจากแหล่งที่ข้อมูลนั้นตั้งอยู่ (เช่น S3) ช่วยลดการถ่ายโอนข้อมูลที่ไม่จำเป็น
* **การนำเข้าข้อมูลและการแมป Schema ที่ยืดหยุ่น:**
    * รองรับแหล่งข้อมูลขาเข้าสูงสุด 20 แหล่ง
    * สามารถทำงานกับชุดข้อมูลที่เข้ารหัสได้
    * Schema สามารถดึงมาจาก AWS Glue หรือกำหนดเองก็ได้
    * มีการทำ **Normalization** ในตัว (เช่น การตัดช่องว่าง, การปรับเป็นตัวพิมพ์เล็ก) ซึ่งเปิดใช้งานเป็นค่าเริ่มต้น
* **Workflow การจับคู่ที่กำหนดค่าได้:** รองรับทั้งแบบใช้กฎ, ใช้ ML หรือใช้ข้อมูลจากผู้ให้บริการ (Data-provider) พร้อมระบบตรวจสอบสถานะงานที่ง่ายดาย
* **เทคนิคการจับคู่:**
    * **Rule-based:** กำหนดกฎเองตามลำดับความสำคัญ และส่งผลลัพธ์เป็นกลุ่มที่มี Tag ระบุไว้
    * **ML-powered:** ใช้โมเดลที่กำหนดค่าไว้ล่วงหน้าพร้อมคะแนนความเชื่อมั่น (0.0–1.0)
    * **Data Service Provider:** เชื่อมต่อกับชุดข้อมูลภายนอก เช่น LiveRamp และ UID2 (ต้องสมัครสมาชิกกับผู้ให้บริการแยกต่างหาก)
* **Advanced Fuzzy Matching:** รองรับการจับคู่แบบคลุมเครือ (เช่น Levenshtein, Cosine Similarity, Soundex) พร้อมกำหนดเกณฑ์ความคลาดเคลื่อนสำหรับคำที่พิมพ์ผิดหรือการเขียนที่ต่างกัน
* **Near Real-time Lookup:** ใช้ **GetMatchID API** เพื่อทำ Hash ข้อมูล PII ที่เข้ามาและคืนค่า Match IDs ช่วยให้ใช้งานแอปพลิเคชันแบบเรียลไทม์ได้ เช่น การทำ Personalization หรือการตรวจจับทุจริต

### กรณีการใช้งาน (Use Cases)
* **ทำความสะอาดข้อมูล (Data deduplication):** ลบระเบียนที่ซ้ำกันเพื่อเตรียมข้อมูลสำหรับการวิเคราะห์หรือการรันโมเดล AI
* **สร้างโปรไฟล์ลูกค้าแบบ 360 องศา:** เชื่อมโยงปฏิสัมพันธ์ของลูกค้าที่กระจัดกระจายให้เป็นโปรไฟล์เดียว
* **การตลาดและการโฆษณา:** แปลงหรือเพิ่ม ID จากผู้ให้บริการ เช่น LiveRamp หรือ UID2 เพื่อการกำหนดกลุ่มเป้าหมายและการวัดผลแคมเปญ
* **ยกระดับประสบการณ์ลูกค้า:** การจับคู่แบบเรียลไทม์ช่วยให้การแนะนำสินค้าตรงใจขึ้น ปรับปรุงการดูแลผู้ป่วย หรือตรวจจับการฉ้อโกงได้ดีขึ้น

---

### ความปลอดภัย (Security)
* **การเข้ารหัสข้อมูล:** ใช้คีย์ที่ AWS เป็นเจ้าของโดยค่าเริ่มต้น หรือเลือกใช้คีย์ KMS ของลูกค้าเองเพื่อการควบคุมที่มากขึ้น
* **VPC & PrivateLink:** เชื่อมต่อผ่าน Interface Endpoints และเรียกใช้ API ได้อย่างปลอดภัยจากภายใน VPC
* **IAM Integration:** ควบคุมสิทธิ์อย่างละเอียดผ่านนโยบาย IAM รองรับการเข้าถึงข้ามบัญชี และการควบคุมระดับทรัพยากร (ใช้ **Service Roles** ไม่ใช่ Service-linked roles)
* **การตรวจสอบ (Audit):** บันทึกการกระทำผ่าน API ทั้งหมดใน **AWS CloudTrail** และบันทึก Log ของ Workflow ลงใน **CloudWatch**

### ค่าบริการ (Pricing)
* **การจับคู่แบบ Rule-based หรือ ML-powered:** $0.25 ต่อ 1,000 ระเบียนที่ประมวลผล
* **การจับคู่ผ่านผู้ให้บริการ (Data service provider):** $0.10 ต่อ 1,000 ระเบียนที่ประมวลผล (ไม่รวมค่าสมาชิกของผู้ให้บริการรายนั้นๆ)
* **หมายเหตุ:** **ไม่มี Free Tier** สำหรับบริการ AWS Entity Resolution
