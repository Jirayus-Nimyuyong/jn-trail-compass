# AWS Glue DataBrew Cheat Sheet
**AWS Glue DataBrew** เป็นเครื่องมือที่ถูกออกแบบมาเพื่อเพิ่มความคล่องตัวในกระบวนการวิเคราะห์ข้อมูล
* ช่วยให้คุณโต้ตอบกับข้อมูลได้โดยตรง โดยไม่จำเป็นต้องเขียนโค้ดที่ซับซ้อน
* มีคลัง "สูตรสำเร็จในการแปลงข้อมูล" (Transformations) กว่า 250 แบบ ช่วยในการทำความสะอาด ปรับมาตรฐาน และจัดรูปแบบข้อมูลให้พร้อมสำหรับการวิเคราะห์
* รองรับกฎคุณภาพข้อมูล (Data Quality Rules) และการตรวจจับข้อมูลส่วนบุคคล (PII) เพื่อตรวจสอบความถูกต้องและปกปิดข้อมูลที่ละเอียดอ่อน
* เชื่อมต่อกับ **Amazon AppFlow** เพื่อดึงข้อมูลจาก SaaS เช่น Salesforce, Zendesk, Slack และ ServiceNow
* ติดตามต้นกำเนิดและการเปลี่ยนแปลงของข้อมูลผ่าน **Visual Data Lineage** เพื่อการกำกับดูแลและการตรวจสอบย้อนกลับที่ดีขึ้น

### AWS Glue DataBrew มักถูกใช้เพื่อ:
* ลดเวลาที่ใช้ในการเตรียมข้อมูลสำหรับ Analytics และ Machine Learning
* ทำงานเตรียมข้อมูลให้เป็นอัตโนมัติด้วยชุดการแปลงข้อมูลที่พร้อมใช้งานทันที
* ส่งเสริมการทำงานร่วมกันระหว่าง Business Analysts, Data Scientists และ Data Engineers
* สำรวจและแปลงข้อมูลดิบจำนวนมหาศาลโดยไม่ต้องจัดการโครงสร้างพื้นฐานเอง

### คุณสมบัติเด่น (Features)

#### 1. การแปลงข้อมูล (Transformations)
* มีฟังก์ชันกว่า 250 แบบ เช่น การกรองแถว, การแทนที่ค่า, การแยกหรือรวมคอลัมน์ และการใช้เทคนิค NLP เพื่อแยกประโยค
* รองรับการทำ **Cryptographic Hash** เพื่อแปลงข้อมูลคอลัมน์ที่ละเอียดอ่อนให้เป็นรหัสที่ไม่ระบุตัวตน (Anonymizing) อย่างปลอดภัย
* มีกฎคุณภาพข้อมูลในตัว และตรวจจับ PII เช่น อีเมล, เบอร์โทรศัพท์, บัตรเครดิต หรือเลขบัตรประชาชนได้อัตโนมัติ

#### 2. รูปแบบและแหล่งข้อมูล (Data Formats & Sources)
* รองรับ CSV, JSON, Parquet และ **Apache ORC** (ทั้งขาเข้าและขาออก)
* อ่านข้อมูลจาก S3, Redshift และ RDS ได้ รวมถึงรองรับการใช้ **Custom SQL** จาก Redshift และ Snowflake เพื่อจำกัดและเพิ่มประสิทธิภาพในการสแกนชุดข้อมูลขนาดใหญ่

#### 3. งานและการจัดตารางเวลา (Job & Scheduling)
* สร้าง Job เพื่อทำงานเตรียมข้อมูลอัตโนมัติและตั้งเวลาล่วงหน้าได้
* **Profile Jobs:** สร้างสถิติคุณภาพข้อมูลและข้อมูลเชิงลึกในระดับคอลัมน์ที่สามารถกำหนดค่าได้เอง

#### 4. ความปลอดภัย (Security)
* ทำงานร่วมกับ **IAM** เพื่อควบคุมการเข้าถึง ข้อมูลทั้งหมดจะถูกเข้ารหัสทั้งในขณะรับส่ง (In transit) และขณะจัดเก็บ (At rest)
* ควบคุมการเข้าถึงแบบละเอียด (Fine-grained access control) ผ่าน IAM Policy สำหรับทั้งชุดข้อมูล, Job และ Recipe

#### 5. การเชื่อมต่อ (Integration)
* เชื่อมต่อกับ AWS Glue (ETL), QuickSight (Visualization) และ SageMaker (ML)
* เขียนข้อมูลที่แปลงแล้วกลับไปยัง AWS Glue Data Catalog, Redshift, S3 และปลายทาง **JDBC** (เช่น MySQL, PostgreSQL, Oracle, SQL Server)
* รองรับการทำงานร่วมกับ **AWS Lake Formation** สำหรับตารางที่อยู่บน S3

### ส่วนประกอบหลัก (Components)
* **Project:** พื้นที่ทำงานของคุณที่รวมชุดข้อมูล, การแปลงข้อมูล และกระบวนการที่ตั้งเวลาไว้เข้าด้วยกัน
* **Dataset:** คอลเลกชันของข้อมูลที่จัดระเบียบเป็นแถวและคอลัมน์
* **Recipe:** ชุดคำสั่งหรือขั้นตอนที่ DataBrew จะดำเนินการกับข้อมูล (หนึ่ง Recipe มีได้หลายขั้นตอน)
* **Job:** กระบวนการรันคำสั่งจาก Recipe เพื่อแปลงข้อมูลจริงตามตารางเวลาที่ตั้งไว้
* **Data Lineage:** หน้าจออินเทอร์เฟซแบบภาพที่แสดงเส้นทางไหลของข้อมูลจากแหล่งต้นทาง
* **Data Profile:** รายงานฉบับสมบูรณ์เกี่ยวกับลักษณะและคุณภาพของข้อมูลที่ DataBrew สร้างขึ้น
* **Data Quality Rules:** กฎการตรวจสอบที่คุณกำหนดเองเพื่อควบคุมความถูกต้องของข้อมูลตามความต้องการทางธุรกิจ

* **Job Execution:** คิดตามจำนวนโหนดที่ใช้ ในราคาโหนดละ $0.48 ต่อชั่วโมง
* ราคาอาจแตกต่างกันไปตาม AWS Region
