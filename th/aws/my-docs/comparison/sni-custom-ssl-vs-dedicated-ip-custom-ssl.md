# การเปรียบเทียบรูปแบบการใช้ SSL บน CloudFront

### **Server Name Indication (SNI) Custom SSL**
* อาศัยส่วนขยาย **SNI** ของโปรโตคอล TLS ซึ่งช่วยให้หลายโดเมนสามารถให้บริการทราฟฟิก SSL ผ่าน **IP Address เดียวกัน** ได้
* ให้ระดับความปลอดภัยในระดับเดียวกับการใช้ Dedicated IP Custom SSL
* หากคุณกำหนดค่า CloudFront ให้รองรับ HTTPS โดยใช้ SNI ระบบจะเชื่อมโยงชื่อโดเมนรองของคุณเข้ากับ IP Address ของแต่ละ Edge Location โดย IP Address จะถูกกำหนดในระหว่างการเจรจา SSL/TLS Handshake และ **ไม่ได้ถูกจองไว้ (Dedicated)** ให้กับ Distribution ของคุณเพียงผู้เดียว
* **ข้อจำกัด:** เบราว์เซอร์รุ่นเก่าบางตัวไม่รองรับ SNI และจะไม่สามารถสร้างการเชื่อมต่อกับ CloudFront เพื่อโหลดเนื้อหาในรูปแบบ HTTPS ได้
* **ค่าใช้จ่าย:** คุณสามารถใช้ SNI Custom SSL ได้โดย **ไม่มีค่าธรรมเนียม** รายเดือนหรือค่าธรรมเนียมแรกเข้าสำหรับการจัดการใบรับรอง (Certificate)

---

### **Dedicated IP Custom SSL**
* มีประโยชน์หลักสำหรับ **เบราว์เซอร์ที่ไม่รองรับ SNI**
* สำหรับฟีเจอร์นี้ เครือข่ายการส่งเนื้อหาของ Amazon จะจัดสรร **IP Address เฉพาะ (Dedicated IP)** เพื่อใช้บริการเนื้อหา SSL ของคุณในแต่ละ Edge Location
* คุณต้องอัปโหลดใบรับรอง SSL และเชื่อมโยงเข้ากับ CloudFront Distribution ของคุณ
* คุณสามารถเชื่อมโยงใบรับรอง SSL ได้มากกว่า 2 ใบกับบัญชี AWS ของคุณ โดยการยื่นแบบฟอร์มขอเพิ่มขีดจำกัด (CloudFront Limit Increase Form)
* **ข้อดี:** วิธีนี้ใช้งานได้กับทุกคำขอ HTTPS **ไม่ว่าผู้ใช้จะใช้เบราว์เซอร์หรือโปรแกรมรับชมใดก็ตาม**
* **ค่าใช้จ่าย:** เนื่องจากมีต้นทุนเพิ่มจากการจัดสรร IP Address เฉพาะต่อใบรับรอง SSL ทาง AWS จึงคิดค่าธรรมเนียมคงที่รายเดือนที่ **600 ดอลลาร์สหรัฐ** ต่อหนึ่งใบรับรอง โดยคิดราคาเฉลี่ยตามชั่วโมงการใช้งานจริง (Pro-rated)
* คุณสามารถเปลี่ยนไปใช้ SNI แทนได้ทุกเมื่อเพื่อยกเลิกค่าใช้จ่ายที่เกี่ยวข้องกับการใช้ Dedicated IP
