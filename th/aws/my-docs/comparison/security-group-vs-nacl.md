# การเปรียบเทียบ Security Group และ Network ACL

| หัวข้อ | Security Group (กลุ่มความปลอดภัย) | Network ACL (รายการควบคุมการเข้าถึงเครือข่าย) |
| :--- | :--- | :--- |
| **ระดับการทำงาน** | ทำหน้าที่เป็นไฟร์วอลล์สำหรับ **Amazon EC2 instances** ที่เกี่ยวข้อง | ทำหน้าที่เป็นไฟร์วอลล์สำหรับ **Subnets** (เซกเมนต์ของเครือข่าย) ที่เกี่ยวข้อง |
| **ขอบเขตการควบคุม** | ควบคุมทราฟฟิกทั้งขาเข้าและขาออกใน **ระดับอินสแตนซ์** | ควบคุมทราฟฟิกทั้งขาเข้าและขาออกใน **ระดับซับเน็ต** |
| **ลำดับชั้นการป้องกัน** | คุณสามารถป้องกันอินสแตนซ์ใน VPC ได้โดยใช้เพียง Security Group | Network ACL เป็นชั้นการป้องกันเพิ่มเติม (Layer of defense) |
| **ประเภทของกฎ** | รองรับเฉพาะกฎการ **อนุญาต (Allow)** เท่านั้น | รองรับทั้งกฎการ **อนุญาต (Allow)** และกฎการ **ปฏิเสธ (Deny)** |
| **สถานะ (State)** | **Stateful:** ทราฟฟิกขากลับจะได้รับอนุญาตโดยอัตโนมัติ ไม่ว่ากฎจะเป็นอย่างไร | **Stateless:** ทราฟฟิกขากลับต้องถูกกำหนดอนุญาตไว้อย่างชัดเจนในกฎ |
| **การประเมินกฎ** | ประเมินกฎ **ทั้งหมด** ก่อนตัดสินใจว่าจะอนุญาตทราฟฟิกหรือไม่ | ประเมินกฎ **ตามลำดับหมายเลข** เริ่มจากหมายเลขที่ต่ำที่สุด |
| **ผลกระทบ** | มีผลเฉพาะกับอินสแตนซ์ที่เชื่อมโยงกับมันเท่านั้น | มีผลกับ **ทุกอินสแตนซ์** ที่อยู่ในซับเน็ตที่เชื่อมโยงกับมัน |
| **การแยกกฎ** | แยกกฎสำหรับทราฟฟิกขาเข้าและขาออกออกจากกัน | แยกกฎสำหรับทราฟฟิกขาเข้าและขาออกออกจากกัน |

### **พฤติกรรมเริ่มต้น (Default Behaviors)**

**Security Group:**
* Security Group ที่สร้างขึ้นใหม่จะ **ปฏิเสธ (Deny) ทราฟฟิกขาเข้าทั้งหมด** โดยค่าเริ่มต้น
* Security Group ที่สร้างขึ้นใหม่จะมีกฎขาออกที่ **อนุญาต (Allow) ทราฟฟิกขาออกทั้งหมด** โดยค่าเริ่มต้น
* อินสแตนซ์ที่อยู่ใน Security Group เดียวกันจะ **ไม่สามารถคุยกันได้** จนกว่าคุณจะเพิ่มกฎอนุญาต
* Security Group จะเชื่อมโยงกับ **Network Interfaces (ENI)**
* **Default Security Group ของ VPC:** จะอนุญาตทราฟฟิกขาเข้าจากอินสแตนซ์ในกลุ่มเดียวกัน และอนุญาตทราฟฟิกขาออกทั้งหมด

**Network ACL (NACL):**
* **Default NACL:** จะ **อนุญาต (Allow)** ทราฟฟิกขาเข้าและขาออกทั้งหมดโดยค่าเริ่มต้น
* **Custom NACL (สร้างเอง):** จะ **ปฏิเสธ (Deny)** ทราฟฟิกขาเข้าและขาออกทั้งหมด จนกว่าคุณจะเพิ่มกฎอนุญาต
* ทุกซับเน็ตใน VPC ต้องเชื่อมโยงกับ NACL หากไม่ได้ระบุไว้ ระบบจะเลือก Default NACL ให้โดยอัตโนมัติ
* NACL หนึ่งอันสามารถเชื่อมโยงกับหลายซับเน็ตได้ แต่ **หนึ่งซับเน็ตสามารถเชื่อมโยงกับ NACL ได้เพียงอันเดียวเท่านั้น** ในเวลาเดียวกัน
* ทุก NACL จะมีกฎที่แก้ไขหรือลบไม่ได้ซึ่งมีหมายเลขเป็น **ดอกจัน (*)** ทำหน้าที่ปฏิเสธทราฟฟิกที่ไม่ตรงกับกฎหมายเลขอื่นๆ
