### **S3 Transfer Acceleration (TA)**
* **S3 Transfer Acceleration** ช่วยให้การรับส่งข้อมูลผ่านอินเทอร์เน็ตสาธารณะไปยัง S3 เร็วขึ้น โดยใช้ประโยชน์จากเครือข่าย **AWS Edge Locations** ของ Amazon CloudFront ที่กระจายอยู่ทั่วโลก
* **ไม่มีการรับประกัน** ว่าจะเร็วขึ้นเสมอไป หากระบบประเมินว่า S3 TA ไม่ได้เร็วกว่าการส่งแบบปกติไปยังภูมิภาคปลายทาง AWS จะไม่คิดค่าธรรมเนียมสำหรับธุรกรรมนั้น
* **ไม่เหมาะสำหรับ** งานที่ทนต่อการหยุดชะงักของการรับส่งข้อมูลไม่ได้
* รองรับความปลอดภัยและฟีเจอร์เหมือนการส่งข้อมูลปกติ รวมถึงรองรับ **Multi-part upload**

**การเปรียบเทียบ:**
* **S3 TA vs AWS Snow\*:** ตระกูล Snow เหมาะกับการย้ายข้อมูลก้อนใหญ่ทีเดียว แต่ถ้าการย้ายข้อมูลผ่านอินเทอร์เน็ตใช้เวลาเกินหนึ่งสัปดาห์ หรือเป็นงานที่ต้องส่งต่อเนื่องและมีแบนด์วิดท์มากกว่า 25Mbps บริการ S3 TA จะเป็นตัวเลือกที่ดี
* **S3 TA vs Direct Connect:** Direct Connect เหมาะสำหรับผู้ที่ต้องการเครือข่ายส่วนตัว (Private) ส่วน S3 TA เหมาะสำหรับการส่งข้อมูลจากไคลเอนต์ที่กระจายอยู่ทั่วโลกผ่านอินเทอร์เน็ตสาธารณะ
* **S3 TA vs VPN:** ใช้ VPN เมื่อต้องการให้ทรัพยากรอยู่ในเครือข่ายส่วนตัว และสามารถใช้ S3 TA ควบคู่เพื่อเพิ่มความเร็วได้
* **S3 TA vs Multipart Upload:** ใช้ Multipart Upload เมื่อไฟล์มีขนาดใหญ่เพื่อให้จัดการการส่งที่ล้มเหลวได้ดีขึ้น (ส่งเฉพาะส่วนที่เสียใหม่ได้) ซึ่งสามารถใช้ร่วมกับ S3 TA ได้เลย

### **AWS Direct Connect**
* ข้อมูลที่เดิมต้องส่งผ่านอินเทอร์เน็ตจะถูกส่งผ่าน **การเชื่อมต่อเครือข่ายทางกายภาพแบบส่วนตัว (Private)** ระหว่าง AWS กับดาต้าเซ็นเตอร์ของคุณ ทราฟฟิกจะวิ่งอยู่บนเครือข่ายหลัก (Backbone) ของ AWS ตลอดเวลา
* **ข้อดี:** ลดต้นทุน, เพิ่มแบนด์วิดท์ และเครือข่ายมีความเสถียรมากกว่าอินเทอร์เน็ต
* รองรับทั้ง **IPv4 และ IPv6** บน Virtual Interface เดียวกัน แต่ **ไม่รองรับ Multicast**
* **ไม่มีความซ้ำซ้อน (Not redundant) ในตัวเอง:** หากต้องการความทนทานต้องติดตั้งสายที่สอง และควรเปิดใช้งาน **Bidirectional Forwarding Detection (BFD)** เพื่อให้ตรวจพบปัญหาและสลับสาย (Failover) ได้เร็ว
* **Direct Connect vs IPsec VPN:** VPN ส่งข้อมูลผ่านอินเทอร์เน็ต (ตั้งค่าง่าย, แบนด์วิดท์ต่ำถึงปานกลาง) ส่วน Direct Connect ใช้สายส่วนตัว (ไม่ผ่านอินเทอร์เน็ต) สามารถใช้ทั้งสองอย่างร่วมกันเพื่อความปลอดภัยและการเชื่อมต่อที่เสถียรได้

### **AWS VPN**
ประกอบด้วย 2 บริการหลัก:
1. **AWS Site-to-Site VPN:** เชื่อมต่อเครือข่าย On-premises หรือสาขาเข้ากับ Amazon VPC อย่างปลอดภัย
2. **AWS Client VPN:** เชื่อมต่อผู้ใช้งานรายบุคคลเข้ากับ AWS หรือเครือข่าย On-premises
* ข้อมูลจะถูก **เข้ารหัส (Encrypted)** ก่อนส่งผ่านอินเทอร์เน็ต เพื่อรักษาความลับและความถูกต้องของข้อมูล
* ความเร็ว (Throughput) ขึ้นอยู่กับหลายปัจจัย เช่น ประสิทธิภาพของ Gateway, ขนาดแพ็กเกจ และความหน่วงของเครือข่าย
* เซสชันทั้งหมดเป็นแบบ **Full-tunnel VPN** (ไม่สามารถทำ Split tunnel ได้ในบางกรณี)

### **Snowball Edge**
* เป็นโซลูชันขนส่งข้อมูลระดับ **Petabyte** โดยใช้อุปกรณ์ฮาร์ดแวร์ที่ปลอดภัยเพื่อย้ายข้อมูลเข้าและออกจาก AWS
* **ข้อดี:** ค่าเครือข่ายถูกลง, ระยะเวลาโอนย้ายสั้นลง และมีความปลอดภัยสูง (เข้ารหัส 256-bit)
* **การกำหนดค่าอุปกรณ์:**
    * **Storage Optimized:** เน้นพื้นที่เก็บข้อมูล (สูงสุด 80-100 TB)
    * **Compute Optimized:** เน้นพลังประมวลผล (52 vCPUs, 208 GiB RAM)
    * **Compute Optimized with GPU:** เหมือนด้านบนแต่มี GPU สำหรับงานประมวลผลกราฟิกหรือ AI
* ข้อมูลที่ขนส่งจะถูกนำไปเก็บไว้ใน **Amazon S3** เมื่ออุปกรณ์ไปถึงศูนย์ AWS
* สามารถนำมาทำเป็น **Cluster** (5-10 เครื่อง) เพื่อใช้งานเป็นที่เก็บข้อมูลและประมวลผลในพื้นที่ (Local) โดยมีความทนทานของข้อมูลสูงถึง 99.999%
* **ข้อกำหนด:** ต้องส่งข้อมูลให้เสร็จภายใน **360 วัน** นับจากวันที่เตรียมอุปกรณ์
* **ไม่สามารถ** ส่งข้อมูลออก (Export) จาก S3 Glacier โดยตรงได้ ต้องทำการกู้คืน (Restore) มาที่ S3 ก่อน

### **Snowmobile**
* คือ Snowball Edge รุ่นยักษ์ที่มาในรูปแบบของ **รถบรรทุก**
* เป็นบริการย้ายข้อมูลระดับ **Exabyte** รองรับได้สูงสุด **100PB ต่อคัน**
* **ความปลอดภัยขั้นสูง:** มีเจ้าหน้าที่รักษาความปลอดภัยเฉพาะทาง, ติดตามด้วย GPS, มีระบบเตือนภัย, กล้องวงจรปิด 24/7 และอาจมีรถคุ้มกันระหว่างเดินทาง
* ข้อมูลจะถูกอัปโหลดเข้า S3 หรือ Glacier เมื่อถึงภูมิภาค AWS ที่กำหนด
* **Snowball Edge vs Snowmobile:** * หากข้อมูล > 10PB ในที่เดียว ให้ใช้ Snowmobile
    * หากข้อมูล < 10PB หรือกระจายอยู่หลายที่ ให้ใช้ Snowball Edge
* **Snowmobile ไม่รองรับการส่งข้อมูลออก (Export)** หากต้องการส่งข้อมูลออกจาก AWS ให้ใช้ Snowball Edge แทน
* เมื่อโอนย้ายและตรวจสอบเสร็จสิ้น AWS จะลบข้อมูลในอุปกรณ์ด้วยซอฟต์แวร์ตามมาตรฐาน NIST
