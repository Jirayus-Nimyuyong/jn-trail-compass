# การเปรียบเทียบ Amazon S3 และ Amazon S3 Glacier

* **Amazon S3** เป็นบริการจัดเก็บข้อมูลที่มีความทนทาน ปลอดภัย เรียบง่าย และรวดเร็ว ในขณะที่ **Amazon S3 Glacier** ใช้สำหรับโซลูชันการเก็บรักษาข้อมูลระยะยาว (Archiving)
* ใช้ **S3** หากคุณต้องการความหน่วงต่ำ (Low Latency) หรือต้องเข้าถึงข้อมูลบ่อยครั้ง ใช้ **S3 Glacier** เพื่อต้นทุนการจัดเก็บที่ต่ำ และในกรณีที่คุณไม่ต้องการเข้าถึงข้อมูลในระดับมิลลิวินาที
* **Glacier** มีตัวเลือกการดึงข้อมูล (Retrieval) 3 รูปแบบ ซึ่งแต่ละแบบจะมีค่าใช้จ่ายและความเร็วในการดึงข้อมูลที่แตกต่างกัน ส่วนใน **S3** คุณสามารถดึงข้อมูลได้ภายในหน่วยมิลลิวินาที
* ทั้ง **S3** และ **Glacier** ถูกออกแบบมาให้มีความทนทาน (Durability) ที่ **99.999999999%** (เลข 9 จำนวน 11 ตัว) โดยกระจายข้อมูลในหลาย Availability Zones
* ทั้ง **S3** และ **Glacier** ถูกออกแบบมาให้มีความพร้อมใช้งาน (Availability) ที่ **99.99%**
* **S3** สามารถใช้โฮสต์เนื้อหาเว็บแบบสแตติก (Static Web Content) ได้ แต่ **Glacier** ทำไม่ได้
* ใน **S3** ผู้ใช้จะสร้างสิ่งที่เรียกว่า **Buckets** แต่ใน **Glacier** ผู้ใช้จะสร้าง **Archives** และ **Vaults**
* คุณสามารถจัดเก็บข้อมูลได้ไม่จำกัดจำนวน (Virtually unlimited) ทั้งใน **S3** และ **Glacier**
* Archive ของ **Glacier** เพียงตัวเดียวสามารถบรรจุข้อมูลได้สูงสุดถึง **40TB**
* **S3** รองรับระบบ Versioning (การจัดเก็บข้อมูลหลายเวอร์ชัน)
* คุณสามารถรันการวิเคราะห์ (Analytics) และคิวรีข้อมูล (Querying) บน **S3** ได้
* คุณสามารถตั้งค่า **Lifecycle Policy** สำหรับอ็อบเจกต์ใน **S3** เพื่อโอนย้ายข้อมูลไปยัง **Glacier** โดยอัตโนมัติ หรือจะอัปโหลดข้อมูลไปยัง **S3** หรือ **Glacier** โดยตรงก็ได้
* **S3 Standard-IA** และ **One Zone-IA** มีการคิดค่าบริการความจุขั้นต่ำที่ **128KB** ต่ออ็อบเจกต์ ส่วน **Glacier** ขั้นต่ำอยู่ที่ **40KB**
* อ็อบเจกต์ใน **S3** มีระยะเวลาการจัดเก็บขั้นต่ำ **30 วัน** (ยกเว้น S3 Standard) ส่วนอ็อบเจกต์ที่เก็บใน **Glacier** มีระยะเวลาขั้นต่ำ **90 วัน** หากอ็อบเจกต์ถูกลบ เขียนทับ หรือเปลี่ยนคลาสก่อนครบกำหนด จะถูกเรียกเก็บค่าใช้งานปกติบวกกับค่าธรรมเนียมตามสัดส่วนของเวลาที่เหลือจนครบกำหนดขั้นต่ำ
* **Glacier** มีค่าธรรมเนียมการดึงข้อมูล (Retrieval fee) ต่อ GB
* คุณสามารถเปลี่ยนคลาสของอ็อบเจกต์จากคลาส **S3** หนึ่งไปยังอีกคลาสหนึ่งได้ แต่อ็อบเจกต์ใน **Glacier** สามารถเปลี่ยนคลาสไปยัง **Glacier Deep Archive** ได้เพียงอย่างเดียวเท่านั้น
* ทั้ง **S3** (Standard, Intelligent-tiering, Standard-IA และ One Zone-IA) และ **Glacier** มีการรับประกันระดับการให้บริการ (**SLA**)
