# AWS CloudTrail vs Amazon CloudWatch Cheat Sheet

* **CloudWatch** คือบริการเฝ้าติดตาม (Monitoring) สำหรับทรัพยากรและแอปพลิเคชันบน AWS ส่วน **CloudTrail** คือบริการเว็บที่บันทึกกิจกรรมการเรียกใช้ API ภายในบัญชี AWS ของคุณ ทั้งคู่เป็นเครื่องมือเฝ้าติดตามที่มีประโยชน์มากใน AWS
* โดยค่าเริ่มต้น CloudWatch จะมีการเฝ้าติดตามขั้นพื้นฐาน (Basic Monitoring) ให้ฟรีสำหรับทรัพยากรต่างๆ เช่น EC2 instances, EBS volumes และ RDS DB instances ในขณะที่ CloudTrail ก็ถูกเปิดใช้งานโดยอัตโนมัติทันทีเมื่อคุณสร้างบัญชี AWS
* คุณสามารถใช้ **CloudWatch** เพื่อรวบรวมและติดตามตัวชี้วัด (Metrics), รวบรวมและเฝ้าติดตามไฟล์ Log รวมถึงการตั้งการแจ้งเตือน (Alarms) ในทางกลับกัน **CloudTrail** จะบันทึกข้อมูลว่า "ใคร" เป็นคนส่งคำขอ, ใช้บริการอะไร, ดำเนินการ (Action) อะไรบ้าง, พารามิเตอร์ที่ใช้คืออะไร และผลลัพธ์ที่ตอบกลับมาจากบริการของ AWS เป็นอย่างไร โดย Log ของ CloudTrail จะถูกนำไปเก็บไว้ใน S3 bucket หรือ CloudWatch Logs log group ตามที่คุณระบุ
* คุณสามารถเปิดใช้งาน **Detailed Monitoring** สำหรับทรัพยากร AWS เพื่อส่งข้อมูลตัวชี้วัดไปยัง CloudWatch ให้ถี่ขึ้นได้ โดยจะมีค่าใช้จ่ายเพิ่มเติม
* CloudTrail จะส่งสำเนา Log ของ **Management Events** (เหตุการณ์ด้านการจัดการ) ให้ฟรี 1 ชุดในแต่ละภูมิภาค (Region) ซึ่งรวมถึงการดำเนินการจัดการทรัพยากรในบัญชี เช่น เมื่อมีผู้ใช้ล็อกอินเข้าสู่ระบบ ส่วนการบันทึก **Data Events** (เหตุการณ์ด้านข้อมูล) จะมีการคิดค่าบริการ ซึ่งรวมถึงการดำเนินการที่เกิดขึ้น "ภายใน" ตัวทรัพยากรเอง เช่น กิจกรรม API ระดับอ็อบเจกต์ใน S3 หรือกิจกรรมการทำงานของฟังก์ชัน Lambda

---

### **ความแตกต่างที่สำคัญ**

* CloudTrail ช่วยให้คุณมั่นใจในเรื่องการปฏิบัติตามกฎระเบียบ (Compliance) และมาตรฐานข้อบังคับต่างๆ
* CloudWatch Logs จะรายงานเกี่ยวกับ Log ของตัวแอปพลิเคชัน ในขณะที่ CloudTrail Logs จะให้ข้อมูลเฉพาะเจาะจงว่าเกิดอะไรขึ้นบ้าง (ใคร ทำอะไร) ภายในบัญชี AWS ของคุณ
* **CloudWatch Events** คือกระแสข้อมูลเหตุการณ์ของระบบแบบเกือบเรียลไทม์ (Near real-time) ที่อธิบายการเปลี่ยนแปลงของทรัพยากร AWS ส่วน **CloudTrail** จะมุ่งเน้นไปที่การเรียกใช้ API ของ AWS ที่เกิดขึ้นในบัญชีของคุณ
* โดยปกติ CloudTrail จะส่งเหตุการณ์ (Event) ภายใน 15 นาทีหลังจากมีการเรียก API ส่วน CloudWatch จะส่งข้อมูลตัวชี้วัดทุกๆ 5 นาทีสำหรับการเฝ้าติดตามขั้นพื้นฐาน และทุกๆ 1 นาทีสำหรับการเฝ้าติดตามแบบละเอียด (Detailed Monitoring) ทั้งนี้ CloudWatch Logs Agent จะส่งข้อมูล Log ทุกๆ 5 วินาทีโดยค่าเริ่มต้น
