# Amazon SageMaker Data Wrangler Cheat Sheet

**Amazon SageMaker Data Wrangler** ช่วยให้การเตรียมข้อมูล (Data Preparation) และการสร้างคุณลักษณะ (Feature Engineering) สำหรับ Machine Learning เป็นเรื่องง่ายขึ้น
* เป็นฟีเจอร์หนึ่งใน **Amazon SageMaker Studio Classic**
* รวมข้อมูลจากแหล่งต่างๆ เข้าด้วยกัน ช่วยให้คุณสำรวจ ล้าง แปลง และแสดงภาพข้อมูล (Visualize) พร้อมทั้งเปลี่ยนขั้นตอนเหล่านี้ให้เป็นระบบอัตโนมัติในเวิร์กโฟลว์ Machine Learning ของคุณ

### ฟังก์ชันการทำงานหลัก (Core Functionalities)

#### 1. การนำเข้าข้อมูล (Import)
* เข้าถึงและนำเข้าข้อมูลจากคลังข้อมูล (Data Warehouse) และ Data Lake บนคลาวด์ เช่น **Amazon S3, Athena, Redshift, Snowflake และ Databricks**
* ชุดข้อมูลที่นำเข้าสามารถมีได้สูงสุด **1,000 คอลัมน์**



#### 2. Data Wrangler Flow
* สร้าง Flow เพื่อออกแบบลำดับขั้นตอนการเตรียมข้อมูล โดยการรวมชุดข้อมูลจากแหล่งต่างๆ และกำหนดการแปลงข้อมูล (Transformations) ที่จำเป็น
* **Transform (การแปลงข้อมูล):** ใช้เครื่องมือมาตรฐานในการล้างข้อมูล เช่น การจัดรูปแบบสตริง เวกเตอร์ และตัวเลข รวมถึงการสร้างฟีเจอร์ใหม่ด้วยเทคนิค Text Embedding หรือ Categorical Encoding

#### 3. ข้อมูลเชิงลึก (Data Insights)
* ตรวจสอบคุณภาพข้อมูลอัตโนมัติและตรวจจับปัญหาที่อาจเกิดขึ้นผ่านรายงาน **Data Quality and Insights** ซึ่งประกอบด้วย 6 ส่วนหลัก:
    * **Summary:** สรุปภาพรวมข้อมูล ค่าที่หายไป (Missing values) รายการที่ไม่ถูกต้อง และจำนวนข้อมูลที่ผิดปกติ (Outliers)
    * **Target column:** วิเคราะห์คอลัมน์เป้าหมายสำหรับการทำนาย และจัดอันดับฟีเจอร์ตามพลังในการพยากรณ์
    * **Quick model:** ให้ค่าประมาณประสิทธิภาพการพยากรณ์ที่คาดหวังของโมเดล
    * **Feature summary:** จัดอันดับฟีเจอร์ตามคะแนนความสามารถในการทำนาย (0 ถึง 1) หากได้คะแนน 1 อาจหมายถึงเกิดปัญหา **Target Leakage** (ฟีเจอร์เปิดเผยข้อมูลที่ปกติไม่ควรมีในเวลาทำนายจริง)
    * **Samples:** ระบุว่าข้อมูลตัวอย่างมีความผิดปกติหรือมีข้อมูลซ้ำหรือไม่
    * **Definitions:** คำอธิบายคำศัพท์ทางเทคนิคที่ใช้ในรายงาน

#### 4. การวิเคราะห์ (Analyze)
* ตรวจสอบความสัมพันธ์ของฟีเจอร์ด้วยเครื่องมือแสดงภาพ (เช่น Scatter plots, Histograms) และเครื่องมือวิเคราะห์ (เช่น Target leakage analysis)
* การวิเคราะห์ทั้งหมดจะทำโดยใช้ข้อมูล **100,000 แถว** จากชุดข้อมูลของคุณ

#### 5. การส่งออก (Export)
* ส่งออกเวิร์กโฟลว์การเตรียมข้อมูลไปยังปลายทางต่างๆ เช่น:
    * **Amazon S3**
    * **Amazon SageMaker Pipelines:** เพื่อทำระบบ ML อัตโนมัติ
    * **Amazon SageMaker Feature Store:** คลังเก็บฟีเจอร์ส่วนกลาง
    * **Python Script:** บันทึกขั้นตอนทั้งหมดเป็นสคริปต์ Python สำหรับเวิร์กโฟลว์ที่กำหนดเอง

### ฟังก์ชันเพิ่มเติม (Additional Functionalities)
* **Pushdown processing:** รันคิวรีโดยตรงบน Athena, Redshift หรือ Snowflake เพื่อประสิทธิภาพที่เร็วขึ้น
* **Custom Code:** รองรับการเขียนโค้ด Python, SQL และ PySpark สำหรับการแปลงข้อมูลขั้นสูง
* **Lineage Tracking:** ติดตามที่มาของข้อมูลเพื่อให้ทุกขั้นตอนสามารถทำซ้ำได้ (Reproducible)

### กรณีการใช้งาน (Use Cases)
* **การเตรียมข้อมูลสำหรับ ML:** ลดความยุ่งยากในการล้างและแปลงข้อมูลด้วยเครื่องมือแบบ Visual
* **เวิร์กโฟลว์อัตโนมัติ:** สร้างขั้นตอนการแปลงข้อมูลที่ใช้ซ้ำได้ในสภาพแวดล้อมการทำงานจริง (Production)
* **การสำรวจข้อมูล (EDA):** ใช้เครื่องมือภาพเพื่อค้นหารูปแบบและความผิดปกติของข้อมูล
* **การตรวจสอบคุณภาพข้อมูล:** ตรวจจับและบรรเทาปัญหาคุณภาพข้อมูลและความลำเอียง (Bias) เพื่อให้การทำนายมีความยุติธรรมมากขึ้น
