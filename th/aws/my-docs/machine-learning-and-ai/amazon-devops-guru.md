# Amazon DevOps Guru Cheat Sheet

**Amazon DevOps Guru** เป็นบริการแบบ Managed เต็มรูปแบบที่ช่วยปรับปรุงประสิทธิภาพและความพร้อมใช้งานของแอปพลิเคชัน
* ช่วยตรวจจับและวิเคราะห์ปัญหาด้านการปฏิบัติงาน (Operational issues) โดยอัตโนมัติ
* ลดภาระในการเฝ้าติดตามด้วยตนเอง โดยการระบุความผิดปกติ (Anomalies) และสร้างคำแนะนำที่นำไปปฏิบัติได้จริง
* ใช้ **Machine Learning** ในการวิเคราะห์ตัวชี้วัด (Metrics), ล็อก (Logs) และเหตุการณ์ (Events) ของแอปพลิเคชัน
* ตรวจจับการเบี่ยงเบนจากพฤติกรรมปกติเพื่อระบุปัญหาที่อาจเกิดขึ้น
* ให้ข้อมูลเชิงลึกทั้งแบบ **Reactive insights** (สำหรับปัญหาปัจจุบัน) และ **Proactive insights** (เพื่อช่วยป้องกันอุบัติการณ์ในอนาคต)
* แจ้งเตือนผู้ใช้เมื่อพบปัญหาที่อาจเกิดขึ้น และให้คำแนะนำที่ชาญฉลาดเพื่อเร่งการแก้ไขปัญหา

---

### คุณสมบัติ (Features)
* **ML-Driven Insights:** ตรวจจับความผิดปกติใน Logs, Metrics, Events และ Traces
* **Proactive + Reactive Insights:** ครอบคลุมบริการต่างๆ เช่น Lambda, EC2, RDS, DynamoDB และอื่นๆ
* **Integration Ready:** ทำงานร่วมกับ CloudWatch, AWS Config, X-Ray, EventBridge และ Systems Manager OpsCenter
* **Auto Configuration:** เฝ้าติดตามทรัพยากรใหม่โดยอัตโนมัติ ไม่ต้องตั้งค่าด้วยตนเอง
* **DevOps Guru for RDS:** ตรวจจับปัญหาเฉพาะทางของฐานข้อมูลและให้แนวทางการแก้ไขที่เหมาะสม

---

### กรณีการใช้งาน (Use Cases)
* การเฝ้าติดตามเชิงรุกสำหรับ Microservices และแอปพลิเคชัน Serverless
* การวินิจฉัยฐานข้อมูลอัจฉริยะ (RDS, Aurora)
* การรับข้อมูลเชิงลึกอัตโนมัติเมื่อประสิทธิภาพการทำงานลดลง
* การลดค่า MTTR (เวลาเฉลี่ยในการแก้ไขปัญหา)
* การแยกแยะหาสาเหตุที่แท้จริง (Root cause) ในสภาพแวดล้อมที่ซับซ้อน

---

### ความปลอดภัย (Security)
* **IAM Integration:** ควบคุมการเข้าถึงอย่างละเอียดผ่าน AWS IAM
* **Service-Linked Role:** สร้างขึ้นโดยอัตโนมัติเพื่อให้ DevOps Guru เข้าถึงข้อมูลได้อย่างปลอดภัย
* **No Public Access:** เข้าถึงได้เฉพาะผ่านเซสชัน API หรือ Console ที่มีการยืนยันตัวตนเท่านั้น
