# Amazon Bedrock AgentCore Gateway Cheat Sheet

**Amazon Bedrock AgentCore Gateway** เป็นบริการแบบ Managed ที่เปลี่ยนแปลงวิธีการที่เอเจนท์ AI ค้นหา เข้าถึง และใช้งานเครื่องมือต่างๆ โดยการจัดทำ "เกตเวย์" ส่วนกลางที่มีความปลอดภัยสำหรับการจัดการและการรันเครื่องมือ (Tools) ทั่วทั้งองค์กรของคุณ

### ภาพรวม (Overview)
Amazon Bedrock AgentCore Gateway ทำหน้าที่เป็นจุดเข้าใช้งานจุดเดียว (Single point of entry) เพื่อให้เอเจนท์ AI ค้นหาและใช้เครื่องมือหรือ API ที่ได้รับอนุมัติ ช่วยเพิ่มความคล่องตัวในการจัดการโดยรวมศูนย์การยืนยันตัวตน การตรวจสอบ และการควบคุมการเข้าถึงสำหรับทุกการโต้ตอบของเอเจนท์ ทำให้เกิดธรรมาภิบาลและความปลอดภัยที่สอดคล้องกันในขณะที่ยังคงความยืดหยุ่นในการพัฒนาของแต่ละทีม

---

### คุณสมบัติของ Amazon Bedrock AgentCore Gateway
* **การจัดการเครื่องมือแบบรวมศูนย์:** มีแคตตาล็อกกลางที่ทีมต่างๆ สามารถลงทะเบียน ทำเวอร์ชัน และจัดการเครื่องมือทั้งหมดที่เอเจนท์ AI สามารถใช้ได้ รองรับการค้นหาเครื่องมืออัตโนมัติ (Discovery) และเก็บบันทึกประวัติการใช้งาน (Audit trail) อย่างละเอียด
* **การควบคุมการเข้าถึงที่ปลอดภัย:** บังคับใช้นโยบายการเข้าถึงแบบละเอียด (Fine-grained) เพื่อควบคุมว่าเอเจนท์ตัวใดสามารถใช้เครื่องมือใดได้บ้าง ภายใต้เงื่อนไขอะไร โดยเชื่อมต่อกับ AWS IAM เพื่อความปลอดภัยสูงสุด
* **การตรวจสอบและวิเคราะห์แบบหนึ่งเดียว:** ช่วยให้มองเห็นรูปแบบการใช้งานเครื่องมือ ตัวชี้วัดประสิทธิภาพ และอัตราข้อผิดพลาดผ่าน Logging ส่วนกลาง ช่วยในการแก้ปัญหาและเพิ่มประสิทธิภาพการจัดสรรทรัพยากร
* **ธรรมาภิบาลระดับองค์กร (Enterprise Governance):** กำหนดนโยบายที่สอดคล้องกันทั่วทั้งองค์กรเกี่ยวกับการจัดการข้อมูล มาตรฐานความปลอดภัย และแนวทางปฏิบัติ เพื่อให้เป็นไปตามข้อกำหนดทางกฎหมาย (Compliance)

---

### กรณีการใช้งาน (Use Cases)
* **การกำหนดมาตรฐานเครื่องมือในองค์กร:** ช่วยให้องค์กรขนาดใหญ่กำหนดมาตรฐานการใช้งานเครื่องมือร่วมกันในหลายทีม ลดความซ้ำซ้อนและเพิ่มความปลอดภัย
* **การประสานงาน Multi-Agent:** จัดการการเข้าถึงเครื่องมือเมื่อมีเอเจนท์หลายตัวจำเป็นต้องใช้ทรัพยากรเดียวกันพร้อมกันในเวิร์กโฟลว์ที่ซับซ้อน
* **ความพร้อมในการตรวจสอบ (Audit Readiness):** รักษาประวัติการโต้ตอบของเอเจนท์อย่างละเอียด ซึ่งจำเป็นมากสำหรับอุตสาหกรรมที่มีกฎระเบียบเข้มงวด เช่น การแพทย์ การเงิน และภาครัฐ
* **เพิ่มประสิทธิภาพให้นักพัฒนา:** มี Portal แบบ Self-service ให้นักพัฒนาค้นหาและเชื่อมต่อเครื่องมือที่ได้รับอนุมัติได้ทันที โดยไม่ต้องกังวลเรื่องการตั้งค่าระบบยืนยันตัวตนหรือการจำกัดปริมาณ (Rate limiting) เอง

---

### การนำไปใช้งาน (Implementation)
* **การตั้งค่าเกตเวย์:** สร้างและกำหนดค่าผ่าน Console, CLI หรือ CloudFormation โดยกำหนดค่าการยืนยันตัวตนและนโยบายเครือข่ายส่วนกลาง
* **การลงทะเบียนเครื่องมือ:** ระบุรายละเอียดเครื่องมือ ข้อกำหนดการยืนยันตัวตน และนโยบายการใช้งาน (เช่น Timeout, Rate limit) ให้กับแต่ละเครื่องมือ
* **การกำหนดนโยบายการเข้าถึง:** กำหนดสิทธิ์ตามตัวตนของเอเจนท์ ประเภทเครื่องมือ หรือช่วงเวลา เพื่อควบคุมการใช้งานในระดับทีมหรือบุคคล
* **การเชื่อมต่อกับระบบเดิม:** เชื่อมเกตเวย์เข้ากับผู้ให้บริการตัวตน (Identity Providers) และระบบเฝ้าติดตามเดิมที่มีอยู่ภายในองค์กร

---

### ความปลอดภัย (Security)
* **การยืนยันตัวตน:** รองรับทั้ง IAM Roles, API Keys และ OAuth Tokens โดยจะตรวจสอบทุกคำขอก่อนอนุญาตให้เข้าถึงเครื่องมือ
* **การปกป้องข้อมูล:** ข้อมูลทั้งหมดที่ผ่านเกตเวย์จะถูกเข้ารหัสระหว่างทาง (TLS 1.2+) และจัดเก็บข้อมูลลับของเครื่องมือใน AWS KMS อย่างปลอดภัย
* **ความปลอดภัยเครือข่าย:** สามารถรันเกตเวย์ภายใน Amazon VPC เพื่อเข้าถึงเครื่องมือภายในองค์กรผ่านเครือข่ายส่วนตัว (PrivateLink) โดยไม่ผ่านอินเทอร์เน็ตสาธารณะ

---

### แนวทางปฏิบัติที่ดีที่สุด (Best Practices)
* **การจัดระเบียบเครื่องมือ:** แบ่งหมวดหมู่และใช้ระบบ Namespace เพื่อให้ค้นหาเครื่องมือได้ง่าย และจัดทำคู่มือการใช้งานที่ชัดเจน
* **การออกแบบนโยบายการเข้าถึง:** ยึดหลักให้สิทธิ์ขั้นต่ำ (Least privilege) และหมั่นตรวจสอบนโยบายการเข้าถึงอย่างสม่ำเสมอ
* **การจัดการวงจรชีวิต (Lifecycle):** กำหนดกระบวนการทำเวอร์ชันและการยกเลิกการใช้งาน (Deprecation) ที่ชัดเจน เพื่อให้ทีมที่ใช้งานเตรียมตัวเปลี่ยนผ่านได้ทัน
* **เพิ่มประสิทธิภาพ:** ติดตามตัวชี้วัดเพื่อหาคอขวดและใช้กลยุทธ์การแคช (Caching) สำหรับข้อมูลที่ถูกเรียกใช้บ่อย

---

### ค่าบริการ (Pricing)
* **รูปแบบการใช้งานจริง (Usage-Based):** คิดราคาตามจำนวนคำขอ (Request) ที่ผ่านเกตเวย์ ปริมาณการประมวลผลข้อมูล และการใช้บริการ AWS ที่เกี่ยวข้อง
* **ส่วนประกอบของต้นทุน:** รวมค่าบริการ API Requests, ระยะเวลาที่ใช้รันเครื่องมือ และค่าโอนถ่ายข้อมูลระหว่างเกตเวย์กับเครื่องมือ
* **ไม่มีค่าใช้จ่ายล่วงหน้า:** ไม่มีการผูกมัดหรือค่าธรรมเนียมขั้นต่ำ โดยตรวจสอบรายละเอียดได้ผ่าน AWS Cost Explorer
