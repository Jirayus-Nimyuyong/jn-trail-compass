# Amazon Textract Cheat Sheet

**Amazon Textract** เป็นบริการวิเคราะห์เอกสารแบบ Managed เต็มรูปแบบ สำหรับตรวจจับและสกัดข้อมูลจากเอกสารที่ถูกสแกน
* คืนค่าข้อมูลที่สกัดออกมาในรูปแบบคู่ Key-Value (เช่น ชื่อ: สมชาย ดีใจ)
* รองรับเอกสารแทบทุกประเภท
* ตรวจจับข้อความภาษาอังกฤษมาตรฐานและสัญลักษณ์ ASCII ได้
* **การเชื่อมต่อ:** ใช้งานร่วมกับ AWS SDKs (Python, Java, Node.js ฯลฯ), AWS CLI และ Boto3
* **รูปแบบไฟล์:** รองรับไฟล์ภาพ (PNG, JPG) และไฟล์ PDF (ทั้งหน้าเดียวและหลายหน้า)
* **ลายมือ:** สามารถตรวจจับลายมือได้หลายภาษา (ไม่ใช่แค่ภาษาอังกฤษ)
* **ทำงานร่วมกับ S3:** สามารถประมวลผลเอกสารที่จัดเก็บใน S3 ได้โดยตรง

### กรณีการใช้งานทั่วไป (Common Use Cases)
* สร้างดัชนีเพื่อการค้นหาเอกสาร (Search Indexes)
* นำเข้าข้อมูลจากเอกสารเข้าสู่แอปพลิเคชันทางธุรกิจ
* สร้างโซลูชันการประมวลผลเอกสารอัตโนมัติ
* สกัดข้อความสำหรับแอปพลิเคชัน NLP (Natural Language Processing)
* การตรวจสอบความถูกต้องและข้อกำหนดของเอกสาร (Compliance)
* **การประมวลผลใบแจ้งหนี้ (Invoice):** สกัดเลขที่ใบแจ้งหนี้, วันที่ และจำนวนเงินรวมโดยอัตโนมัติ
* **การสแกนใบเสร็จ:** จัดหมวดหมู่ค่าใช้จ่ายทางบัญชีอัตโนมัติ
* **การตรวจสอบเอกสารทางกฎหมาย:** ระบุข้อกำหนดในสัญญา, คู่สัญญา และวันที่
* **แบบฟอร์มการแพทย์:** สกัดข้อมูลคนไข้และรหัสทางการแพทย์
* **การย้ายข้อมูล (Data Migration):** ย้ายข้อมูลจากกระดาษแบบเก่าเข้าสู่ฐานข้อมูลที่มีโครงสร้าง

### แนวคิดสำคัญ (Concepts)
* **Confidence Score (คะแนนความเชื่อมั่น):** ระบบจะคืนค่าคะแนนสำหรับทุกองค์ประกอบที่ตรวจพบ เพื่อระบุความน่าจะเป็นที่การทำนายนั้นถูกต้อง
* **การตรวจสอบด้วยคน:** ผลลัพธ์ที่มีคะแนนความเชื่อมั่นต่ำ สามารถส่งต่อไปยัง **Amazon Augmented AI (A2I)** เพื่อให้มนุษย์ช่วยตรวจสอบได้
* **การทำงานแบบอซิงโครนัส (Asynchronous):** ช่วยให้คุณประมวลผลเอกสาร PDF ที่มีจำนวนหลายหน้าได้

### รายละเอียด APIs
1.  **Detect Document Text API:**
    * ใช้เทคโนโลยี OCR เพื่อสกัดข้อความพิมพ์และลายมือ
    * คืนค่าข้อความทั้งหมดในรูปแบบบล็อกบรรทัด (**LINE**) และคำ (**WORD**)
    * เหมาะสำหรับการสกัดข้อความทั่วไปที่ไม่เน้นโครงสร้าง
2.  **Analyze Document API:**
    * สกัดข้อความพิมพ์, ลายมือ รวมถึงข้อมูลในตาราง และคู่ Key-Value จากแบบฟอร์ม
    * คืนค่าความสัมพันธ์ของตารางเพื่อให้ง่ายต่อการประมวลผลต่อ
    * รองรับพารามิเตอร์ `FeatureTypes` (เช่น `["TABLES", "FORMS"]`) เพื่อควบคุมการสกัดข้อมูล

**ฟังก์ชันเพิ่มเติม:**
* **StartDocumentTextDetection / StartDocumentAnalysis:** API แบบอซิงโครนัสสำหรับเอกสารขนาดใหญ่หรือหลายหน้า
* **GetDocumentTextDetection / GetDocumentAnalysis:** ใช้สำหรับดึงผลลัพธ์จากการทำงานแบบอซิงโครนัส

### ค่าบริการ (Pricing)
* **จ่ายตามจริง (Pay-as-you-go):** จ่ายเฉพาะส่วนที่ใช้งานจริง
* ค่าบริการจะแตกต่างกันระหว่าง Detect Document Text API และ Analyze Document API โดยแบบหลังจะมีราคาสูงกว่าเนื่องจากมีความซับซ้อนในการวิเคราะห์โครงสร้างข้อมูล
