# Amazon Titan Cheat Sheet

**Amazon Titan** เป็นตระกูลโมเดลประสิทธิภาพสูงที่ออกแบบมาเพื่อใช้งานทั่วไป ซึ่งได้รับการฝึกฝนล่วงหน้า (Pre-trained) โดย AWS บนชุดข้อมูลมหาศาล โมเดลเหล่านี้ถูกออกแบบมาให้พร้อมใช้งานทันที หรือสามารถนำไปปรับแต่ง (Fine-tune) ด้วยข้อมูลของคุณเอง เพื่อให้เหมาะสมกับงานเฉพาะทางโดยไม่จำเป็นต้องติดป้ายกำกับข้อมูล (Annotate) จำนวนมหาศาล

ตระกูล Titan ประกอบด้วยโมเดล 3 ประเภทหลัก: **Text Generation (สร้างข้อความ)**, **Embeddings (ข้อความและมัลติโมดัล)** และ **Image Generation (สร้างรูปภาพ)**

### คุณสมบัติ (Features)
* เป็นโมเดลพื้นฐาน (Foundation Models) พัฒนาโดย AWS สำหรับงาน Generative AI
* **Titan Text:** รองรับการสรุปความ, การเขียน, การตอบคำถาม (Q&A) และการสร้างโค้ด
* **Titan Embeddings:** แปลงข้อความเป็นเวกเตอร์สำหรับการค้นหาเชิงความหมาย, RAG และการทำ Personalization
* **Titan Image Generator:** สร้างและแก้ไขรูปภาพจากคำสั่งข้อความ (Prompts)
* **ความปลอดภัย:** มีตัวกรองความปลอดภัยในตัวตามหลักการ Responsible AI เพื่อลดผลลัพธ์ที่เป็นอันตราย
* **การปรับแต่ง:** สามารถ Fine-tune โมเดลด้วยข้อมูลของคุณเองเพื่อความต้องการเฉพาะด้าน
* **การเชื่อมต่อ:** เข้าใช้งานได้ผ่าน Amazon Bedrock และรวมเข้ากับเวิร์กโฟลว์ของ AWS ได้ง่าย

---

### กรณีการใช้งาน (Use Cases)
* **การสร้างเนื้อหา:** เขียนคำโฆษณาอัตโนมัติ, ร่างบล็อก และอีเมล โดยใช้ Titan Text
* **การค้นหาเชิงความหมาย (Semantic Search):** สร้างระบบค้นหาที่เข้าใจ "ความหมาย" ของคำถาม (ไม่ใช่แค่คำสำคัญ) โดยใช้ Titan Embeddings
* **การตลาดด้วยภาพ:** สร้างรูปภาพคุณภาพระดับสตูดิโอสำหรับแคมเปญโฆษณา หรือภาพพื้นหลังสินค้า E-commerce
* **RAG (Retrieval Augmented Generation):** ผสมผสาน Titan Text และ Embeddings เพื่อตอบคำถามโดยอ้างอิงจากข้อมูลส่วนตัวของบริษัท
* **การจัดการรูปภาพ:** ลบพื้นหลังออกจากภาพสินค้า หรือเติมรายละเอียดที่ขาดหายไป (Inpainting)

### Amazon Titan Text Models (โมเดลข้อความ)

1. **Titan Text G1 – Premier:**
   * เน้นการสร้างข้อความขั้นสูง การตอบคำถามตามบริบท และการสรุปความ
   * **Max tokens:** 32K | **ภาษา:** อังกฤษ
   * รองรับ Knowledge Base, Agents และการปรับแต่งโมเดล

2. **Titan Text G1 – Express:**
   * ออกแบบมาสำหรับงานภาษาขั้นสูง งานแชท และ RAG
   * **Max tokens:** 8K | **ภาษา:** อังกฤษ (GA), และอีกกว่า 100 ภาษา (Preview)

3. **Titan Text G1 – Lite:**
   * โมเดลน้ำหนักเบาและมีประสิทธิภาพ เน้นการ Fine-tune สำหรับงานสรุปความและเขียนคำโฆษณา
   * **Max tokens:** 4K | **ภาษา:** อังกฤษ

---

### Amazon Titan Text Embeddings Models (โมเดลเวกเตอร์ข้อความ)

* **Titan Text Embeddings V2:**
    * ปรับแต่งมาเพื่อ RAG และการค้นหาเชิงความหมายโดยเฉพาะ
    * สามารถปรับขนาดเวกเตอร์ขาออก (Output dimensions) ได้: 1024, 512, 256 เพื่อรักษาสมดุลระหว่างความแม่นยำและค่าจัดเก็บ
    * **Max tokens:** 8,192
* **Titan Text Embeddings G1:**
    * โมเดลรุ่นแรกสำหรับการค้นหาเชิงความหมายทั่วไป
    * **Output Vector Size:** 1,536 (คงที่)

---

### Amazon Titan Multimodal Embeddings G1
* แปลงทั้ง "ข้อความ" และ "รูปภาพ" (หรือทั้งคู่) ให้อยู่ในพื้นที่เวกเตอร์เดียวกัน
* ช่วยให้สามารถ "ค้นหาด้วยรูปภาพ" หรือค้นหาจาก "ข้อความไปยังรูปภาพ" ได้
* **รองรับ:** รูปภาพขนาดสูงสุด 25 MB | **Output vector:** 1024, 384, 256

---

### Amazon Titan Image Generator G1 (โมเดลสร้างรูปภาพ)

1. **Titan Image Generator v1:**
   * สร้างและแก้ไขรูปภาพจากคำสั่งภาษาธรรมชาติ
   * รองรับ Inpainting/Outpainting (สูงสุด 1,408 x 1,408 px) และ Image Variation (สูงสุด 4,096 x 4,096 px)

2. **Titan Image Generator v2:**
   * รวมฟีเจอร์ของ v1 และเพิ่มความสามารถใหม่:
   * **Image Conditioning:** ใช้ภาพอ้างอิงเพื่อกำหนดโครงสร้างและองค์ประกอบภาพ
   * **Background Removal:** ลบพื้นหลังอัตโนมัติสำหรับภาพที่มีวัตถุหลายชิ้น
   * **Color Palette:** สร้างภาพตามรหัสสี Hex ที่กำหนด
