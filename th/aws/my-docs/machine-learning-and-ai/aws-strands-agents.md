# AWS Strands Agents Cheat Sheet

**AWS Strands Agents** เป็น SDK แบบ **Open-source** ที่ช่วยให้นักพัฒนาสามารถสร้าง ทดสอบ และติดตั้งใช้งานเอเจนท์ AI ได้ง่ายๆ เพียงแค่กำหนด Prompt และรายการเครื่องมือ (Tools) ในโค้ด ชื่อ "Strands" ได้แรงบันดาลใจมาจากเกลียว DNA สองสาย โดยทำหน้าที่เชื่อมต่อองค์ประกอบหลักสองส่วนของเอเจนท์เข้าด้วยกัน นั่นคือ **โมเดล (Model)** และ **เครื่องมือ (Tools)**

เฟรมเวิร์กนี้ใช้ความสามารถในการใช้เหตุผลขั้นสูงของโมเดลเพื่อวางแผนขั้นตอนต่อไปของเอเจนท์และรันเครื่องมือโดยอัตโนมัติ สามารถขยายขอบเขตจากตัวต้นแบบในเครื่องไปสู่ระบบเอเจนท์ที่ซับซ้อนบนคลาวด์ได้

### คุณสมบัติหลักของ Strands Agents
* **Foundation-Driven Intelligence:** ใช้ Foundation Model (FM) เป็นกลไกหลักในการตัดสินใจและวางแผนงานด้วยตนเอง แทนการทำตามสคริปต์ที่กำหนดไว้ตายตัว
* **โปรโตคอลเครื่องมือมาตรฐาน:** รองรับ **Model Context Protocol (MCP)** ช่วยให้การเชื่อมต่อ LLM กับข้อมูลและเครื่องมือภายนอกเป็นไปอย่างสม่ำเสมอและเคลื่อนย้ายได้ง่าย
* **Native AWS Ecosystem:** เชื่อมต่อกับ Amazon Bedrock, AWS Lambda และ AWS Step Functions ได้ทันที เพื่อสร้างเวิร์กโฟลว์อัตโนมัติบน AWS
* **ความยืดหยุ่นของโมเดล:** เลือกใช้โมเดลได้หลากหลาย (เช่น Anthropic Claude หรือตระกูล Amazon Nova) เพื่อให้เหมาะกับงานแต่ละประเภท
* **รองรับหลายรูปแบบ (Multi-Format):** จัดการข้อมูลได้หลากหลาย ทั้งข้อความ เสียง และรูปภาพ เพื่อการโต้ตอบที่สมจริงยิ่งขึ้น

### กรณีการใช้งาน (Use Cases)
* **เวิร์กโฟลว์บน AWS:** สำหรับองค์กรที่ต้องการใช้บริการของ AWS ในการทำงานอัตโนมัติ
* **การใช้งานระดับองค์กร:** สำหรับทีมที่ต้องการความปลอดภัย การขยายตัว และการปฏิบัติตามข้อกำหนด
* **การประสานงานที่ซับซ้อน:** สำหรับสถานการณ์ที่ต้องมีการควบคุมทรัพยากร AWS หลายส่วนในขั้นตอนที่ซับซ้อน

### แนวทางการนำไปใช้งาน
1.  **เลือกโมเดล:** เลือกใช้ Amazon Nova (Premier, Pro, Lite, หรือ Micro) ตามความต้องการ
2.  **กำหนดเครื่องมือ:** สร้างเครื่องมือที่เชื่อมต่อกับระบบองค์กรและแหล่งข้อมูล
3.  **สร้าง Prompt:** กำหนดบุคลิก (Persona) งาน และกฎพฤติกรรมของเอเจนท์
4.  **เปิดใช้ Multimodality:** ให้เอเจนท์ประมวลผลได้ทั้งข้อความ ภาพ และเสียง
5.  **ติดตั้งใช้งาน:** ให้เอเจนท์ตอบคำถามทางธุรกิจและทำงานโดยอัตโนมัติ

### ส่วนประกอบของเอเจนท์ (Agents)
* **Agent Loop:** วงจรภายใน (**Think → Act → Observe**)
    1. รับข้อมูลและบริบทจากผู้ใช้
    2. ประมวลผลด้วย LLM
    3. ตัดสินใจว่าจะใช้เครื่องมือเพื่อเข้าถึงข้อมูลหรือดำเนินการบางอย่างหรือไม่
    4. รันเครื่องมือและรวบรวมผลลัพธ์
    5. ใช้เหตุผลจากข้อมูลใหม่ที่ได้รับ
    6. ให้คำตอบสุดท้ายหรือเริ่มวงจรใหม่หากจำเป็น
* **State (สถานะ):** เก็บข้อมูลประวัติการสนทนา (Conversation History), สถานะของเอเจนท์ (Agent State) และสถานะของคำขอ (Request State)
* **Structured Output:** บังคับให้โมเดลตอบกลับตาม Schema ที่กำหนด (เช่น Pydantic) เพื่อความปลอดภัยของประเภทข้อมูลและไม่ต้องเขียนโค้ดเพื่อ Parse ข้อมูลเอง

### เครื่องมือ (Tools)
* **Tools:** ฟังก์ชันหรือ API ที่เอเจนท์เรียกใช้เพื่อดำเนินการ
* **Model Context Protocol (MCP):** โปรโตคอลเปิดที่ช่วยให้เอเจนท์เชื่อมต่อกับเครื่องมือ บริการ หรือเอเจนท์ตัวอื่นได้อย่างปลอดภัย

### ผู้ให้บริการโมเดล (Model Providers)
* Amazon Bedrock, Anthropic, LiteLLM, LlamaAPI, Ollama, OpenAI และรองรับ **Custom Providers** สำหรับโมเดลส่วนตัวหรือโมเดลเฉพาะทาง

### ระบบ Multi-Agent
* **Agent2Agent (A2A):** โปรโตคอลสำหรับให้เอเจนท์ส่งข้อความหรือมอบหมายงานให้กันและกัน
* **Agents as Tools:** เอเจนท์เฉพาะทางที่ถูกห่อหุ้มไว้เป็นเครื่องมือ เพื่อให้เอเจนท์ตัวหลัก (Orchestrator) มอบหมายงานให้
* **Agent Swarm/Graph/Workflow:** รูปแบบการทำงานร่วมกันของกลุ่มเอเจนท์เพื่อแก้ปัญหาที่ซับซ้อน แบ่งบทบาท และจัดการลำดับขั้นตอนการทำงาน

### ความปลอดภัยและความเป็นส่วนตัว
* **Responsible AI:** แนวทางปฏิบัติเพื่อความโปร่งใสและปลอดภัย
* **Guardrails:** เชื่อมต่อกับ Amazon Bedrock Guardrails เพื่อกรองเนื้อหาที่ไม่เหมาะสม
* **PII Redaction:** ตรวจจับและปกปิดข้อมูลละเอียดอ่อนโดยอัตโนมัติ

---

### เปรียบเทียบ Strands Agents vs. Strands Agents SOPs
* **Strands Agents (SDK):** ไลบรารี Python สำหรับนักพัฒนาที่ต้องการควบคุมการเขียนโปรแกรมอย่างเต็มที่
* **Strands Agents SOPs:** เครื่องมือที่เน้นการกำหนดค่า (Configuration-driven) โดยใช้ภาษาธรรมชาติ "Standard Operating Procedures" เพื่อการรันเวิร์กโฟลว์ที่เคร่งครัด

### ค่าบริการ (Pricing)
* **Strands Agents เป็น Open-source ที่ใช้งานได้ฟรี**
* **ค่าใช้จ่ายที่เกิดขึ้น:** จะมาจากค่าการเรียกใช้โมเดล (Model Inference) ตามจำนวน Token และค่าโครงสร้างพื้นฐานของ AWS (เช่น Lambda, EC2) ที่ใช้รันเอเจนท์
