# Amazon Translate Cheat Sheet

**Amazon Translate** เป็นบริการแปลภาษาด้วยโครงข่ายประสาทเทียม (Neural Machine Translation) ที่ให้การแปลที่สละสลวยและมีความแม่นยำสูงกว่าโมเดลการแปลแบบสถิติหรือแบบกฎเกณฑ์ในสมัยก่อน
* ขับเคลื่อนด้วยโมเดลการเรียนรู้เชิงลึก (Deep Learning) ที่ให้การแปลที่รวดเร็ว แม่นยำ และราคาประหยัดระหว่างภาษาที่รองรับ
* รองรับการแปลแบบกลุ่ม (Batch), แบบเรียลไทม์ และแบบตามความต้องการ (On-demand)

### กรณีการใช้งานทั่วไป (Common Use Cases)
* การปรับเนื้อหาให้เข้ากับภาษาท้องถิ่น (Language localization)
* แปลเนื้อหาเพื่อนำไปวิเคราะห์ข้อความ (Text analytics)
* การสื่อสารข้ามภาษา (Cross-lingual communication)

---

### แนวคิดสำคัญ (Concepts)
Amazon Translate ใช้โมเดลการแปลที่ประกอบด้วย 2 ส่วนหลัก:
* **Encoder (ตัวเข้ารหัส):** อ่านข้อความต้นฉบับทีละคำ และสร้างตัวแทนความหมาย (Semantic representation) ของแต่ละคำขึ้นมา
* **Decoder (ตัวถอดรหัส):** นำตัวแทนความหมายที่สร้างขึ้นมาแปลเป็นภาษาเป้าหมายทีละคำ โดยใช้วิธีที่เรียกว่า **Attention mechanism** เพื่อช่วยแปลคำหรือวลีที่คลุมเครือให้ถูกต้อง
* **การตรวจจับภาษาอัตโนมัติ:** เมื่อเปิดใช้งานระบบนี้ Amazon Translate จะใช้บริการ **Amazon Comprehend** อยู่เบื้องหลังเพื่อตรวจจับภาษาของข้อความต้นฉบับโดยอัตโนมัติ

---

### คุณสมบัติเด่น (Features)
* **รองรับภาษาที่หลากหลาย** ครอบคลุมการใช้งานทั่วโลก
* **Neural-Network Based:** ให้การแปลคุณภาพสูงด้วยเทคโนโลยีการเรียนรู้เชิงลึก
* **Customized Machine Translation:** ปรับแต่งการแปลให้เหมาะกับคำศัพท์เฉพาะทางในธุรกิจของคุณ เพื่อควบคุมโทนเสียง สไตล์ และการเลือกใช้คำ
* **ความปลอดภัย:** การสื่อสารระหว่างแอปพลิเคชันและ Amazon Translate ได้รับการปกป้องด้วย SSL
* **การแปลเอกสารแบบเรียลไทม์:** รองรับการแปลเอกสารทั้งฉบับ (PDF, Word, PowerPoint, HTML) โดยยังคงรักษาการจัดรูปแบบ (Formatting) เดิมไว้
* **การแปลแบบกลุ่ม (Batch) ผ่าน S3:** รองรับงานแปลขนาดใหญ่แบบอซิงโครนัสโดยใช้โฟลเดอร์ Input/Output ใน Amazon S3
* **Terminology Support:** อัปโหลดไฟล์คำศัพท์เฉพาะ (CSV/TMX) เพื่อบังคับการเลือกใช้คำที่ต้องการ
* **Parallel Data Support:** อัปโหลดประโยคตัวอย่างคู่ขนานเพื่อปรับปรุงคุณภาพการแปลให้เหมาะกับเนื้อหาเฉพาะด้าน
* **Formality Control:** เลือกโทนเสียงแบบ **เป็นทางการ (Formal)** หรือ **ไม่เป็นทางการ (Informal)** ได้ในภาษาที่รองรับ
* **การเชื่อมต่อ:** ใช้งานร่วมกับ Amazon Comprehend, S3, Lambda และ SDK เพื่อสร้างเวิร์กโฟลว์อัตโนมัติ
