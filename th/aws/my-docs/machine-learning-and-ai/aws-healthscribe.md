# AWS HealthScribe Cheat Sheet

**AWS HealthScribe** เป็นบริการที่รองรับมาตรฐาน HIPAA ออกแบบมาเพื่อช่วยให้ผู้พัฒนาซอฟต์แวร์ด้านสุขภาพสามารถสร้างแอปพลิเคชันทางคลินิกที่สร้างบันทึกทางการแพทย์เบื้องต้นจากการสนทนาระหว่าง "คนไข้และบุคลากรทางการแพทย์" ได้โดยอัตโนมัติ ขับเคลื่อนโดย Amazon Bedrock ซึ่งช่วยให้การเชื่อมต่อระบบง่ายขึ้นด้วยการใช้การจดจำเสียงและ Generative AI โดยไม่จำเป็นต้องจัดการโครงสร้างพื้นฐาน Machine Learning เอง

> **ข้อจำกัดด้านภูมิภาค:** บริการนี้มีให้ใช้งานเฉพาะในภูมิภาค **US East (N. Virginia) หรือ us-east-1** เท่านั้น ซึ่งหมายความว่าทรัพยากร AWS ของคุณ เช่น Amazon S3 buckets สำหรับเก็บไฟล์เสียงและข้อมูลขาออก จะต้องอยู่ในภูมิภาคเดียวกันนี้เพื่อการทำงานที่เข้ากันได้และมีประสิทธิภาพสูงสุด

---

### คุณสมบัติ (Features)
* **สรุปบันทึกทางคลินิก (Summarized Clinical Notes):** สร้างบันทึกทางการแพทย์แยกตามหัวข้อ เช่น อาการสำคัญ (Chief complaint), ประวัติการเจ็บป่วยปัจจุบัน (History of present illness) และแผนการรักษา (Treatment plan)
* **การสกัดคำศัพท์ทางการแพทย์:** ระบุอาการเจ็บป่วย รายการยา และขั้นตอนการรักษาจากบทสนทนา
* **บันทึกการปรึกษาอย่างละเอียด:** ให้บันทึกการสนทนา (Transcripts) พร้อมเครื่องหมายเวลาในระดับคำสำหรับการโต้ตอบแบบบทต่อบท
* **การระบุบทบาทผู้พูด:** แยกแยะระหว่างเสียงของบุคลากรทางการแพทย์และเสียงของคนไข้
* **การแบ่งส่วนบทสนทนา (Transcript Segmentation):** จัดระเบียบบทสนทนาออกเป็นส่วนที่เกี่ยวข้อง เช่น การคุยทั่วไป (Small talk), ข้อมูลเชิงอัตวิสัย (Subjective) และข้อมูลเชิงวัตถุวิสัย (Objective)
* **การจับคู่หลักฐาน (Evidence Mapping):** เชื่อมโยงประโยคในบันทึกที่สร้างขึ้นไปยังส่วนที่สอดคล้องกันในบทสนทนาต้นฉบับ เพื่อใช้ในการตรวจสอบความถูกต้อง

---

### กรณีการใช้งาน (Use Cases)
* **ลดเวลาการทำเอกสาร:** ช่วยสร้างบันทึกทางคลินิกอัตโนมัติ ทำให้บุคลากรทางการแพทย์ประหยัดเวลาในการทำเอกสาร
* **เพิ่มประสิทธิภาพของผู้ช่วยบันทึกแพทย์ (Medical Scribe):** ช่วยให้ผู้ช่วยบันทึกข้อมูลสามารถสร้างบันทึกที่แม่นยำโดยใช้บทสนทนาที่ AI สร้างขึ้น
* **สร้างสรุปการปรึกษาที่เข้าใจง่ายสำหรับคนไข้:** มอบบทสรุปเพื่อให้คนไข้เข้าใจรายละเอียดการปรึกษาและคำแนะนำได้ง่ายขึ้น

---

### ความปลอดภัย (Security)
* **รองรับมาตรฐาน HIPAA:** มั่นใจได้ว่าองค์กรด้านสุขภาพจะปฏิบัติตามข้อกำหนดทางกฎหมายในการจัดการข้อมูล
* **ความเป็นส่วนตัวของข้อมูล:** AWS **ไม่นำข้อมูลของลูกค้าไปใช้ฝึกโมเดล** และลูกค้าสามารถควบคุมสถานที่จัดเก็บข้อมูลของตนเองได้ทั้งหมด
* **การเข้ารหัสข้อมูล:** ข้อมูลมีการเข้ารหัสทั้งในขณะรับส่งและขณะจัดเก็บ เพื่อรักษาความปลอดภัยและความเป็นส่วนตัวของคนไข้
