# Amazon Personalize Cheat Sheet

**Amazon Personalize** เป็นบริการ Machine Learning แบบ Managed เต็มรูปแบบ สำหรับสร้างระบบแนะนำ (Recommendation Systems)
* ช่วยให้คุณสามารถฝึกฝน (Train), สร้าง และติดตั้งโมเดลการแนะนำได้โดยไม่จำเป็นต้องมีความเชี่ยวชาญด้าน Machine Learning เชิงลึก
* รองรับการให้คำแนะนำทั้งแบบเป็นกลุ่ม (Batch) และแบบเรียลไทม์ (Real-time)

### กรณีการใช้งานทั่วไป (Common Use Cases)
* แนะนำสินค้าและเนื้อหา (Content) แบบเฉพาะบุคคล
* จัดอันดับสินค้า (Product Rankings)
* ปรับปรุงการสื่อสารทางการตลาดผ่านการส่งข้อความแจ้งเตือน (Push Notifications) และอีเมลเฉพาะบุคคล
* ปรับเปลี่ยนการแนะนำแบบเรียลไทม์ตามพฤติกรรมผู้ใช้ที่เปลี่ยนไป
* แนะนำสินค้าที่ใช้คู่กัน (Complementary products) ตามรูปแบบการซื้อ
* ปรับปรุงความเกี่ยวข้องของผลการค้นหาให้เหมาะกับผู้ใช้แต่ละคน
* แนะนำรายการหรือเนื้อหาที่ช่วยเพิ่มความผูกพันของผู้ใช้ (User engagement) และลดการเลิกใช้งาน (Churn)

### แนวคิดสำคัญ (Concepts)
Amazon Personalize สามารถให้คำแนะนำตามข้อมูลเรียลไทม์, ข้อมูลประวัติย้อนหลัง หรือผสมผสานทั้งสองอย่าง
* **Event trackers:** บันทึกการโต้ตอบของผู้ใช้ (User interactions) แบบเรียลไทม์
* **Recipe (สูตร):** หมายถึงอัลกอริทึมที่จะใช้ในการฝึกฝนโซลูชันสำหรับกรณีใช้งานที่กำหนด
    * **USER_PERSONALIZATION:** ปรับแต่งมาเพื่อระบบแนะนำเฉพาะบุคคล
    * **PERSONALIZED_RANKING:** ใช้ Hierarchical Recurrent Neural Network (HRNN) เพื่อจัดลำดับรายการคำแนะนำที่ดีที่สุด (เช่น การจัดอันดับผลการค้นหา)
    * **RELATED_ITEMS:** ทำนายรายการที่คล้ายคลึงกับรายการที่กำหนด
* **Datasets (ชุดข้อมูล):** ประกอบด้วยชุดข้อมูลผู้ใช้ (Users), รายการสินค้า (Items) และการโต้ตอบ (Interactions) ซึ่งจำเป็นต่อการฝึกโมเดล
* **Solution:** โมเดลที่ผ่านการฝึกฝนพร้อมสำหรับการให้คำแนะนำ
* **Campaign:** โซลูชันที่ถูกติดตั้งใช้งานเพื่อการทำ Inference ทั้งแบบเรียลไทม์หรือแบบกลุ่ม
* **Schema:** กำหนดโครงสร้างของชุดข้อมูล (คุณลักษณะและประเภทข้อมูล)

### ค่าบริการ (Amazon Personalize Pricing)
* **จ่ายตามการใช้งานจริง (Pay-per-use):** ไม่มีค่าใช้จ่ายล่วงหน้า
* **รายการเรียกเก็บเงิน:** คิดตามปริมาณการนำเข้าข้อมูล (Data ingestion), การฝึกโมเดล (Training) และการเรียกใช้คำแนะนำ (Inference)
* **ปัจจัยของต้นทุน:** ขึ้นอยู่กับการนำเข้าชุดข้อมูล, การฝึกโมเดล, การติดตั้ง Campaign และการทำ Inference แบบเรียลไทม์
* **ข้อควรระวัง:** ควรคำนึงถึงค่าธรรมเนียมการเก็บรักษาข้อมูล (Data retention) และค่าจัดเก็บข้อมูลสำหรับการใช้งานในระยะยาว
