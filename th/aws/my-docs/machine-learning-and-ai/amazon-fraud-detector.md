# Amazon Fraud Detector Cheat Sheet

**Amazon Fraud Detector** เป็นบริการแบบ Managed เต็มรูปแบบที่ใช้ Machine Learning และความเชี่ยวชาญของ Amazon เพื่อช่วยให้ธุรกิจสามารถระบุและป้องกันการฉ้อโกงออนไลน์ได้ บริการนี้ช่วยให้การสร้าง, การติดตั้งใช้งาน และการจัดการโมเดลตรวจจับการฉ้อโกงเป็นไปอย่างรวดเร็วและมีประสิทธิภาพ แม้กระทั่งสำหรับผู้ที่มีประสบการณ์ด้าน ML จำกัด

---

### คุณสมบัติ (Features)
* **การสร้างโมเดลอัตโนมัติ (Automated Model Creation):** สร้างและฝึกฝนโมเดลตรวจจับการฉ้อโกงแบบปรับแต่งเองจากข้อมูลประวัติย้อนหลังโดยอัตโนมัติ
* **การพยากรณ์แบบเรียลไทม์ (Real-Time Predictions):** ติดตั้งระบบประเมินความเสี่ยงจากการฉ้อโกงสำหรับเหตุการณ์รายบุคคล หรือการประมวลผลแบบกลุ่ม (Batch)
* **เครื่องมือกฎเกณฑ์ที่ปรับแต่งได้ (Customizable Rules Engine):** มอบการตัดสินใจตามกฎเกณฑ์ที่ยืดหยุ่น ซึ่งสามารถรวมเข้ากับโมเดลตรวจจับการฉ้อโกงและข้อมูลนำเข้าจากภายนอกได้
* **การปรับปรุงโมเดลอย่างต่อเนื่อง (Continuous Model Improvement):** โมเดลจะพัฒนาขึ้นเมื่อมีข้อมูลมากขึ้น ช่วยให้การตรวจจับการฉ้อโกงแม่นยำยิ่งขึ้น
* **การเชื่อมต่อกับบริการ AWS:** เชื่อมต่อกับ AWS Lambda, Amazon SageMaker และ Amazon EventBridge ได้ง่าย เพื่อสร้างเวิร์กโฟลว์ที่ขับเคลื่อนด้วยเหตุการณ์ (Event-driven) และขยายขนาดได้

---

### กรณีการใช้งาน (Use Cases)
* **การฉ้อโกงจากการเปิดบัญชีใหม่ (New Account Fraud):** ตรวจจับการลงทะเบียนบัญชีที่ทุจริตในระหว่างขั้นตอนการสมัครใช้งาน
* **การฉ้อโกงด้านการชำระเงิน (Payment Fraud):** ระบุและบล็อกธุรกรรมการชำระเงินที่น่าสงสัยก่อนที่จะมีการประมวลผล
* **การเข้ายึดครองบัญชี (Account Takeover):** ติดธงบัญชีที่ถูกเจาะข้อมูลในระหว่างความพยายามเข้าสู่ระบบ
* **การละเมิดโปรแกรมทดลองใช้และสะสมคะแนน:** ป้องกันการละเมิดสิทธิ์การทดลองใช้ฟรีและข้อเสนอพิเศษจากโปรแกรมสมาชิก
* **การฉ้อโกงจากผู้ขายใน Marketplaces:** ตรวจจับกิจกรรมที่ทุจริตจากผู้ขายในตลาดออนไลน์

---

### ความปลอดภัย (Security)
* **การเข้ารหัสข้อมูล (Data Encryption):** ข้อมูลทั้งหมดจะถูกเข้ารหัสทั้งในระหว่างการรับส่งและขณะจัดเก็บ เพื่อรับรองความลับอย่างสมบูรณ์
* **การควบคุมการเข้าถึง (Access Control):** ใช้ประโยชน์จาก AWS IAM เพื่อจัดการสิทธิ์และการเข้าถึงในระดับละเอียด
* **การเชื่อมต่อส่วนตัว (Private Connectivity):** ใช้ AWS PrivateLink เพื่อการเชื่อมต่อที่เป็นส่วนตัวและปลอดภัยภายใน VPC ของคุณ
* **การปฏิบัติตามข้อกำหนด (Compliance):** สอดคล้องกับมาตรฐานอุตสาหกรรมและกฎระเบียบต่างๆ รองรับความต้องการด้านการปฏิบัติตามข้อกำหนดขององค์กร

---

### ค่าบริการ (Pricing)
* **จ่ายตามจริง (Pay-As-You-Go):** คิดค่าบริการตามจำนวนการทำพยากรณ์การฉ้อโกง, ชั่วโมงการประมวลผล และปริมาณการจัดเก็บข้อมูลที่ใช้
* **สิทธิ์ใช้งานฟรี (Free Tier):** ฟรีสำหรับการทำพยากรณ์การฉ้อโกงสูงสุด 30,000 ครั้งในแต่ละเดือน
* **ไม่มีค่าธรรมเนียมขั้นต่ำ:** โครงสร้างราคาที่ยืดหยุ่นและขยายขนาดได้ โดยไม่ต้องมีข้อผูกมัดหรือค่าใช้จ่ายล่วงหน้า
