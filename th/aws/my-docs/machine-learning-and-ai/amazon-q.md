# Amazon Q Cheat Sheet

**Amazon Q** เป็นผู้ช่วย AI ที่ถูกออกแบบมาให้เป็น Generative AI หมายความว่ามันสามารถสร้างเนื้อหา, แก้ไขปัญหา และปฏิบัติงานต่างๆ โดยใช้ข้อมูลและความเชี่ยวชาญภายในบริษัทของคุณ

### กรณีการใช้งาน (Use Cases)
Amazon Q ออกแบบมาเพื่อระบุคำตอบที่รวดเร็วและตรงประเด็น, ช่วยให้กระบวนการทำงานคล่องตัวขึ้น, เร่งการตัดสินใจ และส่งเสริมความคิดสร้างสรรค์รวมถึงนวัตกรรมในที่ทำงาน

* **ข้อมูลเชิงลึกทางธุรกิจ (Business Insights):** ด้วยการเชื่อมต่อกับ QuickSight, Amazon Q สามารถรวมข้อมูลที่ไม่มีโครงสร้าง (เอกสาร) เข้ากับข้อมูลที่มีโครงสร้าง (แดชบอร์ด/ฐานข้อมูล) เพื่อตอบคำถามเช่น "แนวโน้มรายได้และคำอธิบายสรุปของเราเป็นอย่างไร?"
* **การบริการลูกค้า (Customer Service):** ใน Amazon Connect, Q สามารถตรวจจับเจตนาของลูกค้าและแนะนำหรือสร้างคำตอบระหว่างการแชทสดหรือการโทรศัพท์
* **ห่วงโซ่อุปทาน (Supply Chain):** Q เชื่อมต่อกับ AWS Supply Chain เพื่อวิเคราะห์ข้อมูล (เช่น ความเสี่ยงของสต็อกสินค้า) และให้ข้อมูลเชิงลึกด้านการดำเนินงานและการเงิน
* **Generative BI:** การใช้ Q ใน QuickSight ช่วยสร้างสรุปเนื้อหาอัตโนมัติ, สร้างแดชบอร์ดภาพ และให้ผู้ใช้ทั่วไปที่ไม่ใช่ฝ่ายเทคนิคสามารถถามคำถามเกี่ยวกับข้อมูลด้วยภาษาธรรมชาติได้

### ประเภทของ Amazon Q (Types)
* **Amazon Q Business:** เวอร์ชันที่สามารถปรับแต่งให้เข้ากับธุรกิจของคุณ โดยเชื่อมต่อกับข้อมูล, สารสนเทศ และระบบต่างๆ ภายในบริษัท
* **Amazon Q Developer:** เวอร์ชันที่มอบความเชี่ยวชาญของ Amazon Q สำหรับการสร้างระบบบน AWS
* **Amazon Q ในบริการต่างๆ (Q in Services):**
    * **Q in QuickSight:** สำหรับ Generative BI ในแดชบอร์ดข้อมูล
    * **Q in Connect:** สำหรับการแชท/เสียงในการบริการลูกค้า

### คุณสมบัติ (Features)
* ให้ข้อมูลและคำแนะนำที่เกี่ยวข้องได้ทันที
* เข้าใจและเคารพในตัวตนตามธรรมาภิบาล (Governance Identities) ที่มีอยู่เดิม
* เคารพในบทบาท (Roles) และสิทธิ์การใช้งาน (Permissions) เดิมที่มีอยู่ในระบบ

### ความปลอดภัย (Security)
* ใช้ **AWS Identity Center / IAM** สำหรับการยืนยันตัวตนและการอนุญาตสิทธิ์
* รองรับ **IAM Federation** เพื่อให้คุณสามารถใช้ผู้ให้บริการตัวตน (Identity Provider) เดิมของคุณได้
* ข้อมูลที่ใช้ใน Q (พรอมต์, คำตอบ) จะคงความเป็นส่วนตัวภายในบัญชีของคุณ **AWS จะไม่นำข้อมูลของคุณไปใช้ฝึกโมเดลสำหรับผู้อื่น**
* สำหรับการทำดัชนี (Indexing) Q จะคิดค่าบริการตามความจุของดัชนีแม้ว่าจะไม่ได้ใช้งาน หากลบดัชนีทิ้ง การเรียกเก็บเงินจะหยุดลง

### โมดูลย่อย (Sub-modules)
* **Amazon QuickSight:** ช่วยสร้างภาพข้อมูล (Visuals), แดชบอร์ด และเรื่องราวที่ขับเคลื่อนด้วยข้อมูล
* **Amazon Connect:** ปรับปรุงการบริการลูกค้าโดยตรวจจับเจตนาของลูกค้าโดยอัตโนมัติระหว่างการโทรและแชท
* **AWS Supply Chain:** ให้ข้อมูลเชิงลึกที่ลึกซึ้งยิ่งขึ้นเกี่ยวกับความเสี่ยงสินค้าขาดสต็อกหรือสินค้าล้นสต็อก
