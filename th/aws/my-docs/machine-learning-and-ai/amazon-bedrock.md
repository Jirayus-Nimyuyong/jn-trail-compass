# Amazon Bedrock Cheat Sheet

**Amazon Bedrock** เป็นบริการแบบ Managed เต็มรูปแบบที่รวบรวมโมเดลพื้นฐาน (Foundation Models - FMs) ประสิทธิภาพสูงจากบริษัท AI ชั้นนำผ่าน API เดียว ช่วยให้คุณสร้างและขยายแอปพลิเคชัน Generative AI ที่สามารถสร้างข้อความ, รูปภาพ, เสียง และข้อมูลสังเคราะห์ได้ตามคำสั่ง (Prompts)

### คุณสมบัติหลัก (Key Features)
* **Unified API:** ทดลอง เปรียบเทียบ และประเมินโมเดลต่างๆ สำหรับกรณีใช้งานเฉพาะของคุณผ่าน API เดียว
* **ความเป็นส่วนตัวของข้อมูล:** เนื้อหาของคุณจะไม่ถูกนำไปใช้ปรับปรุงโมเดลฐาน และมีการเข้ารหัสทั้งขณะรับส่ง (In transit) และขณะจัดเก็บ (At rest)
* **Agents:** สร้างเอเจนท์ที่สามารถดำเนินงานโดยใช้ระบบองค์กร, API และแหล่งข้อมูลของคุณ โดยเอเจนท์สามารถใช้เหตุผล วางแผน และดำเนินการหลายขั้นตอนได้
* **Serverless:** ไม่ต้องจัดการ ปรับขนาด หรือเตรียมโครงสร้างพื้นฐานด้วยตนเอง
* **การเชื่อมต่อ:** ใช้งานร่วมกับบริการอื่นๆ ของ AWS เช่น Lambda, S3, IAM, CloudWatch และ VPC ได้อย่างปลอดภัย

---

### ความสามารถในการเลือกโมเดล (Model Choice Capability)
* **Model Catalog:** เข้าถึงโมเดลกว่า 100 แบบจากผู้ให้บริการชั้นนำ เช่น **Amazon, Anthropic, DeepSeek, Mistral AI, Meta**
* **API Keys:** วิธีการยืนยันตัวตนที่ง่ายขึ้น มีทั้งแบบระยะสั้น (หมดอายุใน 12 ชม.) และแบบระยะยาว
* **Import Models:** นำโมเดลที่คุณปรับแต่งเอง (Proprietary) มาใช้บน Bedrock ผ่าน API เดียวกันได้ โดยไม่ต้องจัดการโครงสร้างพื้นฐาน

---

### การประเมินผล (Evaluate)
* **Model Evaluation:**
    * **แบบอัตโนมัติ:** ใช้โปรแกรมวัดผลหรือใช้ "LLM as a judge" (โมเดลตัดสินโมเดล)
    * **แบบใช้มนุษย์:** ใช้ทีมงานของคุณเองในการตรวจสอบและให้คะแนนการตอบสนอง
* **RAG Evaluation:** ประเมินความแม่นยำและความเกี่ยวข้องของ **Knowledge Bases** โดยใช้คะแนนตามหลักการ RAG

---

### การอนุมานและการประมวลผล (Inference)
* **Cross-region Inference:** กระจายคำขอไปยังหลาย Region ในช่วงเวลาที่มีการใช้งานหนาแน่นเพื่อเพิ่มปริมาณงาน (Throughput)
* **Batch Inference:** ประมวลผลคำขอจำนวนมากแบบอซิงโครนัส (Asynchronous) เหมาะสำหรับชุดข้อมูลขนาดใหญ่
* **Provisioned Throughput:** จองกำลังการประมวลผลที่แน่นอนและสม่ำเสมอสำหรับงานระดับ Production ที่ต้องการ Latency ต่ำ

---

### ความสามารถในการเพิ่มประสิทธิภาพต้นทุน (Optimize Cost Capability)
* **Prompt Router Models:** ระบบอัจฉริยะที่จะส่งคำถามไปยังโมเดลที่คุ้มค่าและมีประสิทธิภาพที่สุดในตระกูลเดียวกันโดยอัตโนมัติ
* **Prompt Caching:** บันทึกและนำบริบทขนาดใหญ่ (เช่น เอกสารคู่มือ) กลับมาใช้ซ้ำ ช่วยลด Latency และลดต้นทุนได้สูงสุด 90%
* **Model Distillation:** สร้างโมเดล "นักเรียน" ที่ขนาดเล็กและเร็วกว่า โดยถ่ายทอดความรู้จากโมเดล "ครู" ขนาดใหญ่ ช่วยให้ทำงานเร็วขึ้น 500% และประหยัดขึ้น 75%
* **Prompt Management:** ห้องสมุดส่วนกลางสำหรับสร้าง บันทึก ทำเวอร์ชัน และแชร์ Prompt

---

### ความสามารถในการปรับแต่ง (Customization Capability)
* **Knowledge Bases:** เวิร์กโฟลว์ RAG แบบเบ็ดเสร็จ เชื่อมต่อโมเดลกับข้อมูลของคุณ (S3, Salesforce ฯลฯ) เพื่อให้ได้คำตอบที่แม่นยำและเป็นปัจจุบัน
* **Supervised Fine-Tuning:** ปรับแต่งโมเดลด้วยชุดข้อมูลคู่คำถาม-คำตอบของคุณ เพื่อให้โมเดลมีสำเนียงหรือรูปแบบเฉพาะทาง
* **Reinforcement Fine-Tuning:** ขัดเกลาโมเดลด้วยวงจรการตอบรับ (Feedback loops) เพื่อให้สอดคล้องกับความต้องการของมนุษย์
* **Continued Pre-training:** ฝึกฝนโมเดลด้วยข้อมูลดิบจำนวนมากเพื่อให้คุ้นเคยกับศัพท์เฉพาะทางของโดเมนนั้นๆ

---

### ความสามารถในการพัฒนาเอเจนท์ (Agent Development Capability)
* **Amazon Bedrock Agents:** เอเจนท์ที่จัดการงานหลายขั้นตอนได้เอง
* **Action Groups:** กำหนดการดำเนินการที่เอเจนท์สามารถทำได้ผ่าน API ขององค์กร
* **Multi-Agent Orchestration:** เอเจนท์สามารถเรียกใช้เอเจนท์เฉพาะทางตัวอื่นๆ เพื่อทำงานที่ซับซ้อนร่วมกันได้

---

### ความปลอดภัยและกลไกป้องกัน (Safety and Guardrails)
* **PII Redaction:** ตรวจจับและปกปิดข้อมูลที่ระบุตัวบุคคลได้ในคำตอบของโมเดล
* **Content Filters:** กรองเนื้อหาที่เป็นอันตราย (ความเกลียดชัง, ความรุนแรง ฯลฯ)
* **Denied Topics:** บล็อกไม่ให้โมเดลตอบในหัวข้อที่ห้ามไว้ (เช่น คำแนะนำด้านการเงิน)
* **Contextual Grounding:** ตรวจสอบและกรองการมโน (Hallucination) โดยยืนยันว่าคำตอบอ้างอิงจากข้อมูลต้นฉบับจริงหรือไม่
* **Watermarking:** รูปภาพที่สร้างโดย Amazon Titan จะมีลายน้ำที่มองไม่เห็นเพื่อระบุว่าเป็น AI สร้างขึ้น

---

### ค่าบริการ (Pricing)
* **On-Demand:** จ่ายตามจริงตามจำนวน Token (Input/Output) หรือจำนวนรูปภาพที่สร้าง
* **Batch Inference:** ราคาถูกกว่า On-Demand สำหรับการประมวลผลแบบกลุ่ม
* **Provisioned Throughput:** จ่ายตามกำลังการผลิตที่จองไว้ (สัญญา 1 หรือ 6 เดือน) เหมาะสำหรับงานหนักและสม่ำเสมอ
* **Customization:** คิดค่าใช้จ่ายตามจำนวน Token ที่ใช้ฝึก (Training) และค่าจัดเก็บโมเดลรายเดือน
* **Guardrails:** คิดราคาตามจำนวนตัวอักษรหรือรูปภาพที่ถูกตรวจสอบ
