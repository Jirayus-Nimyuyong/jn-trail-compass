# Amazon Augmented AI (A2I) Cheat Sheet

**Amazon A2I** เป็นบริการที่ช่วยให้คุณรวม "การตรวจสอบโดยมนุษย์" (Human Review) เข้ากับเวิร์กโฟลว์ของ Machine Learning ได้อย่างง่ายดาย
* ช่วยลดความยุ่งยากในการจัดการผู้ตรวจสอบจำนวนมากในระดับสเกล
* เชื่อมต่อโดยตรงกับ **Amazon Textract** และ **Amazon Rekognition**
* โครงสร้างเวิร์กโฟลว์ของ A2I: **HumanLoop → Human Review Workflow → Output Consolidation**
* คุณสามารถกำหนดเงื่อนไขได้ว่าเมื่อใดควรส่งให้มนุษย์ตรวจสอบ (เช่น เมื่อค่าความเชื่อมั่นต่ำกว่า 80%)
* A2I เชื่อมต่อโดยตรงกับ **SageMaker Pipelines** และ **SageMaker Ground Truth**

### กรณีการใช้งานทั่วไป (Common Use Cases)
* **การคัดกรองเนื้อหา (Content Moderation):** เมื่อต้องการให้มนุษย์ช่วยตัดสินผลลัพธ์ที่ไม่แน่ชัดจากโมเดล ML
* **ตรวจสอบการทำนายที่มีความเชื่อมั่นต่ำ:** เช่น เอกสารที่สแกนมาไม่ชัดเจน หรือมีลายมือที่อ่านยาก
* **การตรวจสอบการปกปิดข้อมูล PII:** เพื่อให้แน่ใจว่าข้อมูลที่ละเอียดอ่อนถูกระบุและปกปิดอย่างถูกต้อง โดยเฉพาะในเวิร์กโฟลว์ที่ต้องปฏิบัติตามข้อกำหนดทางกฎหมาย
* **การยืนยันผลการทำนายที่ก้ำกึ่ง:** เพื่อเฝ้าติดตามปัญหา Model Drift (ประสิทธิภาพโมเดลเสื่อมถอย) และรักษาความแม่นยำในระยะยาว
* **ตรวจสอบผล OCR สำหรับเอกสารทางการแพทย์:** เพื่อแก้ไขข้อความที่อ่านผิด หรือความผิดพลาดด้านรูปแบบในงานที่ความแม่นยำเป็นเรื่องวิกฤต

### แนวคิดหลัก (Concepts)

#### 1. ประเภทงาน (Task Type)
ประเภทของงานที่ต้องการให้มนุษย์ตรวจสอบ ได้แก่:
* การสกัดคู่ Key-value จาก **Amazon Textract**
* เนื้อหาที่ไม่ปลอดภัยที่ถูกตรวจพบโดย **Amazon Rekognition**
* เวิร์กโฟลว์ Machine Learning ที่กำหนดเอง (Custom ML workflows)
* **การรีวิวการจำแนกประเภทเอกสาร:** สำหรับตรวจสอบความถูกต้องของการแบ่งหมวดหมู่เอกสารจำนวนมาก
* **การรีวิวความแม่นยำในการสกัดข้อความ:** เจาะจงสำหรับแบบฟอร์ม, ตาราง และลายมือเขียน (Textract AnalyzeDocument)

#### 2. Worker Task Template (เทมเพลตงานสำหรับผู้ปฏิบัติงาน)
เทมเพลตที่ใช้กำหนดชุดคำสั่งให้ผู้ปฏิบัติงานเห็นเมื่อต้องทำภารกิจตรวจสอบ

#### 3. ประเภทของผู้ปฏิบัติงาน (Worker Types)
* **Amazon Mechanical Turk:** บริการ Crowdsourcing ที่ให้คุณจ้างแรงงานออนไลน์ที่กระจายอยู่ทั่วโลกได้ตลอด 24 ชั่วโมง
* **Private (ส่วนตัว):** กลุ่มผู้ปฏิบัติงานที่คุณจัดหามาเอง (เช่น พนักงานภายในบริษัท)
* **Vendor (ผู้ให้บริการภายนอก):** ผู้ให้บริการตรวจสอบโดยมนุษย์จาก **AWS Marketplace**

#### 4. ตัวเลือกการปรับแต่ง UI
รองรับส่วนประกอบต่างๆ เช่น:
* เมนูแบบเลื่อนลง (Dropdowns), กล่องล้อมรอบวัตถุ (Bounding boxes), ตัวเลือกหลายรายการ (Multi-select), ช่องกรอกข้อความอิสระ (Free-text fields)
* **HTML + Liquid templating:** คุณสามารถปรับแต่ง UI สำหรับผู้ปฏิบัติงานได้อย่างเต็มที่ด้วย HTML, CSS และ Liquid

### ค่าบริการ (Amazon Augmented AI Pricing)
* **$0.02 – $0.03** ต่อการตรวจสอบรูปภาพจาก Amazon Rekognition
* **$0.02 – $0.03** ต่อการตรวจสอบหน้าเอกสารจาก Amazon Textract
* **$0.02 – $0.08** ต่อการตรวจสอบวัตถุในเวิร์กโฟลว์แบบกำหนดเอง (Custom workflows)
