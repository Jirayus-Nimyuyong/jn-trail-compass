# Amazon CodeGuru Security Cheat Sheet

**Amazon CodeGuru Security** เป็นเครื่องมือวิเคราะห์แอปพลิเคชันแบบสแตติก (Static Analysis) ที่ใช้ Machine Learning เพื่อระบุช่องโหว่ด้านความปลอดภัยและการละเมิดนโยบาย โดยจะให้คำแนะนำที่นำไปปฏิบัติได้จริงเพื่อลดความเสี่ยง และสร้างตัวชี้วัดเพื่อช่วยติดตามสถานะความปลอดภัยของแอปพลิเคชันของคุณ อ้างอิงจากแนวทางปฏิบัติที่ดีที่สุดด้านความปลอดภัยของ Amazon.com และ AWS มานานหลายปี

### คุณสมบัติ (Features)
* **Static Code Analysis:** ใช้ ML และการให้เหตุผลแบบอัตโนมัติเพื่อตรวจจับปัญหาความปลอดภัยในซอร์สโค้ด (เช่น ข้อผิดพลาดประเภท Injection, การฝังรหัสผ่านไว้ในโค้ด เป็นต้น)
* **Repository Scanning:** สแกนพื้นที่เก็บโค้ด (Repository) ทั้งหมดหรือเฉพาะเจาะจงที่ Pull Requests
* **ML-Based Detectors:** รวมถึงการตรวจจับช่องโหว่ตามมาตรฐาน **OWASP Top 10**
* **CI/CD Integration:** เชื่อมต่อกับ GitHub, Bitbucket และ AWS CodeCommit ได้อย่างราบรื่น
* **Secrets Detector:** ตรวจจับข้อมูลลับที่ถูก Hardcoded ไว้ เช่น API keys, Tokens และรหัสผ่าน
* **Remediation Guidance:** ให้คำแนะนำในการแก้ไขที่นำไปใช้ได้จริง พร้อมตัวอย่างโค้ดและลิงก์เอกสารประกอบ

---

### กรณีการใช้งาน (Use Cases)
* ป้องกันข้อผิดพลาดด้านความปลอดภัยก่อนการติดตั้งใช้งาน (Deployment)
* ปรับปรุงความตระหนักด้านความปลอดภัยของนักพัฒนาผ่านคำแนะนำในบรรทัดโค้ด (Inline suggestions)
* สแกนฐานข้อมูลโค้ดเก่า (Legacy codebases) เพื่อหาช่องโหว่ที่ซ่อนอยู่
* ปฏิบัติตามแนวทางปฏิบัติการเขียนโค้ดที่ปลอดภัยใน CI/CD Pipelines

---

### ความปลอดภัย (Security)
* **IAM Controls:** ปฏิบัติตามหลักการให้สิทธิ์ขั้นต่ำ (Least privilege) ผ่าน IAM roles
* **Data Privacy:** โค้ดจะถูกเข้ารหัสทั้งในขณะจัดเก็บ (At rest) และระหว่างการรับส่ง (In transit)
* **Audit Logging:** เชื่อมต่อกับ **AWS CloudTrail** เพื่อการตรวจสอบย้อนกลับ
* **ไม่มีการแชร์ข้อมูลภายนอก:** โค้ดจะไม่ถูกส่งออกไปนอก AWS การวิเคราะห์ทั้งหมดทำอยู่บนโครงสร้างพื้นฐานของ AWS
