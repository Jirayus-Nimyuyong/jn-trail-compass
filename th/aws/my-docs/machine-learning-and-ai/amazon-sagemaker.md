# Amazon SageMaker AI Cheat Sheet

**Amazon SageMaker AI** เป็นบริการแบบ Managed เต็มรูปแบบที่ช่วยให้นักวิทยาศาสตร์ข้อมูล (Data Scientists) และนักพัฒนาสามารถสร้าง, ฝึกฝน (Train) และติดตั้งใช้งาน (Deploy) โมเดล Machine Learning ในระดับสเกลใหญ่ได้อย่างง่ายดาย
* มีอัลกอริทึมในตัว (Built-in) ที่พร้อมใช้งานทันที
* รองรับอัลกอริทึมที่กำหนดเองผ่าน Docker Containers
* ติดตั้งใช้งานโมเดลได้เพียงคลิกเดียว (One-click deployment)

---

### แนวคิดหลัก (Concepts)
* **Hyperparameters:** ชุดตัวแปรที่ควบคุมการฝึกโมเดล เปรียบเสมือน "ปุ่มหมุนวอลลุ่ม" ที่คุณปรับแต่งเพื่อให้ได้เป้าหมายของโมเดล
* **Automatic Model Tuning:** การหาเวอร์ชันที่ดีที่สุดของโมเดลโดยการรันงานฝึกอัตโนมัติภายใต้ขอบเขต Hyperparameters ที่กำหนด
* **Training:** กระบวนการสร้างโมเดล Machine Learning
* **Inference:** กระบวนการนำโมเดลที่ฝึกแล้วมาใช้ในการทำนายผล
* **Local Mode:** การสร้างและติดตั้ง Estimators ลงในเครื่องของคุณเองเพื่อทดสอบ (ต้องติดตั้ง SageMaker Python SDK)
* **Estimators:** อ็อบเจกต์ระดับสูงที่นิยามงานฝึก รวมถึงอัลกอริทึม, ประเภทอินสแตนซ์, ข้อมูลเข้า/ออก และ Hyperparameters
* **Predictor:** ใช้สำหรับการทำ Inference หลังจากติดตั้งโมเดลแล้ว รองรับทั้งการทำนายแบบซิงโครนัสและอซิงโครนัส

---

### โหมดการรับข้อมูลฝึก (Input Modes)
1.  **File mode:** ดาวน์โหลดข้อมูลทั้งหมดลงในพื้นที่ของอินสแตนซ์ SageMaker ก่อนเริ่มการฝึก (ช้ากว่า Pipe mode แต่เหมาะกับการฝึกแบบเพิ่มพูนหรือ Incremental training)
2.  **Pipe mode:** สตรีมข้อมูลโดยตรงจาก Amazon S3 เข้าสู่คอนเทนเนอร์ของอัลกอริทึม
    * ไม่ต้องใช้พื้นที่เก็บข้อมูลขนาดใหญ่
    * เริ่มต้นและฝึกได้เร็วขึ้น มี I/O Throughput สูงกว่า
    * **ข้อกำหนด:** ต้องใช้รูปแบบข้อมูลแบบ **protobuf RecordIO** เพื่อใช้งานโหมดนี้

---

### การติดตั้งใช้งานเพื่อการทำ Inference
1.  **SageMaker Hosting Services:** ให้ Endpoint แบบ HTTPS ที่คงอยู่ตลอดเวลา เหมาะสำหรับเว็บแอปพลิเคชันที่ต้องการการตอบสนองในระดับเสี้ยววินาที (Sub-second latency)
2.  **SageMaker Batch Transform:** ไม่ต้องการ Endpoint ที่คงอยู่ตลอดเวลา ใช้สำหรับการทำนายผลกับชุดข้อมูลทั้งหมดในคราวเดียว

---

### ฟีเจอร์เด่นของ SageMaker
* **AutoPilot:** สร้าง, ปรับแต่ง และติดตั้งโมเดลอัตโนมัติจากข้อมูลแบบตาราง (CSV หรือ Parquet)
* **GroundTruth:** บริการติดป้ายกำกับข้อมูล (Data Labeling) โดยใช้คน (Human annotators)
* **Data Wrangler:** เครื่องมือแบบ Visual สำหรับเตรียมและล้างข้อมูล
* **Neo:** ปรับแต่งโมเดลให้ทำงานเร็วขึ้นบนอุปกรณ์ปลายทาง (Edge Devices) โดยไม่เสียความแม่นยำ
* **Debugger:** ให้ข้อมูลเชิงลึกแบบเรียลไทม์ระหว่างการฝึก เช่น การตรวจสอบค่าน้ำหนัก (Weights) และ Gradients
* **Managed Spot Training:** ใช้เครื่องที่ว่างอยู่ในการฝึก ช่วยประหยัดต้นทุนได้สูงสุด 90%
* **Studio / Notebooks:** สภาพแวดล้อม IDE และ Jupyter Notebook แบบ Managed สำหรับการทำงาน ML ครบวงจร
* **Pipelines:** บริการ CI/CD สำหรับจัดการเวิร์กโฟลว์ ML ตั้งแต่ต้นจนจบ
* **Feature Store:** คลังเก็บข้อมูลคุณลักษณะ (Features) ส่วนกลางเพื่อใช้ซ้ำในการฝึกและ Inference
* **JumpStart:** โมเดลพื้นฐาน (Foundation Models) และโซลูชันสำเร็จรูปที่พร้อมใช้งานทันที (เช่น การสรุปข้อความ หรือตรวจจับวัตถุ)

---

### การตรวจสอบ (Monitoring) & การปรับแต่ง (Optimization)
* ส่งตัวชี้วัด (Metrics) ของอินสแตนซ์และการฝึกไปยัง **CloudWatch** เพื่อดูประสิทธิภาพแบบเรียลไทม์
* ใช้ **CloudTrail** เพื่อตรวจจับการเรียกใช้ API ที่ไม่ได้รับอนุญาต
* ใช้ **Model Monitor** เพื่อตรวจจับปัญหา Data Drift (ข้อมูลเปลี่ยนไปจากตอนฝึก) หรือประสิทธิภาพที่ลดลงในระบบจริง
* แนะนำให้แปลงข้อมูลเป็น Parquet หรือ RecordIO เพื่อใช้ Pipe Mode และใช้ **Amazon FSx for Lustre** เพื่อเร่งความเร็วใน File Mode

---

### ค่าบริการ (Pricing)
* **การฝึก (Training):** คิดตามชั่วโมงการใช้งานอินสแตนซ์
* **การทำ Inference:** คิดตามชั่วโมงการเปิดใช้งาน Endpoint
* **Managed Spot Training:** ส่วนลดพิเศษสำหรับการใช้ Compute ที่ว่างอยู่
* **ค่าจัดเก็บและโอนถ่ายข้อมูล:** คิดแยกต่างหาก
* **AutoPilot, JumpStart, Clarify:** จ่ายตามการใช้งานจริง (ตามการทำ Inference หรือการฝึก)
