# Amazon Bedrock AgentCore Code Interpreter Cheat Sheet

**Amazon Bedrock AgentCore Code Interpreter** เป็นเครื่องมือเฉพาะทางที่ช่วยให้เอเจนท์ AI สามารถเขียน รัน และแก้ไขข้อผิดพลาด (Debug) โค้ด Python ภายในสภาพแวดล้อมที่ปลอดภัย (Sandbox) เพื่อใช้ในการวิเคราะห์ข้อมูล การคำนวณทางคณิตศาสตร์ และการประมวลผลไฟล์

### คุณสมบัติของ Code Interpreter
* **การรันโค้ดที่ปลอดภัย (Secure Code Execution):** รันโค้ด Python ในสภาพแวดล้อม Sandbox ที่ถูกแยกส่วนและไม่มีการเชื่อมต่อเครือข่ายภายนอก มาพร้อมกับไลบรารียอดนิยมอย่าง **pandas, numpy และ matplotlib** สำหรับการวิเคราะห์ข้อมูลเชิงลึก พร้อมระบบจัดการหน่วยความจำและทรัพยากรโดยอัตโนมัติ
* **ความสามารถในการประมวลผลไฟล์:** เอเจนท์สามารถสร้าง อ่าน และประมวลผลไฟล์ประเภทต่างๆ เช่น **CSV, JSON และข้อความ** ภายในสภาพแวดล้อมที่ปลอดภัย ข้อมูลที่ถูกสร้างขึ้นจากการรันโค้ดจะพร้อมใช้งานในรูปแบบผลลัพธ์สำหรับผู้ใช้
* **การวิเคราะห์ข้อมูลและแสดงผลภาพ (Visualization):** วิเคราะห์ข้อมูลที่ซับซ้อนโดยใช้ pandas และสร้างแผนภูมิหรือกราฟด้วย matplotlib โดยระบบสามารถจัดการการล้างข้อมูล (Data cleaning) การแปลงข้อมูล และการสำรวจข้อมูลได้อย่างครบวงจร

---

### กรณีการใช้งาน (Use Cases)
* **การวิเคราะห์ข้อมูลและออกรายงาน:** ประมวลผลชุดข้อมูลที่อัปโหลดเพื่อสร้างข้อมูลเชิงลึก สรุปผล และรายงานเชิงภาพ เหมาะสำหรับงานด้าน Business Intelligence และการสำรวจข้อมูล
* **การคำนวณทางคณิตศาสตร์:** แก้โจทย์คณิตศาสตร์ที่ซับซ้อนและการคำนวณทางวิทยาศาสตร์ ตั้งแต่เลขคณิตพื้นฐานไปจนถึงการวิเคราะห์ตัวเลขขั้นสูง รองรับการสร้างแบบจำลองทางการเงินและการคำนวณทางวิศวกรรม
* **การประมวลผลและสร้างไฟล์:** สกัดข้อมูลจากไฟล์ที่ผู้ใช้อัปโหลด หรือแปลงรูปแบบข้อมูล (Data transformation) เช่น การจัดการไฟล์ CSV/JSON และการสร้างรายงานอัตโนมัติ

---

### การนำไปใช้งาน (Implementation)
* **การทำงานร่วมกับเอเจนท์:** รวมเข้ากับเวิร์กโฟลว์ของ AgentCore ผ่านพรอมต์ภาษาธรรมชาติ โดยเอเจนท์จะตัดสินใจเองว่าเมื่อใดที่ต้องใช้การรันโค้ดตามคำขอของผู้ใช้ ระบบจะจัดการทั้งการสร้างโค้ด การรัน และการตีความผลลัพธ์ให้โดยอัตโนมัติ
* **การจัดการเซสชัน (Session Management):** รักษาสถานะของตัวแปรและข้อมูลตลอดการสนทนาแบบหลายโต้ตอบ (Multi-turn) โดยแต่ละเซสชันจะแยกขาดจากกันเพื่อความปลอดภัยและป้องกันข้อมูลปนเปื้อน

---

### ความปลอดภัย (Security)
* **สภาพแวดล้อม Sandbox:** การรันโค้ดทั้งหมดเกิดขึ้นในสภาพแวดล้อมที่ควบคุมอย่างเข้มงวด ไม่มีการเข้าถึงอินเทอร์เน็ตภายนอก เพื่อป้องกันการดำเนินการที่อาจเป็นอันตรายและจำกัดการบริโภคทรัพยากร
* **การควบคุมการเข้าถึง:** ปฏิบัติตามสิทธิ์ IAM และนโยบายความปลอดภัยเดียวกับ AgentCore ตัวหลัก จำกัดการใช้งานเฉพาะไลบรารีที่กำหนดไว้ และมีการบันทึก Log กิจกรรมทั้งหมดเพื่อการตรวจสอบ

---

### แนวทางปฏิบัติที่ดีที่สุด (Best Practices)
* **ความปลอดภัยของโค้ด:** ตรวจสอบเสมอว่าโค้ดที่ถูกสร้างขึ้นตรงกับงานที่ได้รับมอบหมาย และไม่พยายามรันคำสั่งที่ถูกสั่งห้าม เฝ้าติดตามการรันโค้ดเพื่อป้องกันการใช้ทรัพยากรเกินขีดจำกัดหรือการเกิด Infinite loops
* **การจัดการข้อผิดพลาด:** เตรียมระบบจัดการเมื่อการรันโค้ดล้มเหลวอย่างเหมาะสม และใช้ความสามารถในการ Debug เพื่อระบุและแก้ไขปัญหาของโค้ด พร้อมแจ้งข้อความข้อผิดพลาดที่ชัดเจนแก่ผู้ใช้
* **การเพิ่มประสิทธิภาพทรัพยากร:** คำนึงถึงขีดจำกัดของทรัพยากรประมวลผลและเวลา โดยเฉพาะงานที่ซับซ้อนหรือชุดข้อมูลขนาดใหญ่ ควรใช้อัลกอริทึมที่เหมาะสมเพื่อให้การตอบสนองรวดเร็ว

---

### ค่าบริการ (Pricing)
* **รูปแบบราคาตามการใช้งานจริง (Usage-Based):** เป็นส่วนหนึ่งของบริการ Amazon Bedrock AgentCore โดยคิดราคาตามเซสชันการรันโค้ดและทรัพยากรประมวลผลที่ใช้จริง
* **ไม่มีค่าธรรมเนียมเพิ่มเติม:** ไม่มีค่าใช้จ่ายแยกต่างหากสำหรับความสามารถ Code Interpreter นอกเหนือจากต้นทุนการใช้งาน AgentCore มาตรฐาน
