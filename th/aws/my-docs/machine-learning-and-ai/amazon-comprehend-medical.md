# Amazon Comprehend Medical Cheat Sheet

**Amazon Comprehend Medical** เป็นบริการของ AWS แบบ Managed เต็มรูปแบบที่รองรับมาตรฐาน HIPAA โดยใช้โมเดล Machine Learning และการประมวลผลภาษาธรรมชาติ (NLP) ที่ผ่านการฝึกฝนมาล่วงหน้า
* ทำหน้าที่สกัดข้อมูลทางการแพทย์ที่มีโครงสร้างจากข้อความทางคลินิกที่ไม่มีโครงสร้าง เช่น บันทึกของแพทย์, สรุปการจำหน่ายผู้ป่วย, ผลแล็บ และบันทึกกรณีศึกษา
* ตรวจจับเอนทิตี (Entities) เช่น อาการทางการแพทย์, ยา, การรักษา, ขั้นตอนการรักษา, กายวิภาค และข้อมูลสุขภาพที่ต้องได้รับความคุ้มครอง (PHI)
* รองรับ **Ontology Linking** โดยการจับคู่เอนทิตีที่สกัดได้เข้ากับรหัสมาตรฐานทางการแพทย์ เช่น **ICD-10-CM, RxNorm และ SNOMED CT**
* รองรับการวิเคราะห์ข้อความภาษาอังกฤษ (สหรัฐอเมริกา) เท่านั้น

### ประโยชน์ของ Amazon Comprehend Medical
* **ความแม่นยำสูง:** ใช้โมเดล Deep Learning NLP ที่ทันสมัยและได้รับการฝึกฝนอย่างต่อเนื่องด้วยคลังข้อมูลทางการแพทย์ขนาดใหญ่
* **API สำหรับการเชื่อมต่อ:** ใช้งานง่ายทั้งแบบซิงโครนัส (เอกสารฉบับเดียว) และอซิงโครนัส (ประมวลผลแบบกลุ่ม) ผ่าน CLI, SDK หรือคอนโซล
* **ขยายขนาดได้:** รองรับการประมวลผลเอกสารทางคลินิกจำนวนมหาศาลผ่านการทำงานร่วมกับ Amazon S3
* **ความเป็นส่วนตัวและสอดคล้องตามข้อกำหนด:** ออกแบบมาตามมาตรฐาน HIPAA มีการเข้ารหัสข้อมูลขณะรับส่ง และไม่มีการจัดเก็บข้อมูลลูกค้าอย่างถาวร
* **คุ้มค่า:** จ่ายเฉพาะข้อความที่วิเคราะห์จริง ไม่มีข้อผูกมัดขั้นต่ำ และมี Free Tier ให้ใช้งานฟรี 8.5 ล้านตัวอักษรในเดือนแรก

### การทำงานของ Amazon Comprehend Medical
* ใช้โมเดล NLP ในการระบุคำศัพท์และแนวคิดทางการแพทย์ที่เกี่ยวข้อง พร้อมให้ **คะแนนความเชื่อมั่น (Confidence Scores)** เพื่อระบุความแน่นอนในการตรวจจับ
* **การปฏิบัติการผ่าน API หลัก:**
    * **DetectEntitiesV2:** สกัดเอนทิตี เช่น อาการ, ยา, กายวิภาค, การทดสอบ, การรักษา ฯลฯ
    * **DetectPHI:** ค้นหาข้อมูลสุขภาพส่วนบุคคล (PHI) เพื่อการจัดการความเป็นส่วนตัว
* เชื่อมโยงคำศัพท์ที่ตรวจพบเข้ากับรหัสมาตรฐาน: **ICD-10-CM** (สำหรับการวินิจฉัย), **RxNorm** (สำหรับยา) และ **SNOMED CT** (สำหรับแนวคิดทางการแพทย์ทั่วไป)
* บนคอนโซลมีอินเทอร์เฟซแบบภาพ แสดงการติดป้ายกำกับเอนทิตีแยกตามสีเพื่อให้ดูข้อมูลได้ง่าย

### กรณีการใช้งาน (Use Cases)
* **การจัดการกรณีผู้ป่วย:** สกัดข้อมูลทางคลินิกเพื่อปรับปรุงการบันทึกเอกสาร, ช่วยในการตัดสินใจ และคัดกรองโรคในระยะเริ่มต้น
* **การวิจัยทางคลินิก:** ระบุกลุ่มตัวอย่างผู้ป่วยได้เร็วขึ้นจากการสกัดข้อมูลยาหรืออาการที่เกี่ยวข้อง และเฝ้าระวังความปลอดภัยของยา (Pharmacovigilance)
* **การเรียกเก็บเงินทางการแพทย์:** ช่วยลงรหัสการวินิจฉัยและขั้นตอนการรักษาโดยอัตโนมัติ เพื่อเพิ่มความแม่นยำและรวดเร็วในการเคลมประกัน
* **การตรวจสอบการเคลมประกัน:** เร่งกระบวนการตรวจสอบและอนุมัติ รวมถึงการตรวจจับการทุจริตโดยใช้ข้อมูลทางการแพทย์ที่สกัดได้
* **สุขภาพประชากร:** วิเคราะห์ข้อมูลจำนวนมากเพื่อติดตามแนวโน้มสุขภาพและความต้องการทรัพยากรในระดับประชากร

### ความปลอดภัย (Security)
* ปฏิบัติตามกฎระเบียบ **HIPAA** อย่างเคร่งครัดในการจัดการข้อมูล PHI
* ข้อมูลระหว่างการรับส่งถูกเข้ารหัสด้วย HTTPS ผ่าน TLS
* ไม่มีการจัดเก็บข้อมูลที่วิเคราะห์ไว้อย่างถาวร เพื่อลดความเสี่ยงในการรั่วไหลของข้อมูล
* ควบคุมการเข้าถึงผ่าน **AWS IAM** (Roles/Policies) เพื่อกำหนดสิทธิ์อย่างละเอียด

### ค่าบริการ (Pricing)
* คิดราคาตามปริมาณข้อความที่ประมวลผล (คิดต่อตัวอักษร)
* **AWS Free Tier:** ให้ใช้ฟรี 8.5 ล้านตัวอักษรในเดือนแรกสำหรับผู้ใช้ใหม่
* ไม่มีค่าธรรมเนียมล่วงหน้า จ่ายตามการใช้งานจริง
* ราคาจะแตกต่างจาก Amazon Comprehend รุ่นมาตรฐาน เนื่องจากใช้โมเดลเฉพาะทางทางการแพทย์
