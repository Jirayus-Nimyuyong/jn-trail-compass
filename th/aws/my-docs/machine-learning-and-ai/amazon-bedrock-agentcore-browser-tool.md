# Amazon Bedrock AgentCore Browser Tool Cheat Sheet

**Amazon Bedrock AgentCore Browser Tool** คือความสามารถในการท่องเว็บที่ช่วยให้เอเจนท์ AI เข้าถึงและโต้ตอบกับเว็บไซต์ที่ใช้งานอยู่จริง สามารถสกัดข้อมูลแบบเรียลไทม์ และทำงานบนเว็บแบบอัตโนมัติผ่านคำสั่งภาษาธรรมชาติ

### คุณสมบัติของ Browser Tool
* **การเข้าถึงเนื้อหาเว็บสด (Live Web Content Access):** ช่วยให้เอเจนท์สามารถไปยัง URL ที่ระบุ และสกัดข้อความ ลิงก์ และข้อมูลที่มีโครงสร้างจากหน้าเว็บได้ รองรับเนื้อหาแบบไดนามิกที่เรนเดอร์ด้วย JavaScript และ Web Framework สมัยใหม่ โดยระบบจะจัดการเซสชันและติดตามการเปลี่ยนเส้นทาง (Redirect) ให้โดยอัตโนมัติ
* **การปฏิบัติการเว็บแบบโต้ตอบ (Interactive Web Operations):** เอเจนท์สามารถคลิก กรอกแบบฟอร์ม โต้ตอบกับปุ่ม และองค์ประกอบอื่นๆ บนเว็บเพื่อทำงานที่ซับซ้อนหลายขั้นตอนได้ รองรับการเลือก Dropdown, ติ๊ก Checkbox และการนำทางผ่านกระบวนการหลายหน้าเว็บ โดยยังคงรักษาสถานะเซสชันและคุกกี้ไว้ตลอดการใช้งาน
* **การสกัดข้อมูลแบบเรียลไทม์:** ช่วยให้เอเจนท์ได้รับข้อมูลที่เป็นปัจจุบันที่สุดจากไซต์ข่าว รายการสินค้า หรือเว็บแอปพลิเคชันที่มีการเปลี่ยนแปลงตลอดเวลา สามารถเฝ้าติดตามเนื้อหาที่เปลี่ยนไป สกัดข้อมูลที่จำกัดด้วยเวลา และรวบรวมข้อมูลจากหลายแหล่งเพื่อการวิจัยและวิเคราะห์

---

### กรณีการใช้งาน (Use Cases)
* **การวิจัยและการหาข่าวกรองเว็บ (Web Research):** รวบรวมข้อมูลคู่แข่งโดยอัตโนมัติ เช่น ราคา คุณสมบัติ และสถานะสินค้า ทำวิจัยตลาดโดยการรวบรวมข้อมูลจากหลายแหล่งและติดตามแนวโน้มอุตสาหกรรม
* **การเฝ้าติดตามเนื้อหาและการอัปเดต:** ตรวจสอบการเปลี่ยนแปลงของเนื้อหาเฉพาะเจาะจงบนเว็บไซต์ การขึ้นลงของราคา หรืออัปเดตสถานะสินค้า พร้อมสร้างการแจ้งเตือนและรายงานเมื่อเนื้อหาเป้าหมายมีการเปลี่ยนแปลง
* **การโต้ตอบกับเว็บอัตโนมัติ:** กรอกแบบฟอร์มเว็บ ส่งใบสมัคร และทำงานป้อนข้อมูลอัตโนมัติข้ามหลายเว็บไซต์ จัดการกระบวนการลงทะเบียนหรืออินเทอร์เฟซการค้นหาโดยไม่ต้องใช้คนทำด้วยตนเอง

---

### การนำไปใช้งาน (Implementation)
* **เวิร์กโฟลว์การรวมเอเจนท์:** ตัวเครื่องมือ Browser จะรวมเข้ากับ AgentCore ผ่านพรอมต์ภาษาธรรมชาติ โดยเอเจนท์จะตัดสินใจเองว่าเมื่อใดควรท่องเว็บตามคำขอของผู้ใช้ สามารถกำหนดค่าพารามิเตอร์ เช่น ระยะเวลา Timeout, การหน่วงเวลาการโต้ตอบ และความชอบในการสกัดเนื้อหา
* **การจัดการเซสชัน (Session Management):** ตั้งค่าเซสชันการท่องเว็บด้วยการระบุภูมิภาคที่ต้องการ (Geographic preferences) และการตั้งค่า User Agent รวมถึงการกำหนด Allowlist/Blocklist ของโดเมนเพื่อควบคุมว่าเว็บไซต์ใดที่เอเจนท์เข้าถึงได้

---

### ความปลอดภัย (Security)
* **การควบคุมการเข้าถึง:** Browser Tool จะสืบทอดสิทธิ์ IAM และนโยบายความปลอดภัยจาก AgentCore ตัวหลัก เพื่อให้แน่ใจว่าการเข้าถึงอยู่ภายใต้การกำกับดูแลที่ถูกต้อง
* **ความเป็นส่วนตัวและการปฏิบัติตามข้อกำหนด:** การโต้ตอบบนเว็บทั้งหมดจะถูกบันทึก Log ไว้เพื่อการตรวจสอบ (Audit) สามารถกำหนดนโยบายการเก็บรักษาข้อมูลประวัติการท่องเว็บและเนื้อหาที่สกัดออกมาได้ตามมาตรฐาน GDPR หรือ CCPA

---

### แนวทางปฏิบัติที่ดีที่สุด (Best Practices)
* **กลยุทธ์การท่องเว็บที่มีประสิทธิภาพ:** ระบุวัตถุประสงค์และเว็บไซต์เป้าหมายให้ชัดเจนเพื่อลดทราฟฟิกที่ไม่จำเป็น และใช้ URL โดยตรงแทนการค้นหาแบบกว้างๆ เพื่อประหยัดเวลา
* **การจัดการข้อผิดพลาดที่แข็งแกร่ง:** เตรียมระบบจัดการเมื่อเครือข่ายขัดข้อง เว็บไซต์เข้าไม่ได้ หรือเนื้อหาเปลี่ยนไปในรูปแบบที่ไม่คาดคิด รวมถึงการเฝ้าระวังเรื่อง CAPTCHA และการจำกัดปริมาณคำขอ (Rate limiting)
* **การทำงานร่วมกับเครื่องมืออื่น:** รวม Browser Tool เข้ากับความสามารถอื่นๆ เช่น ใช้ Code Interpreter เพื่อวิเคราะห์ข้อมูลที่สกัดมา หรือใช้ Knowledge Base เพื่อตรวจสอบความถูกต้องของข้อมูล

---

### ค่าบริการ (Pricing)
* **รูปแบบราคาตามการใช้งานจริง (Pay-per-use):** คิดราคาตามจำนวนเซสชันการท่องเว็บและปริมาณการประมวลผลข้อมูล โดยจะนับรวมในค่าบริการทรัพยากรประมวลผลที่ใช้ระหว่างการโต้ตอบบนเว็บและการสกัดเนื้อหา ไม่มีค่าธรรมเนียมสิทธิ์การใช้งานแยกต่างหากนอกเหนือจากต้นทุนการใช้งาน AgentCore มาตรฐาน
