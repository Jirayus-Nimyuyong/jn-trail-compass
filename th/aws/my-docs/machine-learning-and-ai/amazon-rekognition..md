# Amazon Rekognition Cheat Sheet

**Amazon Rekognition** เป็นบริการที่ช่วยให้คุณเพิ่มการวิเคราะห์ภาพและวิดีโอประสิทธิภาพสูงลงในแอปพลิเคชันของคุณได้อย่างง่ายดาย โดยแบ่งออกเป็น 2 บริการย่อย:
1.  **Rekognition Image:** สำหรับค้นหา ตรวจสอบ และจัดระเบียบรูปภาพจำนวนมหาศาล
2.  **Rekognition Video:** สำหรับสกัดบริบทจากการเคลื่อนไหวในวิดีโอที่บันทึกไว้หรือสตรีมสด

### Rekognition Image
บริการจดจำรูปภาพที่ตรวจจับวัตถุ, ฉาก, ใบหน้า, สกัดข้อความ และอื่นๆ อีกมากมาย
* **ความสามารถ:** ค้นหาและเปรียบเทียบใบหน้า, ใช้โมเดล Deep Neural Network เพื่อติดป้ายกำกับ (Label) วัตถุและฉากนับพันรายการ
* **Face Liveness Detection:** ตรวจสอบว่าใบหน้าเป็นคนจริงหรือการปลอมแปลง (Spoof)
* **Face Collections:** ใช้ `IndexFaces` และ `SearchFaces` เพื่อการค้นหาใบหน้าที่ขยายขนาดได้
* **Custom Labels:** ฝึกโมเดลของคุณเองเพื่อตรวจจับวัตถุหรือรูปแบบเฉพาะทางธุรกิจ
* **การตรวจจับข้อความ:** รองรับหลายภาษาและการจดจำลายมือ
* **Moderation:** ตรวจจับเนื้อหาที่ไม่เหมาะสมหรือเนื้อหาสำหรับผู้ใหญ่ที่แฝงมาอย่างแนบเนียน
* **รูปแบบไฟล์:** รองรับ JPEG, PNG และ HEIF/HEIC (จากอุปกรณ์ Apple) อัปโหลดผ่าน S3 (สูงสุด 15MB) หรือ Byte Array (สูงสุด 5MB)

**กรณีการใช้งานทั่วไป:**
* ห้องสมุดภาพที่ค้นหาได้ (Searchable Image Library)
* การตรวจสอบตัวตนผู้ใช้ด้วยใบหน้า
* การวิเคราะห์ความรู้สึก (Sentiment Analysis)
* การจดจำใบหน้าและการคัดกรองเนื้อหาที่ไม่เหมาะสม (Image Moderation)

---

### Rekognition Video
บริการจดจำวิดีโอที่ตรวจจับกิจกรรม, เข้าใจการเคลื่อนไหวของคนในเฟรม, จดจำวัตถุ, คนดัง, ข้อความ และฉากต่างๆ
* **ความสามารถ:** จัดทำดัชนี Metadata เพื่อให้ค้นหาวิดีโอได้ง่าย
* **ข้อกำหนด:** วิเคราะห์วิดีโอได้สูงสุด 8GB ใน S3 เข้ารหัสด้วย H.264 รูปแบบไฟล์ที่รองรับคือ MPEG-4 และ MOV
* **Person Tracking:** ติดตามแต่ละบุคคลตลอดทั้งวิดีโอ แม้จะมีการเดินข้ามช็อตหรือถูกบัง (Occlusion)
* **Real-time Video:** ใช้ **Kinesis Video Stream** เป็นข้อมูลขาเข้าเพื่อประมวลผลวิดีโอสตรีมสด และส่งผลลัพธ์ไปยัง Kinesis Data Stream
* **Activity Recognition:** ใช้ `StartLabelDetection` และ `GetLabelDetection` สำหรับเหตุการณ์ที่ระบุเวลา (Time-stamped events)

**กรณีการใช้งานทั่วไป:**
* จัดทำดัชนีค้นหาสำหรับคลังวิดีโอ (Video Archives)
* กรองเนื้อหาที่แสดงออกอย่างโจ่งแจ้งหรือเนื้อหาสำหรับผู้ใหญ่ในวิดีโอ

### แนวคิดหลัก (Concepts)
* **Label (ฉลาก/ป้ายกำกับ):** วัตถุ, ฉาก หรือแนวคิดที่พบในภาพ พร้อม **Confidence Score** (0-100) บ่งบอกความน่าจะเป็นที่คำทำนายจะถูกต้อง
* **Object and Scene Detection:** กระบวนการวิเคราะห์ภาพ/วิดีโอเพื่อกำหนดป้ายกำกับผ่าน `DetectLabels` API
* **Hierarchy (ลำดับชั้น):** Amazon Rekognition จะคืนค่าป้ายกำกับ "ตัวพ่อ" (Parent labels) เพื่อแสดงความสัมพันธ์ของวัตถุในหมวดหมู่ต่างๆ
* **Unsafe Content Detection:** API ที่ใช้ Deep Learning เพื่อตรวจจับเนื้อหาสำหรับผู้ใหญ่ที่หยาบคายหรือส่อไปในทางลามก
* **Facial Recognition:** การระบุหรือตรวจสอบตัวตนโดยค้นหาใบหน้าจาก "Face Collection" (ชุดข้อมูลใบหน้าที่คุณสร้างขึ้น)
* **Sentiment and Demographic Analysis:** วิเคราะห์ความรู้สึกและข้อมูลประชากร (เช่น เพศ, ช่วงอายุ)
* **Text in Image:** ออกแบบมาเพื่อตรวจจับข้อความในโลกแห่งความเป็นจริง (เช่น ป้ายถนน) มากกว่าข้อความในเอกสาร
* **Celebrity Recognition:** ฟีเจอร์จดจำบุคคลที่มีชื่อเสียงทั้งในภาพและวิดีโอ

### ค่าบริการ (Amazon Rekognition Pricing)
* **Rekognition Image:** จ่ายตามจำนวนภาพที่วิเคราะห์และจำนวน Metadata ของใบหน้าที่จัดเก็บ
* **Rekognition Video:** จ่ายตามระยะเวลาของวิดีโอที่วิเคราะห์ (หน่วยเป็นนาที) และจำนวน Metadata ของใบหน้าที่จัดเก็บต่อเดือน
