# Amazon Kendra Cheat Sheet

**Amazon Kendra** เป็นบริการค้นหาข้อมูลอัจฉริยะสำหรับองค์กร (Intelligent Enterprise Search) ที่มีความสามารถในการขยายตัวสูง
* ใช้ Machine Learning ในการค้นหาข้อมูลที่ไม่มีโครงสร้าง (Unstructured Data) และเพิ่มความแม่นยำของผลลัพธ์
* เชื่อมต่ออย่างแนบแน่นกับบริการอื่นๆ ของ AWS เช่น Amazon S3 และ Amazon Lex
* มอบความปลอดภัยระดับองค์กร

### คุณสมบัติ (Features)
* **Natural Language Processing (NLP):** ใช้ NLP เพื่อให้ได้คำตอบที่แม่นยำสูงโดยที่ผู้ใช้ไม่จำเป็นต้องมีความเชี่ยวชาญด้าน Machine Learning (ML)
* **การปรับแต่งผลลัพธ์ (Fine-tuning):** ปรับแต่งผลการค้นหาได้ตามคุณลักษณะของเนื้อหา (Attributes), ความสดใหม่ (Freshness), พฤติกรรมผู้ใช้ และอื่นๆ
* **คำตอบด่วนด้วย ML (Instant Answers):** ให้คำตอบด่วน, คำถามที่พบบ่อย (FAQs) และการจัดอันดับเอกสารแบบเบ็ดเสร็จ (Fully Managed)
* **GenAI Index:** ออกแบบมาเพื่อรองรับงานประเภท **Retrieval-Augmented Generation (RAG)**
* **Hybrid Retrieval:** รองรับการค้นหาแบบผสมผสาน (ค้นหาเชิงความหมาย + คำสำคัญ) เพื่อผลลัพธ์ที่ตรงประเด็นยิ่งขึ้น
* **Retriever API:** ดึงข้อมูลเชิงความหมายพร้อมการกรองด้วย Metadata เพื่อส่งเนื้อหาที่จำเป็นที่สุดให้แก่ LLMs
* **Experience Builder:** อินเทอร์เฟซแบบลากวาง (No-code) สำหรับสร้างแอปพลิเคชันค้นหา พร้อมรองรับการล็อกอินผ่าน SSO (IAM Identity Center)
* **การเสริมข้อมูลเอกสาร (Custom Document Enrichment):** ใช้ AWS Lambda ในการดึงเอนทิตี (Entities), จำแนกประเภท หรือแปลงเนื้อหาจากไฟล์ PDF ที่สแกนมาหรือ OCR

### ประโยชน์ (Benefits)
* ช่วยเพิ่มผลิตภาพของพนักงานได้ถึง **25%**
* ลดต้นทุนการเป็นเจ้าของ (TCO) ในระยะ 5 ปีได้ถึง **82%** เมื่อเทียบกับเครื่องมือค้นหาองค์กรแบบดั้งเดิม
* ลดต้นทุนการพัฒนาแอปพลิเคชันได้ถึง **80%**

### กรณีการใช้งาน (Use Cases)
* **เพิ่มขีดความสามารถในการค้นหาของพนักงาน:** สร้างอินเทอร์เฟซการค้นหาแบบรวมศูนย์เพื่อให้พนักงานเข้าถึงข้อมูลเชิงลึกประกอบการตัดสินใจ
* **เพิ่มประสิทธิภาพการตอบโต้ลูกค้า:** ลดค่าใช้จ่ายในคอนแทคเซ็นเตอร์ด้วยบอทบริการตนเอง (Self-service bots) และระบบช่วยงานพนักงาน (Agent Assistance)
* **รวมระบบค้นหาเข้ากับแอป SaaS:** เพิ่มความเร็วในการดึงข้อมูลภายในแอปพลิเคชันด้วยระบบค้นหาที่ขับเคลื่อนด้วย ML

### รูปแบบเอกสารและแหล่งข้อมูล
* **รูปแบบที่รองรับ:** PDF, HTML, Word, PowerPoint, RTF, JSON, Markdown, CSV, Excel, XML และอื่นๆ
* **แหล่งข้อมูล:** เชื่อมต่อได้หลากหลาย เช่น Adobe Experience Manager, Alfresco, Amazon S3, RDS, GitHub, Box, Dropbox, Salesforce และ SharePoint

### ค่าบริการ (Pricing)
* **Kendra Enterprise Edition (KEE):** สำหรับงานจริง (Production) ราคาประมาณ **$1,008 ต่อเดือน** (รองรับ 100,000 เอกสาร และ 8,000 คำขอต่อวัน)
* **Kendra Developer Edition (KDE):** สำหรับนักพัฒนาทำตัวต้นแบบ (PoC) ราคาประมาณ **$810 ต่อเดือน** (ไม่แนะนำสำหรับงานจริง)
* **ข้อเสนอพิเศษ:** สำหรับลูกค้าใหม่ของ Developer Edition สามารถใช้งานฟรีได้ถึง **750 ชั่วโมงใน 30 วันแรก** (ไม่รวมค่าบริการตัวเชื่อมต่อ/Connector)
* **การขยายระบบ:** ลูกค้าสามารถเพิ่ม Capacity Units เพื่อรองรับจำนวนเอกสารหรือจำนวนคำขอที่มากขึ้นได้ตามต้องการ
