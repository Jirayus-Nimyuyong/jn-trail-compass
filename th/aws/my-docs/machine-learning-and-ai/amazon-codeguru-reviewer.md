# Amazon CodeGuru Reviewer Cheat Sheet

**Amazon CodeGuru Reviewer** ใช้การวิเคราะห์โปรแกรมและ Machine Learning เพื่อตรวจจับข้อบกพร่องในโค้ดภาษา Java และ Python ที่นักพัฒนามักระบุได้ยาก มีให้บริการในหลายภูมิภาค โดยเน้นการตรวจจับข้อบกพร่องเชิงรุก ให้คำแนะนำที่นำไปปฏิบัติได้จริงเพื่อแก้ไขปัญหา และปฏิบัติตามแนวทางปฏิบัติที่ดีที่สุด การรวม CodeGuru Reviewer เข้ากับเวิร์กโฟลว์การตรวจสอบโค้ดจะช่วยปรับปรุงคุณภาพและความสามารถในการบำรุงรักษาโค้ดของคุณได้ตั้งแต่เริ่มต้น

### คุณสมบัติ (Features)
* **Automated Code Reviews:** ตรวจสอบโค้ดใน Pull Requests โดยอัตโนมัติเพื่อตรวจจับปัญหาที่อาจเกิดขึ้น
* **Security Best Practices:** ให้คำแนะนำด้านความปลอดภัย รวมถึงการหาช่องโหว่ เช่น SQL Injection, Cross-site Scripting (XSS) และการจัดการ Exception ที่ไม่เหมาะสม
* **Code Quality Improvement:** เสนอแนวทางการทำ Code Refactoring เพื่อปรับปรุงความสามารถในการบำรุงรักษาและความอ่านง่ายของโค้ด
* **Performance Recommendations:** ระบุคอขวดด้านประสิทธิภาพ (Performance Bottlenecks) และแนะนำการปรับแต่งเพื่อเพิ่มประสิทธิภาพของแอปพลิเคชัน
* **Integration with Git Repositories:** รองรับการเชื่อมต่อกับ GitHub, Bitbucket และ AWS CodeCommit
* **Customizable Reviews:** ตั้งค่าการตรวจสอบเพื่อบังคับใช้มาตรฐานการเขียนโค้ดเฉพาะสำหรับทีมหรือโปรเจกต์ของคุณ
* **Pull Request Feedback:** ให้คำแนะนำแบบ Inline ใน Pull Request เพื่อให้นักพัฒนาสามารถดำเนินการแก้ไขได้ทันที

---

### กรณีการใช้งาน (Use Cases)
* ตรวจจับช่องโหว่โดยอัตโนมัติ เช่น ปัญหาการควบคุมการเข้าถึง (Access Control) และการเข้ารหัสที่อ่อนแอ
* รักษาฐานข้อมูลโค้ดให้ง่ายต่อการบำรุงรักษาด้วยคำแนะนำในการล้างโค้ด (Code Cleanup) และการทำ Refactoring
* ระบุโค้ดหรืออัลกอริทึมที่ไม่มีประสิทธิภาพซึ่งอาจนำไปสู่ปัญหาด้าน Performance
* เชื่อมต่อกับ CI/CD Pipelines เพื่อตรวจสอบคุณภาพโค้ดอย่างต่อเนื่องตลอดวงจรการพัฒนา
* ตรวจสอบให้แน่ใจว่าโค้ดทั้งหมดเป็นไปตามคู่มือสไตล์ (Style Guidelines) และมาตรฐานที่กำหนดไว้
* เสริมสร้างการทำงานร่วมกันในทีมด้วยการให้ Feedback การตรวจโค้ดที่สม่ำเสมอและระบุปัญหาเชิงรุก

### ความปลอดภัย (Security)
* **Automated Security Analysis:** วิเคราะห์โค้ดแบบ Static เพื่อตรวจจับข้อผิดพลาดด้านความปลอดภัยทั่วไป เช่น SQL Injection, Buffer Overflows และ Insecure Deserialization
* **Integration with AWS Secrets Manager:** ตรวจสอบวิธีการจัดการข้อมูลที่ละเอียดอ่อนในโค้ด เพื่อให้แน่ใจว่ามีการจัดการความลับ (Secrets) อย่างถูกต้อง
* **Code Quality and Security Best Practices:** ส่งเสริมการเขียนโค้ดที่ปลอดภัยผ่านคำแนะนำอัตโนมัติตามมาตรฐานอุตสาหกรรม
* **Compliance with Industry Standards:** ช่วยรักษาความสอดคล้องตามกรอบความปลอดภัย เช่น OWASP Top 10, PCI-DSS และอื่นๆ
* **Review of Dependencies:** ระบุช่องโหว่ในไลบรารีภายนอก (Third-party libraries) และ Dependencies ที่รวมอยู่ในโปรเจกต์

### ค่าบริการ (Pricing)
* **คิดราคาตามบรรทัดโค้ด:** ราคาขึ้นอยู่กับจำนวนบรรทัดของโค้ดที่ถูกวิเคราะห์ โดยมีสิทธิ์ใช้งานฟรีในช่วงต้นและคิดค่าบริการสำหรับบรรทัดเพิ่มเติม
* **Free Tier:** รวมการตรวจสอบโค้ดฟรี 100 ครั้งต่อเดือน
* **Paid Tier:** คิดค่าบริการตามปริมาณโค้ดที่ตรวจสอบ (โดยปกติวัดเป็นจำนวนบรรทัด)
* **การรวมกับบริการ AWS:** ค่าใช้จ่ายจะรวมเข้ากับโครงสร้างราคาของ AWS ดังนั้นคุณจะจ่ายตามบริการที่ใช้งานจริง (เช่น AWS CodeCommit, CodePipeline)
* **ค่าใช้จ่ายเพิ่มเติม:** แม้ว่า CodeGuru จะคิดราคาตามปริมาณโค้ด แต่การรวมเข้ากับเวิร์กโฟลว์ CI/CD ในวงกว้างอาจมีค่าใช้จ่ายเพิ่มเติมสำหรับบริการ AWS อื่นๆ ที่เกี่ยวข้อง
