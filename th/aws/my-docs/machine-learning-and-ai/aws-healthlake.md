# AWS HealthLake Cheat Sheet

**AWS HealthLake** เป็นบริการแบบ Managed เต็มรูปแบบที่รองรับมาตรฐาน HIPAA ออกแบบมาเพื่อช่วยให้องค์กรด้านสาธารณสุขสามารถจัดเก็บ แปลง และวิเคราะห์ข้อมูลสุขภาพในระดับสเกลใหญ่ได้ โดยรองรับมาตรฐาน **FHIR (Fast Healthcare Interoperability Resources) R4** เพื่อการแลกเปลี่ยนข้อมูลที่ราบรื่น ช่วยให้ผู้ให้บริการทางการแพทย์สามารถสกัดข้อมูลเชิงลึกจากข้อมูลสุขภาพผ่านการวิเคราะห์ขั้นสูงและโมเดล Machine Learning

### คุณสมบัติ (Features)
* **FHIR R4 Data Store:** จัดเก็บข้อมูลสุขภาพอย่างปลอดภัยในรูปแบบมาตรฐาน FHIR ทำให้ง่ายต่อการคิวรีและเรียกใช้ข้อมูลสุขภาพ
* **การนำเข้าข้อมูล (Data Import):** รองรับการนำเข้าข้อมูลจาก Amazon S3 รวมถึงบันทึกทางคลินิก ผลแล็บ และการเคลมประกัน
* **Natural Language Processing (NLP):** สกัดข้อมูลเชิงลึกที่มีความหมายจากบันทึกทางคลินิกที่ไม่มีโครงสร้างโดยอัตโนมัติ เช่น การวินิจฉัยโรค รายการยา และขั้นตอนการรักษา
* **FHIR APIs:** ให้บริการ API ตามมาตรฐาน FHIR สำหรับการจัดการข้อมูล เพื่อให้ง่ายต่อการเชื่อมต่อกับระบบสุขภาพอื่นๆ
* **การเชื่อมต่อด้านการวิเคราะห์:** เชื่อมต่อกับ **Amazon Athena** เพื่อคิวรีข้อมูล และ **Amazon QuickSight** เพื่อแสดงภาพข้อมูลสุขภาพได้อย่างไร้รอยต่อ
* **การเชื่อมต่อ Machine Learning:** รองรับการทำงานร่วมกับ **Amazon SageMaker** เพื่อสร้าง ฝึกฝน และติดตั้งใช้งานโมเดลโดยใช้ข้อมูลสุขภาพ

---

### กรณีการใช้งาน (Use Cases)
* **การแลกเปลี่ยนข้อมูลสุขภาพ (Healthcare Interoperability):** อำนวยความสะดวกในการแลกเปลี่ยนข้อมูลระหว่างระบบสุขภาพต่างๆ เพื่อรองรับกฎระเบียบ เช่น 21st Century Cures Act
* **แอปพลิเคชันทางคลินิก:** ช่วยให้แอปพลิเคชันสามารถแสดงมุมมองข้อมูลสุขภาพของผู้ป่วยแบบ 360 องศา
* **การสร้างแบบจำลองพยากรณ์โรค:** ใช้โมเดล Machine Learning เพื่อทำนายผลลัพธ์ทางสุขภาพและแนวโน้มในกลุ่มประชากรผู้ป่วย
* **การจัดการสุขภาพประชากร:** วิเคราะห์ข้อมูลสุขภาพเพื่อเฝ้าติดตามและปรับปรุงสุขภาพของประชากรกลุ่มใหญ่

---

### ความปลอดภัย (Security)
* **การรองรับ HIPAA:** เป็นบริการที่ได้รับรองมาตรฐาน HIPAA มั่นใจได้ในการปฏิบัติตามกฎระเบียบความเป็นส่วนตัวของข้อมูลสุขภาพ
* **การเข้ารหัสข้อมูล:** รองรับการเข้ารหัสข้อมูลทั้งในขณะจัดเก็บ (At rest) และระหว่างการรับส่ง (In transit) โดยมีตัวเลือกให้ลูกค้าจัดการกุญแจเข้ารหัสเองได้
* **การควบคุมการเข้าถึง:** เชื่อมต่อกับ **AWS IAM** เพื่อกำหนดสิทธิ์การเข้าถึงข้อมูลสุขภาพอย่างละเอียด
* **การบันทึกประวัติการใช้งาน (Audit Logging):** ทำงานร่วมกับ **AWS CloudTrail** เพื่อบันทึกและตรวจสอบการเข้าถึงข้อมูลใน HealthLake เพื่อวัตถุประสงค์ด้านความปลอดภัยและการตรวจสอบ

---

### ค่าบริการ (Pricing)
* **การจัดเก็บข้อมูล (Data Storage):** คิดราคาตามปริมาณข้อมูลที่จัดเก็บใน HealthLake data store
* **การนำเข้าข้อมูล (Data Ingestion):** มีค่าธรรมเนียมเมื่อนำเข้าข้อมูลจาก Amazon S3 หรือแหล่งอื่นๆ เข้าสู่ HealthLake
* **การส่งออกข้อมูล (Data Export):** มีค่าใช้จ่ายเมื่อมีการส่งออกข้อมูลออกจาก HealthLake
* **คำขอผ่าน API (API Requests):** คิดราคาตามจำนวนครั้งที่มีการเรียกใช้ API เพื่อโต้ตอบกับบริการ
