# Amazon CodeGuru Profiler Cheat Sheet

**Amazon CodeGuru Profiler** เป็นเครื่องมือสำหรับนักพัฒนาที่ช่วยวิเคราะห์และปรับปรุงประสิทธิภาพของแอปพลิเคชัน โดยการทำ Profiling อย่างต่อเนื่องเพื่อระบุคอขวดด้านประสิทธิภาพ (Performance Bottlenecks), โค้ดที่ไม่มีประสิทธิภาพ และการทำงานที่สิ้นเปลืองทรัพยากร เครื่องมือนี้จะให้ข้อมูลเชิงลึกเกี่ยวกับพฤติกรรมการทำงานของแอปพลิเคชันในขณะรัน (Runtime) เพื่อปรับแต่ง CPU, หน่วยความจำ (Memory) และประสิทธิภาพโดยรวมของแอปพลิเคชันให้เหมาะสมที่สุด

### คุณสมบัติ (Features)
* **Performance Profiling:** ทำ Profiling แอปพลิเคชันของคุณอย่างต่อเนื่อง และแสดงตัวชี้วัดประสิทธิภาพ เช่น การใช้งาน CPU, การใช้หน่วยความจำ และเวลาที่ใช้ในฟังก์ชันต่างๆ
* **Flame Graphs:** การแสดงผลในรูปแบบกราฟความร้อน (Visual representation) เพื่อดูว่าใช้เวลาไปกับแต่ละฟังก์ชันมากน้อยเพียงใด และฟังก์ชันเหล่านั้นมีความสัมพันธ์กันอย่างไร ช่วยให้นักพัฒนาจุดที่เกิดปัญหา (Hot spots) ในโค้ดได้อย่างรวดเร็ว
* **Anomaly Detection:** ตรวจจับความผิดปกติของประสิทธิภาพโดยการเปรียบเทียบประสิทธิภาพของแอปพลิเคชันในช่วงเวลาต่างๆ และแจ้งเตือนเมื่อพบพฤติกรรมที่ผิดปกติ
* **Recommendations:** ให้คำแนะนำที่นำไปปฏิบัติได้จริงโดยอ้างอิงจากข้อมูล Profiling เพื่อช่วยเพิ่มประสิทธิภาพแอปพลิเคชันและการใช้ทรัพยากร
* **Integration with AWS Services:** เชื่อมต่อกับบริการอื่นๆ ของ AWS ได้ง่าย เช่น CloudWatch, CodeBuild และ CodePipeline เพื่อการเฝ้าติดตามและทำ Profiling ประสิทธิภาพแบบอัตโนมัติ

---

### กรณีการใช้งาน (Use Cases)
* ระบุส่วนของโค้ดที่มีการใช้งาน CPU หรือหน่วยความจำสูง เพื่อให้นักพัฒนาสามารถปรับปรุงการบริโภคทรัพยากรให้เหมาะสม
* ช่วยลดต้นทุนด้านทรัพยากรโดยการชี้เป้าโค้ดที่ไม่มีประสิทธิภาพหรือการใช้ทรัพยากรที่ไม่จำเป็น
* เหมาะสำหรับแอปพลิเคชันที่ทำงานในสเกลใหญ่ ซึ่งประสิทธิภาพอาจลดลงทีละน้อยโดยไม่มีสัญญาณเตือนที่ชัดเจน ช่วยให้นักพัฒนาตรวจพบปัญหาได้ตั้งแต่เนิ่นๆ
* ข้อมูลจาก Profiler สามารถรวมเข้ากับ CI/CD Pipelines เพื่อเฝ้าติดตามประสิทธิภาพแอปพลิเคชันโดยอัตโนมัติในทุกๆ การติดตั้งใช้งาน (Deployment)

### ความปลอดภัย (Security)
* **Encryption:** CodeGuru Profiler ใช้โปรโตคอลการเข้ารหัสของ Amazon เพื่อให้แน่ใจว่าข้อมูล Profiling ปลอดภัยทั้งในขณะรับส่งและขณะจัดเก็บ
* **IAM Integration:** การควบคุมการเข้าถึงจัดการผ่าน AWS Identity and Access Management (IAM) เพื่อให้แน่ใจว่าเฉพาะผู้ใช้และบทบาท (Roles) ที่ได้รับอนุญาตเท่านั้นที่สามารถดูและแก้ไขข้อมูล Profiling ได้
* **Secure Data Storage:** ข้อมูลถูกจัดเก็บอย่างปลอดภัยใน Amazon S3 Buckets พร้อมการควบคุมการเข้าถึงที่เหมาะสม
* **Fine-Grained Permissions:** อนุญาตให้กำหนดสิทธิ์ในระดับละเอียดเพื่อควบคุมว่าใครสามารถเข้าถึงและแก้ไขข้อมูล Profiling ได้บ้าง

### ค่าบริการ (Pricing)
* **Amazon CodeGuru Profiler** ใช้รูปแบบการจ่ายตามการใช้งานจริง (Pay-as-you-go) โดยขึ้นอยู่กับจำนวนจุดข้อมูล (Data points) ของการทำ Profiling ที่ถูกรวบรวม
* **Free Tier:** รวมจุดข้อมูล Profiling ฟรีสูงสุด 100 ล้านจุดต่อเดือน
* **Pricing:** หลังจากพ้นช่วง Free Tier ค่าใช้จ่ายจะขึ้นอยู่กับจำนวนจุดข้อมูลที่บันทึกและภูมิภาค (Region) ที่ใช้งาน
* **ตัวอย่าง:** ราคาสำหรับจุดข้อมูล 100 ล้านจุด จะอยู่ที่ประมาณ $0.002 ถึง $0.003 ต่อหนึ่งจุดข้อมูล (ขึ้นอยู่กับภูมิภาค)
