# AWS DeepLens Cheat Sheet

**AWS DeepLens** คือกล้องที่รองรับการเรียนรู้เชิงลึก (Deep Learning) สำหรับนักพัฒนา
* เป็นกล้องที่รองรับการเชื่อมต่อไร้สายและทำงานร่วมกับ AWS Cloud ได้อย่างสมบูรณ์
* มีกำลังการประมวลผลสูงถึง **100 GFLOPS** (1 พันล้านคำสั่งต่อวินาที)
* มาพร้อมกับโปรเจกต์ตัวอย่างเพื่อให้คุณเริ่มต้นใช้งานได้ทันที
* ปรับแต่งมาให้เหมาะสมกับเฟรมเวิร์ก **Apache MXNet, TensorFlow และ Caffe**
* ทำงานร่วมกับ **Amazon Rekognition** สำหรับการวิเคราะห์รูปภาพขั้นสูง

> **หมายเหตุสำคัญ:** AWS DeepLens ได้สิ้นสุดอายุการใช้งาน (End-of-life) แล้ว โดยหลังจากวันที่ **31 มกราคม 2024** บริการ AWS DeepLens (การเข้าถึงคอนโซล, โปรเจกต์ และ API) ได้ถูกปิดตัวลง อุปกรณ์ไม่สามารถจัดการผ่านคอนโซล AWS หรือ DeepLens API ได้อีกต่อไป

### กรณีการใช้งานทั่วไป (Common Use Cases)
การพัฒนาแอปพลิเคชันด้านคอมพิวเตอร์วิทัศน์ (Computer Vision) เช่น:
* การตรวจจับใบหน้า (Face Detection)
* การตรวจจับกิจกรรม (Activity Detection)
* การตรวจจับวัตถุ (Object Detection)
* การจำแนกประเภทนก (Bird Classification)
* การถ่ายโอนสไตล์ทางศิลปะ (Artistic Style Transfer)

### บริการ AWS ที่จำเป็นในการสร้างโปรเจกต์:
1.  **Amazon SageMaker:** ใช้ฝึกฝน (Train) และตรวจสอบ (Validate) โมเดลที่สร้างเองหรือโมเดลที่ฝึกมาล่วงหน้า
2.  **AWS Lambda:** ใช้สำหรับการประมวลผลข้อมูลขั้นต้น (Preprocessing), การดึงผลลัพธ์การทำนาย (Inference) และการแสดงผลลัพธ์
3.  **AWS IoT Greengrass:** ทำหน้าที่ติดตั้งโปรเจกต์แอปพลิเคชันและชุดคำสั่ง Lambda ลงในตัวเครื่อง AWS DeepLens รวมถึงจัดการการอัปเดตซอฟต์แวร์และค่าคอนฟิกต่างๆ

---

### ชุดไลบรารีของอุปกรณ์ AWS DeepLens (Device Library)
* **awscam module:** ใช้รันโค้ดสำหรับการทำ Inference ตามโมเดลของโปรเจกต์
* **mo module:** ทำหน้าที่แปลงไฟล์โมเดลจาก Caffe, Apache MXNet หรือ TensorFlow ให้เป็นรูปแบบไฟล์โมเดลของ AWS DeepLens พร้อมทั้งปรับแต่งประสิทธิภาพ (Optimization) ให้เหมาะสม
* **DeepLens_Kinesis_Video module:** สามารถส่งฟีดวิดีโอจากอุปกรณ์ AWS DeepLens ไปยัง Amazon Kinesis Video Streams ได้
