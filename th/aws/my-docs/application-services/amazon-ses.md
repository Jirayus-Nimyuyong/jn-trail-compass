# Amazon SES Cheat Sheet

**Amazon SES** เป็นบริการส่งอีเมลที่มีประสิทธิภาพด้านต้นทุนและขยายขนาดได้ ช่วยให้คุณส่งเมลจากภายในแอปพลิเคชันใดก็ได้
* เป็นบริการระดับภูมิภาค (Regional Service)
* **Amazon SES** เหมาะสำหรับแอปพลิเคชันที่ต้องการสื่อสารผ่านอีเมล รองรับการกำหนด Custom Header และไฟล์แนบ MIME หลายประเภท
* **Amazon SNS** (เปรียบเทียบ) เหมาะสำหรับแอปพลิเคชันที่เน้นการส่งข้อความแจ้งเตือน (Push Notifications) ผ่านหลายโปรโตคอล เช่น HTTP, SQS และอีเมล แต่ SNS **ไม่รองรับ** ไฟล์แนบมัลติมีเดีย

### กรณีการใช้งานทั่วไป (Common Use Cases)
* Transactional emails (อีเมลแจ้งธุรกรรม เช่น รีเซ็ตรหัสผ่าน, ยืนยันคำสั่งซื้อ)
* Marketing emails (อีเมลการตลาด)
* Mass email communications (การส่งอีเมลจำนวนมาก)

---

### คุณสมบัติเด่น (Features)
* **ทางเลือกในการติดตั้งที่ยืดหยุ่น:**
    * **Shared IP:** ส่งผ่าน IP ที่ใช้ร่วมกับลูกค้า SES รายอื่น (เริ่มใช้งานได้ทันที AWS ดูแลชื่อเสียง IP ให้)
    * **Dedicated IP:** เช่า IP ส่วนตัวเพื่อจัดการชื่อเสียง (Reputation) ของตัวเอง
    * **BYOIP:** รองรับการนำ IP ของตัวเองมาใช้ (Bring Your Own IP)
* **การจัดการตัวตนและความปลอดภัย:** รองรับมาตรฐานการตรวจสอบสิทธิ์ **DKIM, SPF และ DMARC**
* **สถิติการส่งข้อมูล:** ติดตามจำนวนการส่ง, การส่งถึง, การเปิด, การคลิก, การตีกลับ (Bounce), การร้องเรียน (Complaint) และการปฏิเสธ
* **Reputation Dashboard:** แดชบอร์ดตรวจสอบประเด็นที่ส่งผลกระทบต่อการส่งอีเมล เช่น อัตราการตีกลับ
* **Email Receiving:** สามารถใช้ SES เพื่อ **รับอีเมล** และดำเนินการต่อ เช่น เก็บใน S3, รัน Lambda หรือส่งแจ้งเตือนไปที่ SNS
* **Virtual Deliverability Manager (VDM):** ให้คำแนะนำที่นำไปใช้ได้จริงเพื่อปรับปรุงการตั้งค่าและอัตราการส่งถึงผู้รับ (Deliverability)
* **Account-Level Suppression List:** รายการระงับการส่งระดับบัญชี เพื่อป้องกันการส่งไปยังที่อยู่เมลที่เสีย (Bad addresses)

---

### แนวคิดหลัก (Concepts)
* **SES SMTP:** เชื่อมต่อผ่านอินเทอร์เฟซ SMTP หรือใช้เป็น SMTP Relay โดยสามารถเข้าถึงผ่าน **VPC Endpoint (AWS PrivateLink)** ได้อย่างเป็นส่วนตัว
* **Reputation (ชื่อเสียง):** มาตรฐานความเชื่อมั่นว่า IP หรือโดเมนของคุณไม่ใช่แหล่งสแปม หากมีการ Bounce หรือ Complaint สูงเกินไป SES อาจลดโควตาหรือปิดบัญชีของคุณ
* **Bounce (การตีกลับ):** เกิดขึ้นเมื่อส่งเมลไม่ถึงผู้รับ (Hard bounce คือผิดพลาดถาวร, Soft bounce คือผิดพลาดชั่วคราว)
* **Complaint (การร้องเรียน):** เกิดขึ้นเมื่อผู้รับกดรายงานว่าเป็นสแปม
* **Global Suppression List:** รายการอีเมลที่เคยทำให้เกิด Hard bounce กับลูกค้า SES รายอื่น ระบบจะระงับการส่งให้อัตโนมัติเพื่อป้องกันชื่อเสียงของคุณ
* **Configuration Sets:** กลุ่มของกฎที่ใช้กับอีเมลที่ส่ง เช่น การตั้งค่าการเผยแพร่เหตุการณ์ (Event Publishing) หรือการจัดการ IP Pool

---

### วิธีการตรวจสอบสิทธิ์อีเมล (Authentication)
1. **SPF:** แจ้งผู้ให้บริการอีเมลปลายทางว่าเซิร์ฟเวอร์ใดได้รับอนุญาตให้ส่งเมลในนามโดเมนของคุณ
2. **DKIM:** ใช้กุญแจเข้ารหัสลับ (Cryptographic Key) เพื่อยืนยันว่าข้อความไม่ถูกแก้ไขระหว่างทาง
3. **DMARC:** ใช้ SPF และ DKIM ร่วมกันเพื่อตรวจจับการปลอมแปลงอีเมล (Spoofing)

### การเปรียบเทียบ: Shared IP vs Dedicated IP

| คุณสมบัติ | Shared IP | Dedicated IP |
| :--- | :---: | :---: |
| พร้อมใช้งานทันที ไม่ต้องตั้งค่าเพิ่ม | **ใช่** | ไม่ |
| ชื่อเสียง (Reputation) จัดการโดย AWS | **ใช่** | ไม่ |
| เหมาะสำหรับปริมาณการส่งที่สม่ำเสมอ | ใช่ | ใช่ |
| เหมาะสำหรับการส่งที่คาดเดาปริมาณยาก | **ใช่** | ไม่ |
| เหมาะสำหรับการส่งปริมาณมหาศาล | ใช่ | ใช่ |
| เหมาะสำหรับการส่งปริมาณน้อย | **ใช่** | ไม่ |
| มีค่าบริการรายเดือนเพิ่มเติม | ไม่ | **ใช่** |
| ควบคุมชื่อเสียงผู้ส่งได้เบ็ดเสร็จ | ไม่ | **ใช่** |

### ความปลอดภัยและข้อจำกัด (Security & Limits)
* **ความปลอดภัย:** ใช้เทคโนโลยีป้องกันสแปมในตัว สแกนไวรัสในไฟล์แนบ และรองรับการเชื่อมต่อแบบ **TLS 1.2**
* **Sandbox Mode:** ผู้ใช้ใหม่จะอยู่ในระบบทดสอบ (Sandbox) ซึ่งส่งเมลได้เฉพาะที่อยู่เมลที่ได้รับการยืนยัน (Verified Identities) เท่านั้น
* **ข้อจำกัด:**
    * ส่งเมลได้เฉพาะจากโดเมนหรืออีเมลที่คุณเป็นเจ้าของ
    * ขนาดข้อความสูงสุด **10 MB**
    * มีโควตาการส่งสูงสุดใน 24 ชั่วโมง (Sending Quota) และอัตราการส่งสูงสุดต่อวินาที (Max Send Rate)

### ค่าบริการ (Pricing)

* การรับอีเมล 1,000 ฉบับแรกฟรี
