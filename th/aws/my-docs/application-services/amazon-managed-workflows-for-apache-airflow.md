# Amazon Managed Workflows for Apache Airflow (MWAA) Cheat Sheet

**Amazon MWAA** เป็นบริการที่ช่วยจัดการและทำให้เวิร์กโฟลว์ข้อมูล (Data Workflows) เป็นไปอย่างอัตโนมัติโดยใช้ Apache Airflow
* เวิร์กโฟลว์ถูกออกแบบในรูปแบบ **Directed Acyclic Graphs (DAGs)** โดยใช้ภาษา Python

### กรณีการใช้งาน (Use Cases)
* **เวิร์กโฟลว์ข้อมูลที่ซับซ้อน:** จัดการงานประมวลผลข้อมูลที่มีความซับซ้อนสูง
* **งาน ETL:** ประสานงานกระบวนการ Extract, Transform, Load (ETL)
* **Machine Learning:** จัดเตรียมชุดข้อมูลสำหรับโมเดลการเรียนรู้ของเครื่อง
* **การประสานงานข้อมูลข้ามบริการ AWS:** เชื่อมต่อกับ S3, Redshift, Lambda และ RDS ได้อย่างง่ายดาย
* **เวิร์กโฟลว์ที่ขับเคลื่อนด้วยเหตุการณ์ (Event-Driven):** สามารถสั่งรัน DAG ตามเหตุการณ์จาก EventBridge หรือ S3
* **การตรวจสอบคุณภาพข้อมูล:** ตรวจสอบความถูกต้องและเฝ้าติดตามชุดข้อมูลโดยอัตโนมัติในฐานะส่วนหนึ่งของ Pipeline

### คุณสมบัติหลัก (Key Features)
* **การติดตั้ง:** ตั้งค่าและใช้งานได้ง่าย (Easy setup)
* **การปรับขนาด (Scaling):** ปรับทรัพยากรโดยอัตโนมัติเพื่อให้สอดคล้องกับความต้องการของปริมาณงาน
* **ความปลอดภัย:** มีมาตรการในตัวเพื่อการปกป้องข้อมูล
* **การตรวจสอบ:** ติดตามการทำงานของเวิร์กโฟลว์อย่างครอบคลุม
* **ความคุ้มค่า:** ลดค่าใช้จ่ายในการดำเนินงานเนื่องจากเป็นบริการแบบ Managed
* **การรองรับ Plugin:** ขยายความสามารถของ Airflow ด้วย Custom Operators, Hooks และ Sensors
* **การจัดการเวอร์ชัน:** รองรับ Apache Airflow หลายเวอร์ชันโดยไม่กระทบต่อการทำงาน
* **การเชื่อมต่อกับ AWS IAM:** ควบคุมการเข้าถึง DAG และทรัพยากรต่างๆ อย่างละเอียด
* **การบันทึก Log และการตรวจสอบ:** เก็บ Log ไว้ที่ศูนย์กลางใน CloudWatch เพื่อใช้ตรวจสอบและแก้ไขปัญหา

### ความปลอดภัย (Security)
* **การแยกเครือข่าย:** ทำงานภายใน Amazon Virtual Private Cloud (VPC)
* **การเข้ารหัสข้อมูล:** ใช้ AWS Key Management Service (KMS) สำหรับการเข้ารหัสข้อมูลโดยอัตโนมัติ
* **IAM Roles สำหรับ Tasks:** แต่ละงานสามารถรับบทบาท (Assume Role) เพื่อเข้าถึงทรัพยากร AWS ได้อย่างปลอดภัย
* **การจัดการความลับ:** เชื่อมต่อกับ AWS Secrets Manager เพื่อจัดการข้อมูลประจำตัว (Credentials) อย่างปลอดภัย
* **Audit Trails:** บันทึกประวัติการทำงานทั้งหมดใน Airflow เพื่อความสอดคล้องตามข้อกำหนด (Compliance)

### ค่าบริการ (Pricing)
* **ราคาค่าสภาพแวดล้อม (Environment):** คิดตามรายชั่วโมงขึ้นอยู่กับขนาดของสภาพแวดล้อม
* **ราคา Worker Instance เพิ่มเติม:** คิดตามรายชั่วโมงขึ้นอยู่กับปริมาณงานที่รัน
* **ราคา Scheduler Instance เพิ่มเติม:** คิดตามรายชั่วโมงขึ้นอยู่กับความต้องการด้านความพร้อมใช้งาน (Availability)
* **ที่เก็บข้อมูลฐานข้อมูล:** คิดตามจำนวน GB-Month ของพื้นที่เก็บข้อมูลที่ใช้จริง
* **ค่าถ่ายโอนข้อมูล:** อาจมีค่าบริการสำหรับการโอนถ่ายข้อมูลระหว่าง VPC และ AWS Regions อื่นๆ
* **ค่าจัดเก็บ Log:** ค่าจัดเก็บและเรียกดู Log ใน CloudWatch จะถูกคิดแยกต่างหาก
* **การรัน DAG:** เป็นต้นทุนทางอ้อมที่ขึ้นอยู่กับจำนวนงานที่ดำเนินการและทรัพยากรประมวลผลที่ใช้
