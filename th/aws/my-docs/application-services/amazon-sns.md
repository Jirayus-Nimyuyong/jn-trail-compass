# Amazon SNS Cheat Sheet

**Amazon SNS** เป็นบริการเว็บที่ช่วยให้การตั้งค่า การใช้งาน และการส่งการแจ้งเตือนจากคลาวด์เป็นเรื่องง่าย โดย SNS ใช้รูปแบบการส่งข้อความแบบ **"Publish-Subscribe" (pub-sub)** ซึ่งจะส่งการแจ้งเตือนไปยังลูกค้าด้วยกลไกแบบ **"Push"** แทนที่จะให้ลูกค้าต้องคอยตรวจสอบหรือ "Poll" ข้อมูลใหม่ด้วยตัวเอง

### คุณสมบัติเด่น (Features)
* **Event-driven Hub:** เชื่อมต่อโดยตรงกับแหล่งเหตุการณ์ของ AWS (เช่น EC2, S3, RDS) และปลายทาง (เช่น SQS, Lambda) ช่วยให้เวิร์กโฟลว์ทำงานอัตโนมัติแบบแยกส่วน (Decoupled)
* **Message Filtering:** ช่วยให้ผู้รับ (Subscriber) สร้างนโยบายการกรอง เพื่อรับเฉพาะการแจ้งเตือนที่สนใจเท่านั้น
* **Message Fanout:** เมื่อข้อความถูกส่งไปยัง Topic ระบบจะทำสำเนาและส่งไปยังปลายทางหลายแห่งพร้อมกัน ช่วยให้ประมวลผลแบบขนานได้
* **Mobile Notifications:** ส่งการแจ้งเตือนแบบ Push ไปยัง iOS, Android, Windows และอื่นๆ รวมถึงการส่ง SMS ไปยัง 200+ ประเทศ และอีเมล (SMTP)
* **ความทนทานของข้อมูล (Durability):** SNS จะทำสำเนาข้อความเก็บไว้ในหลาย Availability Zones (AZ) ภายใน Region ก่อนจะยืนยันการรับข้อความ
* **Time to Live (TTL):** กำหนดอายุของข้อความ หากส่งไม่สำเร็จภายในเวลาที่กำหนด ข้อความจะถูกลบโดยอัตโนมัติ
* **FIFO Topics:** รองรับการตัดข้อความซ้ำ (Deduplication) เพื่อป้องกันการส่งข้อความซ้ำซ้อน และรองรับการส่งต่อไปยัง SQS FIFO
* **Raw Message Delivery:** ส่งเฉพาะเนื้อหาข้อความ (Payload) โดยไม่ต้องมีโครงสร้าง JSON ของ SNS หุ้มไว้
* **Dead Letter Queues (DLQ):** ส่งข้อความที่ส่งไม่สำเร็จไปยังคิวสำรองเพื่อตรวจสอบข้อผิดพลาด

---

### ผู้ส่งและผู้รับ (Publishers and Subscribers)
* **Publishers (ผู้ส่ง):** สื่อสารแบบอซิงโครนัส (Asynchronous) โดยการส่งข้อความไปยัง **Topic** ซึ่งเป็นช่องทางการสื่อสารหลัก
* **Subscribers (ผู้รับ):** ลงทะเบียนเพื่อรับข้อความจาก Topic ผ่านโปรโตคอลที่รองรับ (HTTP/S, Email, SMS, SQS, Lambda, Kinesis Firehose)

### SNS Topics
* **Logical Endpoint:** Publisher ไม่ต้องระบุที่อยู่ปลายทางเอง แต่ส่งไปที่ Topic แล้ว SNS จะกระจายให้ผู้รับทุกคนในรายชื่อ
* **การเรียงลำดับ:** SNS จะพยายามส่งข้อความตามลำดับที่ได้รับ แต่ **ไม่มีการรับประกัน** ลำดับที่แน่นอน (ยกเว้นกรณีใช้ FIFO Topics)
* **การติดตามสถานะ:** สามารถบันทึกสถานะการส่ง (Delivery Status) สำหรับปลายทางประเภทแอปพลิเคชัน, HTTP, Lambda, SQS และ Firehose

### คุณลักษณะของข้อความ (Message Attributes)
* **Structured Metadata:** สามารถใส่ข้อมูลเพิ่มเติมแยกจากเนื้อหาหลัก (เช่น Timestamp, พิกัดภูมิศาสตร์, ID)
* **Mobile Push:** ใช้ช่วยจัดโครงสร้างข้อความแจ้งเตือนบนมือถือ
* **Filtering:** ใช้คุณลักษณะเหล่านี้ในนโยบายการกรอง (Filter Policies) เช่น การกรองตามช่วงตัวเลข หรือการจับคู่คำนำหน้า (Prefix matching)

### การส่งข้อความประเภทต่างๆ
* **System to System:**
    * **Lambda:** เมื่อมีข้อความเข้า ฟังก์ชันจะถูกเรียกใช้ (Invoke) ทันที
    * **SQS:** SNS จะส่งข้อความเข้าไปในคิวในรูปแบบ JSON พร้อม Metadata
    * **HTTP/S:** SNS จะส่ง HTTP POST ไปยังเอนด์พอยต์ที่ระบุ
* **User Notifications:**
    * **Mobile Push:** แสดงผลเป็นข้อความแจ้งเตือน (Alerts), อัปเดตตัวเลข (Badge) หรือเสียง
    * **Direct Addressing:** ส่งข้อความตรงไปยังเอนด์พอยต์เดียวโดยเฉพาะ (ไม่ต้องผ่าน Topic ของกลุ่ม)
    * **SMS:** เลือกประเภทได้ระหว่าง **Transactional** (ความสำคัญสูง เช่น OTP) หรือ **Promotional** (การตลาด ราคาถูกกว่า)

### การพยายามส่งใหม่ (Delivery Retries)
หากส่งไม่สำเร็จ SNS มีนโยบายการรันใหม่ 4 ระยะ:
1.  รันใหม่ทันทีโดยไม่มีการหน่วงเวลา
2.  รันใหม่โดยมีการหน่วงเวลาขั้นต่ำ
3.  รันใหม่ตามรูปแบบ Back-off (เชิงเส้นหรือทวีคูณ)
4.  รันใหม่โดยมีการหน่วงเวลาสูงสุด

### ความปลอดภัยและการตรวจสอบ (Security & Monitoring)
* **Encryption:** รองรับการเข้ารหัสที่ฝั่งเซิร์ฟเวอร์ (Server-side encryption) เพื่อป้องกันการเข้าถึงโดยไม่ได้รับอนุญาต
* **VPC Endpoints:** ใช้ **AWS PrivateLink** เพื่อส่งข้อความไปยัง SNS จากใน VPC โดยไม่ต้องผ่านอินเทอร์เน็ตสาธารณะ
* **Access Control:** ใช้นโยบายควบคุมการเข้าถึง (IAM และ Resource-based) อย่างละเอียด
* **Tracing:** รองรับ **AWS X-Ray** เพื่อติดตามเส้นทางข้อความไปยังบริการปลายทาง
* **Logging:** ใช้ **CloudWatch** ดู Metrics และ **CloudTrail** บันทึกการเรียกใช้ API

### ค่าบริการ (Pricing)
* **Pay-as-you-go:** ไม่มีค่าใช้จ่ายล่วงหน้า จ่ายตามจำนวนข้อความที่ส่ง (ทุกๆ 64 KB นับเป็น 1 ข้อความ)
* **ค่าส่งปลายทาง:** แตกต่างกันตามประเภท (SMS มีราคาตามประเทศและเครือข่าย)
* **FIFO Topics:** มีราคาแยกต่างหากตามจำนวนข้อความและขนาด Payload
* **Free Tier:** ฟรี 1 ล้านคำขอ, 1 แสนการแจ้งเตือน HTTP, 1 พันอีเมล และ 1 ล้าน Mobile Push ต่อเดือน

### ขีดจำกัด (Limits)
* **Subscriptions:** สูงสุด 10 ล้านรายการต่อ Topic
* **Topics:** สูงสุด 100,000 รายการต่อบัญชี
* **ขนาดข้อความ:** SMS สูงสุด **140 bytes**, ข้อความประเภทอื่นสูงสุด **256 KB**
