# AWS WAF Cheat Sheet

**AWS WAF** เป็นไฟร์วอลล์สำหรับเว็บแอปพลิเคชันที่ช่วยปกป้องเว็บแอปพลิเคชันและ API จากการโจมตีทางเว็บทั่วไป โดยอนุญาตให้คุณกำหนดค่ากฎ (Rules) เพื่อ **อนุญาต (Allow), บล็อก (Block), หรือเฝ้าสังเกตการณ์ (Count)** คำขอทางเว็บตามเงื่อนไขที่คุณกำหนด
* เงื่อนไขต่างๆ ได้แก่ ที่อยู่ IP, HTTP Headers, เนื้อหาในคำขอ (Request Body), สตริง URI, ความพยายามในการทำ SQL Injection และ Cross-site Scripting (XSS)

---

## คุณสมบัติเด่น (Features)

### 1. การกรองตามกฎที่ยืดหยุ่น / ประเภทของกฎ
* สร้างกฎโดยใช้เงื่อนไขจาก IP, Headers, Body, URI Paths, ตำแหน่งทางภูมิศาสตร์ และอื่นๆ
* ตรวจจับและบล็อกการโจมตีทั่วไป เช่น **SQL injection (SQLi)** และ **Cross-site scripting (XSS)**
* **JSON Body Inspection:** ตรวจสอบความถูกต้องของ Keys/Values เพื่อการปกป้อง API ที่ปลอดภัย
* **Rate-Based Rules:** บล็อกหรือจำกัดอัตราการส่งคำขอจาก IP ที่เกินเพดานที่กำหนดภายในช่วงเวลา 5 นาทีโดยอัตโนมัติ
* **ตัวเลือกการจับคู่ใหม่:** รองรับ ASN match, JavaScript fingerprinting (JA4) และการรวม Key แบบกำหนดเองสำหรับเงื่อนไขขั้นสูง
* **Bot Control:** ขยายหมวดหมู่การตรวจจับบอท (โฆษณา, AI, ตัวดึงข้อมูล, โซเชียลมีเดีย) และการยืนยันตัวตน Web Bot สำหรับ AI Agents

### 2. กฎที่มีการจัดการ (Managed Rules)
* ชุดกฎที่กำหนดค่าไว้ล่วงหน้าและอัปเดตอัตโนมัติจาก AWS และพาร์ทเนอร์ใน AWS Marketplace
* **อัปเดตล่าสุด:** ปรับปรุงชุดกฎ Known Bad Inputs, POSIX Operating System, Core Rule Set (CRS) และชุดกฎ Anti-DDoS สำหรับการปกป้อง ALB

### 3. Web ACLs (Access Control Lists)
* รวมกฎหลายข้อเข้าเป็น Web ACL เดียวกัน
* กำหนดการดำเนินการต่อกฎ: อนุญาต, บล็อก, หรือนับ (Count)
* กำหนดการดำเนินการเริ่มต้น (Default Action) สำหรับคำขอที่ไม่ตรงกับกฎใดเลย
* **การเพิ่มขีดจำกัด:** จับคู่ประเทศใน Geo match ได้สูงสุด 50 ประเทศต่อกฎ และเชื่อมต่อกับ ALB ได้สูงสุด 100 แห่งต่อหนึ่ง Web ACL

### 4. การแสดงผลและการตรวจสอบ (Visibility and Monitoring)
* แสดงมาตรวัดแบบเรียลไทม์ใน **Amazon CloudWatch**
* บันทึก Log ฉบับเต็มพร้อมรายละเอียด: IP, ตำแหน่งทางภูมิศาสตร์, URI, User-Agent, Referer
* **การปรับปรุง Log:** มีตัวเลือกการปกป้องข้อมูล (Data Protection) ที่กำหนดค่าได้ในระดับ Web ACL
* ทำงานร่วมกับ **WAF Security Automations** เพื่อติดตั้งชุดกฎอัตโนมัติและวิเคราะห์ Log ผ่าน Amazon Athena

---

## การเชื่อมต่อและการทำงานร่วมกัน (Integration)
* ทำงานร่วมกับ **CloudFront, ALB, API Gateway, และ AWS AppSync** เพื่อการปกป้องทั้งในระดับภูมิภาคและระดับโลก
* **การเชื่อมต่อใหม่:** รองรับแผนราคาแบบเหมาจ่ายของ CloudFront และการปกป้องฝั่งไคลเอนต์จาก AWS Marketplace

---

## กรณีการใช้งาน (Use Cases)
* ปกป้องเว็บแอปพลิเคชันจาก SQL injection, XSS และภัยคุกคามทั่วไปตามมาตรฐาน **OWASP**
* บังคับใช้การตรวจสอบความถูกต้องของคำขอ API โดยใช้การตรวจสอบ JSON
* จำกัดอัตราทราฟฟิกที่ไม่พึงประสงค์หรือทราฟฟิกที่มาจากบอท
* ใช้ Managed Rules เพื่อบรรเทาช่องโหว่ที่เป็นที่รู้จักโดยอัตโนมัติ
* เพิ่ม Custom Headers เพื่อการตรวจสอบในขั้นตอนถัดไปหรือเพื่อการวิเคราะห์

---

## ความปลอดภัย (Security)
* บล็อกหรือกรองทราฟฟิกที่เป็นอันตรายโดยใช้กฎที่ปรับแต่งได้
* Managed Rules ได้รับการอัปเดตอย่างต่อเนื่องโดย AWS และผู้เชี่ยวชาญด้านความปลอดภัย
* ให้ Log ฉบับเต็มสำหรับการวิเคราะห์ทางนิติวิทยาศาสตร์และการสืบสวน
* สามารถใช้งานร่วมกับ **AWS Shield** เพื่อบรรเทาการโจมตี DDoS

---

## ค่าบริการ (Pricing)
AWS WAF คิดค่าบริการตาม:
1. **จำนวน Web ACLs** ที่คุณติดตั้ง
2. **จำนวนกฎ (Rules)** ต่อหนึ่ง Web ACL (ทั้งแบบจัดการเองหรือแบบสำเร็จรูป)
3. **จำนวนคำขอทางเว็บ (Web Requests)** ที่ประมวลผลในแต่ละเดือน
* *หมายเหตุ: ค่าใช้จ่ายจะแตกต่างกันไปตามภูมิภาคและปริมาณทราฟฟิก*
