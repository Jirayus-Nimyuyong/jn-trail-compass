# Amazon Cloud Directory Cheat Sheet

**Amazon Cloud Directory** เป็นบริการไดเรกทอรีแบบ Cloud-native ที่มีการจัดการเต็มรูปแบบ ออกแบบมาเพื่อจัดการโครงสร้างข้อมูลแบบลำดับขั้น (Hierarchical) ที่มีความซับซ้อน เช่น แผนผังองค์กร, ทะเบียนอุปกรณ์ และอื่นๆ

* รองรับไดเรกทอรีที่มีวัตถุ (Objects) และความสัมพันธ์นับร้อยล้านรายการ เหมาะสำหรับองค์กรขนาดใหญ่
* คุณสามารถออกแบบ Schema แบบกำหนดเองตามความต้องการเฉพาะและแชร์ Schema ข้ามแอปพลิเคชันได้
* ไม่จำเป็นต้องจัดการเซิร์ฟเวอร์หรือปรับขนาดด้วยตนเอง AWS จะดูแลให้ทั้งหมด
* ใช้โครงสร้างลำดับขั้นร่วมกับ Facets และ Attributes ที่ยืดหยุ่นเพื่อจัดระเบียบข้อมูลให้เหมาะสมกับแอปพลิเคชันของคุณมากที่สุด
* **สถานะการบริการ:** Amazon Cloud Directory จะไม่เปิดรับลูกค้าใหม่ตั้งแต่วันที่ **7 พฤศจิกายน 2025** เป็นต้นไป แต่ลูกค้าเดิมยังสามารถใช้งานบริการต่อไปได้ตามปกติ

## คุณสมบัติ (Features)
* **ลำดับขั้นหลายมิติ:** สร้างลำดับขั้นที่ซับซ้อนและมีหลายระดับ ครอบคลุมมิติต่างๆ เช่น สถานที่, ศูนย์ต้นทุน และโครงสร้างการรายงาน
* **Schema แบบกำหนดเอง:** กำหนด Facets และ Attributes ให้เหมาะสมกับแอปพลิเคชัน เพื่อความยืดหยุ่นสูงสุด
* **ความสามารถในการค้นหา:** เครื่องมือค้นหาในตัวช่วยให้ค้นหาวัตถุและความสัมพันธ์ภายในไดเรกทอรีได้อย่างรวดเร็ว
* **การเข้ารหัสและความปลอดภัย:** เข้ารหัสข้อมูลอัตโนมัติทั้งขณะจัดเก็บ (At rest) และระหว่างรับ-ส่ง (In transit)
* **นโยบายวัตถุ (Object Policies):** ใช้นโยบายเพื่อบังคับใช้ความถูกต้องของข้อมูลและการควบคุมการเข้าถึงทั่วทั้งไดเรกทอรี
* **Managed Schemas:** เพิ่มการรองรับตัวเลือก Schema แบบสำเร็จรูปเพื่อลดความยุ่งยากในการจัดการและแชร์ข้ามแอปพลิเคชัน
* **การอัปเกรด Schema ทันที:** ใช้การเปลี่ยนแปลง Schema กับไดเรกทอรีได้โดยตรงโดยไม่ต้องหยุดระบบหรือย้ายข้อมูล
* **การทำดัชนีตาม Facet:** ใช้ Facets เพื่อสร้างดัชนี (Indexes) ช่วยให้การค้นหาและคิวรีวัตถุแบบลำดับขั้นรวดเร็วขึ้น
* **การทำงานแบบ Batch:** รองรับการทำรายการวัตถุและลิงก์หลายรายการพร้อมกันเพื่อประสิทธิภาพที่สูงขึ้น

## กรณีการใช้งาน (Use Cases)
* **แผนผังองค์กร:** เก็บข้อมูลพนักงาน, โครงสร้างการรายงาน, บทบาท และลำดับขั้นในองค์กร
* **ระบบจัดการเรียนรู้:** จัดการทรัพยากรทางการศึกษา, รายวิชา และข้อมูลการลงทะเบียนของนักเรียน
* **ทะเบียนอุปกรณ์:** ติดตามอุปกรณ์, การตั้งค่า และความสัมพันธ์กับส่วนประกอบเครือข่ายอื่นๆ
* **การจัดการเครือข่าย:** จำลองและจัดการส่วนประกอบเครือข่ายและการเชื่อมต่อที่ซับซ้อน
* **นโยบายความปลอดภัย:** ใช้การควบคุมการเข้าถึงที่ละเอียดและบังคับใช้นโยบายความปลอดภัยขององค์กร

---

## ความปลอดภัย (Security)
* **การทำงานร่วมกับ IAM:** เชื่อมต่อกับ AWS Identity and Access Management (IAM) อย่างราบรื่นเพื่อควบคุมการเข้าถึงทรัพยากรไดเรกทอรี
* **การปฏิบัติตามข้อกำหนด:** รองรับมาตรฐาน ISO, SOC, PCI, FedRAMP และ HIPAA
* **การตรวจสอบ:** เชื่อมต่อกับ CloudTrail เพื่อบันทึกและตรวจสอบการเรียกใช้ API ทั้งหมด
* **VPC Endpoints:** เปิดการเชื่อมต่อแบบส่วนตัวระหว่าง VPC ของคุณและ Cloud Directory เพื่อเพิ่มความปลอดภัย

    * **Strongly Consistent Reads:** $0.0043 ต่อ 1,000 read calls
