# AWS Artifact Cheat Sheet

**AWS Artifact** เป็นพอร์ทัลแบบบริการตนเอง (Self-service) ที่มีผลผูกพันทางกฎหมาย สำหรับเข้าถึงรายงานการปฏิบัติตามข้อกำหนด (Compliance Reports) และข้อตกลงออนไลน์ต่างๆ ของ AWS ตามความต้องการ ทำหน้าที่เป็นแหล่งเก็บข้อมูลกลางสำหรับหลักฐานการตรวจสอบ (Audit Artifacts) ช่วยให้คุณแสดงต่อผู้ตรวจสอบหรือหน่วยงานกำกับดูแลได้ว่า โครงสร้างพื้นฐาน AWS ของคุณเป็นไปตามมาตรฐานความปลอดภัยและการปฏิบัติตามข้อกำหนดที่เฉพาะเจาะจง

### ภาพรวมและความสามารถหลัก
* **แหล่งเก็บข้อมูลการปฏิบัติตามข้อกำหนดส่วนกลาง:** จุดเดียวสำหรับดาวน์โหลดหลักฐานการตรวจสอบและจัดการข้อตกลง
* **หลักฐานการตรวจสอบ (Audit Artifacts):** รายงานและใบรับรองที่ยืนยันว่าระบบควบคุมความปลอดภัยของ AWS มีประสิทธิภาพและถูกต้องตามข้อกำหนด
* **ข้อตกลงทางกฎหมาย:** ตรวจสอบ ตอบรับ และจัดการสัญญาต่างๆ เช่น Business Associate Addendum (BAA) สำหรับ HIPAA
* **การแสดงผลของบุคคลที่สาม:** เข้าถึงเอกสารความปลอดภัยสำหรับผู้จำหน่ายซอฟต์แวร์อิสระ (ISVs) ผ่าน AWS Marketplace

---

### คุณสมบัติเด่น (Features)
* **การควบคุม IAM ที่ละเอียด:** ใช้ Managed Policies (เช่น `ReportsReadOnlyAccess`, `AgreementsFullAccess`) เพื่อจำกัดสิทธิ์การเข้าถึง
* **ข้อตกลงระดับองค์กร (Organization-Level):** เปิดใช้งานข้อตกลงสำหรับบัญชีสมาชิกทั้งหมดผ่าน Management Account
* **ลายน้ำเฉพาะตัว (Unique Watermarking):** รายงานทุกฉบับที่ดาวน์โหลดจะถูกฝังลายน้ำที่สืบกลับไปยังบัญชีของคุณได้ เพื่อความปลอดภัยและการตรวจสอบ
* **การสนับสนุน AWS GovCloud:** มีสิทธิ์การใช้งานและนโยบายเฉพาะสำหรับภูมิภาค GovCloud (US)
* **การแจ้งเตือนและ Logging:** รองรับการแจ้งเตือนผ่าน EventBridge และบันทึกกิจกรรมผ่าน CloudTrail

---

### ข้อตกลง AWS Artifact และการควบคุมการเข้าถึง

#### 1. การเข้าถึงและสิทธิ์
* **สิทธิ์เริ่มต้น:** ผู้ใช้ **Root** และ **IAM Administrators** มีสิทธิ์ดาวน์โหลดและตอบรับข้อตกลงโดยอัตโนมัติ
* **ผู้ใช้ IAM ทั่วไป:** ต้องได้รับสิทธิ์ IAM อย่างชัดเจน (เช่น `artifact:DownloadAgreement`) จึงจะดูหรือดาวน์โหลดเอกสารได้
* **เงื่อนไขเบื้องต้น:** การใช้ข้อตกลงระดับองค์กร AWS Organization ของคุณต้องเปิดใช้งานชุดคุณสมบัติแบบ **“All Features”** เท่านั้น (ไม่ใช่แค่ Consolidated Billing)

#### 2. ประเภทข้อตกลงที่สำคัญ
* **Nondisclosure Agreement (NDA):** มักจำเป็นต้องตอบรับก่อนที่จะสามารถดูรายงานการตรวจสอบที่เป็นความลับของ AWS ได้
* **Business Associate Addendum (BAA):** จำเป็นสำหรับบริษัทที่อยู่ภายใต้กฎหมาย **HIPAA** ที่ต้องจัดการข้อมูลสุขภาพ (PHI) การตอบรับสิ่งนี้จะกำหนดให้บัญชีของคุณเป็น **HIPAA Account** ทันที
* **ข้อตกลงระดับภูมิภาค:** ครอบคลุมกฎระเบียบท้องถิ่น เช่น Australian Notifiable Data Breach (ANDB)

> **เคล็ดลับระดับโปร:** อย่าสับสนระหว่าง **AWS Artifact Agreements** (ข้อตกลงทางกฎหมาย/การปฏิบัติตามข้อกำหนด) กับบริการ **AWS Marketplace Agreements** (สัญญาเชิงพาณิชย์/ราคาสำหรับซอฟต์แวร์)

### ลำดับขั้นระหว่างบัญชีรายบุคคลและองค์กร (มักออกสอบ)
| หัวข้อ | ข้อตกลงระดับบัญชี (Account) | ข้อตกลงระดับองค์กร (Organization) |
| :--- | :--- | :--- |
| **ขอบเขต** | ใช้กับเฉพาะบัญชีที่ล็อกอินเข้าไปเท่านั้น | ยอมรับโดย Management Account และมีผลกับทุกบัญชีในองค์กร |
| **ลำดับความสำคัญ** | หากมีทั้งสองแบบ | **ข้อตกลงระดับองค์กรจะมีลำดับความสำคัญสูงกว่า** |

---

### วงจรชีวิตและตรรกะการสิ้นสุดข้อตกลง
* **การออกจากองค์กร:** หากบัญชีสมาชิกออกจากองค์กร (หรือถูกลบออก) ข้อตกลงระดับองค์กรทั้งหมดที่ยอมรับในนามของบัญชีนั้น **จะสิ้นสุดผลบังคับใช้ทันที** และบัญชีจะกลับสู่สถานะรายบุคคล
* **การยกเลิก:** การยกเลิกข้อตกลงระดับองค์กรจะลบความคุ้มครองของ **ทุกบัญชี** สมาชิก (เว้นแต่บัญชีนั้นจะมีข้อตกลงระดับบัญชีของตัวเอง)

---

### ข้อจำกัดและข้อกำหนด
* **การห้ามแชร์:** โดยทั่วไปคุณ **ไม่สามารถแชร์เอกสารเหล่านี้ต่อสาธารณะ** (เช่น บนเว็บไซต์) เอกสารเหล่านี้เป็นความลับและมีไว้สำหรับคุณและผู้ตรวจสอบ/หน่วยงานกำกับดูแลเท่านั้น
* **สิทธิ์ของ Non-Admin:** ผู้ใช้ IAM ที่ไม่ใช่ Admin จำเป็นต้องมีสิทธิ์อย่างชัดเจนเพื่อเข้าถึง Artifact (เช่น `artifact:Get`, `artifact:DownloadAgreement`)
