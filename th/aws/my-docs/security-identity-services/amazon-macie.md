# Amazon Macie Cheat Sheet

**Amazon Macie** เป็นบริการด้านความปลอดภัยและความเป็นส่วนตัวของข้อมูลแบบ Managed ซึ่งใช้การเรียนรู้ของเครื่อง (Machine Learning) และการจับคู่รูปแบบ (Pattern Matching) เพื่อค้นหาและปกป้องข้อมูลที่ละเอียดอ่อนใน **Amazon S3**

* **จุดเน้นหลัก:** ตรวจสอบสถานะความปลอดภัยของ S3 Bucket (การเข้ารหัส/การเข้าถึงสาธารณะ) และการค้นหาข้อมูลที่ละเอียดอ่อน (PII, PHI, ข้อมูลประจำตัว)
* **หมายเหตุเกี่ยวกับรุ่นเก่า:** ฟีเจอร์ของ Macie Classic (การตรวจจับความผิดปกติของ CloudTrail) ถูกถอดออกแล้ว แนะนำให้ใช้ **Amazon GuardDuty** และ **CloudTrail Insights** แทน

---

## คุณสมบัติเด่น (Features)

### 1. การค้นหาข้อมูลที่ละเอียดอ่อนอัตโนมัติ (Automated Discovery)
* สุ่มตรวจวัตถุใน S3 อย่างต่อเนื่องเพื่อตรวจจับข้อมูลที่ละเอียดอ่อน
* มี **Interactive Heatmap** แสดง Bucket ที่พบข้อมูลสำคัญ (เช่น บัตรเครดิต, PII, PHI)
* รองรับวัตถุที่เข้ารหัสด้วย DSSE-KMS และครอบคลุมสูงสุด 10,000 Buckets ต่อบัญชี

### 2. งานค้นหาข้อมูลเฉพาะเจาะจง (Targeted Discovery Jobs)
* สแกนเชิงลึกใน Bucket ที่ระบุพร้อมกำหนดขอบเขตเอง (Prefix, Tags, ขนาดไฟล์)
* ตั้งเวลาทำงานได้: ครั้งเดียว หรือ รายวัน/สัปดาห์/เดือน

### 3. การตรวจสอบคลังเก็บข้อมูล S3 (Inventory & Assessment)
* ประเมินความปลอดภัยของ Bucket อัตโนมัติ: ตรวจพบ Bucket ที่ไม่เข้ารหัส, เข้าถึงได้สาธารณะ หรือมีการแชร์ให้บุคคลภายนอก
* สร้าง **Policy Findings** เมื่อพบการตั้งค่าที่ผิดพลาด

### 4. ตัวระบุข้อมูล (Data Identifiers)
* **Managed Identifiers:** รูปแบบสำเร็จรูปสำหรับ PII, การเงิน และข้อมูลประจำตัว รองรับข้อมูลเฉพาะประเทศ (เช่น บัตรประชาชนเม็กซิโก, เลข Aadhaar อินเดีย, และ IBAN กว่า 50 ประเทศ)
* **Custom Identifiers:** กำหนดรูปแบบเองโดยใช้ **Regular Expressions (Regex)** (เช่น รหัสพนักงานเฉพาะขององค์กร)
* **Allow Lists:** กำหนดข้อยกเว้นเพื่อให้ Macie ข้ามข้อความที่ระบุ เพื่อลดการแจ้งเตือนที่ผิดพลาด (False Positives)

## แนวคิดสำคัญ (Concepts)

### ประเภทของผลการตรวจพบ (Findings)
1.  **Policy Findings:** ปัญหาเรื่องความปลอดภัยของตัว Bucket (เช่น มีการเปิด Public)
2.  **Sensitive Data Findings:** ข้อมูลละเอียดอ่อนที่พบภายในไฟล์ (ระบุตำแหน่งบรรทัดและคอลัมน์ที่พบชัดเจน)

### แหล่งข้อมูลที่รองรับ (S3 Only)
* **ข้อความ/โค้ด:** .txt, .csv, .json, .xml, .html และซอร์สโค้ดภาษาต่างๆ
* **เอกสาร:** MS Office (.docx, .xlsx), PDF
* **ไฟล์บีบอัด:** .zip, .tar, .gz (Macie จะแตกไฟล์และสแกนเนื้อหาข้างใน)
* **Big Data:** Apache Parquet, Avro

## การจัดการและการเชื่อมต่อ (Management & Integration)
* **Multi-Account:** ทำงานร่วมกับ **AWS Organizations** โดยมีบัญชี Delegated Administrator จัดการและดู Findings ของทุกบัญชีสมาชิกได้จากที่เดียว
* **การส่งออกข้อมูล:** ส่ง Findings ไปยัง **Amazon EventBridge** (เพื่อทำระบบอัตโนมัติ) และ **AWS Security Hub**
* **การเก็บรักษา:** Findings จะถูกเก็บใน Macie เป็นเวลา **90 วัน** หากต้องการเก็บนานกว่านั้นต้องส่งออกไปยัง S3 Bucket

---

## กรณีการใช้งาน (Use Cases)
* **การปฏิบัติตามข้อกำหนด (Compliance):** ค้นหาข้อมูล PII (GDPR) หรือ PHI (HIPAA) ใน S3 Data Lakes เพื่อตรวจสอบว่ามีการเข้ารหัสหรือลบทิ้งแล้วหรือไม่
* **การตรวจสอบก่อนย้ายข้อมูล:** สแกนข้อมูลก่อนย้ายไปยังสภาพแวดล้อมที่มีความปลอดภัยต่ำกว่า
* **การตรวจสอบข้อมูลประจำตัว:** ตรวจจับกรณีที่เผลออัปโหลด AWS Secret Keys หรือใบรับรองส่วนตัว (Private Certificates) ขึ้น S3
