# AWS Shield Cheat Sheet

**AWS Shield** เป็นบริการป้องกันการโจมตีแบบ Distributed Denial of Service (DDoS) ที่มีการจัดการเต็มรูปแบบ เพื่อปกป้องแอปพลิเคชันที่ทำงานบน AWS

### ระดับและคุณสมบัติของ Shield (Shield Tiers and Features)

#### 1. ระดับมาตรฐาน (Standard)
* **ลูกค้า AWS ทุกราย** จะได้รับประโยชน์จากการปกป้องของ Shield Standard โดยอัตโนมัติ
* มีการตรวจสอบการไหลของเครือข่าย (Network flow monitoring) แบบ **Always-on** ซึ่งจะตรวจสอบทราฟฟิกขาเข้ามายัง AWS และตรวจจับทราฟฟิกที่เป็นอันตรายแบบเรียลไทม์
* ใช้เทคนิคต่างๆ เช่น การกรองแพ็กเก็ต (Deterministic packet filtering) และการจัดลำดับความสำคัญทราฟฟิก (Priority-based traffic shaping) เพื่อบรรเทาการโจมตีโดยอัตโนมัติโดยไม่ส่งผลกระทบต่อแอปพลิเคชันของคุณ
* เมื่อใช้งานร่วมกับ **CloudFront** และ **Route 53** จะช่วยให้การปกป้องความพร้อมใช้งาน (Availability) ครอบคลุมถึงการโจมตีในระดับโครงสร้างพื้นฐาน (Infrastructure-layer) ที่เป็นที่รู้จักทั้งหมด
* คุณสามารถดูเหตุการณ์ที่ตรวจพบและได้รับการบรรเทาได้ใน AWS Shield Console ของบัญชีคุณ

#### 2. ระดับขั้นสูง (Advanced)
* ให้การตรวจจับที่เหนือกว่าโดยการตรวจสอบ Network flows และตรวจสอบทราฟฟิกระดับแอปพลิเคชัน (Application-layer) ไปยังทรัพยากรต่างๆ เช่น Elastic IPs, ELB, CloudFront และ Route 53
* จัดการการป้องกันและบรรเทาการโจมตี DDoS ส่วนใหญ่สำหรับ **Layer 3, Layer 4 และ Layer 7**
* รวมสิทธิ์การเข้าถึงทีมตอบโต้ DDoS (AWS DDoS Response Team - DRT) ตลอด **24×7** (ต้องมี Support ระดับ Business หรือ Enterprise)
* เพิ่มขีดความสามารถในการบรรเทาผลกระทบโดยอัตโนมัติเพื่อป้องกันการโจมตีขนาดใหญ่หรือซับซ้อน และทีม DRT ยังสามารถใช้การบรรเทาด้วยมือ (Manual) ได้ด้วย
* แสดงรายละเอียดการโจมตี DDoS ผ่านการแจ้งเตือน **CloudWatch** แบบเกือบเรียลไทม์ และการวินิจฉัยอย่างละเอียดในหน้า AWS WAF & Shield Console
* มี **การคุ้มครองค่าใช้จ่ายจาก DDoS (DDoS cost protection)** ซึ่งจะให้เครดิตคืนสำหรับค่าบริการส่วนเกินที่เกิดจากการสเกลทรัพยากรในช่วงที่โดนโจมตี
* พร้อมใช้งานทั่วโลกในทุกตำแหน่ง Edge ของ CloudFront และ Route 53 ที่รองรับ
* ให้สิทธิ์เข้าถึงข้อมูลประวัติการโจมตีย้อนหลังได้ถึง **13 เดือน**

### คุณสมบัติเพิ่มเติมอื่นๆ
* รองรับการทำงานร่วมกับ **AWS WAF** เพื่อการปกป้องระดับแอปพลิเคชันขั้นสูง
* ให้บันทึกเหตุการณ์ (Event logs) และการวินิจฉัยโดยละเอียดเพื่อการสืบสวนและวิเคราะห์

### ค่าบริการ (AWS Shield Pricing)

* **Shield Standard:** รวมอยู่ในบริการโดยอัตโนมัติ **ไม่มีค่าใช้จ่ายเพิ่มเติม** สำหรับลูกค้า AWS ทุกราย
* **Shield Advanced:** เป็นบริการแบบชำระเงินที่ต้องมีข้อตกลงสมัครใช้งาน **1 ปี (1-year subscription)**
    * คิด **ค่าธรรมเนียมรายเดือน (Monthly subscription fee)** ต่อองค์กรหรือต่อบัญชี (ขึ้นอยู่กับการตั้งค่า)
    * มี **ค่าธรรมเนียมตามการใช้งานเพิ่มเติม (Usage-based fees)** สำหรับการถ่ายโอนข้อมูลขาออก (Data Transfer Out) จาก CloudFront, ELB, EC2 และ AWS Global Accelerator
