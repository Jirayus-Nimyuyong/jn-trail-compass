# Amazon Cognito Cheat Sheet

**Amazon Cognito** เป็นบริการจัดการผู้ใช้และการยืนยันตัวตน (User Management and Authentication) ที่สามารถรวมเข้ากับเว็บหรือแอปพลิเคชันมือถือของคุณได้ Cognito ช่วยให้สามารถยืนยันตัวตนผ่านผู้ให้บริการภายนอก และมอบข้อมูลประจำตัว AWS ชั่วคราว (Temporary Credentials) เพื่อเข้าถึงทรัพยากรหลังบ้านของแอปหรือบริการใดๆ ที่อยู่หลัง Amazon API Gateway

* รองรับ **SAML, OpenID Connect (OIDC)** และ **Social Identity Providers** (Facebook, Google, Apple, Microsoft, ฯลฯ) รวมถึงผู้ให้บริการของคุณเอง
* **Cognito ID Tokens** ทั้งหมดจะอยู่ในรูปแบบ **JSON Web Tokens (JWT)**

---

## คุณสมบัติเด่น (Features)
* **AWS PrivateLink:** รองรับการเรียกใช้งาน API ผ่าน VPC Endpoints เพื่อความปลอดภัยระดับเครือข่าย
* **Passkeys & OTP:** ผู้ใช้สามารถลงชื่อเข้าใช้ด้วย Passkeys หรือรหัสผ่านครั้งเดียว (One-Time Passwords) ได้แล้ว
* **การปรับปรุง Managed Login:** สามารถเพิ่มลิงก์ข้อกำหนดการใช้งาน (Terms & Conditions) และนโยบายความเป็นส่วนตัว รวมถึงใช้งานร่วมกับ **AWS WAF** เพื่อป้องกันการโจมตี
* **Identity Pool:** ปรับปรุงนโยบายความเชื่อถือของ IAM Role ให้เจาะจงสำหรับการทำ OIDC Federation มากขึ้น
* **Refresh Token Rotation:** สามารถหมุนเวียน (Rotate) และยกเลิกการใช้งาน Refresh Token ตัวเดิมเมื่อมีการขอ Token ใหม่ เพื่อความปลอดภัยที่สูงขึ้น
* **การปรับแต่ง Token:** สามารถใช้ Lambda Trigger (Pre token generation) เพื่อแก้ไข Claims หรือ Scopes ใน Access Token ได้
* **Advanced Security:** ระบบตรวจจับภัยคุกคาม, การป้องกันการใช้รหัสผ่านซ้ำ และการส่งออก Log กิจกรรมของผู้ใช้

## ส่วนประกอบหลัก (Key Concepts)

### 1. User Pools (ไดเรกทอรีผู้ใช้)
เป็นไดเรกทอรีที่ให้บริการลงทะเบียน (Sign-up) และลงชื่อเข้าใช้ (Sign-in) สำหรับผู้ใช้แอปของคุณ
* ผู้ใช้สามารถล็อกอินผ่าน Cognito โดยตรง หรือผ่านบุคคลที่สาม (Federation)
* **Tokens ที่ได้รับ:**
    * **Access Tokens:** ใช้สำหรับอนุญาตการเข้าถึงทรัพยากร (หมดอายุได้ตั้งแต่ 5 นาที - 24 ชั่วโมง)
    * **ID Tokens:** มีข้อมูลอัตลักษณ์ของผู้ใช้ (Identity)
    * **Refresh Tokens:** ใช้เพื่อขอ ID หรือ Access Token ใหม่ (หมดอายุได้ตั้งแต่ 1 ชั่วโมง - 10 ปี)
* **การจัดการ:** สามารถจัดกลุ่มผู้ใช้ (Groups) และจับคู่กับ **IAM Roles** เพื่อควบคุมการเข้าถึงทรัพยากรได้

### 2. Identity Pools (การมอบสิทธิ์เข้าถึง AWS)
ใช้คุณสมบัตินี้หากคุณต้องการให้ผู้ใช้เข้าถึงบริการของ AWS โดยตรง
* มอบข้อมูลประจำตัว AWS ชั่วคราว (เช่น Access Key/Secret Key) เพื่อเข้าถึงบริการอย่าง Amazon S3 หรือ DynamoDB
* รองรับทั้งผู้ใช้ที่ยืนยันตัวตนแล้ว (Authenticated) และผู้ใช้ทั่วไป/แขก (Unauthenticated/Guest)
* ทำงานร่วมกับ User Pool หรือผู้ให้บริการภายนอกเพื่อแลกเปลี่ยน Token เป็นสิทธิ์ของ AWS ผ่าน API **AssumeRoleWithWebIdentity**

## กรณีการใช้งานทั่วไป (Common Use Cases)
* **ยืนยันตัวตนในแอป:** ใช้ User Pool เพื่อจัดการการลงชื่อเข้าใช้และรับ JWT Token เพื่อควบคุมหน้าเว็บหรือส่วนประกอบในแอป
* **ปกป้อง Serverless API:** ใช้ **Cognito Authorizer** บน API Gateway เพื่อตรวจสอบความถูกต้องของ Token ก่อนอนุญาตให้เรียกใช้งาน Lambda
* **เข้าถึงทรัพยากร AWS โดยตรง:** แอปมือถือล็อกอินผ่าน User Pool แล้วนำ Token มาแลกเป็นสิทธิ์ AWS ที่ Identity Pool เพื่ออัปโหลดไฟล์ขึ้น S3 โดยตรง (ไม่ต้องผ่าน Server หลังบ้าน)
* **ซิงค์ข้อมูลผู้ใช้:** ใช้ร่วมกับ **AWS AppSync (GraphQL)** เพื่อซิงค์โปรไฟล์ผู้ใช้หรือสถานะเกมข้ามอุปกรณ์ทั้งในโหมดออนไลน์และออฟไลน์

## ความปลอดภัยขั้นสูง (Advanced Security Features)
* **Adaptive Authentication:** ตรวจจับกิจกรรมที่ผิดปกติ (เช่น ล็อกอินจากเครื่องใหม่หรือสถานที่ใหม่) และให้คะแนนความเสี่ยงเพื่อบล็อกหรือบังคับใช้ MFA อัตโนมัติ
* **Compromised Credentials Detection:** ตรวจสอบว่าชื่อผู้ใช้/รหัสผ่านเคยหลุดในเหตุการณ์ข้อมูลรั่วไหลที่อื่นบนอินเทอร์เน็ตหรือไม่ และบังคับให้เปลี่ยนรหัสผ่าน
* **MFA:** รองรับการยืนยันตัวตนผ่าน SMS, อีเมล หรือแอปสร้างรหัส (TOTP)

---

## การเชื่อมต่อกับ AWS Lambda
คุณสามารถสั่งให้ Lambda ทำงานตามเหตุการณ์ต่างๆ (Triggers) เช่น:
* **Pre Sign-up:** ตรวจสอบข้อมูลก่อนให้ลงทะเบียน
* **Post Confirmation:** ส่งอีเมลต้อนรับหลังจากยืนยันตัวตนเสร็จ
* **User Migration:** ย้ายข้อมูลผู้ใช้จากระบบเก่ามายัง Cognito อย่างราบรื่นขณะที่เขาล็อกอินครั้งแรก

## ค่าบริการ (Pricing)
* **คิดตามจำนวนผู้ใช้ต่อเดือน (MAU):** * ระดับ **Lite + Essentials:** ฟรี 10,000 MAUs แรก
    * ระดับ **Plus (Advanced Security):** คิดเงินตั้งแต่ผู้ใช้รายแรก (ไม่มีช่วงฟรี)
* **Machine-to-Machine (M2M):** คิดค่าบริการต่อจำนวนการขอ Token
* **MFA:** คิดค่าบริการส่งข้อความตามจริงของ AWS SNS (SMS) หรือ SES (Email)
