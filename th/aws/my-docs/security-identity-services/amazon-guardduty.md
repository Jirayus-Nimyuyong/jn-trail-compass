# Amazon GuardDuty Cheat Sheet

**Amazon GuardDuty** เป็นบริการตรวจจับภัยคุกคามอัจฉริยะที่วิเคราะห์เหตุการณ์นับพันล้านรายการในบัญชี AWS ของคุณจากแหล่งข้อมูลดังนี้:
* **AWS CloudTrail:** กิจกรรมของผู้ใช้และการเรียกใช้ API
* **VPC Flow Logs:** ข้อมูลทราฟฟิกเครือข่าย
* **DNS Logs:** รูปแบบการคิวรีชื่อโดเมน

### คุณสมบัติเด่น (Features)
* **UnauthorizedAccess:** ตรวจจับการเรียกใช้ API จากโฮสต์ภายนอกโดยใช้ข้อมูลประจำตัวชั่วคราวที่สร้างโดย Lambda
* **Extended Threat Detection:** ตรวจจับการโจมตีหลายขั้นตอน (ลำดับเหตุการณ์บน EC2/ECS/EKS)
* **Runtime Monitoring:** ตรวจสอบเหตุการณ์ระดับระบบปฏิบัติการและคอนเทนเนอร์ (Agent ล่าสุดรองรับ EC2, ECS, EKS-Fargate)
* **Malware Protection for Backup:** สแกน EBS Snapshots, EC2 AMIs และจุดกู้คืนข้อมูล (Recovery Points)
* **S3 Malware Protection:** สแกนวัตถุขนาดสูงสุด 100 GB และรองรับการสั่งสแกนผ่าน API
* **AI Workloads Protection:** ตรวจจับภัยคุกคามในเวิร์กโหลด AI ผ่าน Lambda
* **การทำงานร่วมกับบริการอื่น:** เชื่อมต่อกับ AWS Detective, Security Hub และ EventBridge ได้อย่างราบรื่น

---

### การทำงานและประเภทการตรวจสอบเฉพาะทาง

* **EKS Protection:** ตรวจสอบ Kubernetes Audit Logs และเหตุการณ์ Runtime ภายใน Pods/Nodes
* **Lambda Protection:** ตรวจสอบ Network Logs เพื่อตรวจจับโค้ดอันตรายหรือการขุดเหรียญคริปโต
* **RDS Protection:** วิเคราะห์การพยายามล็อกอินของ Amazon Aurora เพื่อตรวจจับการขโมยข้อมูลประจำตัวหรือการสุ่มรหัสผ่าน (Brute-force)
* **S3 Protection:** ตรวจสอบกิจกรรมในระดับวัตถุเพื่อหารูปแบบการเข้าถึงที่ผิดปกติหรือการดึงข้อมูลออกภายนอก
* **Malware Protection:** สแกนหาไฟล์อันตรายบน EBS Volumes หรือวัตถุใหม่ใน S3 โดย **ไม่ส่งผลกระทบต่อประสิทธิภาพการทำงาน** (สแกนผ่าน Snapshot หรือสภาพแวดล้อมที่แยกส่วน)

---

### รายละเอียดของ Findings (สิ่งที่ตรวจพบ)
GuardDuty จะสร้าง **Findings** เมื่อตรวจพบกิจกรรมที่น่าสงสัย ซึ่งสามารถดูได้ผ่าน Console, CLI หรือ API โดยในสรุปจะประกอบด้วย:
* **Finding Type:** คำอธิบายปัญหาความปลอดภัยที่กระชับและเข้าใจง่าย
* **Severity:** ระดับความรุนแรง (สูง, กลาง, หรือ ต่ำ)
* **Account ID / Resource ID:** ระบุบัญชีและทรัพยากรที่ได้รับผลกระทบ
* **Action:** อธิบายประเภทกิจกรรม (เช่น การเชื่อมต่อเครือข่าย, การเรียก API, การสแกนพอร์ต)
* **Actor:** ข้อมูลผู้กระทำการ (ตำแหน่งทางภูมิศาสตร์ของ IP, ISP, ที่อยู่ IP)

---

### นิยามของวัตถุประสงค์ในการคุกคาม (Threat Purpose)
* **Backdoor:** ทรัพยากรที่ถูกบุกรุกกำลังติดต่อกับเซิร์ฟเวอร์ C&C (Command & Control)
* **Cryptocurrency:** ตรวจพบซอฟต์แวร์ขุดเหรียญดิจิทัล
* **Stealth:** พยายามปกปิดการกระทำหรือลบร่องรอย (เช่น การสั่งปิด Log)
* **Recon:** การสำรวจหาช่องโหว่ (เช่น การสแกนพอร์ต, การไล่รายชื่อผู้ใช้)
* **PrivilegeEscalation:** พยายามยกระดับสิทธิ์การใช้งานให้สูงขึ้น
* **Trojan:** ซอฟต์แวร์อันตรายที่แอบทำงานเงียบๆ เพื่อโจมตีระบบ

---

### การจัดการ Findings
* **Filters:** ใช้กรองเพื่อดูเฉพาะเหตุการณ์ที่สนใจ
* **Suppression Rules:** เก็บถาวร (Archive) ข้อมูลที่ตรงตามเงื่อนไขที่กำหนดโดยอัตโนมัติ
* **Trusted IP Lists:** รายชื่อ IP ที่เชื่อถือได้ (Whitelist) เพื่อไม่ให้แจ้งเตือน
* **Threat Lists:** รายชื่อ IP อันตรายที่กำหนดเอง (Blacklist)

---

### ค่าบริการ (Pricing)
* **Foundational:** คิดตามปริมาณข้อมูล CloudTrail, VPC Flow Logs และ DNS Logs ที่วิเคราะห์
* **EKS Protection:** คิดตามจำนวน vCPU ต่อชั่วโมง (Runtime Monitoring) และต่อจำนวน Audit Logs 1 ล้านรายการ
* **Lambda Protection:** คิดตามจำนวน GB ของ Network Activity Logs ที่สแกน
* **Malware Protection:** คิดตามจำนวน GB ของข้อมูลที่สแกน (EBS หรือ S3)
* **RDS Protection:** คิดตามจำนวนเหตุการณ์การล็อกอิน 1 ล้านรายการที่วิเคราะห์
* **ทดลองใช้ฟรี:** บัญชีใหม่ (หรือฟีเจอร์ใหม่ที่เพิ่งเปิด) มักจะได้รับสิทธิ์ **ทดลองใช้ฟรี 30 วัน**
