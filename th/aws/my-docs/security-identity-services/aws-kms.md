# AWS KMS Cheat Sheet

**AWS Key Management Service (KMS)** เป็นบริการ Managed Service ที่ช่วยให้คุณเข้ารหัสข้อมูลได้อย่างง่ายดาย KMS มอบโซลูชันการจัดเก็บคีย์ที่มีความพร้อมใช้งานสูง การจัดการ และการตรวจสอบสิทธิ์ (Auditing) เพื่อให้คุณเข้ารหัสข้อมูลภายในแอปพลิเคชันของคุณเอง และควบคุมการเข้ารหัสข้อมูลที่จัดเก็บไว้ในบริการต่างๆ ของ AWS

---

## คุณสมบัติเด่น (Features)
* **การตรวจสอบ:** ทำงานร่วมกับ **CloudTrail** เพื่อให้คุณตรวจสอบได้ว่า ใครใช้คีย์ไหน กับทรัพยากรอะไร และเมื่อไหร่
* **การหมุนเวียนคีย์ (Rotation):** สามารถตั้งค่าให้ KMS หมุนเวียนคีย์โดยอัตโนมัติปีละครั้ง โดยไม่จำเป็นต้องเข้ารหัสข้อมูลเดิมซ้ำ
* **ความทนทาน:** จัดเก็บคีย์หลายสำเนาในระบบที่ออกแบบมาให้มีความทนทานสูงถึง **99.999999999%**
* **ความเป็นส่วนตัว:** เชื่อมต่อโดยตรงผ่าน **VPC Private Endpoint** ได้ ทราฟฟิกจะไม่ไหลออกไปยังอินเทอร์เน็ตสาธารณะ
* **ความยืดหยุ่น:** รองรับคีย์แบบ Multi-Region (ทำสำเนาคีย์ข้ามภูมิภาค) และรองรับการหมุนเวียนคีย์แบบ On-demand (ตามความต้องการ)
* **ประเภทคีย์ที่หลากหลาย:** รองรับทั้งคีย์แบบสมมาตร (Symmetric), อสมมาตร (Asymmetric - สำหรับการลงลายมือชื่อและถอดรหัส), HMAC และอัลกอริทึม Post-quantum
* **การควบคุม:** ใช้ ABAC (Attribute-based access control) ผ่าน Tag และ Alias เพื่อกำหนดสิทธิ์การเข้าถึงคีย์อย่างละเอียด

## แนวคิดหลัก (Concepts)

### ประเภทของ KMS Keys
| ประเภทของคีย์ | ดูรายละเอียดได้ | จัดการได้ | ใช้เฉพาะบัญชีเรา |
| :--- | :---: | :---: | :---: |
| **Customer managed keys** | ใช่ | **ใช่** | ใช่ |
| **AWS managed keys** | ใช่ | ไม่ใช่ | ใช่ |
| **AWS owned keys** | ไม่ใช่ | ไม่ใช่ | ไม่ใช่ |

* **Customer managed keys:** คีย์ที่คุณสร้างและเป็นเจ้าของเอง มีอำนาจควบคุมเต็มรูปแบบ (เปิด/ปิด, ลบ, หมุนเวียนคีย์, ตั้งนโยบาย)
* **AWS managed keys:** สร้างโดยบริการของ AWS (เช่น S3, EBS) เพื่อใช้งานแทนคุณ คุณดูได้แต่แก้ไขหรือลบไม่ได้
* **AWS owned keys:** คีย์ที่ AWS เป็นเจ้าของเพื่อใช้ในหลายบัญชี คุณไม่สามารถมองเห็นหรือจัดการได้

### คำศัพท์สำคัญ
* **Data keys:** คีย์ที่ใช้เข้ารหัสข้อมูลจริงๆ (KMS จะสร้าง/เข้ารหัส/ถอดรหัส Data keys ให้ แต่จะไม่จัดเก็บหรือจัดการ Data keys เหล่านั้นให้คุณ)
* **Envelope encryption:** วิธีการนำข้อมูลไปเข้ารหัสด้วย Data key แล้วนำ Data key นั้นไปเข้ารหัสซ้ำด้วย Root key (KMS Key) อีกชั้นหนึ่ง
* **Encryption Context:** ชุดข้อมูล Key-value ที่ใส่เพิ่มเข้าไปเพื่อเพิ่มความปลอดภัยและใช้ในการตรวจสอบสิทธิ์
* **Key Policies:** เอกสาร JSON ที่กำหนดว่าใครสามารถ "จัดการ" หรือ "ใช้งาน" คีย์นั้นได้ (เป็นวิธีหลักในการกำหนดสิทธิ์)
* **Grants:** วิธีให้สิทธิ์การใช้งานคีย์แบบชั่วคราว โดยไม่ต้องไปแก้ไข Key Policy

## การนำเข้าและการลบคีย์
* **การนำเข้าคีย์ (Importing):** คุณสามารถนำคีย์จากภายนอก (Key Material) มาใส่ใน KMS ได้ โดยสามารถกำหนดวันหมดอายุได้ หากหมดอายุคีย์จะใช้งานไม่ได้ทันที
* **การลบคีย์ (Deleting):** การลบคีย์เป็นการกระทำที่ **ย้อนคืนไม่ได้** ข้อมูลที่ถูกเข้ารหัสด้วยคีย์นั้นจะไม่สามารถกู้คืนได้อีกตลอดไป (KMS จะมีช่วงเวลา Waiting Period ก่อนลบจริงเพื่อให้คุณเปลี่ยนใจได้)
* **การปิดใช้งาน (Disable):** สามารถปิดการใช้งานคีย์ชั่วคราวเพื่อไม่ให้ใครใช้งานได้โดยไม่ต้องลบทิ้ง

---

## กรณีการใช้งาน (Use Cases)
* **S3 Bucket Encryption:** เข้ารหัสข้อมูลใน Bucket และตรวจสอบการเข้าถึงผ่าน CloudTrail
* **EBS Volume Encryption:** เข้ารหัสไดรฟ์สำหรับอินสแตนซ์ EC2
* **Secrets Manager:** เข้ารหัสรหัสผ่านฐานข้อมูลหรือ API Keys
* **Digital Signing:** ใช้คีย์แบบอสมมาตรเพื่อลงลายมือชื่อในโค้ดหรือเอกสาร

## ค่าบริการ (Pricing)
1. **ค่าจัดเก็บคีย์ (Key Storage):**
   * Customer Managed Keys: **$1.00** ต่อคีย์ / เดือน
   * AWS Managed Keys: **ฟรี**
2. **ค่าการหมุนเวียนคีย์ (Rotation):**
   * การหมุนเวียนครั้งที่ 1 และ 2: คิดตามสัดส่วน $1/เดือน
   * การหมุนเวียนครั้งต่อๆ ไป: **ฟรี** (จำกัดเพดานราคาที่การหมุนครั้งที่สอง)
3. **ค่าคำขอใช้งาน (Request Costs):**
   * **Free Tier:** ฟรี 20,000 คำขอ / เดือน
   * มาตรฐาน (Symmetric): ประมาณ $0.03 ต่อ 10,000 คำขอ
   * อสมมาตร (Asymmetric): ราคาจะสูงกว่าตามประเภทของอัลกอริทึม (RSA หรือ ECC)
