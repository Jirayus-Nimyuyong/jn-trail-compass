# AWS Secrets Manager Cheat Sheet

**AWS Secrets Manager** เป็นบริการจัดการความลับ (Secret Management) ที่ช่วยให้คุณสามารถ **หมุนเวียน (Rotate), จัดการ และเรียกใช้ข้อมูลประจำตัวของฐานข้อมูล, API Keys, OAuth Tokens และความลับอื่นๆ** ได้อย่างปลอดภัยตลอดอายุการใช้งาน ช่วยขจัดความจำเป็นในการเขียนรหัสผ่านลงในโค้ด (Hard-code) และเพิ่มระดับความปลอดภัยให้สูงขึ้น

### คุณสมบัติเด่น (Features)
* **การเข้ารหัสและการส่งข้อมูล:** ความลับจะถูกเข้ารหัสขณะจัดเก็บ (At rest) ด้วยคีย์ **AWS KMS** และส่งผ่านเครือข่ายอย่างปลอดภัยด้วย **TLS**
* **การหมุนเวียนความลับ (Secret Rotation):** หมุนเวียนความลับตามกำหนดการหรือตามความต้องการผ่าน Console, SDK หรือ CLI
* **รองรับการหมุนเวียนแบบ Native:** หมุนเวียนรหัสผ่านอัตโนมัติสำหรับ Amazon RDS, Amazon DocumentDB และ Amazon Redshift
* **การหมุนเวียนแบบกำหนดเอง:** ใช้ฟังก์ชัน **AWS Lambda** เพื่อขจัดความลับอื่นๆ (เช่น Oracle บน EC2 หรือ OAuth tokens)
* **Metadata ของความลับ:** เก็บชื่อ, คำอธิบาย, ARN ของคีย์ KMS และแท็ก (Tags) สำหรับการจัดกลุ่มหรือทำ ABAC
* **Secret Versions & Staging Labels:** รองรับการมีหลายเวอร์ชันพร้อมกัน โดยเวอร์ชันล่าสุดจะมีป้ายกำกับว่า `AWSCURRENT` ส่วนเวอร์ชันก่อนหน้าคือ `AWSPREVIOUS`
* **การทำสำเนาข้ามภูมิภาค (Cross-Region Replication):** คัดลอกความลับไปยังหลายภูมิภาคพร้อม Metadata, แท็ก และการตั้งค่าการหมุนเวียน
* **การรองรับ IPv6 & Dual-Stack:** รองรับการเข้าถึงผ่านทั้ง IPv4 และ IPv6

---

### ขั้นตอนการทำงานของการหมุนเวียนความลับ (How Secret Rotation Works)
1. **สร้างฟังก์ชันการหมุนเวียน:** ฟังก์ชัน Lambda สร้างชุดรหัสผ่านใหม่ (`AWSPENDING`) และจัดเก็บเป็นเวอร์ชันใหม่
2. **ทดสอบความลับใหม่:** ฟังก์ชันจะตรวจสอบว่ารหัสผ่านในสถานะ `AWSPENDING` ใช้งานกับบริการปลายทางได้จริงหรือไม่
3. **อัปเดตป้ายกำกับ (Staging Labels):** หากสำเร็จ ป้าย `AWSCURRENT` จะถูกย้ายไปยังเวอร์ชันใหม่ และเวอร์ชันเก่าจะกลายเป็น `AWSPREVIOUS`
4. **การอัปเดตฝั่งแอปพลิเคชัน:** แอปพลิเคชันจะเริ่มดึงรหัสผ่านใหม่ไปใช้งานโดยอัตโนมัติ

### ความปลอดภัย (AWS Secrets Manager Security)
* **ไม่มีการแคชข้อมูล:** โดยค่าเริ่มต้น Secrets Manager จะไม่เขียนหรือแคชความลับลงในพื้นที่จัดเก็บที่คงทน (Persistent storage)
* **บังคับใช้ TLS:** รองรับเฉพาะคำขอที่ใช้ TLS และ Perfect Forward Secrecy เท่านั้น
* **การควบคุมการเข้าถึง:** ใช้ **IAM Policies** และการกำหนดสิทธิ์ตามแท็ก (Tag-based access control)
* **VPC Endpoints:** ตั้งค่าเพื่อให้ทราฟฟิกระหว่าง VPC และ Secrets Manager วิ่งอยู่ภายในเครือข่ายของ AWS เท่านั้น
* **การลบข้อมูล:** Secrets Manager จะไม่ลบความลับทิ้งทันที แต่จะกำหนดเวลาลบโดยมี **ระยะเวลากู้คืนขั้นต่ำ 7 วัน** (ในระหว่างนี้สามารถกู้คืนได้) ยกเว้นกรณีใช้ CLI สั่งลบแบบไม่รอระยะเวลากู้คืน

* จ่ายตามจำนวนการเรียกใช้งาน API (ต่อ 10,000 ครั้ง) ต่อเดือน
* **ไม่มีค่าใช้จ่ายเพิ่มเติม** สำหรับการทำสำเนาความลับข้ามภูมิภาค (จ่ายเพียงค่าจัดเก็บและ API ตามปกติในภูมิภาคนั้นๆ)
