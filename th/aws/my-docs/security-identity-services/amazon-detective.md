# Amazon Detective Cheat Sheet

**Amazon Detective** เป็นบริการที่รวบรวมข้อมูล Log จากทรัพยากร AWS ของคุณโดยอัตโนมัติ และใช้การเรียนรู้ของเครื่อง (Machine Learning), การวิเคราะห์ทางสถิติ และทฤษฎีกราฟ เพื่อสร้างชุดข้อมูลที่เชื่อมโยงกัน ช่วยให้คุณสามารถดำเนินการตรวจสอบความปลอดภัยได้อย่างรวดเร็วและมีประสิทธิภาพมากขึ้น

* สามารถทำงานร่วมกับบริการความปลอดภัยของ AWS เช่น **Amazon GuardDuty, Amazon Macie, และ AWS Security Hub** รวมถึงผลิตภัณฑ์ของพาร์ทเนอร์เพื่อระบุปัญหาด้านความปลอดภัย

---

## ภาพรวมและแหล่งข้อมูล (Overview & Data Sources)
* **การนำเข้าข้อมูลอัตโนมัติ:** วิเคราะห์เหตุการณ์นับล้านล้านรายการจาก:
    * VPC Flow Logs
    * AWS CloudTrail (ทั้ง Management และ Data Events)
    * ข้อมูลที่ตรวจพบจาก Amazon GuardDuty
    * Amazon EKS Audit Logs (ใหม่)
    * ข้อมูลจาก AWS Security Hub (ASFF)
* **มุมมองแบบรวมศูนย์:** สร้างมุมมองเชิงโต้ตอบระหว่างทรัพยากร ผู้ใช้ และการปฏิสัมพันธ์ระหว่างกันตามช่วงเวลาอัตโนมัติ
* **การตรวจสอบ EKS:** รองรับการตรวจสอบปริมาณงาน Kubernetes ช่วยให้คุณติดตามกิจกรรมที่น่าสงสัยลงไปถึงระดับ Pods, Container Images และการเรียกใช้ Kubernetes API

---

## คุณสมบัติเด่น (Features)
* **Generative AI Support:** สรุปกลุ่มเหตุการณ์ (Finding Group Summaries) อัตโนมัติด้วยภาษาธรรมชาติ ช่วยให้นักวิเคราะห์เข้าใจ "เรื่องราว" เบื้องหลังเหตุการณ์ความปลอดภัยได้ทันที
* **การรวมข้อมูลกับ Security Lake:** สามารถสืบค้นข้อมูล Log ดิบจาก Amazon Security Lake ได้โดยตรงผ่านหน้าจอ Detective
* **การสืบสวน IAM:** ตรวจสอบผู้ใช้และบทบาท (Roles) ของ IAM ที่มีตัวบ่งชี้ว่าอาจถูกบุกรุก (Indicators of Compromise)
* **การแสดงผลขั้นสูง:** มีแผนผังเวลา (Timeline) และเลย์เอาต์แบบรัศมี (Radial layout) เพื่อให้ง่ายต่อการแปลความหมายของกลุ่มเหตุการณ์
* **ไม่ต้องใช้ GuardDuty:** ปัจจุบันคุณไม่จำเป็นต้องเปิดใช้งาน GuardDuty ก็สามารถใช้ Detective ได้

---

## แนวคิดหลัก (Concepts)
* **Behavior Graph (กราฟพฤติกรรม):** ชุดข้อมูลที่เชื่อมโยงกันซึ่งสร้างจากข้อมูลต้นทางที่เกี่ยวข้องกับบัญชี AWS ช่วยให้เห็นโครงสร้างของความสัมพันธ์ระหว่างเอนทิตี
* **Delegated Administrator:** บัญชี AWS ที่ได้รับมอบหมายให้จัดการกราฟพฤติกรรมสำหรับองค์กร (ทำหน้าที่เชิญบัญชีสมาชิกและดำเนินการตรวจสอบ)
* **Entity (เอนทิตี):** รายการที่ดึงมาจากข้อมูลต้นทาง เช่น ที่อยู่ IP, อินสแตนซ์ EC2, ผู้ใช้ AWS หรือ Pods ของ Kubernetes
* **Relationship (ความสัมพันธ์):** กิจกรรมที่เกิดขึ้นระหว่างเอนทิตี เช่น IP เชื่อมต่อไปยัง EC2
* **Finding Groups (กลุ่มเหตุการณ์):** หัวใจสำคัญที่รวมเหตุการณ์ที่เกี่ยวข้องกัน (เช่น การเดารหัสผ่านตามด้วยการขโมยสิทธิ์ IAM) ให้กลายเป็นเหตุการณ์ความปลอดภัยเดียว เพื่อให้ตรวจสอบได้ง่ายขึ้น

---

## การทำงานและการตั้งค่า
* **บริการระดับภูมิภาค:** ต้องเปิดใช้งานแยกตามภูมิภาค (Region) และจะวิเคราะห์ข้อมูลภายในภูมิภาคนั้นๆ
* **ประวัติย้อนหลังอัตโนมัติ:** หากใช้ GuardDuty อยู่แล้ว Detective จะนำเข้าข้อมูล Log ย้อนหลัง **2 สัปดาห์** มาประมวลผลทันทีที่เปิดใช้งาน
* **การวิเคราะห์ IAM Role:** สามารถวิเคราะห์เซสชันของบทบาท IAM ผ่าน VPC Flow Logs และ CloudTrail เพื่อดูว่าผู้ใช้หรือแอปพลิเคชันทำอะไรภายใต้บทบาทที่สวมสิทธิ์ (Assumed Role)

---

## การเปรียบเทียบ (Detective vs. GuardDuty vs. Security Hub)
* **Amazon GuardDuty:** บริการ "ตรวจจับ" ภัยคุกคาม (เหมือนสัญญาณกันขโมย)
* **AWS Security Hub:** ศูนย์กลาง "รวบรวม" และจัดลำดับความสำคัญของการแจ้งเตือน (เหมือนหน้าจอรวมภาพกล้องวงจรปิด)
* **Amazon Detective:** บริการ "ตรวจสอบ" และวิเคราะห์หาสาเหตุหลัก (เหมือนทีมนิติวิทยาศาสตร์ที่เข้ามาดูหลักฐานและลำดับเหตุการณ์)

---

## กรณีการใช้งานทั่วไป (Use Cases)
* **คัดกรองเหตุการณ์ความปลอดภัย (Triage):** ตัดสินใจอย่างรวดเร็วว่าสิ่งที่ GuardDuty ตรวจพบเป็นภัยคุกคามจริงหรือเป็นเพียง False Positive
* **ตรวจสอบเหตุการณ์ (Incident Investigation):** เจาะลึกขอบเขตของการรั่วไหล (เช่น "IP ที่ถูกบุกรุกนี้ไปคุยกับ EC2 เครื่องไหนอีกบ้าง?")
* **การล่าภัยคุกคาม (Threat Hunting):** ค้นหาภัยคุกคามที่ซ่อนอยู่หรือรูปแบบที่ผิดปกติใน Log เชิงรุก

---

## ค่าบริการ (Pricing)
* **คิดตามปริมาณข้อมูล:** จ่ายตามจำนวนกิกะไบต์ (GB) ของข้อมูล Log ที่นำเข้า (VPC Flow Logs, CloudTrail, EKS Logs)
* **ราคาแบบขั้นบันได:** ยิ่งปริมาณข้อมูลมาก ราคาต่อ GB จะยิ่งถูกลง
* **ทดลองใช้ฟรี:** บัญชีใหม่ทดลองใช้งานได้ฟรี **30 วัน**
* **ไม่มีค่าซ้ำซ้อน:** คุณจ่ายเพียงค่าธรรมเนียมการนำข้อมูลเข้า Detective เท่านั้น ไม่ต้องเสียค่าเปิด Log (เช่น VPC Flow Logs) แยกต่างหากเพื่อใช้กับบริการนี้
