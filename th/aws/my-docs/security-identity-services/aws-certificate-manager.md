# AWS Certificate Manager (ACM) Cheat Sheet

**AWS Certificate Manager (ACM)** เป็นบริการที่ช่วยให้คุณจัดหา (Provision), จัดการ และติดตั้งใช้งานใบรับรอง SSL/TLS ทั้งแบบสาธารณะ (Public) และแบบส่วนตัว (Private) เพื่อใช้กับบริการของ AWS โดยจะช่วยขจัดขั้นตอนที่ต้องทำด้วยมือ เช่น การสั่งซื้อ, การอัปโหลด และการต่ออายุใบรับรอง

* **Public Certificates (ฟรี):** สำหรับเว็บไซต์ที่เข้าถึงผ่านอินเทอร์เน็ตสาธารณะ (เช่น `www.example.com`) ซึ่งเบราว์เซอร์ส่วนใหญ่จะเชื่อถือโดยค่าเริ่มต้น
* **Private Certificates (มีค่าใช้จ่าย):** สำหรับทรัพยากรภายใน (เช่น ฐานข้อมูล, ภายใน API) ภายใต้เครือข่ายส่วนตัว
* **การต่ออายุอัตโนมัติ (Auto-Renewal):** ACM จะต่ออายุใบรับรองให้โดยอัตโนมัติหากใบรับรองนั้นถูกใช้งานอยู่กับบริการของ AWS ที่กำหนดค่าไว้อย่างถูกต้อง

---

## คุณสมบัติเด่น (Features)
* **การนำเข้าซ้ำ (Certificate Re-Import):** อนุญาตให้นำใบรับรองกลับมานำเข้าใหม่ภายใต้ ARN เดิมได้
* **ECDSA & Key Algorithm:** รองรับอัลกอริทึม ECDSA สำหรับใบรับรองสาธารณะ และรองรับ RSA/EC เพิ่มเติมเมื่อนำเข้าใบรับรองเอง
* **IAM Condition Key:** รองรับการใช้เงื่อนไขในนโยบาย IAM เมื่อมีการขอใบรับรอง เพื่อการควบคุมสิทธิ์ที่ละเอียดขึ้น
* **การจัดการระดับองค์กร:** รองรับการใช้ Private CA ข้ามบัญชี (Cross-account) ภายในองค์กร
* **การตรวจสอบและ Log:** มีมาตรวัด CloudWatch และเหตุการณ์ EventBridge สำหรับการหมดอายุและการต่ออายุ

---

## บริการที่ทำงานร่วมกัน (Integrated Services)
ใบรับรองของ ACM สามารถติดตั้งได้เฉพาะกับบริการที่กำหนดเท่านั้น **ไม่สามารถติดตั้งบน EC2 ตัวเดียวได้โดยตรง** (ต้องใช้ร่วมกับ Load Balancer หรือ CloudFront)
* Elastic Load Balancing (ALB, NLB)
* Amazon CloudFront
* Amazon API Gateway
* AWS Elastic Beanstalk / CloudFormation / Nitro Enclaves

> **"กฎของ CloudFront" (หัวข้อสำคัญสำหรับการสอบ):**
> หากต้องการใช้ใบรับรอง ACM กับ **Amazon CloudFront** คุณ **ต้อง** ขอหรือนำเข้าใบรับรองในภูมิภาค **US East (N. Virginia) `us-east-1` เท่านั้น** เนื่องจาก CloudFront เป็นบริการระดับโลกและจัดการใบรับรองจากศูนย์กลางที่นั่น

---

## ตรรกะการต่ออายุ (Renewal Logic)
* **ใบรับรองที่ออกโดย Amazon (Public):** **ต่ออายุอัตโนมัติ** โดย AWS จะดำเนินการให้ 60 วันก่อนหมดอายุ (หากยังถูกใช้งานอยู่)
* **ใบรับรองที่นำเข้าเอง (Imported):** **ต้องต่ออายุเอง (Manual)** โดยคุณเป็นผู้รับผิดชอบในการตรวจสอบวันหมดอายุและนำเข้าเวอร์ชันใหม่เข้าระบบ
* **AWS Private CA:** **ต่ออายุอัตโนมัติ** โดย ACM จะจัดการให้หากใช้งานร่วมกับบริการที่รองรับ

---

## แนวคิดสำคัญ (Concepts)
* **ระยะเวลาใช้งาน:** ใบรับรองสาธารณะของ ACM มีอายุ **13 เดือน (395 วัน)** และไม่สามารถแก้ไขได้
* **ความปลอดภัยของ Private Key:** * แบบ Public: คุณ **ไม่สามารถ** ดาวน์โหลด Private Key ออกมาได้ AWS จะจัดการเก็บรักษาภายใน
    * แบบ Private: หากส่งออก (Export) จาก Private CA คุณ **สามารถ** เข้าถึง Private Key ได้
* **การแก้ไขโดเมน:** คุณไม่สามารถเพิ่มหรือลดชื่อโดเมนจากใบรับรองที่มีอยู่ได้ **ต้องขอใบรับรองใหม่เท่านั้น**
* **กฎการลบ:** คุณไม่สามารถลบใบรับรองที่ **กำลังถูกใช้งานอยู่** ได้ ต้องถอดการเชื่อมต่อออกจากทรัพยากรนั้นก่อน

---

## วิธีการตรวจสอบความเป็นเจ้าของโดเมน (Domain Validation)
1. **DNS Validation (แนะนำ):** ACM จะให้ระเบียบ CNAME เพื่อไปใส่ใน DNS (Route 53 หรือที่อื่น) ช่วยให้ระบบ **ต่ออายุอัตโนมัติได้ตลอดไป** ตราบใดที่ระเบียบนั้นยังอยู่
2. **Email Validation:** ส่งอีเมลไปยังผู้ดูแลโดเมน (WHOIS) เพื่อให้คลิกลิงก์ยืนยัน (กำลังถูกลดความสำคัญลงและแทนที่ด้วย DNS)
3. **HTTP Validation:** ใช้ได้เฉพาะกับใบรับรองที่ออกเพื่อใช้งานกับ **Amazon CloudFront** เท่านั้น

## ค่าบริการ (Pricing)
* **Public SSL/TLS:** **ฟรี** (จ่ายเฉพาะค่าทรัพยากรที่นำใบรับรองไปเกาะ เช่น ค่า Load Balancer)
* **AWS Private CA:** **มีค่าใช้จ่าย**
    * ค่าธรรมเนียมรายเดือนต่อ CA: ประมาณ $400 (โหมดทั่วไป) หรือ $50 (โหมดอายุสั้น)
    * ค่าธรรมเนียมต่อใบรับรอง: คิดตามสัดส่วนการใช้งาน (เริ่มที่ประมาณ $0.75 ต่อใบ)
* **Imported Certificates:** **ฟรี** ทั้งการนำเข้าและการจัดการ
