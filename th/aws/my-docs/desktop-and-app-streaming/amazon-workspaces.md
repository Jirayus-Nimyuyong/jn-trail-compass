# Amazon WorkSpaces Cheat Sheet

**Amazon WorkSpaces** เป็นบริการเดสก์ท็อปบนคลาวด์ (Cloud Desktop) ที่มีความปลอดภัยและได้รับการจัดการแบบเต็มรูปแบบ (Fully-managed)

### คุณสมบัติเด่น (Features)
* **การจัดการตัวตน:** คุณสามารถสร้าง Directory แยกต่างหากเพื่อจัดการผู้ใช้ หรือเชื่อมต่อกับ **Microsoft Active Directory** เดิมที่มีอยู่เพื่อให้ผู้ใช้เข้าถึงทรัพยากรขององค์กรได้ทันทีด้วยรหัสผ่านเดิม
* **เดสก์ท็อปถาวร (Persistent Desktop):** ให้ประสบการณ์การใช้งานเดสก์ท็อปที่เก็บข้อมูลและการตั้งค่าไว้ตลอด
* **Bundles (ชุดรวม):** มีตัวเลือกฮาร์ดแวร์และซอฟต์แวร์ที่หลากหลายให้เลือกตามความต้องการใช้งาน
* **Bring Your Own License (BYOL):** คุณสามารถนำสิทธิ์การใช้งาน (License) Windows 7 หรือ Windows 10 ที่มีอยู่เดิมมาใช้บน Amazon WorkSpaces ได้
* **ความปลอดภัยและมาตรฐาน:** รองรับมาตรฐานความปลอดภัยระดับสากล เช่น **HIPAA-eligibility, SOC, FedRAMP และ PCI**
* **การจัดเก็บข้อมูล:** ผู้ใช้จะได้รับพื้นที่เก็บข้อมูล (SSD) ตาม Bundle ที่เลือก โดยข้อมูลใน 'User Volume' จะถูกสำรองข้อมูลไปยัง S3 โดยอัตโนมัติอย่างสม่ำเสมอ
* **เทคโนโลยีการสตรีม:** ใช้เทคโนโลยี **PC-over-IP (PCoIP)** เพื่อความปลอดภัยในการส่งภาพหน้าจอ
* **การจัดการแอปพลิเคชัน:** ใช้ **Amazon WorkSpaces Application Manager** เพื่อติดตั้งและจัดการแอปพลิเคชันภายในเครื่อง
* **การสำรองข้อมูล:** User Volume จะถูกสำรองข้อมูลทุกๆ 12 ชั่วโมง
* **การปรับขนาดพื้นที่:** เมื่อเปิดใช้งานแล้ว **ไม่สามารถลดขนาดพื้นที่ (Volume)** ได้ แต่สามารถกดเพิ่มขนาดพื้นที่ได้ตลอดเวลา

---

### โปรโตคอลการสตรีม (WorkSpaces Streaming Protocol - WSP)
* เป็นโปรโตคอลยุคใหม่ (ทางเลือกนอกเหนือจาก PCoIP) 
* ให้ความทนทานต่อเครือข่ายที่ดีกว่า รองรับการเปลี่ยนเส้นทางเว็บแคม (Webcam redirection) และเพิ่มประสิทธิภาพบนเครือข่ายที่ไม่เสถียร

### ส่วนขยายและการใช้งานอื่นๆ
* **Web Access:** เข้าใช้งานผ่านเบราว์เซอร์สมัยใหม่ได้โดยไม่ต้องติดตั้งโปรแกรม Client (รองรับ Chrome, Edge, Firefox, Safari)
* **Multi-Region Resilience:** สามารถคัดลอก Image และใช้ Directory เดียวกันข้ามภูมิภาค (Region) เพื่อทำระบบสำรองข้อมูล (Disaster Recovery)
* **Cost Optimizer:** โซลูชันอัตโนมัติที่จะตรวจจับ WorkSpaces ที่มีการใช้งานต่ำ และสลับโหมดการคิดเงินระหว่างรายชั่วโมงและรายเดือนเพื่อลดค่าใช้จ่าย
* **อุปกรณ์ที่รองรับ:** Chromebooks, iPads, Fire tablets, Windows, macOS, Linux

---

### ความแตกต่างระหว่าง Rebuild และ Restore
* **Rebuild (สร้างใหม่):** สร้าง Root Volume (ไดรฟ์ระบบ) ใหม่ทั้งหมด แต่ยังคงเก็บข้อมูลใน User Volume (ไดรฟ์ผู้ใช้) ไว้เหมือนเดิม
* **Restore (คืนค่า):** คืนค่าทั้ง Root Volume และ User Volume กลับไปที่ Snapshot (จุดสำรองข้อมูล) ล่าสุด

---

### ค่าบริการ (Pricing)
คิดค่าบริการตามประเภทของ Bundle และจำนวนเครื่องที่คุณเปิดใช้งาน โดยมี 2 รูปแบบหลัก:
1. **แบบรายเดือน (Monthly billing):** จ่ายค่าธรรมเนียมรายเดือนคงที่สำหรับการใช้งานแบบไม่จำกัด เหมาะสำหรับผู้ที่ใช้งานเป็นหลักเต็มเวลา
2. **แบบรายชั่วโมง (Hourly billing):** จ่ายค่าธรรมเนียมรายเดือนราคาถูก (เพื่อรักษาพื้นที่เก็บข้อมูล) และจ่ายค่าบริการเพิ่มตามจำนวนชั่วโมงที่ใช้งานจริงในเดือนนั้นๆ
