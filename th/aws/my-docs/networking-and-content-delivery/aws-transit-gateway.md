# AWS Transit Gateway Cheat Sheet

**AWS Transit Gateway** เป็นบริการด้านเครือข่ายที่ใช้โมเดลแบบ **Hub and Spoke** (ศูนย์กลางและซี่ล้อ) เพื่อช่วยให้ลูกค้าสามารถเชื่อมต่อศูนย์ข้อมูล On-premises และ Amazon VPC หลายๆ แห่งเข้าด้วยกันผ่านเกตเวย์เพียงตัวเดียว

* ด้วยบริการนี้ ลูกค้าเพียงแค่สร้างและจัดการการเชื่อมต่อเดียวจากเกตเวย์กลางไปยังแต่ละศูนย์ข้อมูล, สำนักงานสาขา หรือ VPC ในเครือข่ายของคุณ
* หากมีการสร้าง VPC ใหม่ คุณเพียงแค่เชื่อมต่อ (Attach) มันเข้ากับ Transit Gateway ก็จะสามารถสื่อสารกับเครือข่ายอื่นๆ ที่เชื่อมต่ออยู่ได้ทันที (ขึ้นอยู่กับกฎในตารางเส้นทาง)



---

## คุณสมบัติเด่น (Features)

### 1. การทำ Inter-region Peering (การเชื่อมต่อข้ามภูมิภาค)
* ใช้เครือข่ายทั่วโลกของ AWS เพื่อเราต์ทราฟฟิกข้ามภูมิภาค (Regions)
* เป็นวิธีที่ง่ายและคุ้มค่าในการทำสำเนาข้อมูลเพื่อสำรองข้อมูลตามภูมิศาสตร์ (Geographic redundancy) หรือแชร์ทรัพยากรข้ามภูมิภาค
* รองรับการเชื่อมต่อ Peering ภายในภูมิภาคเดียวกันด้วย เพื่อขยายการเชื่อมต่อระหว่าง Transit Gateway หลายตัว

### 2. Multicast (การส่งข้อมูลแบบกลุ่ม)
* ช่วยให้ควบคุมผู้รับและผู้ส่งทราฟฟิก Multicast ได้อย่างละเอียด
* สร้างและจัดการกลุ่ม Multicast บนคลาวด์ได้โดยไม่ต้องติดตั้งหรือดูแลฮาร์ดแวร์แบบดั้งเดิมในศูนย์ข้อมูล

### 3. Transit Gateway Connect (การรวมกับ SD-WAN)
* เชื่อมต่ออุปกรณ์ SD-WAN และอุปกรณ์เสมือน (Virtual Appliances) จากภายนอกที่รันใน VPC เข้ากับ AWS ได้โดยตรง
* ใช้โปรโตคอล **GRE (Generic Routing Encapsulation)** แทน IPsec VPN ซึ่งให้แบนด์วิดท์ที่สูงกว่าและประสิทธิภาพดีกว่า

### 4. AWS Transit Gateway Network Manager
* แดชบอร์ดกลางสำหรับแสดงภาพและตรวจสอบเครือข่ายทั่วโลกทั้งบน AWS และ On-premises
* มีระบบ **Route Analyzer** เพื่อวิเคราะห์และแก้ไขปัญหาเส้นทางการเราต์ระหว่างทรัพยากร

### 5. การควบคุมเส้นทางและนโยบาย (Routing and Policy Control)
* รองรับ Policy Tables สำหรับการเราต์แบบไดนามิกและการแลกเปลี่ยนข้อมูลเส้นทางระหว่างเกตเวย์ที่เชื่อมต่อกันอัตโนมัติ
* รองรับการอ้างถึง **Prefix List** ในตารางเส้นทาง เพื่อลดความยุ่งยากในการจัดการเส้นทางจำนวนมาก

### 6. มาตรวัดขั้นสูงและ Flow Logs
* รองรับ **CloudWatch metrics** สำหรับแต่ละจุดเชื่อมต่อ (Attachment) เพื่อการตรวจสอบและแก้ไขปัญหาที่ละเอียดถึงระดับ Availability Zone
* รองรับ **Transit Gateway Flow Logs** เพื่อบันทึกและวิเคราะห์ทราฟฟิกเครือข่าย

### 7. Appliance Mode (โหมดอุปกรณ์เครือข่าย)
* รับประกันว่าทราฟฟิกทั้งไปและกลับ (Bidirectional) จะวิ่งผ่าน Availability Zone เดียวกัน 
* ช่วยให้การทำงานของ Firewall หรือระบบตรวจจับการบุกรุก (IDS) มีความแม่นยำและประสิทธิภาพสูงขึ้น

### 8. ความปลอดภัยและการเข้ารหัส
* รองรับการเข้ารหัสข้อมูลขณะรับ-ส่ง (Encryption in transit) ข้ามจุดเชื่อมต่อต่างๆ
* รองรับการอ้างอิง **Security Group ข้าม VPC** ที่เชื่อมต่อกับ Transit Gateway ช่วยให้จัดการนโยบายความปลอดภัยแบบรวมศูนย์ได้ง่ายขึ้น
* รองรับ **Traffic Mirroring** เพื่อคัดลอกทราฟฟิกส่งไปยังอุปกรณ์ความปลอดภัยเพื่อตรวจสอบภัยคุกคาม

## ค่าบริการ (Pricing)
* **ค่าจุดเชื่อมต่อ (Attachment):** คิดค่าบริการรายชั่วโมงสำหรับแต่ละจุดที่เชื่อมต่อ (VPC, VPN หรือ Connect attachment)
* **ค่าประมวลผลข้อมูล (Data Processing):** คิดค่าบริการตามปริมาณข้อมูล (GB) ที่ประมวลผลผ่าน Transit Gateway
* **ค่าถ่ายโอนข้อมูล (Data Transfer):** คิดค่าบริการโอนย้ายข้อมูลมาตรฐานของ AWS สำหรับทราฟฟิกที่ออกจาก AWS
