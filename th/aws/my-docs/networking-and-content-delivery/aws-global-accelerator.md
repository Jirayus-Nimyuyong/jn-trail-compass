# AWS Global Accelerator Cheat Sheet

**AWS Global Accelerator** เป็นบริการที่ใช้เครือข่ายทั่วโลกของ AWS (AWS Global Network) เพื่อปรับปรุงความพร้อมใช้งาน (Availability) และประสิทธิภาพ (Performance) ของแอปพลิเคชันสำหรับผู้ใช้ทั้งในระดับท้องถิ่นและทั่วโลก

* ให้บริการ **Static IP addresses** ที่ทำหน้าที่เป็นจุดเข้าใช้งานคงที่ (Fixed entry point) ไปยังเอนด์พอยต์ของแอปพลิเคชันในภูมิภาค AWS เดียวหรือหลายภูมิภาค เช่น Application Load Balancers (ALB), Network Load Balancers (NLB) หรืออินสแตนซ์ Amazon EC2
* รองรับการกำหนดค่าแบบ **Dual-Stack** โดยให้ที่อยู่ Static IPv4 จำนวน 2 ชุด และ (เป็นตัวเลือกเสริม) Static IPv6 จำนวน 2 ชุด เพื่อรองรับทราฟฟิกทั้งสองประเภท
* ตรวจสอบสถานะ (Health) ของเอนด์พอยต์อย่างต่อเนื่อง และจะตรวจพบเอนด์พอยต์ที่ไม่สมบูรณ์พร้อมเปลี่ยนเส้นทางทราฟฟิกไปยังเอนด์พอยต์ที่ปกติภายในเวลาไม่ถึง 1 นาที

---

## แนวคิดหลัก (Concepts)
* **Accelerator:** ทรัพยากรที่คุณสร้างขึ้นเพื่อส่งทราฟฟิกไปยังเอนด์พอยต์ที่เหมาะสมที่สุดผ่านเครือข่ายทั่วโลกของ AWS
* **Network zones:** หน่วยที่แยกจากกันโดยมีโครงสร้างพื้นฐานทางกายภาพและชุด IP บริการของตัวเองจาก IP Subnet ที่ไม่ซ้ำกัน
* **Static IP addresses:** AWS Global Accelerator จะให้ IP แบบคงที่ 2 ชุดที่กระจายแบบ Anycast จากเครือข่าย Edge ของ AWS และจะกำหนดชื่อ DNS พื้นฐานมาให้ด้วย (เช่น `a1234567890.awsglobalaccelerator.com`)
* **Listener:** ทำหน้าที่ประมวลผลการเชื่อมต่อขาเข้าจากไคลเอนต์ตามพอร์ตและโปรโตคอล (TCP หรือ UDP) ที่กำหนด
* **Endpoint group:** เชื่อมโยงกับภูมิภาค AWS (Region) เฉพาะแห่ง ประกอบด้วยเอนด์พอยต์ตั้งแต่หนึ่งตัวขึ้นไปในภูมิภาคนั้น
* **Endpoints:** สามารถเป็น NLB, ALB, EC2 หรือ Elastic IP addresses

---

## ประเภทของ Accelerator
1. **Standard Accelerators:** เราต์ทราฟฟิกไปยังเอนด์พอยต์ที่สมบูรณ์และใกล้ที่สุดโดยอิงจากประสิทธิภาพ เหมาะสำหรับเว็บแอปพลิเคชัน, API และการทำ Multi-region failover
2. **Custom Routing Accelerators:** เราต์ทราฟฟิกไปยังอินสแตนซ์ EC2 และพอร์ตที่เฉพาะเจาะจงอย่างแม่นยำ เหมาะสำหรับเกมมัลติเพลเยอร์, VoIP และการจำลองแบบเรียลไทม์ที่ต้องการเชื่อมต่อผู้เล่นเฉพาะคนเข้ากับเซิร์ฟเวอร์เฉพาะเครื่อง

## ประโยชน์ของ AWS Global Accelerator
* **การทำ Regional Failover ทันที:** ตรวจสอบสถานะและเปลี่ยนเส้นทางไปยังเอนด์พอยต์อื่นที่พร้อมใช้งานได้ทันทีเมื่อสถานะเปลี่ยนหรือมีการอัปเดตการตั้งค่า
* **ความพร้อมใช้งานสูง (High Availability):** มีการออกแบบให้แยกส่วนความเสียหาย (Fault-isolating) โดยให้ Static IP 2 ชุดที่ทำงานบน Network Zone ที่เป็นอิสระต่อกัน
* **ลดปัญหาการแคช IP ของไคลเอนต์:** คุณไม่ต้องพึ่งพาการตั้งค่า IP Caching ของอุปกรณ์ฝั่งไคลเอนต์ การแพร่กระจายการตั้งค่าใหม่ (Propagation) ใช้เวลาเพียงไม่กี่วินาที
* **ประสิทธิภาพที่เพิ่มขึ้น:** รับทราฟฟิกจาก Edge Location ที่ใกล้ที่สุดและวิ่งผ่านเครือข่าย AWS Global Network ซึ่งช่วยลดความหน่วง (Latency) และเพิ่มความเร็วในการรับส่งข้อมูล
* **TCP Termination at the Edge:** สร้างการเชื่อมต่อ TCP กับ Edge Location ที่ใกล้ที่สุดก่อน แล้วค่อยเชื่อมต่อไปยังเอนด์พอยต์ ช่วยลดเวลาในการทำ TCP Handshake และเพิ่มทรูพุต (Throughput)
* **การจัดการที่ง่าย:** IP แบบคงที่ช่วยให้คุณย้ายเอนด์พอยต์ข้าม AZ หรือข้ามภูมิภาคได้โดยไม่ต้องอัปเดต DNS หรือแอปพลิเคชันฝั่งไคลเอนต์
* **การควบคุมที่ละเอียด:** สามารถตั้งค่า **Traffic Dial** เพื่อปรับเพิ่ม/ลดทราฟฟิกในระดับภูมิภาค (เช่น สำหรับ Blue/Green Deployment) และกำหนด **Weights** (น้ำหนัก) ให้กับเอนด์พอยต์รายตัวได้
* **Client IP Address Preservation:** ช่วยให้แอปพลิเคชันหลังบ้านมองเห็น IP จริงของไคลเอนต์แทนที่จะเห็น IP ของ Global Accelerator

## ขั้นตอนการติดตั้ง (Deployment Steps)
1. สร้าง Accelerator
2. กำหนดค่า Endpoint Groups
3. ลงทะเบียน Endpoints (รองรับ **Cross-Account Endpoints** หรือการดึงทรัพยากรจากบัญชี AWS อื่นมาใส่ใน Accelerator เดียวกัน)

## การเปรียบเทียบ: Global Accelerator vs CloudFront
| คุณสมบัติ | Global Accelerator | CloudFront |
| :--- | :--- | :--- |
| **เครือข่าย** | ใช้ AWS Global Network | ใช้ AWS Global Network |
| **การแคช** | **ไม่มีการแคชข้อมูล** | **เน้นการแคชข้อมูล (Caching)** |
| **โปรโตคอล** | TCP / UDP | HTTP / HTTPS / WebSocket |
| **ที่อยู่ IP** | Static Anycast IP (2 ชุด) | Dynamic IP (ใช้ DNS) |
| **กรณีใช้งาน** | แอปที่ไม่ใช่ HTTP, การสลับภูมิภาค (Failover), Gaming, VoIP | เว็บไซต์ Static/Dynamic, การสตรีมวิดีโอ |

---

## ความปลอดภัย (Security)
* ปฏิบัติตามมาตรฐาน SOC, PCI, HIPAA, GDPR และ ISO
* เปิดใช้งาน **AWS Shield Standard** อัตโนมัติเพื่อป้องกัน DDoS
* มีระบบ **Flow Logs** เพื่อบันทึกรายละเอียดทราฟฟิกที่วิ่งผ่าน

## ค่าบริการ (Pricing)
* **ค่าธรรมเนียมคงที่ (Fixed Fee):** $0.025 ต่อชั่วโมง (หรือเศษของชั่วโมง) ไม่ว่าจะเปิดหรือปิดการใช้งาน
* **Data Transfer-Premium (DT-Premium):** คิดตามปริมาณข้อมูล (GB) ที่ถ่ายโอนผ่านเครือข่าย AWS
* **ทิศทางหลัก (Dominant Direction):** คุณจะถูกเก็บเงินเฉพาะทิศทางที่มีปริมาณทราฟฟิกสูงกว่าเท่านั้น (ขาเข้า vs ขาออก)
* **Cross-Account:** ไม่มีค่าธรรมเนียมเพิ่มเติมในการใช้เอนด์พอยต์จากบัญชีอื่น แต่คิดค่าโอนย้ายข้อมูลตามปกติ
