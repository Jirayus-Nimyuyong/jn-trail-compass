# AWS CloudTrail Cheat Sheet

กิจกรรมที่ดำเนินการโดยผู้ใช้ (User), บทบาท (Role) หรือบริการของ AWS ใน **AWS Management Console, AWS CLI, SDKs และ APIs** จะถูกบันทึกไว้ในรูปแบบของ **เหตุการณ์ (Events)**

* CloudTrail จะถูกเปิดใช้งานโดยอัตโนมัติเมื่อคุณสร้างบัญชี AWS
* CloudTrail เน้นไปที่การตรวจสอบ (Auditing) กิจกรรมของ API
* สามารถดูเหตุการณ์ย้อนหลังได้ใน **Event History** ซึ่งคุณสามารถค้นหาและดาวน์โหลดกิจกรรมย้อนหลังได้ 90 วัน
* **CloudTrail Lake:** ช่วยให้คุณรวมไฟล์ (Aggregate), จัดเก็บแบบแก้ไขไม่ได้ (Immutable) และคิวรีข้อมูล Log กิจกรรมของคุณได้
* **CloudTrail Insights:** ช่วยระบุพฤติกรรมที่ผิดปกติในบัญชี เช่น การจัดสรรทรัพยากรที่พุ่งสูงขึ้นอย่างรวดเร็ว หรือการเรียกใช้ IAM ที่ผิดปกติ

---

### คุณสมบัติเด่น (Features)
* **Network activity events:** รองรับการบันทึกเหตุการณ์กิจกรรมทางเครือข่ายสำหรับบริการเพิ่มเติม เช่น Lambda, Comprehend และ IoT FleetWise
* **Advanced event selectors:** บันทึก Data Events สำหรับบริการต่างๆ มากขึ้น เช่น Bedrock, SageMaker AI, Aurora และ Q
* **CloudTrail Lake dashboards:** รองรับแดชบอร์ดแบบกำหนดเอง และวิดเจ็ตสูงสุด 10 อันต่อแดชบอร์ด
* **การเข้ารหัสด้วย KMS:** อนุญาตให้เข้ารหัสทั้งไฟล์ Log และไฟล์ Digest โดยใช้คีย์ AWS KMS เพื่อความปลอดภัยขั้นสูง
* **Resource-based policies:** รองรับการกำหนดนโยบายบน CloudTrail Lake เพื่อการคิวรีข้ามบัญชี

---

### Trails (เส้นทางบันทึก)
สร้าง **CloudTrail trail** เพื่อจัดเก็บ วิเคราะห์ และตอบสนองต่อการเปลี่ยนแปลงของทรัพยากร

**ประเภทของ Trail:**
1.  **ทุกภูมิภาค (All Regions):** บันทึกเหตุการณ์ในทุก Region และส่งไฟล์ไปยัง S3 Bucket เดียวกัน (เป็นค่าเริ่มต้นเมื่อสร้างผ่าน Console)
2.  **ภูมิภาคเดียว (One Region):** บันทึกเฉพาะเหตุการณ์ใน Region ที่ระบุเท่านั้น (เป็นค่าเริ่มต้นเมื่อสร้างผ่าน CLI หรือ API)
3.  **Organization Trail:** บันทึกเหตุการณ์ของทุกบัญชีภายใต้ AWS Organizations (ต้องสร้างจากบัญชีหลักหรือ Management Account)

---

### ประเภทของเหตุการณ์ (Events)

* **Management Events (ควบคุม):** บันทึกการดำเนินการด้านการจัดการทรัพยากร (Control Plane) เช่น การสร้าง User หรือการสร้างเครื่อง EC2 (**เปิดใช้งานเป็นค่าเริ่มต้น**)
* **Data Events (ข้อมูล):** บันทึกการดำเนินการภายในทรัพยากร (Data Plane) เช่น การอ่าน/เขียนไฟล์ใน S3 หรือการเรียกใช้งาน Lambda (**ไม่ได้เปิดใช้งานเริ่มต้น**)
* **Insights Events (ข้อมูลเชิงลึก):** ตรวจจับและบันทึกกิจกรรมที่ผิดปกติซึ่งต่างจากพฤติกรรมการใช้งานปกติของบัญชี (**ไม่ได้เปิดใช้งานเริ่มต้น**)

---

### การตรวจสอบและการติดตาม (Monitoring)
* ใช้ **CloudWatch Logs** เพื่อตรวจสอบข้อมูลและตั้งค่า Alarm ตาม Metric Filters ที่กำหนด
* ใช้ **Log file integrity validation** เพื่อตรวจสอบว่าไฟล์ Log ถูกแก้ไขหรือลบหลังจากที่ CloudTrail ส่งมอบแล้วหรือไม่

---

### ค่าบริการ (Pricing)
* การส่งมอบ **Management Events ชุดแรก** ในแต่ละภูมิภาคคือ **ฟรี** (หากสร้างชุดที่สองจะมีการคิดเงิน)
* **Data Events** จะถูกคิดค่าบริการตามปริมาณเหตุการณ์ที่บันทึก
* มีค่าใช้จ่ายในการจัดเก็บข้อมูลบน **Amazon S3** ตามปกติ

---

### ข้อจำกัดที่สำคัญ (Limits - เพิ่มไม่ได้)
* **Trails ต่อภูมิภาค:** สูงสุด 5 Trails
* **Event data stores (CloudTrail Lake):** 5 แห่งต่อภูมิภาค
* **Get, Describe, List APIs:** 10 รายการต่อวินาที (TPS)
* **LookupEvents API:** 2 รายการต่อวินาที (TPS)
