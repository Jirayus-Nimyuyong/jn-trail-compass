# AWS CloudShell Cheat Sheet

เทอร์มินัลที่คุณสามารถเข้าถึงได้โดยตรงจาก AWS Management Console เพื่อโต้ตอบกับทรัพยากร AWS ของคุณ โดยไม่ต้องติดตั้งซอฟต์แวร์ใดๆ บนเครื่องคอมพิวเตอร์ส่วนตัว

* **ตัวแปลคำสั่ง (Interpreters) ที่รองรับ:**
    * Bash (bash)
    * PowerShell (pwsh)
    * Z shell (zsh)
* **สภาพแวดล้อมการประมวลผล (Compute Environment):**
    * รันบน Amazon Linux 2023 (อัปเดตจาก Amazon Linux 2)
    * 1 vCPU
    * 2 GiB RAM
    * พื้นที่จัดเก็บข้อมูลถาวร 1 GB

---

### คุณสมบัติเด่น (Features)
* **การกำหนดค่าเริ่มต้น:** สภาพแวดล้อมถูกกำหนดค่าไว้ล่วงหน้าพร้อมเครื่องมือ (Tools), ยูทิลิตี้, รันไทม์ และ AWS SDKs ต่างๆ
* **พื้นที่จัดเก็บข้อมูล:**
    * **ถาวร (Persistent Storage):** ให้พื้นที่ 1 GB ใน Home Directory ของแต่ละภูมิภาค (Region) เพื่อบันทึกสคริปต์และการตั้งค่าที่ใช้บ่อย
    * **ชั่วคราว (Temporary Storage):** ข้อมูลนอก Home Directory จะถูกลบทิ้งเมื่อสิ้นสุดเซสชัน
* **การจัดการเซสชัน:**
    * เซสชันที่ไม่มีการเคลื่อนไหวหรือรันค้างไว้นานเกินไปจะถูกปิดโดยอัตโนมัติ
    * ใช้ **tmux** เพื่อกู้คืนเซสชันข้ามแท็บเบราว์เซอร์
* **การถ่ายโอนไฟล์:** สามารถอัปโหลดหรือดาวน์โหลดไฟล์ระหว่างเครื่องโลคอลและ CloudShell ผ่าน Amazon S3 หรือไฟล์ Zip
* **การปรับแต่ง:** สามารถปรับเลย์เอาต์ของแท็บ, ขนาดตัวอักษร, ธีมสี (สว่าง/มืด) และเปิด/ปิดฟีเจอร์ Safe Paste
* **การรองรับเพิ่มเติม:** * รองรับ **Docker** ภายใน CloudShell (ในภูมิภาคที่รองรับ)
    * รองรับ **Amazon Q CLI** (เครื่องมือใหม่)
    * รองรับ **VPC** เพื่อเปิดใช้งาน CloudShell ภายในเครือข่ายส่วนตัว

---

### ความปลอดภัย (Security)
* **การยืนยันตัวตน:** ใช้ข้อมูลประจำตัวเดียวกับผู้ใช้ที่ล็อกอินเข้า AWS Management Console ช่วยลดความยุ่งยากในการจัดการสิทธิ์
* **การควบคุมสิทธิ์:** ใช้ **IAM Policies** เพื่ออนุญาตหรือปฏิเสธการเข้าถึง AWS CloudShell ของผู้ใช้
* **Safe Paste:** เปิดใช้งานเป็นค่าเริ่มต้นเพื่อตรวจสอบว่าข้อความหลายบรรทัดที่วางลงไปไม่มีสคริปต์ที่เป็นอันตราย (Malicious scripts) แฝงอยู่
