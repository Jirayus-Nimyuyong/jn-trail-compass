# Amazon Managed Grafana คืออะไร?

**Amazon Managed Grafana** เป็นบริการแสดงผลข้อมูล (Data Visualization) สำหรับการคิวรี (Query), การหาความสัมพันธ์ (Correlate) และการสร้างภาพข้อมูลจากตัวชี้วัด (Metrics), บันทึก (Logs) และร่องรอยการทำงาน (Traces) จากหลายแหล่งข้อมูล

* สร้างแดชบอร์ดและภาพข้อมูลเพื่อวิเคราะห์ Metrics, Logs และ Traces ได้โดยไม่ต้องสร้าง แพ็กเกจ หรือติดตั้งเซิร์ฟเวอร์ Grafana เอง
* AWS จะเป็นผู้จัดการดูแลทั้งในส่วนของการติดตั้ง (Deployment), การตั้งค่า, การปรับขนาด (Scaling) และการบำรุงรักษาเซิร์ฟเวอร์ Grafana ทั้งหมด
* **ทำงานร่วมกับแหล่งข้อมูลของ AWS ดังต่อไปนี้:**
    * Amazon CloudWatch
    * Amazon OpenSearch Service
    * AWS X-Ray
    * Amazon Timestream
    * Amazon Managed Service for Prometheus

## ส่วนประกอบของ Amazon Managed Grafana

### 1. Workspaces (พื้นที่ทำงาน)
* คือเซิร์ฟเวอร์ Grafana ที่ถูกแยกส่วนการทำงานในเชิงตรรกะ (Logically isolated)
* **วิธีการยืนยันตัวตนผู้ใช้:** ผ่าน SAML 2.0 หรือ AWS IAM Identity Center
* แต่ละภูมิภาค (Region) สามารถมีได้สูงสุด 5 Workspaces
* รองรับ Grafana HTTP APIs
* คุณสามารถสร้างสิทธิ์และนโยบายเพื่อจัดการแหล่งข้อมูล (Data sources) และช่องทางการแจ้งเตือนของ Workspace ได้
* **เมื่อลบ Workspace สิ่งต่อไปนี้จะถูกลบไปด้วย:** แดชบอร์ด, การตั้งค่าแหล่งข้อมูล, การแจ้งเตือน (Alerts) และภาพถ่ายข้อมูล (Snapshots)
* ผู้ใช้สามารถมีบทบาทได้เพียง 1 ใน 3 อย่างนี้เท่านั้น: **Admin, Editor หรือ Viewer**

### 2. Teams (ทีม)
* ช่วยให้คุณมอบสิทธิ์ให้กับกลุ่มผู้ใช้หลายคนพร้อมกัน
* ใช้ระบบ **Team Sync** เพื่อซิงโครไนซ์สมาชิกในทีมระหว่าง Grafana Workspace และผู้ให้บริการยืนยันตัวตน (Authorization Provider) โดยอัตโนมัติ

### 3. Data Sources (แหล่งข้อมูล)
* สามารถรวมข้อมูลจากแหล่งข้อมูลที่หลากหลายมาไว้ในแดชบอร์ดเดียวได้
* **TestDB:** แหล่งข้อมูลในตัวสำหรับสร้างข้อมูลสุ่ม (Random walk data) เพื่อการทดสอบ
* **Mixed:** อนุญาตให้คิวรีข้อมูลจากหลายแหล่งพร้อมกันใน Panel เดียว
* **Dashboard:** ดึงชุดผลลัพธ์จาก Panel อื่นในแดชบอร์ดเดียวกันมาใช้งาน

### 4. Panel (แผงควบคุม)
* คือการแสดงผลเชิงภาพของผลลัพธ์จากการคิวรีตั้งแต่หนึ่งรายการขึ้นไป
* **Transformations:** ช่วยในการเปลี่ยนชื่อฟิลด์, รวมอนุกรมเวลา (Time series) ที่แยกกันเข้าด้วยกัน และทำการคำนวณทางคณิตศาสตร์ข้ามคิวรีได้
* **Library Panels:** สร้างแผงควบคุมที่สามารถนำกลับมาใช้ใหม่ได้ในหลายแดชบอร์ด

### 5. Dashboard (แดชบอร์ด)
* ประกอบด้วยหนึ่ง Panel หรือมากกว่า และจัดเรียงเป็นแถว (Rows)
* **Annotations:** ใช้สำหรับแสดงข้อมูลเหตุการณ์ (Event data) ข้ามหลายๆ Panel
* **Folders:** ใช้สำหรับจัดระเบียบและกลุ่มแดชบอร์ด
* **Playlist:** ชุดของแดชบอร์ดที่แสดงผลตามลำดับที่กำหนด
* **Explore:** โหมดที่ตัดตัวเลือกแดชบอร์ดและ Panel ออกเพื่อให้คุณมีสมาธิกับการคิวรีข้อมูลเพียงอย่างเดียว

## ความปลอดภัยของ Amazon Managed Grafana
* จัดการการตั้งค่าแหล่งข้อมูลและสิทธิ์สำหรับหลายบัญชี AWS ได้จากส่วนกลางผ่าน **AWS Organizations**
* ใช้ **CloudFormation StackSets** ในการสร้าง IAM Roles โดยอัตโนมัติเพื่อเชื่อมต่อกับแหล่งข้อมูล
* คุณต้องสร้าง **API Key** สำหรับการยืนยันตัวตนหากต้องการใช้ Grafana APIs ภายใน Workspace

## ค่าบริการ (Pricing)
* คิดค่าบริการตาม **จำนวนผู้ใช้งานที่แอคทีฟ (Active user license)** ต่อหนึ่ง Workspace
* **Grafana Editor license:** คิดตามจำนวน Editor หรือ Administrator ที่ใช้งานจริง
* **Grafana Viewer license:** คิดตามจำนวน Viewer ที่ใช้งานจริง
* **Grafana API user license:** คิดตามจำนวน API user ที่ใช้งานจริง
