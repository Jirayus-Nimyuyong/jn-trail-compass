# AWS Trusted Advisor Cheat Sheet

**Trusted Advisor** จะวิเคราะห์สภาพแวดล้อม AWS ของคุณและให้คำแนะนำตามแนวทางปฏิบัติที่ดีที่สุด (Best Practices) ใน 5 หมวดหมู่:
1.  **การเพิ่มประสิทธิภาพด้านต้นทุน (Cost Optimization)**
2.  **ประสิทธิภาพ (Performance)**
3.  **ความปลอดภัย (Security)**
4.  **ความทนทานต่อความเสียหาย (Fault Tolerance)**
5.  **ขีดจำกัดของบริการ (Service Limits)**

* คำแนะนำในส่วน Service Limits จะสอดคล้องกับ **AWS Service Quotas** เพื่อใช้ติดตามและจัดการขีดจำกัดของทรัพยากร
* การเข้าถึงชุดการตรวจสอบ (Checks) แบบเต็มรูปแบบ จะมีให้สำหรับผู้ที่ใช้แผนสนับสนุนระดับ **Business, Enterprise On-Ramp และ Enterprise Support** เท่านั้น

---

### แนวคิดสำคัญ (Concepts)

* **Organizational View:** ต้องใช้งานร่วมกับ AWS Organizations และมีแผนสนับสนุนที่รองรับ เพื่อดูภาพรวมของทุกบัญชีสมาชิก
* **AWS Support API:** ให้คุณเข้าถึงฟีเจอร์ของ Support Center ผ่านโปรแกรมได้ (Endpoint: `https://support.us-east-1.amazonaws.com`)
* **การเข้าถึงตามแผน Support:**
    * **Basic และ Developer:** เข้าถึงได้เฉพาะการตรวจสอบความปลอดภัยหลัก (Core security) และขีดจำกัดของบริการ (Service limits) ผ่านคอนโซล
    * **Business ขึ้นไป:** เข้าถึงการตรวจสอบทั้งหมดได้ผ่าน Console, API และ CLI

#### สถานะการตรวจสอบบนหน้าแดชบอร์ด
* **สีแดง (Action recommended):** แนะนำให้ดำเนินการแก้ไขทันที
* **สีเหลือง (Investigation recommended):** ตรวจพบปัญหาที่อาจเกิดขึ้น ควรตรวจสอบเพิ่มเติม
* **สีเขียว (No problems detected):** ไม่พบปัญหา
* **สีเทา (Excluded items):** ทรัพยากรที่คุณเลือกละเว้นจากการตรวจสอบ

---

### การวิเคราะห์และรายงานขั้นสูง
คุณสามารถสร้างรายงานสำหรับทุกบัญชีในองค์กรและนำข้อมูลมาสร้างภาพข้อมูล (Visualization) โดยใช้บริการต่อไปนี้:
* **Amazon S3:** เก็บไฟล์รายงาน `resources.json`
* **AWS CloudFormation:** ใช้เทมเพลตสร้างทรัพยากรเพื่อดึงข้อมูลจาก S3
* **Amazon Athena:** ใช้คิวรีข้อมูลรายงานใน S3
* **Amazon QuickSight:** สร้างแดชบอร์ดเพื่อดูผลลัพธ์ของรายงาน

---

### Trusted Advisor Priority
ทีมดูแลบัญชี AWS (AWS Account Team) สามารถใช้ฟีเจอร์นี้เพื่อเฝ้าสังเกตบัญชีของคุณในเชิงรุก และให้คำแนะนำตามลำดับความสำคัญ โดยแหล่งข้อมูลมาจาก:
* **บริการของ AWS:** Trusted Advisor, Security Hub และ Well-Architected ที่สร้างคำแนะนำโดยอัตโนมัติ
* **ทีมดูแลบัญชี:** สร้างคำแนะนำด้วยตนเองเมื่อพบความเสี่ยงในบัญชีของคุณ

---

### ความปลอดภัยและการตรวจสอบ (Security & Monitoring)
* **IAM:** กำหนดสิทธิ์ให้ผู้ใช้หรือบทบาทเข้าถึง Organizational View ของ Trusted Advisor
* **AWS Security Hub:** เมื่อเชื่อมต่อกัน สถานะการตรวจสอบด้านความปลอดภัยจะไปปรากฏเป็น Findings ใน Security Hub เพื่อให้แก้ไขได้ง่ายขึ้น
* **Amazon EventBridge:** ตรวจจับเมื่อสถานะการตรวจสอบมีการเปลี่ยนแปลง และสั่งให้ดำเนินการตามกฎที่ตั้งไว้
* **Amazon CloudWatch:** สร้างการแจ้งเตือน (Alarms) เพื่อตรวจจับการเปลี่ยนแปลงของ Metrics
* **AWS CloudTrail:** บันทึกประวัติการเรียกใช้ API และกิจกรรมบนคอนโซล

---

### ค่าบริการ (Pricing)
* แผนสนับสนุนระดับ **Basic** จะรวมอยู่ในบัญชีของคุณโดยไม่มีค่าใช้จ่ายเพิ่มเติม (ฟรี)
* คุณจะจ่ายค่าบริการก็ต่อเมื่อสมัครแผน **Developer, Business, Enterprise On-Ramp หรือ Enterprise Support** เท่านั้น
