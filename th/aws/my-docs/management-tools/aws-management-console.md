# AWS Management Console Cheat Sheet

### Resource Groups (กลุ่มทรัพยากร)
คือการรวบรวมทรัพยากร AWS ที่อยู่ใน **ภูมิภาค (Region) เดียวกัน** และมีคุณสมบัติตรงตามเงื่อนไขที่กำหนดไว้ในคำสั่งคิวรี (Query)
* Resource Groups ช่วยให้การจัดการและสั่งงานอัตโนมัติกับทรัพยากรจำนวนมากพร้อมกันทำได้ง่ายขึ้น
* **ประเภทของคิวรี** ที่ใช้สร้างกลุ่มมี 2 แบบ:
    * อ้างอิงตาม **Tag (แถบป้าย)**
    * อ้างอิงตาม **AWS CloudFormation stack**

### Tag Editor (ตัวแก้ไขแถบป้าย)
Tags คือคำหรือวลีที่ทำหน้าที่เป็นข้อมูลเมทาดาตา (Metadata) เพื่อใช้ระบุและจัดระเบียบทรัพยากร AWS ของคุณ
* ขีดจำกัดของจำนวน Tag จะแตกต่างกันไปตามประเภททรัพยากร แต่ส่วนใหญ่สามารถมีได้สูงสุด **50 Tags**
* คุณสามารถเรียงลำดับและกรองผลลัพธ์จากการค้นหา Tag เพื่อหา Tag และทรัพยากรที่คุณต้องการทำงานด้วยได้

### คุณสมบัติของ AWS Management Console
* **การนำทางบริการแบบรวมศูนย์ (Unified service navigation):** ให้การเข้าถึงบริการ AWS จากจุดเดียวผ่านแถบนำทางด้านบน พร้อมช่องค้นหาบริการและรายการบริการที่เพิ่งใช้งานล่าสุด
* **ตัวเลือกภูมิภาค (Region selector):** ช่วยให้คุณสลับไปมาระหว่างภูมิภาคต่างๆ ของ AWS เพื่อจัดการทรัพยากรที่จำกัดขอบเขตตามภูมิภาค
* **การสลับบัญชีและบทบาท (Account and role switching):** รองรับการสลับระหว่าง IAM Roles และบัญชี AWS ต่างๆ ได้โดยตรงจากหน้าคอนโซล
* **การค้นหาทั่วโลก (Global search):** สามารถค้นหาบริการของ AWS, คุณสมบัติต่างๆ และเอกสารคู่มือได้โดยตรงจากหน้าอินเทอร์เฟซของคอนโซล
* **แดชบอร์ดประจำบริการ (Service dashboards):** บริการ AWS หลายอย่างมีแดชบอร์ดในตัวสำหรับตรวจสอบการใช้งาน, สถานะความพร้อมใช้งาน (Health) และสถานะการตั้งค่า
* **การเชื่อมต่อกับ CloudShell:** สามารถเปิดใช้งาน AWS CloudShell ได้โดยตรงจากคอนโซลเพื่อรันคำสั่ง AWS CLI โดยไม่ต้องติดตั้งโปรแกรมในเครื่อง
* **การแจ้งเตือนบนคอนโซล (Console notifications):** แสดงการแจ้งเตือน (Alerts), ประกาศสำคัญ และการแจ้งเตือนสถานะความพร้อมใช้งานของบริการที่เกี่ยวข้องกับบัญชีของคุณ
* **การปรับแต่งและการตั้งค่า (Customization and preferences):** ผู้ใช้สามารถปรับแต่งภาษา, ธีม (Theme) และการตั้งค่าภูมิภาคที่ต้องการภายในคอนโซลได้
