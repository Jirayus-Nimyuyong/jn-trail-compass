# AWS License Manager Cheat Sheet

**AWS License Manager** เป็นบริการสำหรับจัดการใบอนุญาตซอฟต์แวร์ (License) จากส่วนกลาง ทั้งในสภาพแวดล้อมบน AWS และ On-premises

* ช่วยให้คุณควบคุมและมองเห็นการใช้งาน License เพื่อจำกัดการใช้งานเกินจำนวนที่กำหนด และลดความเสี่ยงจากการไม่ปฏิบัติตามข้อกำหนด (Noncompliance) หรือการรายงานที่ผิดพลาด
* **รองรับรูปแบบ License ที่หลากหลาย:**
    * **Perpetual:** ใบอนุญาตตลอดชีพ ไม่มีวันหมดอายุ
    * **Floating:** ใบอนุญาตแบบแชร์การใช้งานร่วมกันได้
    * **Subscription:** ใบอนุญาตแบบสมัครสมาชิกที่มีวันหมดอายุ
    * **Usage-based:** ใบอนุญาตตามเงื่อนไขการใช้งานจริง

---

## แนวคิดสำคัญ (Concepts)

### 1. License Configurations (การตั้งค่าใบอนุญาต)
* ประกอบด้วยกฎการใช้งานตามข้อตกลงขององค์กร โดยระบบจะกำหนดพารามิเตอร์และกฎตามค่าที่ระบุ
* กฎเหล่านี้จะเป็นตัวกำหนดว่า AWS จะจัดการกับคำสั่งที่ต้องใช้ License อย่างไร
* สามารถใช้ **AWS RAM** เพื่อแชร์การตั้งค่า License ระหว่างบัญชีได้
* หากปิดการใช้งาน (Deactivated) ทรัพยากรเดิมที่ใช้อยู่จะไม่ได้รับผลกระทบ แต่ระบบจะไม่ติดตามการใช้งานให้อีกต่อไป

### 2. License Reports (รายงานใบอนุญาต)
* สามารถตั้งเวลาบันทึก Snapshot การใช้งานเป็นระยะเพื่อติดตามประวัติ
* รายงานจะถูกส่งไปยัง S3 Bucket โดยตรง แบ่งเป็น:
    * **License configuration report:** รายละเอียดจำนวน License ที่ถูกใช้ไป
    * **Resource report:** รายละเอียดทรัพยากรที่ถูกติดตามและการบริโภค License

### 3. License Type Conversion (การเปลี่ยนประเภทใบอนุญาต)
* คุณสามารถเปลี่ยนประเภท License ได้โดยไม่ต้องติดตั้งเวิร์กโหลดใหม่:
    * จาก License ที่ AWS จัดหาให้ เป็นแบบนำมาเอง (BYOL - Bring Your Own License)
* สามารถเปลี่ยน Tenancy ของอินสแตนซ์ผ่าน CLI ได้ทั้งแบบ Shared, Dedicated Instance, Dedicated Host หรือ Host Resource Groups

## คุณสมบัติและการทำงาน
* **การจัดซื้อ:** ซื้อ License ได้จาก AWS Marketplace, AWS Data Exchange หรือซื้อโดยตรงจากผู้ขายผ่าน Managed Entitlements
* **สิทธิ์การใช้งาน (Entitlements):** รายละเอียดความสามารถของ License จะถูกจัดเก็บในรูปแบบ Entitlements
* **User-based Subscriptions:** รองรับการซื้อ License ของ Microsoft Visual Studio แบบคิดค่าธรรมเนียมรายผู้ใช้
* **ผู้ดูแลระบบ (Administrator):** บัญชีสมาชิกในองค์กรสามารถได้รับมอบหมายเป็นผู้ดูแลระบบได้เพียง 1 บัญชีต่อองค์กร
* **การบังคับใช้อัตโนมัติ:** ระบบสามารถระงับการเปิดใช้งานทรัพยากร (Resource Launch) หากการใช้งานนั้นจะทำให้เกินจำนวน License ที่กำหนดไว้

## การตรวจสอบและการรักษาความปลอดภัย (Monitoring & Security)
* **ทรัพยากรที่ติดตามได้:** EC2 (ทุกรูปแบบ), Managed Instances ใน Systems Manager, RDS Oracle (BYOL), และซอฟต์แวร์ BYOL จาก Marketplace
* **AWS CloudTrail:** บันทึกการเรียกใช้ API และกิจกรรมบนคอนโซลของ License Manager
* **การกระจายสิทธิ์:** ส่งมอบ License ผ่าน IAM Identity หรือใช้ **Digitally signed tokens** ที่สร้างโดยระบบ
* **AWS KMS:** ใช้ API Sign และ Verify ของ KMS เพื่อลงนามและตรวจสอบความถูกต้องของใบอนุญาต
* **VPC Endpoint:** รองรับการสร้าง Interface VPC Endpoint เพื่อเชื่อมต่อกับบริการแบบส่วนตัว
