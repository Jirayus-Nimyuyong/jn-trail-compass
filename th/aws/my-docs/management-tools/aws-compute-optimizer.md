# AWS Compute Optimizer Cheat Sheet

**AWS Compute Optimizer** เป็นบริการที่ให้คำแนะนำในการเลือกใช้ทรัพยากร AWS ที่เหมาะสมที่สุดเพื่อลดค่าใช้จ่ายและเพิ่มประสิทธิภาพให้กับเวิร์กโหลดของคุณ

* ใช้การเรียนรู้ของเครื่อง (Machine Learning) เพื่อวิเคราะห์ข้อมูลสถิติการใช้งานย้อนหลัง
* สามารถดูผลการวิเคราะห์และคำแนะนำครอบคลุมทุกภูมิภาค (Regions) และทุกบัญชี AWS
* **ให้คำแนะนำสำหรับทรัพยากรดังต่อไปนี้:**
    * Amazon EC2 instances
    * Amazon EC2 Auto Scaling groups
    * Amazon EBS volumes
    * AWS Lambda functions

---

## คุณสมบัติเด่น (Features)
* **คำแนะนำอินสแตนซ์ EC2 รุ่นใหม่:** รองรับอินสแตนซ์รุ่นล่าสุด เช่น C8gn, I8ge, M8i, R8i และอื่นๆ
* **การขยายขอบเขต Auto Scaling group:** รองรับกลุ่มที่ใช้อินสแตนซ์ประเภท G หรือ P, แบบผสมประเภท (Mixed), และกลุ่มที่สเกลลดลงเหลือเพียงอินสแตนซ์เดียว
* **คำแนะนำ Aurora I/O-Optimized:** ให้คำแนะนำสำหรับการจัดเก็บข้อมูลของ Aurora DB cluster
* **RDS Rightsizing:** รองรับ Aurora MySQL/PostgreSQL และ Amazon RDS MySQL/PostgreSQL
* **โหมดประมาณการส่วนลด (Savings estimation mode):** นำ Savings Plans และ Reserved Instances มาคำนวณร่วมด้วยเมื่อประมาณการค่าใช้จ่ายที่ประหยัดได้
* **การนำเข้า Metrics จากภายนอก:** สามารถนำเข้าข้อมูลการใช้ Memory ของ EC2 จากเครื่องมือตรวจสอบอื่นๆ ภายนอกเพื่อให้คำแนะนำที่แม่นยำยิ่งขึ้น
* **คำแนะนำด้านไลเซนส์:** ให้ข้อมูลเชิงลึกสำหรับไลเซนส์ Microsoft SQL Server ที่รันบน EC2
* **รองรับ ECS on Fargate:** ให้คำแนะนำในการปรับขนาด (Rightsizing) สำหรับบริการ ECS ที่รันบน Fargate

## แนวคิดหลัก (Concepts)

### การตั้งค่าคำแนะนำ (Recommendation preferences)
คุณสามารถเปิดใช้งานฟีเจอร์เหล่านี้เพื่อเพิ่มประสิทธิภาพของคำแนะนำ:
* **Enhanced infrastructure metrics:** ขยายระยะเวลาการวิเคราะห์ข้อมูลการใช้งานย้อนหลังไปถึง 3 เดือน
* **Inferred workload type:** ระบุความยากง่ายในการย้ายเวิร์กโหลดจาก x86 ไปยัง AWS Graviton (Arm-based)
* **Graviton-based recommendations:** แสดงผลกระทบด้านราคาและประสิทธิภาพหากเปลี่ยนไปใช้ Graviton

### ผู้ดูแลระบบที่ได้รับมอบหมาย (Delegated Administrator)
คุณสามารถตั้งค่าบัญชีสมาชิกในองค์กรให้เป็นผู้ดูแลระบบได้
* กำหนดได้เพียง **1 บัญชีต่อหนึ่งองค์กร**
* **ผู้ดูแลระบบสามารถทำสิ่งต่อไปนี้ได้:**
    * เรียกดูและส่งออก (Export) คำแนะนำ
    * ดูข้อมูลพยากรณ์การใช้งาน (Projected utilization metrics)
    * ตั้งค่าความชอบในคำแนะนำ (Recommendation preferences)
    * จัดการสถานะการเข้าร่วม (Opt-in) ของบัญชีสมาชิก

## แดชบอร์ดและการส่งออกข้อมูล
* แดชบอร์ดช่วยให้คุณดูผลการเพิ่มประสิทธิภาพของทรัพยากรได้ทั่วทุกภูมิภาค
* สามารถส่งออกคำแนะนำไปยัง Amazon S3 bucket เพื่อแชร์ข้อมูลได้

* คิดค่าบริการตามจำนวนชั่วโมงที่ทรัพยากรนั้นทำงาน
