# AWS Health Cheat Sheet

**AWS Health** ให้ข้อมูลเชิงลึกเกี่ยวกับสถานะของทรัพยากร บริการ และบัญชี AWS ของคุณอย่างต่อเนื่อง
* บริการนี้จะส่งการแจ้งเตือน (Alerts) และประกาศต่างๆ ที่เกิดจากการเปลี่ยนแปลงสถานะความพร้อมใช้งาน (Health) ของทรัพยากร AWS
* **AWS Health Dashboard** ทำงานผ่าน AWS Health API และพร้อมใช้งานสำหรับลูกค้าทุกคน
* แดชบอร์ดนี้ไม่จำเป็นต้องมีการตั้งค่าใดๆ และพร้อมใช้งานทันทีสำหรับผู้ใช้ AWS ที่ยืนยันตัวตนแล้ว

### การจัดกลุ่มปัญหาบนแดชบอร์ด
AWS Health Dashboard จัดกลุ่มปัญหาออกเป็น 3 กลุ่ม:
1.  **ปัญหาที่กำลังเกิดขึ้นและปัญหาล่าสุด (Open and recent issues):** จำกัดเฉพาะปัญหาที่มีเวลาเริ่มต้นภายใน 7 วันที่ผ่านมา
2.  **การเปลี่ยนแปลงที่กำหนดไว้ (Scheduled changes):** ประกอบด้วยรายการที่กำลังดำเนินอยู่หรือกำลังจะเกิดขึ้นในอนาคต
3.  **การแจ้งเตือนอื่นๆ (Other notifications):** จำกัดเฉพาะประกาศที่มีเวลาเริ่มต้นภายใน 7 วันที่ผ่านมา

### การใช้งานในระดับองค์กร
* คุณสามารถรวบรวมเหตุการณ์ AWS Health จากทุกบัญชีใน **AWS Organization** ของคุณไว้ที่ส่วนกลางได้
* **AWS Health Organizational View** ช่วยให้เข้าถึงเหตุการณ์ AWS Health ทั้งหมดที่โพสต์ไปยังแต่ละบัญชีในองค์กรได้แบบเรียลไทม์และจากส่วนกลาง รวมถึงปัญหาด้านการดำเนินงาน, การบำรุงรักษาที่กำหนดไว้ และการแจ้งเตือนระดับบัญชี
* คุณสามารถสร้างกฎ **Amazon EventBridge** เพื่อตรวจจับและตอบสนองต่อเหตุการณ์ของ AWS Health ได้โดยอัตโนมัติ

### คุณสมบัติของ AWS Health (AWS Health Features)

* **ขยายขอบเขตการครอบคลุมเหตุการณ์:** เพิ่มประเภทเหตุการณ์ในบริการของ AWS มากขึ้น รวมถึงปัญหาการดำเนินงาน, การแจ้งเตือนเฉพาะบัญชี และเหตุการณ์วงจรชีวิตทรัพยากรที่กำหนดไว้
* **การควบคุม Organizational View ที่ดีขึ้น:** อนุญาตให้ผู้ดูแลระบบที่ได้รับมอบหมาย (Delegated Administrators) สามารถดูและจัดการเหตุการณ์ AWS Health ของทุกบัญชีสมาชิกในองค์กรได้จากส่วนกลาง
* **การเชื่อมต่อกับ EventBridge ที่มีประสิทธิภาพยิ่งขึ้น:** เหตุการณ์ AWS Health สามารถสั่งให้ Workflow ทำงานอัตโนมัติผ่าน Amazon EventBridge เพื่อทำการแก้ไข (Remediation), ส่งการแจ้งเตือน หรือเชื่อมกับระบบจัดการตั๋ว (Ticketing systems)
* **เหตุการณ์เฉพาะบัญชี (Account-specific):** ให้ข้อมูลเหตุการณ์ที่ปรับตามการใช้งานจริงในบัญชีของคุณเท่านั้น แทนที่จะเป็นการแจ้งเตือนระดับบริการทั่วโลกแบบกว้างๆ
* **การเข้าถึงผ่าน API:** คุณสามารถคิวรี กรอง และดึงข้อมูลเหตุการณ์ Health ผ่านโปรแกรม เพื่อนำไปผสานรวมกับเครื่องมือตรวจสอบ (Monitoring) และเครื่องมือจัดการอุบัติการณ์ (Incident management) ของคุณเอง
